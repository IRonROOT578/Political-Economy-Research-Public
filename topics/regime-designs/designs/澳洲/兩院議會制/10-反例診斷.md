# 反例診斷

| 現況路徑 | 本夾怎麼斷 |
|---|---|
| 即時決選讓第一偏好領先者落選 | 眾議院單一改 top-4 孔多賽 |
| 新南威爾斯只寫「1」在聯邦變非正式 | 第一輪單記就是正式票；第二輪只排 4 人 |
| 參議院整案不通過供給，總督解職 | 參議院不表決供給；20 個開會日在眾議院生效；總督不能解職 |
| 雙重解散把選舉時機交給總理 | 無解散。參議院對普通法律只有 60 日擱置，不需要解散它 |
| 每州 12 席，小州的票較重 | 參議院 120 席按人口的十區 |
| 2013 年團體投票票讓 0.51% 當選參議員 | 參議院改彈性名單、聖拉古，無百分比門檻 |
| 執政黨以一般多數改選制 | 選制入憲。眾議院兩道 3/5 再加參議院 3/5，然後公投，且不適用於下一次大選 |
| 高等法院由內閣建議任命 | 三組。乙組由參議院選，60 日順位就任 |
| 參議院變成第二個眾議院 | 參議院沒有單一選區，不能信任，不能擋供給 |

**模型自己的反例**：距離假設把第一偏好 ≥20% 的獨立放在工黨與自由黨之間。2025 年眾議院單一因此給獨立 7 席。見 [`12`](12-預期政治生態.md)。這不是法律上的 20% 門檻。
