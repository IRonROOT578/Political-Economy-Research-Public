## 2 規則

### 2.1 某些議員 ＝ 全院 180

`0-基本` 只說「某些議員」。本夾定為**全院 180，門檻 ≥91**。

| 選項 | 在保加利亞的後果（[`12`](12-預期政治生態.md)、[`14`](14-近期大選重算.md)） |
|---|---|
| 只限單一席次 100（**不採用**） | top-3 孔多賽讓**一個位居兩條軸中間的政黨**拿下幾乎全部單一席次。以 2024-10 的得票重算，ITN 單一 44、GERB 34，兩黨合計 78／100 **就能掌握政府與錢**；兩黨總得票只有 32% |
| **全院 180** | 同樣以 2024-10 重算，ITN 51、GERB 55，**都不過半**，要找夥伴才能組閣 |

★ 這不是說單一席次的放大不好——它正是讓中間政黨贏的機制。**但在一個病根是「一黨收編國家」的國家，掌政府的那張表不該是被放大得最兇的那張表。**

★ 代價：在一黨浪潮下（2026-04 那種 44%），全院也擋不住——那時它本來就有正當的多數。全院門檻只在**分裂**時起作用，而保加利亞 2021–2025 年正是分裂。

**信任供給合一**：選首長、更新首長、表決供給的都是同一批 180 人。

### 2.2 選出：記名排名投票，多輪篩選

新屆集會後 **30 日內**：

| 項目 | 規則 |
|---|---|
| 投票權人 | 全院 180 |
| 候選 | 任何議員 20 人連署提名者（不必是議員） |
| 票面 | 排名，可截斷、可並排；「維持空缺」是票面上的一個選項 |
| 公開 | **記名** |
| 方法 | 孔多賽完成法（Ranked Pairs） |
| 多輪 | 每輪篩掉排名後三分之一，**輪間 72 小時供協商** |
| 當選 | 最後一輪的勝者，且投票的議員中，把他排在「維持空缺」之上者多於之下者（缺席、不投者視為棄權） |

★ **缺席、不投者視為棄權**（`1-優化/行政立法/議會制.md` 可選）：首長**產生**時不設總額過半門檻，只比投票的議員中「排在『維持空缺』之上」與「之下」的人數；以缺席、不投杯葛組閣不再有效。**建設性更新**（換掉現任）仍須過總額半數。

★ 記名在保加利亞特別要緊：**選民要能看到「他的議員把 DPS–新開端的人排在第幾」**。現行制度下的祕密談判與「技術政府」，都是讓議員不必為支持誰負責。

### 2.3 30 日期限：沒有看守內閣

**30 日內未選出**：由**最後一輪的孔多賽第一名**逕行就任，任期照常。

| | 現行（第 99 條） | **本夾** |
|---|---|---|
| 組閣失敗的後果 | 三次授權用完 → 看守內閣 → 解散重選 | **孔多賽第一名就任** |
| 誰承受失敗 | 全國（重選、無預算、看守內閣） | **拖延的議員**——拖到期滿等於把選擇交給票面算術 |
| 總統的角色 | 依序交付授權、從官員名單挑看守總理 | **無** |

**看守內閣這個制度被廢除。** 任何時刻都有一個由議員選出的首長在任：舊首長做到新首長就任為止（§3）。

### 2.4 更新：建設性更新

| 項目 | 規則 |
|---|---|
| 提案 | 議員 **30 人**連署，**須具名一位準人選** |
| 最高行政首長準人選 | 僅 1 名挑戰人選被提名時直接**決定出**為準人選；2 名以上時，先由**全院議員以記名排名投票（孔多賽完成法）選出**一位最高行政首長準人選（`1-優化/行政立法/議會制.md`） |
| 表決 | 準人選與現任兩兩對決，記名 |
| 通過 | 準人選獲 **≥91** |
| 通過後 | **立即就任** |
| 未通過 | 現任留任；同一準人選 6 個月內不得再提 |
| 冷卻 | 每位議員 6 個月內至多連署 2 次 |

**沒有純否定式不信任案。** 倒閣與換人是同一個動作，門檻相同（91）。

### 2.5 首長辭職與死亡

副首長代理，30 日內依 §2.2 選出新首長；逾期依 §2.3。

★ 2025-12 的形狀——政府在抗議中辭職，隨後看守內閣、解散、重選——在本夾變成：**首長辭職，議會 30 日內選出下一個，屆期不動。**抗議能換掉一個人，但不能逼出第 9 次大選。

### 2.6 無解散權

**首長、總統、議會都不能解散議會。**

1. 保加利亞的八次選舉**就是解散權造成的**——現行第 99 條把「組不成」直接接到「解散」。
2. 本夾有內部出口：91 票就能換首長，且沒有時間限制。
3. 解散權讓議員有「拖到重選」的選項；拿掉它之後，**唯一的選項是在 30 日內選一個人**。

代價：議會組成若與民意脫節，只能等 4 年屆滿或走議員更新（[`09`](09-人選更新.md)）。

### 2.7 政府組織

| 職位 | 產生 | 更新 |
|---|---|---|
| 行政首長（總理） | §2.2 | §2.4 |
| 副首長 | 首長提名、全院 ≥91 同意 | 隨首長 |
| 部長 | 首長任免 | 隨首長 |

部長得兼任議員。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆 30 日內未選出 | 孔多賽第一名就任 |
| 新屆選出前 | **上一屆的首長續任**，權限不受限（沒有「看守」的次級政府） |
| 兩件更新案同時提出 | 依連署完成先後；前案通過則後案須重新連署 |
| 首長被選區更新而喪失議員身分 | 首長職務不受影響 |
| 缺額 | 計入 180，門檻不降 |
