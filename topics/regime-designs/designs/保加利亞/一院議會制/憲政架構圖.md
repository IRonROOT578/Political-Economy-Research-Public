## 2 組閣：沒有看守內閣、沒有解散

```mermaid
flowchart LR
  E[新屆集會] --> R1[記名排名投票<br/>每輪篩掉後 1/3<br/>輪間 72 小時]
  R1 -->|勝者 ≥91 排在「維持空缺」之上| OK[就任]
  R1 -->|30 日屆滿| DEF[孔多賽第一名<br/>逕行就任]
  OK --> GOV[首長在任]
  DEF --> GOV
  GOV -->|30 人連署＋具名準人選<br/>對決 ≥91| NEW[準人選立即就任]
  NEW --> GOV
  GOV -.->|辭職或死亡| R1
```

## 3 錢

```mermaid
flowchart LR
  G[政府送供給案] --> W{20 個開會日內<br/>建設性更新 ≥91？}
  W -->|否| ON[供給生效]
  W -->|是| CH[新首長就任<br/>原案失效、重送]
  OTH[非供給行政歲出] -->|全院 ≥91，得刪不得增| OK2[議決]
  OTH -->|60 日未決| PREV[沿用上年度]
  REV[歲入、稅制] -->|全院 ≥91| TAX[議決]
  FR[財政規則：組織法] -.->|財政委員會公告| G
```

```mermaid
flowchart TB

  INI --> O1
```
