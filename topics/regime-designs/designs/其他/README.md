# 其他

對應表（本庫提示詞；其他名單含德／奧／丹等）寫作：

```
# 其他：…、紐西蘭、丹麥…
1. 一憲政設計: 1-優化
選一政體。
```

映射一律 `0-基本`＋`1-優化`，**不繼承任何 `2-配置/`**，政體由本主題選。對話中的額外指示寫在該夾 `00` 與 README。
