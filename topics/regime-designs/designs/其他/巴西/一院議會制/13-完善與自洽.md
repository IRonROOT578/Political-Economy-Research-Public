# 完善與自洽

## 1 條件的落點

| 條件 | 位階 | 落點 |
|---|---|---|
| 不用電子計票 | **硬性** | [`01`](01-國會與選制.md) §2.5：紙本、人工計票 |
| 首長由某些議員選出與更新 | **硬性** | [`02`](02-政府組成與建設性更新.md)：全院 513 |
| 法官不當記名投票的投票權人 | **硬性** | [`07`](07-司法權與檢察.md)：名冊投票與法官互選皆祕密；第一、二審審判法官不入名冊 |
| 開放名單黑金 | **硬性** | [`01`](01-國會與選制.md) §2.4：彈性名單、M≤16 |
| 人選不能被杯葛 | **硬性** | [`07`](07-司法權與檢察.md) §3：定日開議、60 日預設值；[`08`](08-聯邦、緊急狀態與軍方.md) §2：財政分配沉默算同意 |
| 不得把提示詞當預期生態 | **硬性** | [`12`](12-預期政治生態.md) §5：三處不合、四項設計因此改過 |
| 不著重條文、不論可行性 | **硬性** | 全夾；公投民意不列為政體理由 |
| 不用預提 | 使用者指示 | [`03`](03-預算與供給.md) §1 |
| 信任供給合一 | 非硬性 | 全院 513 |
| 建設性更新 | 非硬性 | [`02`](02-政府組成與建設性更新.md) §2.3 |
| 供給自動生效 | 非硬性 | [`03`](03-預算與供給.md) §2.2 |
| 決選與單輪同日 | 非硬性 | 單一第二輪與名單、州長同日 |
| 從中間向兩側 | 非硬性 | [`07`](07-司法權與檢察.md) §2.3 |
| 避免搖擺、二極化、停擺 | 非硬性 | 議會制；top-3；沿用條款 |
| 修憲兩軌 | 可選 | [`05`](05-憲法與修憲.md) §5 |

## 2 張力

| # | 張力 | 處置 |
|:--:|---|---|
| 1 | **向心 vs 恩庇**：孔多賽中位在巴西就是中間大團 | 不改選制，改它執政時拿得到的貨幣 |
| 2 | **代表 vs 二極化**：選民最在意的那條線在國會被壓扁 | 兩大陣營的代表留在名單層；改規則需要他們 |
| 3 | **聯邦 vs 一院**：州失去日常否決 | 只在改州本身時給州否決 |
| 4 | **憲法瘦身 vs 社會權**：退休金、支出下限移出憲法 | 組織法要兩邊都過半，一般多數改不動 |
| 5 | **人工計票 vs 規模**：約 47 萬個投票所 | 逐所公開、多黨計票員；開票時間換信任 |

## 3 自洽檢查

| 檢查 | 結果 |
|---|---|
| 是否存在「沒有政府」 | 否 |
| 是否存在「沒有預算」 | 否 |
| 議員能否不進政府就控制錢 | 否：修正案廢除 |
| 一群人能否單獨改規則 | 只有同時過全院 308 與複數 128 |
| 州能否用不表決擋財政分配 | 否：沉默算同意 |
| 一個法官能否暫停一部法律 | 否 |

## 4 本夾不宣稱能做到的事

- **不宣稱消滅恩庇政治**；只宣稱拿掉修正案、限縮部會與任命、公開協議。
- **不宣稱首長會是強勢領袖**；模型的首長是中間大團裡的協調者。
- **不宣稱模型的第一偏好是對的**：眾議員票高估中間大團，推估只修正了一部分。
- **不宣稱 513、[8,16]、24 部會、10% 是唯一解**。
- **完全不論轉型可行性**。
