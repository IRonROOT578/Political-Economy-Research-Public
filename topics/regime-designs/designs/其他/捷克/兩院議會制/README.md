# 捷克：兩院議會制

本憲政設計最新更新：2026-10-27

```
捷克：0-基本 ＋ 1-優化
選一政體。
```

提示詞見本庫政體設計提示詞。**不繼承任何 `2-配置/`**。

## 一句話

**保留兩院議會制**；眾議院 **200＝單一 110（top-3 孔多賽）＋複數 90（彈性名單、無法定門檻）**，參議院 81 席改 top-3 孔多賽、**決選和所有單輪投票同日**；總理由**眾議院全院記名排名投票**選出（≥101），**總統不任命、只公布**，部長由總理任免、總統 7 日內必須公布；**取消「任命後再信任投票」**，倒閣只能走**建設性更新**；無解散、固定選舉日；供給自動生效；**利益衝突由審計院依組織法認定**；新增有拘束力的一般公投（支持票地板 20%／25%，歐盟、北約可以公投）；憲法法院 15 人三組；新設司法委員會與檢察委員會，檢察總長 7 年不連任；公共媒體財源列組織法。

## 先講結論：捷克要改的不多

四套外國設計裡，捷克是最健康的一個：沒有反覆重選、沒有看守空轉、沒有選舉作廢、沒有預算危機。本夾**保留運作良好的部分**，只改兩類東西：

- **提示詞硬性要求的**：開放名單（偏好票）改成彈性名單。
- **近年真的出過事的**：總統任命的裁量（Rusnok、Agrofert、Turek、北約峰會）、沒有信任也能執政、5% 門檻浪費兩成選票、參議院決選低投票率、檢察總長可被政府撤換、緊急狀態的繞道、公共媒體財源。

## 三個最容易讀錯的地方

**一、新制放大的是 ANO。** ANO 在地緣軸上居中（不反歐盟、北約，但和主權派共享民粹立場），在多數選區是孔多賽贏家。2025 年以 34.5% 的得票拿下 103／200，**單獨過半，不需要 SPD 和 Motorists**（[`12`](12-預期政治生態.md) §3）。

**二、2021 年的結果會反過來。** 以 2021 年得票重算，ANO 也拿 103 席，**Babiš 續任，而不是 Fiala 組閣**。原因是現行 5% 門檻讓約兩成選票落空，新制讓孔多賽贏家過半（[`12`](12-預期政治生態.md) §5.2）。

**三、參議院會變。** 把決選搬到所有人都投票的那天，參議院會跟著眾議院的民意走，不再是反對黨的據點（2026 年現實是 ANO 0／27）。本夾接受這個代價（[`12`](12-預期政治生態.md) §5.3）。

## 本夾承認做不到的事

- **一個約 33% 的居中政黨可以單獨執政**；防線放在規則。
- **主權派在單一選區 0 席**，只剩比例層。
- **參議院的制衡力變弱**。
- **歐盟、北約可以公投**：約 206 萬支持票就能退出。
- **完全不論轉型可行性**。
