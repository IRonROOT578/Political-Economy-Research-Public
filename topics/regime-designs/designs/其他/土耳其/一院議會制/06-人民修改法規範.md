# 人民修改法規範

`1-優化/投票.md`（替代現狀方式）。

| 項目 | 規則 |
|---|---|
| 方式 | 替代現狀方式：領銜人方案、政府方案、維持現狀，3 方案 6 格單選 |
| 地板 | 法律 20%；組織法、修憲 25%（支持票／選舉人總額） |
| 發動 | 選舉人 2%（約 120 萬）；或內閣；或全院 ≥226 |
| 排除 | 年度供給、個案人事、赦免 |
| 效力 | 有拘束力；勝出之法律 2 年內議會以 ≥270 且複數 ≥108 才能修改 |
| 日期 | 一年兩個固定投票日，不得與大選同日以外另定 |

★ 土耳其現行只有修憲公投（1987、1988、2007、2010、2017）。本夾新增一般公投；發動權不只在議會，也在選舉人。
