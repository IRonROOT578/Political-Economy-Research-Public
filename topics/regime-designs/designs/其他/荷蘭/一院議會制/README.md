# 荷蘭：一院議會制

本憲政設計最新更新：2026-10-28

```
荷蘭：0-基本 ＋ 1-優化
選一政體。
```

提示詞見本庫政體設計提示詞。**不繼承任何 `2-配置/`**。

## 一句話

**廢參議院的一院議會制**：國會 **150＝單一 90（top-3 孔多賽）＋複數 60（彈性名單、5 區、M∈[8,16]、無法定門檻；躍升門檻沿用現行的額數 25%）**；首長由**全院記名排名投票**選出（≥76），**30 日內選不出由孔多賽第一名就任**，聯盟協議不再是就任條件；**建設性更新、無解散、廢看守內閣**；供給 20 個開會日未換人即生效；**廢憲法第 120 條，新設憲法法院** 9 人三組；組織法與修憲第二讀要**全院與複數席次各自**達標，修憲另加複決；恢復有拘束力的公投（替代現狀方式）；**國王保留但所有權力形式化**；市長、省長由議會選出；紙本人工計票維持。

## 三個最容易讀錯的地方

**一、新制下的首長是 CDA，不是最大黨。** 以 2025 得票重算，VVD 49、D66 34、CDA 33，但 CDA 是孔多賽贏家：VVD 的議員把它排在 D66 前，D66 的議員把它排在 VVD 前（[`12`](12-預期政治生態.md) §5.2）。

**二、PVV 從 26 席變 11 席。** 它在大部分選區進得了三人決選，但幾乎不是任何人的第二偏好。本夾不改選制，補上矯正型公投與「改規則要複數 3/5」（[`12`](12-預期政治生態.md) §5.1）。

**三、荷蘭的名單本來就是彈性名單。** 個人票達額數 25% 即躍升，正是本設計的規則；本夾只是把額數從全國改成每區。

## 本夾承認做不到的事

- **兩端政黨（PVV、GL-PvdA）在國會大幅縮小**：約三成選民的代表只剩 13%。
- **首長常是第三大黨**，立法要靠最大黨。
- **完全不論轉型可行性**。
