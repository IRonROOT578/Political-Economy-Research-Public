# 完善與自洽

## 1 條件的落點

| 條件 | 位階 | 落點 |
|---|---|---|
| 不用電子計票 | **硬性** | 人工公開唱票（維持） |
| 首長由某些議員選出與更新 | **硬性** | 全院 100 |
| 法官不當記名投票的投票權人 | **硬性** | 審判法官不入名冊 |
| 開放名單黑金 | **硬性** | 彈性名單（新加坡現行沒有名單制，新設時就避開） |
| 人選不能被杯葛 | **硬性** | [`07`](07-司法權與檢察.md) §5 |
| 不得把提示詞當預期生態 | **硬性** | [`12`](12-預期政治生態.md) §5.2：以使用者的「效率、不在意一黨獨大」檢查，五處處置 |
| 信任供給合一 | 非硬性 | 選首長、更新、供給都是全院 |
| 建設性更新、供給自動生效 | 非硬性 | [`02`](02-政府組成與建設性更新.md)、[`03`](03-預算與供給.md) |
| 決選與單輪同日 | 非硬性 | B 日：所有第二輪＋所有單輪投票 |
| 高政治性裁決從中間向兩側、不審思想 | 非硬性 | 憲法法院並行多數；內部安全法排除政治立場 |
| 適合該國 | 非硬性 | **使用者指示：李光耀式行政效率**。保留監護權、精英文官、CPIB、反跳槽；只改提示詞要求的和妨礙長期規劃的 |

## 2 張力

| # | 張力 | 處置 |
|:--:|---|---|
| 1 | **提示詞的選制 vs 集選區的效率理由**（團隊、市鎮理事會規模） | 相鄰單一選區合組市鎮理事會；非議員部長取代「部長帶新人」 |
| 2 | **廢集選區 vs 少數族群保障**：下限從 18 降到 11–13 | 名單規則；少數族群權利總統理事會；接受代價 |
| 3 | **提示詞的公投 vs 福利主義** | 連署 5%；排除財政、稅、安全、儲備金 |
| 4 | **提示詞的中間向外裁決 vs 不多設否決點** | 憲法法院限期、明顯違憲、可定失效期 |
| 5 | **並立制 vs 執政黨得票下滑後的效率**：PAP 45% 時是 WP 28 席的少數政府 | 供給自動生效、建設性更新保住行政；立法效率會掉，承認 |
| 6 | **固定選舉日 vs 危機應變**：2020 年式的疫情年也要照期 | 緊急狀態不得延長任期；選舉照辦 |

## 3 自洽檢查

| 檢查 | 結果 |
|---|---|
| 是否存在「沒有信任的政府」 | 否 |
| 是否存在「沒有預算」 | 否：供給自動生效、非供給沿用 |
| 總統能否卡組閣、卡一般立法 | 否；能卡的只有儲備金和列舉的人事 |
| 執政黨能否決定選舉日 | 否 |
| 執政黨能否單獨修憲 | **能**（得票約 57% 以上），一屆內；核心條款要複決。**本夾接受** |
| 新設機關有幾個 | 兩個：選舉委員會（取代選舉局）、憲法法院 |

## 4 本夾刻意不處理的事

| 事 | 為什麼 |
|---|---|
| 一黨獨大 | 使用者指示不在意 |
| 部長的誹謗訴訟、媒體所有權、POFMA、FICA | 不妨礙行政效率，也不在提示詞要求內 |
| 總檢察長兼公訴人、CPIB 隸屬 | 清廉與速度的來源 |
| 人民協會、CDC | 維持 |

## 5 本夾不宣稱能做到的事

- **不宣稱能讓新加坡更有效率。** 它只宣稱：提示詞要求的改動，都以**不降低效率**的方式放進去。
- **不宣稱少數族群的代表不會減少。**
- **不宣稱 2011 年陳清木當選比陳慶炎「更對」。** 那取決於是否接受孔多賽（[`14`](14-近期大選重算.md) §3）。
- **不宣稱模型的偏好位置是對的**；但結果對偏好位置不敏感（[`12`](12-預期政治生態.md) §5.1）。
- **完全不論轉型可行性。**
