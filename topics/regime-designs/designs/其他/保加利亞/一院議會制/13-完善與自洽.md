# 完善與自洽

`1-優化/總體.md` 非硬性：完善、自洽；適合該國的治理。

## 1 條件的落點

| 條件 | 位階 | 落點 |
|---|---|---|
| 不用電子計票 | **硬性** | [`01`](01-國民議會與選制.md) §2.6：公開唱票，不用投票機 |
| 首長由某些議員選出與更新 | **硬性** | [`02`](02-政府組成與建設性更新.md)：全院 180 |
| 法官不當記名投票的投票權人 | **硬性** | [`07`](07-司法權與檢察.md)：第一、二審審判法官不入名冊；名冊投票與法官互選皆祕密 |
| 開放名單黑金 | **硬性** | [`01`](01-國民議會與選制.md) §2.3：彈性名單 |
| 人選不能被杯葛 | **硬性** | [`07`](07-司法權與檢察.md) §2.4 |
| 不得把提示詞當預期生態 | **硬性** | [`12`](12-預期政治生態.md) §5：三處不合，四項設計因此改過 |
| 不著重條文修辭、不考慮可行性 | **硬性** | 全夾 |
| 信任供給合一 | 非硬性 | 選首長、更新、供給都是全院 180 |
| 建設性更新 | 非硬性 | [`02`](02-政府組成與建設性更新.md) §2.4 |
| 供給自動生效 | 非硬性 | [`03`](03-預算與供給.md) §2.2 |
| 決選與單輪同日 | 非硬性 | 單一席次第二輪與名單同日；總統決選盡量與他票同日 |
| 高政治性裁決從中間向兩側 | 非硬性 | [`07`](07-司法權與檢察.md) §2.2：≥8／12＋三組各 ≥2 |
| 避免搖擺、二極化、停擺 | 非硬性 | top-3 孔多賽；組織法；沿用條款 |
| 適合該國 | 非硬性 | 八病八藥（[`10`](10-反例診斷.md)） |

## 2 張力

| # | 張力 | 處置 |
|:--:|---|---|
| 1 | **向心選制 vs 反收編**：top-3 孔多賽把居中政黨放大到單一 99／100；而保加利亞的病是一黨收編 | 政府歸居中政黨；規則、法院、檢察、財政規則歸比例層與非議會的選舉權人 |
| 2 | **固定 4 年 vs 民意劇變**：2025-12 那樣的大規模抗議無法提前改選 | 抗議可以逼出建設性更新與單一席次議員更新；**不能逼出整個議會重選** |
| 3 | **保留總統 vs 法國夾的「虛位元首長出權力」** | 本夾沒有組閣危機可以長；但總統的直選正當性仍可能用在擱置否決與輿論上 |
| 4 | **反杯葛 vs 小組被他組代選**：一個組全體杯葛時由他組代選，等於政治多數可以替職業名冊選人 | 只在**全組**無人投票時發生；部分杯葛只是浪費自己的票 |
| 5 | **無法定門檻 vs 碎片化**：比例層可能有 8–10 個黨 | 比例層不掌政府（政府由全院選，居中政黨通常靠單一席次過半）；碎片化只影響規則的談判 |

## 3 自洽檢查

| 檢查 | 結果 |
|---|---|
| 是否存在「沒有政府」的狀態 | 否：舊首長做到新首長就任；新屆 30 日內必定產生 |
| 是否存在「沒有預算」的狀態 | 否：供給自動生效、非供給沿用 |
| 是否存在「沒有憲法法官」的狀態 | 否：固定日、無出席人數、全組杯葛由他組代選 |
| 是否有任何機關能決定選舉日 | 否：固定 |
| 一個政黨能否單獨改規則 | 只有同時拿下全院 3/5 與複數 3/5 時（複數 3/5＝比例層約 60% 的得票） |
| 總統能否碰到政府 | 否 |

## 4 本夾不宣稱能做到的事

- **不宣稱能防止一個居中政黨長期執政。** 本夾的判斷是那是孔多賽贏家應得的；它防的是**同一個政黨改寫選制、法院與檢察**。
- **不宣稱能消滅買票。** 它只提高買票的成本，並把買票從名單層推到單一席次的接戰區。
- **不宣稱族群關係會改善。** 刪除族群政黨禁令、讓土耳其裔選民成為第二偏好的爭取對象，是誘因的方向，不是結果。
- **不宣稱 180、[8,16]、20%／25%、30 日、20 日是唯一解。** 有依據的是方向。
- **不宣稱模型的偏好位置是對的。** 進步保加利亞是否真的在兩條軸的中間，決定了 [`12`](12-預期政治生態.md) 大半的數字。
- **完全不論轉型可行性。**
