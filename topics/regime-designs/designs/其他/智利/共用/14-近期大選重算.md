# 近期大選套新制（兩夾共用）

> 國會兩夾相同；總統（總統制夾）與首長（議會制夾）的結果各夾的 `估計結果.md` 也列。圖見 [`席次圖.md`](席次圖.md)。

## 1 方法

| 項目 | 來源與做法 |
|---|---|
| 2025 第一偏好 | SERVEL **逐投票桌**眾議員票（初步結果，28 個選區各一檔），合到投票所（local de votación）：3,496 所（[`_build_cl.py`](_build_cl.py)、[`資料/cl-2025.csv`](資料/cl-2025.csv)） |
| 2025 驗證 | 有效票 10,721,354：REP 13.26%、PDG 12.00%、UDI 8.34%、RN 8.09%、FA 7.53%、PNL 6.34%。總統第一輪逐桌加總 12,967,498：Jara 26.85%、Kast 23.92%、Parisi 19.72%、Kaiser 13.93%、Matthei 12.46%；與 TRICEL 確定結果（12,975,034）相差不到 0.1% |
| 2017 第一偏好 | SERVEL **逐投票桌** TRICEL 確定結果（15 個大區各一檔）：2,149 所，有效票 5,996,972（[`資料/cl-2017.csv`](資料/cl-2017.csv)）。黨名去掉「PARTIDO」字首、掛黨的獨立人士（INDEPENDIENTE＋黨名）歸該黨 |
| 2021 | SERVEL 網站上找不到 2021 年的國會逐桌檔（只有總統第一輪），**國會重算用 2017 代替**；2021 年只做總統 top-3 |
| 座標 | Wikidata 智利市鎮（Q1840161）的座標，以西文名稱對應（346 個市鎮全部對上；5 個以別名對應） |
| 單一 108 | 6 區內依座標的 Hilbert 曲線排序（經度放大 3 倍，因為智利南北狹長），按有效票連續切；top-3 孔多賽 |
| 複數 72 | 各區聖拉古、無門檻；「其他」拆成 5 份小名單 |
| 總統 | 全國第一輪前 3 名，候選人用自己的位置，各候選人的選民分三型排序 |
| 首長（議會制夾） | 全院 180 記名排名，須 ≥91 |
| 校準 | 三次決選：模型對決 2025 Kast 對 Jara 60.2（實際 58.2）、2021 Boric 對 Kast 52.9（55.9）、2017 Piñera 對 Guillier 50.4（54.6）。**勝方三次都對**。制憲三案用兩次公投校準（§4） |

- **PDG 以 12% 第一偏好拿 59／108 個單一席次**：Parisi 的人民黨在經濟、價值兩軸都居中，左右兩邊的選民都把它排第二。74 區的當選者不是第一輪第一名；沒有一區的當選者第一偏好過半。
- **REP（第一大黨 13.3%）只拿 1 個單一席次**：它的選民集中在右側，在三人對決中輸給居中的 PDG、RN。
- 全院 69／180：首長、法律要再拉 22 席以上；組織法要 PDG＋整個右派（[`05`](05-法規位階與修憲.md) §2）。
