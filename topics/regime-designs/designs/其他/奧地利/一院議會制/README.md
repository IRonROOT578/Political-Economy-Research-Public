## 一句話

**廢 Bundesrat 聯邦立法角色的一院議會制**：國會 **180＝單一 108（top-3 孔多賽、不跨邦）＋複數 72（九邦彈性名單、聖拉古、無全國門檻；小邦 M≥4）**；首長由**全院記名排名**選出（≥91），**30 日內選不出由孔多賽第一名就任**；**建設性更新、無解散**；供給自動生效；**直選總統保留但組閣權形式化**；**留九邦 Landtage**，邦權改兩種多數／邦複決；VfGH 三組；紙本人工計票。

## 三個最容易讀錯的地方

**一、2024 重算下 FPÖ 得票第一，席次卻大幅縮小（57→26），首長是 ÖVP。** 單一孔多賽懲罰「無處第二偏好」；**不是**憲法排除（[`12`](12-預期政治生態.md)）。

**二、ÖVP 單獨 103 過半。** 現行要三黨聯合；新制下組閣長跑的前提消失。

**三、聯邦國不等于必須有第二院。** 邦聲音改由九邦名單區＋影響邦權兩種多數（[`08`](08-邦與地方.md)）。
