# 完善與自洽

`1-優化/總體.md` 非硬性：完善、自洽；適合該國的治理。

## 1 條件的落點

| 條件 | 位階 | 落點 |
|---|---|---|
| 不用電子計票 | **硬性** | [`01`](01-國會與選制.md) §2.6：維持紙本、公開唱票 |
| 首長由某些議員選出與更新 | **硬性** | [`02`](02-政府組成與建設性更新.md)：全院 120 |
| 法官不當記名投票的投票權人 | **硬性** | [`07`](07-司法權與檢察.md)：第一、二審審判法官不入名冊；名冊投票與法官互選皆祕密 |
| 開放名單、SNTV 黑金 | **硬性** | [`01`](01-國會與選制.md) §2.3：彈性名單；初選的價碼降低 |
| 人選不能被杯葛（反例：雙重同意） | **硬性** | [`07`](07-司法權與檢察.md) §3：憲法定日、排名投票、60 日預設值；**拆掉現行 7／9 與 2025 年「雙方各 1」** |
| 不得把提示詞當預期生態 | **硬性** | [`12`](12-預期政治生態.md) §5：三處不合，三項設計因此改過 |
| 不著重條文修辭、不考慮可行性 | **硬性** | 全夾 |
| 信任供給合一 | 非硬性 | 全院 120 |
| 建設性更新 | 非硬性 | [`02`](02-政府組成與建設性更新.md) §2.4 |
| 供給自動生效 | 非硬性 | [`03`](03-預算與供給.md) §2.2 |
| 決選與單輪同日 | 非硬性 | 單一第二輪與名單同日 |
| 從中間向兩側 | 非硬性 | [`07`](07-司法權與檢察.md) §2.3 |
| 避免搖擺、二極化、停擺 | 非硬性 | top-3 孔多賽；兩種多數；沿用條款 |
| 修憲兩軌 | 可選 | [`05`](05-憲法與修憲.md) §5 |
| 適合該國 | 非硬性 | 十二病（[`10`](10-反例診斷.md)） |

## 2 張力

| # | 張力 | 處置 |
|:--:|---|---|
| 1 | **向心選制 vs 極端正統派的放大**：top-3 孔多賽讓沙斯成為第二偏好的受益者 | 拿掉它的勒索工具（解散、預算），不拿掉它的席次 |
| 2 | **成文憲法 vs 以色列的分歧**：宗教與國家的分歧讓制憲本身困難 | 宗教政策不入憲；憲法只寫結構與權利通則 |
| 3 | **憲法法院只審修憲程序 vs 「基本結構」** | 不給法院審修憲內容的權；修憲的實質把關放在兩種多數＋跨屆＋複決 |
| 4 | **固定 4 年 vs 戰爭與危機** | 戰爭不能延選舉；危機中換首長走建設性更新 |
| 5 | **受審首長** | 起訴不自動去職（不讓檢察官決定誰執政）；但 30 日內更新免冷卻，國會必須表態 |

## 3 自洽檢查

| 檢查 | 結果 |
|---|---|
| 是否存在「沒有政府」的狀態 | 否 |
| 是否存在「沒有預算」的狀態 | 否 |
| 是否存在「法官、公訴長懸缺」的狀態 | 否：定日開議、60 日預設值 |
| 是否有機關能決定選舉日 | 否 |
| 一個陣營能否單獨改規則 | 只有同時拿下全院 72 與複數 30 時 |
| 總統能否碰到政府 | 否 |

## 4 本夾不宣稱能做到的事

- **不宣稱能消除分裂**。2019-04 的 60:60 在新制下仍是 60:60。
- **不宣稱能降低極端正統派的席次**；只宣稱拿掉它的兩件勒索工具。
- **不處理西岸與加薩**。
- **不宣稱 120、[8,14]、30 日、20 日、60 日是唯一解**。
- **不宣稱模型的偏好位置是對的**；人物軸（Netanyahu）是本屆的特徵，換了領袖就要重估。
- **完全不論轉型可行性**。
