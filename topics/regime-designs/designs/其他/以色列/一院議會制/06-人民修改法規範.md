## 2 替代現狀方式（公投、修憲複決、人選更新共用）

1. 產生 n 個替代方案（公投：領銜人方案、政府方案，n＝2）。
2. 選民對 n＋1 個方案完整排序（3 方案 → **6 格單選**，人工計票）。
3. **先淘汰**：與「維持現狀」對決時支持票未達**選舉人總額**一定比例（地板）者出局。
4. 存活者與「維持現狀」跑孔多賽完成法。

| 標的 | 地板 |
|---|---|
| 法律 | **20%** |
| 組織法、修憲、人選更新 | **25%** |

**沒有投票率門檻**。

## 3 對象與發動

| 項目 | 規則 |
|---|---|
| 發動 | 選舉人 **5%**（約 34 萬）連署，且至少 3 個複數選區各達該區 3%；或政府；或全院 ≥61 |
| 對象 | 法律、組織法、修憲 |
| **排除** | 年度供給、個案人事、赦免 |
| **領土讓與** | 現行「領土讓與公投」基本法（2014）併入：割讓主權領土的條約須經公投，地板 25% |
| 形式審查 | 憲法法院主管庭 |
| 日期 | 與最近一次全國投票同日；一年內無則單獨舉行 |

★ 宗教與國家（民事婚姻、安息日、兵役）**可以公投**：這些是政策，不是憲政結構（[`08`](08-緊急狀態、選舉與宗教.md) §4）。讓它們走公投而不是聯盟協議，正是把它們從「小黨的籌碼」變回「選民的選擇」。

## 4 效力

| 結果 | 效力 |
|---|---|
| 法律案勝出 | 等同法律；國會 **2 年內**以全院 ≥72 才能修改 |
| 組織法案勝出 | 等同組織法；2 年內另須複數 ≥34 |
| 修憲案勝出 | 生效 |
| 維持現狀勝出 | 同一主題 2 年內不得再提 |
