# 預算與供給

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `1-優化/財政.md` | 非硬性 | **信任供給合一**；規劃保障的供給＝部分行政權預算（不含法定義務支出、歲入、稅制） |
| `1-優化/財政.md` | 非硬性 | 議會制：建設性不信任＋**供給在議會不作為下自動生效** |
| `1-優化/行政立法/共用.md` | 非硬性 | 避免預算不決 → 停擺 |

## 2 規則

### 2.1 規劃保障的供給（封閉列舉）

1. 政策裁量性資本門支出。
2. 預備金與政務應變預算。
3. 行政機關經常門運作費用。
4. 列名政策計畫的經常門支出。

**不含**：法定義務支出、歲入、稅制、非行政部門預算、地方的公式化移轉。法定義務支出**始終撥付**。

### 2.2 自動生效

政府把供給案送達國會後，**20 個開會日**內未通過建設性更新（≥61），供給案生效。

**預算倒閣廢除**：現行「財政年度開始 3 個月內預算未過，國會自動解散」這條刪除。

### 2.3 聯盟資金：公開列項

「聯盟資金」（coalition funds）是現行制度下聯盟協議換來、在預算裡分給聯盟夥伴支持者的專款。本夾不禁止政府編這種預算（那是政府的政策），但：

| 規則 | 內容 |
|---|---|
| **單獨列項** | 凡在聯盟協議或政黨間協議中提及的支出，供給案中須逐項列出並標註協議出處 |
| **審計院逐項公告** | 執行率、受款機構 |
| **國會得刪不得增** | 議員不能在供給案上加項 |

★ 為什麼不直接禁止：禁止只會讓它改名藏進一般科目。**本夾讓它變貴的方式是讓它可見**——每一筆都能被選民對到「哪一個協議、哪一個黨」。

### 2.4 非供給歲出與沿用條款

供給以外的行政歲出由全院 ≥61 議決，**得刪不得增**；會計年度開始 **60 日**未決者，**沿用上年度額度**。

### 2.5 歲入、稅制、財政規則

| 事項 | 門檻 |
|---|---|
| 歲入、稅制 | 全院 ≥61，不適用自動生效 |
| 財政規則（赤字、債務上限） | 組織法（[`05`](05-憲法與修憲.md)） |
| 財政委員會 | 5 人，三組選出（全院 STV 2、複數席次 STV 1、央行與審計院合推 2）；每年公告供給案是否符合財政規則 |

### 2.6 審計院

國家審計長制度保留，改為 **9 人合議**，三組各選 3（全院 STV、複數席次 STV、司法職業名冊 STV）；9 年不連任；權力：決算、供給案逾越列舉的認定、聯盟資金與政黨財務的公告。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 送達後政府更迭 | 新首長得撤回重送，期限重新起算 |
| 建設性更新未通過 | 供給案於表決日次日生效 |
| 逾越列舉 | 逾越部分無效 |
| 戰時、緊急狀態 | 預備金先行動支，30 日內補送；**不中止自動生效** |
