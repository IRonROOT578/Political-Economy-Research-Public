# 政府組成與建設性更新

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/行政立法/議會制.md` | **硬性** | 最高行政首長：選出與更新都由**某些議員**投票 |
| `1-優化/行政立法/議會制.md` | 非硬性＋可選 | **建設性更新**；準人選由排名投票選出 |
| `1-優化/投票.md` | 可選 | 間接投票採排名、**記名**；拆成多輪 |
| `1-優化/財政.md` | 非硬性 | **信任供給合一** |

## 2 規則

### 2.1 某些議員 ＝ 全院 300

`0-基本` 只說「某些議員」。本夾定為**全院 300，門檻 ≥151**。

| 選項 | 以 2024-12 得票重算的後果（[`14`](14-近期大選重算.md)） |
|---|---|
| 只限單一席次 180 | PSD 單一 118／180，**以 22% 的得票獨自掌握政府與錢** |
| **全院 300** | PSD 148／300，**差 3 席**，要找夥伴 |

★ 和保加利亞夾同一個理由：top-3 孔多賽讓位居中間的政黨拿下大多數單一席次。在羅馬尼亞，這個政黨是 PSD，也就是病 10「地方大老」網絡最深的政黨。**掌政府的那張表，不該是被放大得最兇的那張。**

**信任供給合一**：選首長、更新首長、表決供給的都是同一批 300 人。

### 2.2 選出：記名排名投票，多輪篩選

新屆集會後 **30 日內**：

| 項目 | 規則 |
|---|---|
| 投票權人 | 全院 300 |
| 候選 | 議員 30 人連署提名（不必是議員） |
| 票面 | 排名，可截斷、可並排；「維持空缺」是票面上的一個選項 |
| 公開 | **記名** |
| 方法 | 孔多賽完成法（Ranked Pairs） |
| 多輪 | 每輪篩掉排名後三分之一，**輪間 72 小時供協商** |
| 當選 | 最後一輪的勝者，且有 **≥151** 人把他排在「維持空缺」之上 |

**總統不參與**：不提名、不諮商、不任命。議會選出即就任。

★ 現行第 103 條讓總統「在諮商國會政黨後」提名總理候選人。2026 年的 168 天裡，總統連提 3 人，各黨都在等他的下一張牌。**本夾把這張牌拿掉**：誰當總理只看議員的排名票。

### 2.3 30 日期限：沒有看守政府

**30 日內未選出**：由**最後一輪的孔多賽第一名**逕行就任，任期照常。

| | 現行 | **本夾** |
|---|---|---|
| 政府倒台後 | 看守政府：不能發緊急命令、不能提法案 | **不存在看守**：現任做到繼任者就任 |
| 組閣失敗的後果 | 兩次信任投票失敗 60 日後，總統**可**解散（從未用過） | **孔多賽第一名就任** |
| 誰承受失敗 | 全國（2026 年 168 天、評等展望負面） | 拖延的議員：拖到期滿等於把選擇交給票面算術 |

### 2.4 更新：建設性更新

| 項目 | 規則 |
|---|---|
| 提案 | 議員 **50 人**連署，**須具名一位準人選** |
| 最高行政首長準人選 | 僅 1 名挑戰人選被提名時直接**決定出**為準人選；2 名以上時，先由**全院議員以記名排名投票（孔多賽完成法）選出**一位最高行政首長準人選（`1-優化/行政立法/議會制.md`） |
| 表決 | 準人選與現任兩兩對決，記名 |
| 通過 | 準人選獲 **≥151** |
| 通過後 | **立即就任** |
| 未通過 | 現任留任；同一準人選 6 個月內不得再提 |
| 冷卻 | 每位議員 6 個月內至多連署 2 次 |

**沒有純否定式的不信任案。** 倒閣和換人是同一個動作。

★ 2026 年在本夾下的樣子：PSD 撤出部長，**政府不倒**，Bolojan 帶著少數內閣繼續執政，預算照 [`03`](03-預算與供給.md) 自動生效。PSD 要換總理，就得當眾提出一位人選，並讓 151 人記名投給他，其中必然包括 AUR 的票。**2026 年那種「先倒閣，再看誰能接」的路徑不存在**（[`14`](14-近期大選重算.md) §4）。

### 2.5 首長辭職、部長退出

| 情況 | 規則 |
|---|---|
| 首長辭職或死亡 | 副首長代理，30 日內依 §2.2 選出新首長；逾期依 §2.3 |
| 聯合政府的政黨撤出部長 | 首長自行補任；**政府不因此倒台** |

### 2.6 無解散權

國會 4 年一屆，選舉日固定（[`01`](01-國民議會與選制.md) §7.2）。總統和國會都不能提前選舉。

★ 2026 年 AUR 主張修憲，讓國會在組閣失敗時更快解散。本夾走相反的方向：**組閣不會失敗，所以不需要解散**。

### 2.7 把法案綁信任案：限於供給

現行第 114 條讓政府把任何法案綁上信任案：3 日內沒人提不信任案，法案就視為通過。本夾：

| | 現行 | **本夾** |
|---|---|---|
| 適用 | 任何法案 | **只有供給**（[`03`](03-預算與供給.md)） |
| 一般法案 | — | 照一般程序，全院過半 |

★ 這不是削弱政府：供給已經有自動生效的保障。一般法案跳過辯論，正是病 4 的一半。
