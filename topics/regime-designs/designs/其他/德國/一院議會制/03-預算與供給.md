# 預算與供給

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `1-優化/財政.md` | 非硬性 | **信任供給合一**；議會制：建設性不信任＋**供給自動生效** |
| `1-優化/行政立法/共用.md` | 非硬性 | 避免預算不決、停擺 |

## 2 規則

| 項目 | 規則 |
|---|---|
| 規劃保障的供給 | 政策裁量性資本門、預備金、行政機關經常門、列名政策計畫（封閉列舉）；**不含**法定義務支出、歲入、稅制、邦／地方公式化移轉 |
| 自動生效 | 預算日送達後 **20 個開會日**內未通過建設性更新（≥211），供給生效 |
| 國會的修正 | **得刪不得增**；刪減案要政府同意，不同意以原案生效 |
| 非供給歲出 | 全院 ≥211，得刪不得增；60 日未決沿用上年度 |
| 歲入、稅制 | 全院 ≥211 |
| 財政規則 | 組織法；獨立財政監督機關每年公告是否遵守（可承接現行債務剎車的組織法位階，細節不論轉型） |
| 審計院（Bundesrechnungshof） | 保留；院長與委員改由三組選出 |

★ 少數政府至少能執行預算；過緊過半（病 8）不再靠拖延預算卡死施政。
