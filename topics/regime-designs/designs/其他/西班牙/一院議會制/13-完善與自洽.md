# 完善與自洽

## 1 條件的落點

| 條件 | 位階 | 落點 |
|---|---|---|
| 不用電子計票 | **硬性** | 紙本、投開票所內人工計票 |
| 首長由某些議員選出與更新 | **硬性** | 全院 350（[`02`](02-政府組成與建設性更新.md)） |
| SNTV、開放名單黑金 | **硬性** | 彈性名單；參議院的限制連記一併廢除 |
| 法官不當記名投票的投票權人 | **硬性** | 丙組名冊與法官選委員皆祕密投票（[`07`](07-司法權與檢察.md)） |
| 人選不能被杯葛 | **硬性** | 定日選舉、缺席票作廢、不延任、60 日預設值 |
| 不得把提示詞當預期生態 | **硬性** | [`12`](12-預期政治生態.md) §5 |
| 建設性更新、供給自動生效 | 非硬性 | [`02`](02-政府組成與建設性更新.md)、[`03`](03-預算與供給.md) |
| 修憲兩軌 | 可選 | [`05`](05-憲法與修憲.md) |
| 替代現狀方式 | 可選 | [`06`](06-人民修改法規範.md)、[`09`](09-人選更新.md) |

## 2 張力

| # | 張力 | 處置 |
|:--:|---|---|
| 1 | 地方黨變小 vs 領土多元 | 財政公式兩種 3/5、自治區議會不變、領土地位程序 |
| 2 | 選舉人平等 vs 小省代表 | 平等優先，可跨省界 |
| 3 | 加那利 M＝7 低於下限 | 例外寫進憲法，理由是地理 |
| 4 | 取消 3/5 vs 跨黨共識 | STV 本身保證比例代表；共識靠三組各至少一人 |

## 3 本夾不宣稱能做到的事

- 不宣稱兩大黨結構會改變：單一席次幾乎全是 PP 與 PSOE。
- 不宣稱領土爭議會解決；它只給爭議一條程序。
- 2023 年以後的政局（特赦法、2025–26 年的政府與預算）不在重算內。
- 完全不論轉型可行性。
