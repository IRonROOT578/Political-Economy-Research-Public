# 西班牙：一院議會制

本憲政設計最新更新：2026-11-06

```
西班牙：0-基本 ＋ 1-優化
選一政體。
```

提示詞見本庫政體設計提示詞。**不繼承任何 `2-配置/`**。只用當時民意（2023-07、2019-11 眾議院）。

## 一句話

**廢參議院的一院議會制**：眾議院 **350＝單一 210（top-3 孔多賽、±10%、可跨省界）＋複數 140（彈性名單、13 區、聖拉古、無法定門檻）**；首長由全院記名排名投票選出（≥176）、**30 日預設值、刪除兩個月後自動重選**、國王不提名；建設性更新、無解散、固定 4 年；新供給案自動生效；法令 30 日內轉為法律案否則失效；選制、自治條例、財政分配要全院與複數各自 3/5；憲法法院與司法總委員會三組、**取消 3/5、不延任**；檢察總長兩種多數選出；領土地位公投有程序。

## 三個最容易讀錯的地方

**一、2023 年的首長是 PP。** 現行制度下 PP 是第一大黨卻組不成政府；本夾全院 168、PP＋VOX 186（[`12`](12-預期政治生態.md) §3）。得票擺動 3 點就翻成 PSOE（§6）。

**二、PSOE 拿下加泰隆尼亞與巴斯克的多數單一席次。** 那裡的決選三人常是「PSOE＋兩個地方黨」，地方黨選民都把 PSOE 排第二。地方黨合計 11 席（現行 26），代表在名單層（§5.1）。

**三、VOX、SUMAR 單一 0 席。** 它們不是任何人的第二偏好；代表全在名單層（各 18）。
