# 義大利：一院議會制

本憲政設計最新更新：2026-10-28

```
義大利：0-基本 ＋ 1-優化
選一政體。
```

提示詞見本庫政體設計提示詞。**不繼承任何 `2-配置/`**。

## 一句話

**廢參議院的一院議會制**：國會 **400＝單一 240（top-3 孔多賽）＋複數 160（彈性名單、13 區、M∈[8,16]、無法定門檻、無多數獎勵）**；首長由全院記名排名投票選出（≥201），30 日預設值、**總統不授權**；建設性更新、無解散、**廢「信任案綁法案」**、法令不得重發；供給自動生效、得刪不得增；**選制骨架入憲，任何修改不適用於下一次大選**；組織法與修憲要全院與複數各自 3/5，修憲一律複決；公投投票率門檻改支持票地板；憲法法院 9 人三組、STV、定日選舉；CSM 不分流（尊重 2026 公投）；總統由國會與大區代表記名選出、權力形式化。

## 三個最容易讀錯的地方

**一、廢了多數獎勵，第一大黨反而被放大得更多。** 2022 得票下 FdI 26% → 195 席（49%）；2018 得票下 M5S 32% → 223 席（單獨過半）。top-3 孔多賽放大每一區的孔多賽贏家，而義大利的第一大黨常常就是它。差別是：**它們改不了選舉法和憲法**（複數 3/5 是 96，FdI 44、M5S 57）（[`12`](12-預期政治生態.md) §5.1）。

**二、南北分裂在單一席次上變得更鮮明。** 2022 得票下北方 FdI 幾乎全拿、南方 M5S 為主：三人決選裡 PD 選民的第二偏好在南方讓 M5S 勝過 FdI。

**三、2022 年的首長是 FdI 還是 M5S，取決於假設。** 五星在「建制」軸上的位置稍往中間移，M5S 就變成孔多賽贏家（[`12`](12-預期政治生態.md) §6）。本夾不宣稱已知。

## 本夾承認做不到的事

- 第一大黨的放大比多數獎勵更大；本夾只保證它改不了規則。
- Lega、FI 在單一席次消失，右派小黨的代表全在名單層。
- 完全不論轉型可行性。
