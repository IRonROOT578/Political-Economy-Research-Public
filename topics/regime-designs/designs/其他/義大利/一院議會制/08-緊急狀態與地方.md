# 緊急狀態與地方

## 1 緊急狀態

| 期間 | 條件 |
|---|---|
| 宣告 | 首長宣告，7 日內全院 ≥201 追認 |
| 每次最長 | 3 個月；延長要全院 ≥240 且複數 ≥96 |
| 不得 | 延選舉、延任期、修憲、停止建設性更新與憲法法院 |

★ 義大利現行憲法沒有一般性的緊急狀態條款，COVID 期間以「民防法」的國家緊急狀態加總理令（DPCM）治理近兩年。本夾給一個有期限的框架，取代用行政命令累積的例外。

## 2 大區

| 項目 | 本夾 |
|---|---|
| 20 個大區 | 維持（5 個特別自治大區維持） |
| 大區權限的分配 | 組織法；**修改時另需過半大區議會同意**（取代參議院代表地方的功能） |
| 「差異化自治」 | 範圍與財政移轉的公式入組織法；個別協議不得違反公式 |
| 大區主席 | top-3 孔多賽直選（維持直選、改選制） |
| 市長 | top-3 孔多賽（現行兩輪多數決） |
