# 人民修改法規範

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/總體.md` | 硬性 | 給**人民修改法規範條件**（如：對象範圍、效力範圍） |
| `1-優化/投票.md` | 可選 | **公民投票三版本**：領銜人版本、政府版本、維持現狀。選民在選票上對 3 版本表達偏好（如：**6 個完整排序選項供投票人單選**）。領銜人版本與政府版本須同時滿足 **(a) 為投票方法贏家；(b) 得到一定票數**（如：防投票率低）；**二者皆未成立時，維持現狀** |
| `1-優化/投票.md` | 非硬性 | 若直接選舉有兩輪，將較重要的決選與其他單輪投票放在同一天 |
| `0-基本/投票.md` | **硬性** | 可人工計票；不集中或長距離運輸選票 |

## 2 規則（主路徑）

### 2.1 三個版本

一次公投的票面上永遠有三個版本：

| 版本 | 誰提 |
|---|---|
| **領銜人版本** | 提案的公民（連署發起人） |
| **政府版本** | 政府就同一議題提出的互斥版本（**若領銜人非政府**） |
| **維持現狀** | 憲法固定提供 |

**政府得不提版本**；不提者票面仍列三格，政府版本欄標示「政府未提出版本」，該格視為與維持現狀合併。

### 2.2 票面與計票

票面為 **6 個完整排序選項供投票人單選**（三版本的全部排列），與單一席次第二輪同一形式（[`01`](01-國民議會與選制.md) §2.7）。

**各投開票所人工計票、當場公告 6 個數字，選票不離開投開票所。**

### 2.3 兩要件

領銜人版本或政府版本要取代現狀，**須同時滿足**：

| 要件 | 內容 |
|---|---|
| **(a) 投票方法贏家** | 為三版本孔多賽比較的勝者 |
| **(b) 票數地板** | 該版本的首選票 ≥ **選舉人總額 20%** |

**二者皆未成立時，維持現狀。**

★ (b) 是提示詞明寫的「防投票率低」。地板取 20%，與一般修憲複決同一個數字（[`06`](06-法律、組織法與修憲.md) §4.1），理由是兩者都是「留得下來的東西」。

★ **杯葛不划算**：不投票不會讓提案自動失敗以外的任何事發生，而**現狀本來就是三個選項之一**——反對者投「維持現狀」比不投票有效得多。

### 2.4 對象範圍

| 得提案 | 不得提案 |
|---|---|
| 法律 | **憲法**（走 [`06`](06-法律、組織法與修憲.md) §4 的修憲程序） |
| **組織法** | 預算、決算、租稅之課徵與稅率 |
| 條約之批准 | 對特定個人之處分 |
| 地方層級權限之調整 | 溯及既往之刑罰 |
| | **限制普選權、定期改選、共和政體者** |

★ 組織法可由公投修改，但其**效力等同組織法**，仍受 [`06`](06-法律、組織法與修憲.md) §2.2 的封閉列舉拘束。

★ 排除預算與租稅是自由發揮，理由：本夾的供給採自動生效（[`03`](03-行政權預算與供給.md)），若預算可被公投推翻，信任供給合一就出現一個繞道。

### 2.5 效力範圍

**有拘束力。** 通過的版本自公告日起 3 個月後施行，效力等同同位階之法規範。

**議會的再修改**：

| 期間 | 規則 |
|---|---|
| 施行後 **3 年**內 | 議會得修改，但須 **≥267（2/3）** |
| 3 年後 | 依該法規範原本的位階門檻（法律 201、組織法 240＋跨會期） |

★ 這一格是本夾對「效力範圍」的具體回答：**公投的產物不是不可動的，但短期內要付出比一般立法高的代價。** 沒有這一格，公投要嘛淪為裝飾（隔天就被改掉），要嘛變成鎖死條款。

### 2.6 提案與連署

| 項目 | 規則 |
|---|---|
| 提議 | 選舉人 **0.5%**（約 **24 萬人**） |
| 連署 | 選舉人 **1.5%**（約 **72 萬人**），且分布於 **8 個以上複數選區**，各區至少 0.5% |
| 期間 | 連署自成案起 **6 個月** |
| 審查 | 憲法法院就 §2.4 的對象範圍為形式審查，**不審實質內容** |
| 政府版本 | 憲法法院公告成案後 **60 日**內提出 |

★ 分布要件是自由發揮：**防止單一大都會區獨力發動全國公投。** 它不提高總量門檻，只要求提案有跨區域的支持。

### 2.7 投票日

公投與定期改選、人選更新投票**同日舉行**。

★ 這是 `1-優化/投票.md` 那條非硬性的落點——把重要的決選與其他單輪投票放同一天，降低投票率低的影響與選民負擔。**每年至多兩個投票日**（4 月與 10 月的第三個星期日）。

★ 現行第 11 條的公投在實務上幾乎不被使用（1958 年以來約 10 次，2005 年後 0 次），而 2008 年新增的第 11 條第 3 項「共同倡議公投」門檻為五分之一議員＋十分之一選舉人（約 470 萬人），**從未成案**。本夾的 1.5% 是刻意調到可用的量級。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 領銜人版本為孔多賽勝者但首選票 18% | **不成立**，維持現狀 |
| 政府版本為孔多賽勝者且達地板 | **政府版本生效** |
| 三版本出現孔多賽循環 | 依孔多賽完成法決；仍平手則維持現狀 |
| 政府未提出版本 | 該格與維持現狀合併，票面仍為 6 格 |
| 連署達總量但只分布於 6 區 | **不成案** |
| 同一議題重複提案 | 前案投票日起 **2 年**內不得再提 |
| 公投通過後議會於 1 年內修改 | 須 ≥267；未達者修法無效 |
| 公投案與修憲複決同日 | 得同日，票面分開 |
| 提案逾越 §2.4 對象範圍 | 憲法法院於成案前駁回；成案後始發現者，投票結果無效 |
