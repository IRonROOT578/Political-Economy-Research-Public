# 司法權與憲法法院

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/其他三權/總體.md` | 硬性 | 給**重要的權力與組織架構**；每權高層人選的投票若為**間接選舉：採記名** |
| `0-基本/其他三權/司法權.md` | **硬性** | **司法院：避免方案的通過，極端、派系化** |
| `0-基本/其他三權/司法權.md` | 非硬性 | **法官**（如：制度中立職；**不含**偏政治性的大法官）**不應當記名投票的投票權人** |

| `1-優化/投票.md` | 可選 | 間接投票的複數席次職位採 **STV 或其修改**；間接投票採**排名、記名** |

★ 對應表**沒有**給法國監察權、考試權。本夾的其他權為**司法權**與**審計權**（[`04`](04-其餘預算與審計權.md) §3）。

## 2 組織（主路徑）

### 2.1 憲法法院

| 項目 | 規則 |
|---|---|
| 名稱 | **憲法法院**（取代現行憲法委員會，並取消其諮詢機關的性格） |
| 人數 | **12** |
| 產生 | 議會**分三組**、各組以 **STV 記名**選出 4 人 |
| 任期 | **9 年，不得連任**，每 3 年改選三分之一 |
| 資格 | 曾任法官、檢察官、律師或法學教授 **12 年**以上；且 **5 年內未任議員、政務人員或政黨職務** |
| **前任元首的當然職位** | **取消** |

★ 現行憲法委員會的三個特徵在本夾全部取消：**9 人由總統、國民議會議長、參議院議長各任命 3 人**（本夾無總統、無參議院）；**前任總統為當然終身委員**（本夾無總統，且當然職位與記名選出的原則衝突）；**得為政府提供事前諮詢**（本夾要求它是裁判者，不是顧問）。

### 2.2 三組選舉權人

| 組 | 選舉權人 | 選出 |
|---|---|---|
| 甲 | 單一席次 230 | **4 人** |
| 乙 | 複數席次 170 | **4 人** |
| 丙 | **司法職業名冊**（§2.3） | **4 人** |

★ **本夾的丙組不是政治性選舉權人。** 台灣總統制夾用「正副總統候選人加權」作丙組（那是 `1-優化/其他三權/總體.md` 的可選條件，且以有直選總統為前提）；本夾沒有直選總統，用不上。

### 2.3 丙組：司法職業名冊

丙組的選舉權人為：**最高法院、最高行政法院、審計院之現任成員，及全國律師公會與法學教授團體推選之代表**，合計 **300 人**，名冊由**議會全院**每 3 年以 ≥201 公告一次。

★ **名冊由議會公告、丙組自己投票**——公告者與投票者分離，避免任一方自我挑選。

★ **法官不擔任記名投票權人的問題**：`0-基本/其他三權/司法權.md` 非硬性寫「法官（如：制度中立職；**不含**偏政治性的大法官）不應當記名投票的投票權人」。

本夾的處理：**丙組的投票採記名，但普通法院的審判法官不列入名冊。** 列入的是最高法院與最高行政法院的**成員**（在本夾其職務含法律見解統一，屬提示詞括號排除的偏政治性一類）、審計院成員、律師與學者。**第一審與第二審的審判法官一律不列入。**

### 2.4 反杯葛：杯葛者浪費投票權

`1-優化/其他三權/總體.md` **硬性**。落點與審計院相同（[`04`](04-其餘預算與審計權.md) §3.4）：

| 規則 | 內容 |
|---|---|
| **不設雙重同意** | 三組各選各的，**任一組不能否決他組人選** |
| **杯葛者的票作廢且不重分配** | 拒絕投票或投空白者，其投票權**歸零，不移轉** |
| **缺額不降低門檻** | STV 當選額數以**該組法定人數**為分母，不因缺席下降 |
| **逾期即由現任續任** | 該組逾期未選出者，原任者續任，**續任期間不計入任期** |

★ 最後一列：**杯葛的效果是讓對手的人繼續在位**，而不是製造空缺。

★ 這一整套是本夾對「2025 之後憲法委員會若被拖延補人會發生什麼」的直接回答——**在本夾它不可能發生。**

### 2.5 內部多個平行架構與多重同意

憲法法院分為**兩庭**，各 6 人，每庭含甲乙丙組各 2 人。

| 事項 | 門檻 |
|---|---|
| 具體個案的違憲審查（法院移送、人民聲請） | **主管庭 6 人中 ≥4** |
| **宣告法律違憲而失效** | **兩庭各 ≥4**（多重同意），且**合計 ≥9／12** |
| **宣告組織法或修憲案違憲** | 全院 **≥9／12** |
| 權限爭議之裁判 | 全院 **≥7／12** |
| 選舉訴訟、選區劃分案之審查 | 全院 **≥7／12** |
| 公投提案之形式審查 | 主管庭 ≥4 |

### 2.6 「避免方案的通過，極端、派系化」怎麼落

`0-基本/其他三權/司法權.md` **硬性**。本夾用三件事同時達成，**沒有一件是全體一致決**：

| 手段 | 內容 |
|---|---|
| **選舉權人分三組** | 任一政治陣營都不可能同時控制甲、乙、丙三組——甲乙選制不同、丙組非政治性 |
| **STV** | 同一組內部，少數也能選上；**一組 4 席的 STV 當選額數為 20%**，多數派拿不走全部 |
| **多重同意** | 最重的方案（宣告法律違憲）須**兩庭各過門檻**，而每庭都含三組的人 |

★ **反面**：不用全體一致決。全體一致決會讓任何方案都過不了——那不是「避免極端方案」，那是「避免所有方案」（對照 [`../../台灣/一院總統制-惡搞/06-三院.md`](../../台灣/一院總統制-惡搞/06-三院.md)）。

★ 而且 §2.4 的反杯葛硬性與全體一致決**直接矛盾**：全體一致決等於給每個人一票否決權，那正是被禁止的杯葛。

## 3 權力

| 權力 | 內容 |
|---|---|
| **事前違憲審查** | 議員 60 人或首長，得於法律公布前聲請 |
| **事後違憲審查** | 各級法院於審理中得移送；**人民窮盡救濟後得聲請**（現行 QPC 的擴充：本夾允許人民直接聲請，不經最高法院篩選） |
| **權限爭議** | 各權之間、中央與地方之間的權限爭議，**由本院終局裁判** |
| **選舉訴訟** | 議員選舉、公投、修憲複決之爭訟 |
| **選區劃分審查** | 劃分案之人口偏差與程序（[`01`](01-國民議會與選制.md) §2.4） |
| **供給逾越之認定** | 依審計院移送，認定供給是否逾越封閉列舉（[`03`](03-行政權預算與供給.md)） |
| **緊急狀態之合憲性** | 得於狀態存續中審查（[`09`](09-緊急狀態.md)） |
| **不含** | 對政策妥當性的審查；事前諮詢；對政府的意見書 |

★ **人民得直接聲請**是對現行 QPC（2010 年起的「合憲性優先問題」）的擴充：現行制度須經最高法院或最高行政法院篩選才能上達。本夾取消篩選，理由是本夾沒有第二院、沒有元首，**憲法法院是唯一的憲法爭議出口，不應再設守門人**。

## 4 普通司法

| 項目 | 規則 |
|---|---|
| 體系 | 普通法院與行政法院**雙軌**（維持法國傳統），管轄爭議由憲法法院裁判 |
| 法官任免 | 由**司法官委員會**提名，行政首長任命；**首長不得拒絕**，僅得附具意見一次 |
| 司法官委員會 | 21 人：法官與檢察官互選 12 人、律師與學者 5 人、議會全院記名選出 4 人。**行政首長與司法首長不擔任主席** |
| 檢察官 | 職務上獨立；**行政首長不得對個案下指令**，一般性刑事政策指令須書面並公告 |
| 法官身分保障 | 非依法定原因與程序不得免職、停職、轉任、減俸 |
| 法官的政治參與 | **審判法官不得為任何記名投票的投票權人**（[`08`](08-司法權與憲法法院.md) §2.3），不得參加政黨 |

★ 現行司法官委員會（CSM）由總統主持的規定在 2008 年已改，本夾更進一步：**行政首長完全不入席**。理由與 §2.1 相同——本夾的首長由 116 票產生，讓他參與法官人事等於把 116 票的多數送進司法權。

## 5 狀態

| 狀態 | 怎麼走 |
|---|---|
| 某組拒絕選出憲法法官 | 原任者續任；**該組不因此取得對他組人選的否決權** |
| 丙組名冊未依期公告 | 沿用前次名冊 |
| 兩庭對同一法律見解不一致 | 未達「兩庭各 ≥4」即**不宣告違憲**，法律繼續有效 |
| 憲法法官出缺 | 由**同組**於 90 日內補選；**分母仍為 12** |
| 法律被宣告違憲 | 自宣告日起失效；本院得定 6 個月以下之過渡期間 |
| 修憲案被宣告違憲 | 僅限違反 [`06`](06-法律、組織法與修憲.md) §4.4 的不得修改事項；其餘不審實質 |
| 憲法法院自己的權限有爭議 | 由本院裁判；**憲法明文不設更上級的裁判者** |
| 議會不編憲法法院預算 | 不得整案為零（[`04`](04-其餘預算與審計權.md) §2.3）；逾 60 日未議決者沿用上年度 |
