# 政府組成與建設性更新

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/行政立法/一院議會制.md` | **硬性** | 最高行政首長負責行政；**選出方式：某些議員投票；更新方式：某些議員投票** |
| `1-優化/行政立法/一院議會制.md` | 非硬性 | **建設性更新信任案**：準人選須在與現任的兩兩對決中獲得超過一定量的某些議員支持 |
| `1-優化/行政立法/一院議會制.md` | 可選 | 準人選由某些議員採**排名投票**選出 |
| `1-優化/投票.md` | 可選 | 間接投票（含議員投票）採**排名、記名**；拆成多輪表決方便協商 |
| `1-優化/財政.md` | 非硬性 | **信任供給合一**：信任與供給的提供者須相同 |
| `配置/法國/總體.md` | **硬性** | **避免政府如在第四共和、2025 倒閣潮不穩** |

★ **本檔是配置第二條硬性的主要落點。**

## 2 規則（主路徑）

### 2.1 某些議員 ＝ 單一席次 230

`0-基本` 只寫「某些議員」，沒有指定是誰。本夾定為**單一席次 230**。

理由是兩條條件的交會：

- `1-優化/財政.md` **信任供給合一**：信任與供給的提供者須**相同**。
- `1-優化/行政立法/共用.md` 可選：**僅單一席次而非複數席次議員表決預算，避免預算上人多嘴雜而難達成共識**。

第二條指定了供給的提供者，第一條把信任的提供者綁成同一批。**於是「某些議員」＝單一席次 230，建設性更新的門檻 ≥116。**

分工：

| | 單一席次 230 | 複數席次 170 |
|---|---|---|
| 選出行政首長 | **是** | 否 |
| 建設性更新 | **是** | 否 |
| 表決行政權供給 | **是** | 否 |
| 法律、組織法、修憲 | 是 | 是 |
| 非行政部門預算、決算 | 是 | 是 |
| 憲法法院與審計院人選 | 甲組 | 乙組 |

**錢與政府是同一批人的事，規則是全院的事。**

### 2.2 選出：記名排名投票，多輪篩選

新屆議會集會後 **30 日內**選出行政首長。

| 項目 | 規則 |
|---|---|
| 投票權人 | 單一席次 **230** |
| 票面 | **排名投票**，可截斷、可並排 |
| 公開性 | **記名**（`1-優化/投票.md` 可選條件，本夾採用） |
| 方法 | 孔多賽完成法 |
| 多輪 | 每輪篩掉孔多賽排名後三分之一，**輪間留 48 小時供協商** |
| 當選 | 最後一輪的孔多賽勝者，且須獲 **≥116** 名單一席次議員將其排在「維持空缺」之上 |

★ 多輪與輪間協商期是 `1-優化/投票.md` 的可選條件，本夾採用。**理由與配置硬性直接相關**：第四共和的組閣失敗多半是各黨在一次投票裡互相否決，沒有一個把否決轉成談判的程序。

★ **記名的理由**：`1-優化/投票.md` 把記名寫在同一條裡。而在本夾它另有一個具體作用——**議員必須對自己選出的政府負責**，這正是 §2.4 那條「不得躲在倒閣後面」的前提。

### 2.3 30 日期限與期滿的規則

**若 30 日內未選出**：由**孔多賽排名第一者**出任行政首長，任期照常。

★ 這一條是對第四共和的直接回應：**憲法不允許「沒有政府」這個狀態存在。**

| | 第四共和 | 荷蘭 | **本夾** |
|---|---|---|---|
| 組閣期限 | 無 | 無 | **30 日** |
| 期滿的後果 | 繼續協商 | 繼續協商 | **孔多賽第一名逕行就任** |
| 誰承受不確定性 | 全國 | 全國 | **拖延的議員自己**——拖到期滿等於把選擇權交給票面算術 |

★ 這是本夾與台灣議會制夾都採的設計；**在法國夾它更關鍵**，因為法國的兩個反例都以「沒有政府或政府隨時可倒」為形狀。

### 2.4 更新：建設性更新信任案

| 項目 | 規則 |
|---|---|
| 提案 | 單一席次議員 **20 人**連署，**且提案書須具名一位準人選** |
| 準人選怎麼產生 | 由連署人以排名投票選出（`1-優化` 可選），或連署書逕行指定 |
| 表決 | 準人選與現任的**兩兩對決** |
| 通過門檻 | 準人選須獲 **≥116／230** 名單一席次議員支持 |
| 通過後 | 準人選**立即就任**，現任解職 |
| 未通過 | 現任留任；**同一準人選 6 個月內不得再被提出** |
| 冷卻期 | 同一屆內，任一議員 6 個月內至多連署 2 次 |
| 是否重啟屆期 | **否**。議會做滿 4 年 |

★ **沒有「純否定式倒閣」這個東西。** 憲法上不存在一個「只推翻現任、不指定繼任者」的程序。

> **在本夾，倒閣與換人是同一個動作。**

### 2.5 這一條怎麼同時治兩個反例

| 反例 | 原機制 | 本夾怎麼擋 |
|---|---|---|
| **第四共和** | 組成須絕對多數、推翻只需相對多數；倒閣不必指定繼任者 | **門檻對稱**：推翻現任所需的 116 票，正是新首長就任所需的 116 票。**拆與組是同一個門檻。** |
| **2025** | 總理由總統任命，議會只能拆不能指定 | **首長由議員選出**，議會本來就握有指定權；**沒有一個「總統再任命另一個人」的環節** |

★ 第二列值得展開：`1-優化/財政.md` 逐字寫的是「建設性不信任案**不適用於**『總統決定總理』的情況」。**本夾不是在第五共和上加裝建設性不信任——那裝不上去。本夾是把那個裝不上去的接口拆掉。**

### 2.6 無解散權

**行政首長不能解散議會，議會也不能自行解散。**

理由：

1. **僵局有內部出口**（換首長只要 116 票且無時限限制），不需要外部出口。
2. 解散權會把政府危機升級成全國性動員，**而那正是 `1-優化/行政立法/共用.md` 那條「避免台美韓式二極化與內耗」要避免的形態**。
3. ★ 2024 年 6 月的解散是 2025 倒閣潮的**直接前因**——它產生了一個三分無多數的議會，而憲法在五年內不得再解散。**解散權在那次事件裡不是出口，是入口。**

代價：若議會的組成與民意嚴重脫節，**只能等到 4 年屆滿**。寫進 [`13`](13-憲政選擇.md) 與 [`15`](15-完善與自洽.md)。

### 2.7 政府的組織

| 職位 | 產生 | 更新 |
|---|---|---|
| **行政首長** | 單一席次 230 選出（§2.2） | 建設性更新（§2.4） |
| 副首長 | 由行政首長提名、單一席次過半同意 | 隨首長更迭 |
| 部長 | 由行政首長任免 | 同上 |

**首長與部長得兼任議員**，兼任者的表決權不受限制。

★ 現行第五共和的 incompatibilité（部長須辭去議席）在本夾取消：那條規則的前提是總理由總統任命、內閣與議會分屬兩個正當性來源。**本夾沒有那個前提**，而讓部長保有議席使政府與其多數之間不需要額外的協調機制。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆 30 日內未選出首長 | **孔多賽排名第一者就任**（§2.3） |
| 首長死亡或辭職 | 副首長代理，**30 日內**依 §2.2 選出新首長；逾期同 §2.3 |
| 建設性更新未通過 | 現任留任；該準人選 6 個月內不得再提 |
| 建設性更新通過 | 準人選**立即**就任，無交接空窗 |
| 同時有兩件建設性更新案 | 依連署完成先後表決；前案通過則後案的「現任」變更，須重新連署 |
| 首長被其選區以人選更新程序更換 | **喪失議員身分，首長職務不受影響**（首長不必是議員） |
| 首長同時是準人選 | 不得——準人選須與現任兩兩對決 |
| 缺額 | **計入 230 的分母**，門檻不下降 |
