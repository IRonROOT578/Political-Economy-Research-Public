# 緊急狀態

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/總體.md` | 硬性 | **緊急狀態**是必須交代的憲政選擇之一 |
| `1-優化/行政立法/共用.md` | **硬性** | 憲法與法律之間設一個法規位階——**緊急狀態的權力清單放在組織法**（[`06`](06-法律、組織法與修憲.md) §2.2） |
| `配置/法國/總體.md` | **硬性** | 避免政府如在第四共和、2025 倒閣潮不穩 |

★ 法國現行憲法有**三套**例外制度：第 16 條（總統的例外權力）、第 36 條（戒嚴）、以及法律層次的 état d'urgence（1955 年法，2015–2017 年連續延長 6 次共 2 年）。**本夾把三套收斂為一套，並把權力清單升到組織法。**

## 2 三條寫死的紅線

1. **緊急狀態不得延後任何選舉、複決或人選更新投票。**
2. **緊急狀態不停止建設性更新程序。**
3. **緊急狀態不得停止憲法法院與審計院的職務，亦不得變更其人選。**

★ 第二條在議會制夾是關鍵：宣告狀態的是行政首長，**若狀態能凍結建設性更新，他就取得一個自己宣告、自己受益的免疫期**。

★ 第三條針對的是 2015–2017 年那次的教訓：連續延長的期間，**審查機關若同時被癱瘓，延長就沒有外部檢查。**

## 3 規則（主路徑）

### 3.1 宣告與失效

| 項目 | 規則 |
|---|---|
| 宣告 | 行政首長逕行宣告，**須同時公告事由、地理範圍與所援引之權力項目** |
| 自動失效 | 宣告後 **12 日** |
| 第一次延長 | 全院 **≥201**，每次 **30 日** |
| **第二次起延長** | 全院 **≥240（3/5）**，每次 30 日 |
| **累計逾 180 日後之延長** | 全院 **≥267（2/3）**，每次 30 日，**且須經憲法法院合憲性審查** |
| 追認失敗 | 立即終止，緊急命令同時失效 |
| 重新宣告 | **同一事由**於終止後 **90 日**內不得重新宣告；不同事由不受限 |
| 地理範圍 | 得為部分領土；**全國範圍之宣告，延長門檻一律以 3/5 起算** |

★ **門檻隨時間遞增**是本夾對 2015–2017 年的直接回應：那次每一次延長的門檻都相同，於是延長成為慣性。**本夾讓延長愈久愈難。**

### 3.2 權力清單（組織法，封閉列舉）

緊急狀態下政府得行使的權力，**以組織法列舉者為限**：

1. 限制特定區域之通行與集會。
2. 對特定場所之臨檢與扣押（須事後 48 小時內送法院審查）。
3. 對特定個人之居住指定（**上限 3 個月，得由法院延長一次**）。
4. 徵用物資與勞務（**須給予補償**）。
5. 管制與災害有關之價格與配給。
6. 動支預備金與政務應變預算（[`03`](03-行政權預算與供給.md) §3）。
7. 徵召預備役與調度公務人力。

**列舉之外的權力不得行使。** 逾越者該處分自始無效，且不因狀態終止而免責。

### 3.3 明文禁止的事項

| 禁止 | 說明 |
|---|---|
| 延後選舉、複決、人選更新 | 紅線一 |
| 停止建設性更新 | 紅線二 |
| 停止或改組憲法法院、審計院 | 紅線三 |
| **停止議會集會** | 議會於狀態期間**當然集會**，不得休會 |
| **設立特別法庭或軍事法庭審判平民** | 無例外 |
| **事前檢查新聞或封鎖通訊網路** | 得限制特定內容之散布，須逐案且得即時聲請法院審查 |
| **解散政黨或禁止政黨活動** | 無例外 |
| 以緊急命令變更選舉制度、選區、稅制 | 無例外 |

### 3.4 防常態化

**狀態終止後 24 個月內，不得將該狀態所援引之行政權力以法律或組織法改為常態權力。違反者該條文無效。**

★ 這一條是對 2017 年的直接回應：法國在結束為期兩年的緊急狀態時，把其中數項權力（行政搜索、居住指定的類似措施）寫進普通法（SILT 法）。**本夾封住這條路徑。**

★ 這條是**改預設值**，不是「揭露＋勸誡」：憲法直接讓那個條文無效，不需要任何人去查有沒有守規矩。

### 3.5 司法審查不中止

- 憲法法院於狀態存續中得審查宣告與延長之合憲性，**不待狀態終止**。
- 個別處分之救濟程序不中止、不延長期間。
- **審計院得於狀態期間查核預備金與應變預算之動支**（[`04`](04-其餘預算與審計權.md) §3.3）。

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 第 12 日議會未表決 | **狀態失效** |
| 延長通過但同期通過建設性更新 | 狀態存續；**新首長承接，期限不重新起算** |
| 狀態期間屆期改選 | **照常改選**，不得延期 |
| 狀態期間公投投票日到來 | **照常投票** |
| 狀態期間議會拒絕集會 | 不生延長之效果——期限依**曆日**計，未追認即失效 |
| 政府援引清單外之權力 | 該處分自始無效；憲法法院得逕行宣告 |
| 同一事由於終止後 60 日重新宣告 | **不合法**（90 日內禁止） |
| 事由改變（如颱風後轉為疫病） | 屬不同事由，得重新宣告，**但累計日數合併計算**以決定延長門檻 |
| 狀態終止後 12 個月，政府提案將某項權力常態化 | 該條文無效（§3.4） |
