# 其餘預算與審計權

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/財政.md` | — | **無任何條件** |
| `0-基本/其他三權/總體.md` | 硬性 | 給除了立法權、行政權以外的權的**權力與組織架構**；高層人選若為間接選舉**採記名** |
| `1-優化/其他三權/總體.md` | **硬性** | **人選不能被杯葛（如：雙重同意），要讓杯葛者付出代價（含：浪費投票權）** |
| `1-優化/其他三權/總體.md` | 可選 | 每院內部有多個平行架構（含：方案採多重同意） |
| `1-優化/財政.md` | 非硬性 | 供給的範圍**不含**歲入、稅制、非行政部門預算 |

★ **`0-基本/其他三權/總體.md` 說的是「除了立法權、行政權以外的權（如：司法權）」——「如」是舉例。** 本夾除司法權外另設**審計權**，這是自由發揮，理由見 §3.1。

## 2 其餘預算（主路徑）

### 2.1 誰表決什麼

| 項目 | 表決者 | 門檻 |
|---|---|---|
| 規劃保障的供給 | 單一席次 230 | 自動生效（[`03`](03-行政權預算與供給.md)） |
| 非供給的行政歲出 | 單一席次 230 | ≥116 |
| **歲入與稅制** | **全院 400** | **≥201** |
| **立法部門預算** | 全院 400 | ≥201 |
| **司法權、審計權預算** | 全院 400 | ≥201 |
| **中央對地方之財政移轉** | 全院 400 | ≥201 |
| 決算 | 全院 400 | ≥201，須先有審計院報告 |

### 2.2 非行政部門預算不得被行政權先刪

政府編列總預算案時，**司法權與審計權的預算按其自行提出的數額編入，政府不得刪減**，僅得附具意見送議會。

★ 理由：本夾的行政首長由 116 名議員產生，若他能先刪掉審查自己的機關的預算，`1-優化/其他三權` 的反杯葛硬性在財政面就被繞過去。

### 2.3 三條底線

1. **法定義務支出始終撥付**，不需年度議決。
2. **不得把任何機關的預算整案凍結為零。**
3. 會計年度開始後 **60 日**未議決者，**沿用上一年度已議決額度**。

★ 第三條是自由發揮，理由與 [`03`](03-行政權預算與供給.md) §2.6 相同：`1-優化/行政立法/共用.md` 把美國式預算停擺列為要避免的事。

### 2.4 議員得否增列

**不得。** 議員對任何預算案只得刪減，不得增列，亦不得移列。

★ 理由是巴西的反例：議員得個別增列預算（emendas parlamentares）使預算成為與個別議員逐一交易的場域，而那正是 Herding cats 的財政形態。**這是本夾的自由發揮**，不是任何條件的要求。

★ 現行法國第 40 條也禁止議員增加支出或減少收入。**本夾保留這個方向，但把它與「行政權不得先刪三權預算」配成一組**——現行制度只有前半，於是行政權在編列階段就握有單方面的裁量。

## 3 審計權（主路徑）

### 3.1 為什麼另設一權

`0-基本/其他三權/總體.md` 只舉了司法權為例。**本夾把審計獨立成一權**，理由：

1. 本夾**沒有第二院**（[`00`](00-讀法與政體選擇.md) §3.2），失去了一個對行政權的外部檢查點。
2. 本夾的供給採**自動生效**（[`03`](03-行政權預算與供給.md) §2.3）——預設是給錢。**事前門檻放低，事後查核就必須放高。**
3. 法國自身已有審計法院（Cour des comptes），現行憲法第 47-2 條把它定位為協助議會與政府的機關；**本夾把它從「協助」升為獨立的一權。**

★ 對應表**沒有**給法國監察權、考試權（那一行寫在 `# 台灣` 標題下）。**審計權不是監察權**：它只查帳與績效，沒有彈劾提案權、沒有糾正權、不調查個人。

### 3.2 組織

| 項目 | 規則 |
|---|---|
| 名稱 | **審計院** |
| 人數 | **15** |
| 產生 | 議會**分三組**、各組以 STV 記名選出 5 人 |
| 任期 | 9 年，**不得連任**，每 3 年改選三分之一 |
| 資格 | 具會計、審計、公共財政或經濟專業，且 5 年內未任政務人員或議員 |

**三組選舉權人**（反杯葛的落點，§3.4）：

| 組 | 選舉權人 | 選出 |
|---|---|---|
| 甲 | 單一席次 230 | 5 人 |
| 乙 | 複數席次 170 | 5 人 |
| 丙 | 地方層級議會代表團（[`10`](10-中央內水平分權與地方.md) §3） | 5 人 |

★ 丙組是本夾對「沒有參議院」的一個具體補償：**地方團體的代表性在中央層級唯一保留的落點就是這裡。**

### 3.3 權力

1. **審計**：對一切公共資金的收支與帳目為合法性與正確性審查。
2. **績效查核**：對政策計畫為效益評估，**得主動選題**。
3. **決算報告**：於會計年度終了後 6 個月內提出，議會據以審議決算。
4. **供給的事後查核**：對依 [`03`](03-行政權預算與供給.md) §2.3 自動生效之供給，**逐案查核其是否落在封閉列舉範圍內**，逾越者於報告中列明並移送憲法法院。
5. **地方財政查核**：對中央財政移轉的使用為查核。

**沒有**：彈劾提案權、糾正權、對個人的調查權、對政策妥當性的否決權。

### 3.4 反杯葛：杯葛者浪費投票權

`1-優化/其他三權/總體.md` **硬性**：人選不能被杯葛，杯葛者要付出代價（**含：浪費投票權**）。

落點：

| 規則 | 內容 |
|---|---|
| **不設雙重同意** | 三組各自選出各自的 5 人，**任一組不能否決他組的人選** |
| **杯葛者的票作廢且不重分配** | 拒絕投票或投空白者，其投票權**歸零，不移轉給他人** |
| **缺額不降低門檻** | STV 的當選額數以**該組法定人數**為分母計算，不因缺席而下降 |
| **逾期即由現任續任** | 該組逾期未選出者，原任者續任至選出為止，**但續任期間不計入任期** |

★ 最後一列是本夾的加碼：**杯葛的效果是讓對手的人繼續在位**，而不是製造空缺。

### 3.5 內部多個平行架構

`1-優化/其他三權/總體.md` 可選條件：每院內部有多個平行架構，方案採多重同意。

審計院分為**三庭**（中央財政庭、社會保險庭、地方財政庭），各 5 人，由三組選出者**平均分配**——每庭各含甲乙丙組各若干人。

- 個案審計由**主管庭**以過半決之。
- **年度決算報告與主動選題的績效查核**須經**三庭各自過半**（多重同意）。

★ 「多重同意」在此不是提高門檻以求癱瘓，是要求**跨組的一致**：一份報告若只有一組選出的人支持，過不了三庭。

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 某組拒絕選出審計委員 | 原任者續任；**該組不因此取得對他組人選的否決權** |
| 審計院預算被議會刪減 | 得刪，但不得整案為零（§2.3） |
| 審計報告指出供給逾越封閉列舉 | 移送憲法法院；經認定逾越者，該筆支出自認定日起停止 |
| 決算逾期未提報告 | 議會得逕行審議決算；審計院院長須到院說明 |
| 三庭意見不一致 | 年度報告不成立，須重新提出；**個案審計不受影響** |
| 地方團體拒絕接受查核 | 中央財政移轉暫停撥付，至接受查核為止 |
| 審計委員出缺 | 由**同組**於 90 日內補選；分母不縮小 |
