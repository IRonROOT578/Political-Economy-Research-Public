# 國家元首與對外代表

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/行政立法/一院議會制.md` | **硬性** | 架構只有**最高行政首長**一個職位；**沒有提到國家元首** |
| `0-基本/總體.md` | **硬性** | 提示詞未提及的部分**可自由發揮** |
| `1-優化/行政立法/共用.md` | 非硬性 | 避免像**台美韓**社會二極化、內耗，以增加敵國在國內「拉一打一、滲透」的難度 |
| `配置/法國/總體.md` | **硬性** | 適合法國的治理；**避免政府如在第四共和、2025 倒閣潮不穩** |

★ **`0-基本` 的一院議會制架構裡沒有國家元首這個職位。設不設是自由發揮。**

## 2 規則（主路徑）

### 2.1 不另設國家元首

**本夾不設一個與行政首長分離的國家元首。行政首長兼任國家元首。**

| 職能 | 誰行使 |
|---|---|
| 對外代表國家、締結條約 | 行政首長（條約批准須全院 ≥201） |
| 派遣與接受使節 | 行政首長 |
| 公布法律 | 行政首長；逾 15 日不公布者由議長公布 |
| 授勳與榮典 | 行政首長 |
| 特赦與減刑 | 行政首長提出，**須經全院 ≥201 同意** |
| 三軍統帥 | 行政首長 |
| 宣告緊急狀態 | 行政首長（[`09`](09-緊急狀態.md)） |
| 任命憲法法院與審計院人選 | **無人任命**——由議會分組選出即為就任（[`04`](04-其餘預算與審計權.md)、[`08`](08-司法權與憲法法院.md)） |

### 2.2 為什麼拿掉這個位子

**三條理由，其中兩條是法國特有的。**

#### 理由一（法國特有）：那個位子是 2025 錯配的來源

`1-優化/財政.md` 的診斷逐字寫著「**建設性不信任案不適用於『總統決定總理』的情況**」。

★ **「總統決定總理」的前提是有一個總統。** 只要憲法上存在一個與行政首長分離、且被認為代表全國的職位，就會有人主張它應該在政府危機時介入——**任命、仲裁、或至少「表態」**。而每一次介入都會重新製造那個錯配。

**本夾的處理不是限制它的權力，是不設這個職位。**

★ 這一點要說清楚：**一個「無實權、由議會選出」的元首並不能解決問題。** 第四共和的總統正是那樣產生的（由兩院聯席選出），而他仍握有 désignation du président du Conseil 的實際主導權——十二年 24 屆政府，每一屆的人選都經過他。**無實權的元首在組閣危機裡會自動長出權力**，因為那是憲法上唯一還在運轉的中立點。

#### 理由二（法國特有）：第五共和的正當性競賽

1962 年公投後總統改為直選，於是出現兩個都能宣稱「人民選我」的職位。**共治（cohabitation）與 2024 年之後的分立都是這個結構的產物。**

本夾把全國層級的行政職位收斂為**一個**，而它由 230 名單一席次議員產生。**沒有第二個宣稱代表全國的職位，就沒有正當性競賽。**

#### 理由三（共通）：反二極化

`1-優化/行政立法/共用.md` 非硬性把**台美韓**列為社會二極化與內耗的例子。一個全國單一選區直選的職位，是二極化最強的動員裝置——它把全國政治壓縮成一場零和的個人對決。

★ 這條理由在六個正式夾裡是共通的；[`../../台灣/一院議會制/`](../../台灣/一院議會制/) 用同一條理由做同一個決定。

### 2.3 代價，以及本夾怎麼處理

| 代價 | 本夾的處理 |
|---|---|
| **交接期間沒有超然的延續者** | 首長死亡或辭職由副首長代理，30 日內選出新首長；建設性更新則**無空窗**（準人選立即就任） |
| **沒有中立的仲裁者** | 權限爭議一律由**憲法法院**裁判（[`08`](08-司法權與憲法法院.md) §3）；憲法不設政治性仲裁 |
| **儀典由一個有黨籍的人主持** | 明白承認。國家儀典的形式由法律定，首長不得變更 |
| **沒有「共和國的守護者」條款** | 現行憲法第 5 條那種概括授權在本夾不存在；緊急狀態的權力由 [`09`](09-緊急狀態.md) 封閉列舉 |

★ 第四列是刻意的：**現行第 16 條（總統的例外權力）的憲法基礎正是第 5 條的守護者條款。** 本夾拿掉守護者條款，第 16 條式的概括例外權力就沒有落腳處。

### 2.4 議長：主持議事，不是元首

議會設議長 1 人、副議長 3 人，由全院記名排名投票選出，任期 4 年。

**議長的權力**：主持議事、決定議程順序（受議事規則拘束）、於首長逾期不公布法律時公布之。

**議長不是元首、不代表國家、不得對外締約、不得主持國家儀典。**

★ 這一條要寫明，否則「沒有元首」會在實務上把議長變成元首。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 首長出訪期間 | 副首長代行國內職務；**對外代表權不移轉** |
| 首長死亡 | 副首長代理全部職務至新首長就任 |
| 首長與副首長同時出缺 | **議長暫行行政首長職務**，並須於 15 日內完成新首長之選出 |
| 條約已簽署但議會不批准 | 條約不生效；首長不得以行政協定規避 |
| 首長拒絕公布法律 | 逾 15 日由議長公布，效力相同 |
| 有人主張某爭議應由「國家元首」仲裁 | **無此職位，無此程序**；屬權限爭議者送憲法法院 |
| 國喪、閱兵等國家儀典 | 由首長主持；首長出缺時由副首長，再次為議長 |
