# 行政權預算與供給

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `1-優化/財政.md` | 非硬性 | **信任供給合一**：禁止只撤供給、不撤信任；提供者須相同。**規劃保障的供給**對應於**部分行政權預算**（如：政策裁量性資本門支出、預備金與政務應變預算；**不含**法定義務支出、歲入、稅制） |
| `1-優化/財政.md` | 非硬性 | **議會制：建設性不信任＋行政權供給自動通過（參考自法國憲法第 49.3 條）**。若某些議員期限內不通過更新信任案，政府提出的供給自動生效 |
| `1-優化/財政.md` | 非硬性 | **法國的問題：政體錯配，建設性不信任案不適用於「總統決定總理」的情況，故只有供給保障但沒有信任保障** |
| `1-優化/行政立法/共用.md` | 可選 | **僅單一席次而非複數席次議員表決預算**，避免預算上人多嘴雜而難達成共識 |
| `配置/法國/總體.md` | **硬性** | 避免政府如在第四共和、2025 倒閣潮不穩 |

★ **本夾是提示詞裡那條「參考自法國憲法第 49.3 條」的原產地。** 提示詞從法國借來供給的形狀，又指出法國自己少了信任那一半——本檔把兩半補齊。

**預提行政權預算是總統制的解法**（`1-優化/財政.md` 的可選條件明寫「總統制」），本夾不適用。

## 2 規則（主路徑）

### 2.1 框架

供給的授權者是單一席次 230 名議員，**而授權的預設值是給，不是不給**。「部分」的限制由 §2.2 的封閉列舉落實。

### 2.2 規劃保障的供給（範圍，封閉列舉）

1. 政策裁量性資本門支出。
2. 預備金與政務應變預算。
3. 行政機關經常門運作費用。
4. **列名**政策計畫的經常門支出。

**不含**：法定義務支出、歲入、稅制、非行政部門預算、中央對地方之財政移轉公式。

法定義務支出（已立法之給付、社會保險、債務還本付息、確定判決）**始終撥付**，不需年度議決。

### 2.3 自動生效

政府將供給案送達單一席次議員後：

- 若 **15 個開會日**內未通過建設性更新信任案，該供給案**生效**。
- 230 人仍得在生效前以 **≥116** 通過建設性更新，順便換掉政府。

> **拒絕這筆錢與換掉這個人是同一個動作。想拒絕供給的人必須拿出繼任者。**

### 2.4 這與第 49.3 條哪裡不同

形狀來自 49.3。**差別四處，每一處都對應提示詞自己指出的問題**：

| | **法國現行第 49.3 條** | **本夾** |
|---|---|---|
| 提案的政府從哪來 | **總統指定的總理** | **230 名單一席次議員自己選出的首長** |
| 議會的回應 | 不信任案（第 49.2 條），**不必提繼任者** | 建設性更新，**不提繼任者不予受理** |
| 倒閣之後 | **下一任總理仍由總統指定**——議會拆掉的東西自己組不回來 | 通過的那一刻準人選就任 |
| 性質 | 政府主動按下的挑釁按鈕，每次使用都被解讀為藐視議會 | **預設值**：不作為即生效 |

★ 第一行正是 `1-優化/財政.md` 點名的**政體錯配**。**本夾沒有一個可以指定首長的總統，錯配不成立，建設性不信任因此真的用得上。**

★ 第三行是 2025 年的實際形狀：Barnier 被倒閣後，議會沒有取得任命權，總統改任命 Bayrou；Bayrou 落敗後，程序再跑一次。**議會每一次行使權力都只讓自己回到原地。**

### 2.5 沒有第 49.3 條的次數限制

現行第 49.3 條在 2008 年修憲後被限制為「預算與社會保險財務法案不限次數，其餘每會期一次」。

**本夾不設次數限制**，因為限制的理由在本夾不存在：

| 為何 2008 年要限次 | 在本夾 |
|---|---|
| 49.3 是政府單方面繞過議會表決的工具 | 供給案的**授權者本來就是選出這個政府的那 230 人** |
| 用得太多等於架空議會 | 議會隨時能以 116 票換人，**而換人與拒絕供給是同一個動作** |
| 議會的唯一回應是倒閣，代價過高 | 建設性更新的代價**不高**——它不解散議會、不重啟屆期、不需要總統同意 |

### 2.6 非供給的行政歲出

規劃保障的供給以外的行政歲出，由單一席次議員 **≥116** 議決：

- **得刪不得增。**
- 不得把整案凍結為零。
- 附條件通過視為未通過。
- 會計年度開始後 **60 日**未作成議決者，**沿用上一年度已議決額度**。

★ 沿用條款是自由發揮，理由自負：`1-優化/行政立法/共用.md` 的非硬性把**美國政府因兩大黨對立而預算停擺**列為要避免的事。**一個把停擺列為反例的提示詞，不會希望本設計自己留一個停擺開關。**

### 2.7 複數席次不參與

170 名複數席次議員不表決任何行政權預算。他們的場域是法律、組織法、修憲與非行政部門預算（[`04`](04-其餘預算與審計權.md)）。

**結構性後果**：執政多數（116／230）與立法多數（201／400）可以是不同的人。**政府能活，大法案仍可能卡住。**

★ 這一點在法國夾要特別交代，因為配置硬性只要求**政府穩定**，沒有要求**立法順暢**。本夾滿足前者、明白承認後者是代價，寫進 [`15`](15-完善與自洽.md)。

### 2.8 歲入與稅制不在供給裡

歲入與稅制由**全院 ≥201** 議決，不適用自動生效。

★ `1-優化/財政.md` 對「規劃保障的供給」的範圍寫得很明確：**不含歲入、稅制**。本夾照做。

**後果**：政府能保住它的裁量支出，但**不能單方面決定收入**。一個 116 票的政府若想加稅，仍要說服全院 201 人。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 供給案送達後政府更迭 | 新首長得撤回並重送，15 個開會日重新起算 |
| 15 個開會日內提出建設性更新但未通過 | 供給案於表決日**次日**生效 |
| 建設性更新通過 | 供給案失效。新首長重送，期限重新起算 |
| 供給案逾越 §2.2 的封閉列舉 | 逾越部分無效，其餘部分仍適用自動生效 |
| 範圍有爭議 | 屬權限爭議，由**憲法法院**裁判；未決期間該項目暫依上年度額度撥付 |
| 歲入不足 | 法定義務優先撥付；供給案內裁量支出依政府提出並經單一席次 ≥116 同意的減列順序削減；**未及議決者按比例齊頭削減** |
| 非供給歲出逾 60 日未決 | 沿用上年度已議決額度，**不歸零** |
| 議會拒絕開議以規避期限 | 期限依**曆日**併計，不因不開議而中止 |
| 單一席次出缺 | 分母仍 230，門檻仍 116 |
| 緊急狀態期間 | 預備金與政務應變得先行動支，30 日內補送單一席次備查（[`09`](09-緊急狀態.md)） |
