# 人選更新

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/總體.md` | 硬性 | **更新人選條件**是必須交代的憲政選擇之一 |
| `0-基本/行政立法/一院議會制.md` | **硬性** | 最高行政首長的**更新方式：某些議員投票** |
| `1-優化/投票.md` | 可選 | **直接投票的單一席次職位的人選更新**：第一輪選出前 k−1 名，第二輪對「k−1 個備胎＋現任」共 k 人採孔多賽完成法；**備胎需在和現任者的兩兩對決中得到一定票數**才能替換現任，反之現任留任 |
| `1-優化/投票.md` | 可選 | **直接投票的複數席次職位的人選更新**：選區內**全部席次重選**，無單獨對任一人罷免 |
| `1-優化/投票.md` | 非硬性 | 兩輪的決選與其他單輪投票同日 |

★ **本夾不繼承** `配置/台灣` 那條「總統更新不應讓立法權凌駕人民罷免權」——那在台灣夾。而**本夾沒有直選的行政首長**，那條的前提也不存在。

## 2 三種更新，三套規則

| 對象 | 誰更新 | 規則 |
|---|---|---|
| **行政首長** | 單一席次 230 | 建設性更新 ≥116（[`02`](02-政府組成與建設性更新.md) §2.4） |
| **單一席次議員** | 該選區選民 | §3：top-3 孔多賽備胎制 |
| **複數席次議員** | 該選區選民 | §4：**全區重選**，無單獨罷免 |

★ 憲法法院法官、審計委員**不設人選更新程序**——任期 9 年、不得連任、每 3 年改選三分之一，且由三組分別選出。**更新的路徑是等任期，不是罷免。** 理由：可罷免的裁判者不是裁判者。

## 3 單一席次議員的更新

`1-優化/投票.md` 可選條件，本夾**逐字採用**。

| 步驟 | 規則 |
|---|---|
| 提議 | 該區選舉人 **2%** |
| 連署 | 該區選舉人 **8%**，期間 60 日 |
| **第一輪** | 選出**前 2 名備胎**（k＝3，故 k−1＝2）。現任**不參加第一輪** |
| **第二輪** | 對「2 名備胎 ＋ 現任」共 **3 人**採孔多賽完成法。票面為 **6 個完整排序選項供單選** |
| **替換要件** | 勝出的備胎須同時滿足：**(a) 為孔多賽勝者**；**(b) 在與現任的兩兩對決中得票 ≥ 該區選舉人總額 25%** |
| 未滿足 | **現任留任** |
| 就任 | 替換者任期至本屆屆滿 |
| 冷卻 | 同一議員一屆內至多被提一次；**就職未滿 12 個月不得提** |

★ (b) 的地板是提示詞明寫的「備胎需在和現任者的兩兩對決中得到**一定票數**」。取 25%，比公投的 20% 高一級，理由：**更新一個已當選者，比通過一項法規範更需要正當性。**

★ **這套設計取消了「罷免」與「補選」的兩段式。** 現行台灣式的兩段罷免（先罷免、再補選）讓反對者只需在第一段集中，第二段可能由更少的票選出繼任者。**本夾把兩段合成一場三人對決：拿掉現任的人必須同時說出誰來接。**

★ **與建設性更新是同一個原理。** 議會裡拆首長要說出繼任者，選區裡拆議員也要說出繼任者。[`13`](13-憲政選擇.md) 把這一致性列為一項。

## 4 複數席次議員的更新

`1-優化/投票.md` 可選條件，本夾**逐字採用**：**選區內全部席次重選，無單獨對任一人罷免。**

| 項目 | 規則 |
|---|---|
| 提議 | 該區選舉人 **3%** |
| 連署 | 該區選舉人 **10%**，期間 60 日 |
| 效果 | 該複數選區**全部 M 席重選**，依 [`01`](01-國民議會與選制.md) §2.3 的彈性名單與聖拉古 |
| 新任期 | 至本屆屆滿 |
| 冷卻 | 同一選區一屆內至多一次；**屆期最後 12 個月不得發動** |
| 原任者 | 得再度參選 |

★ 為什麼不能單獨罷免其中一人：**複數席次的當選是名單與聖拉古分配的結果，拿掉一個人會改變整個分配。** 單獨罷免等於讓一次局部投票改寫全區的比例性。

★ 門檻（3%／10%）**高於單一席次**（2%／8%）：發動一次全區重選的影響面是 8–14 席，代價應對應影響面。

## 5 行政首長

見 [`02`](02-政府組成與建設性更新.md) §2.4。要點：

- 更新者是**單一席次 230**（`0-基本` 硬性：某些議員投票）。
- **沒有純否定式倒閣**——拆與換是同一個動作。
- 門檻 ≥116，與新首長就任所需的門檻**相同**。
- **不重啟屆期**，議會做滿 4 年。

★ **首長不必是議員。** 若首長同時是單一席次議員而被其選區以 §3 更換，他**喪失議員身分，首長職務不受影響**——首長職務的更新只有一條路：建設性更新。

## 6 投票日

一切人選更新投票與公投、定期改選**同日舉行**，每年至多兩個投票日（4 月與 10 月的第三個星期日）。

★ `1-優化/投票.md` 非硬性的落點；同時是對「連署完成即立刻投票」的替代——**連署完成後至最近一個投票日之間的等待期，本身就是一次冷靜期。**

★ 若連署完成日距最近投票日不足 45 日，順延至下一個投票日。

## 7 狀態

| 狀態 | 怎麼走 |
|---|---|
| 單一席次第一輪只有 1 名備胎登記 | 第二輪為 2 人對決，(b) 的 25% 地板仍適用 |
| 無人登記為備胎 | 更新案不成立，現任留任 |
| 備胎為孔多賽勝者但兩兩對決僅得 22% | **現任留任** |
| 現任於程序中辭職 | 更新案轉為**補選**，依 [`01`](01-國民議會與選制.md) §2.2 的 top-3 孔多賽 |
| 複數選區重選後席次分配不變 | 合法且常見；**發動者承擔這個風險** |
| 更新投票與定期改選同日 | 定期改選優先，更新案自動失效 |
| 更新期間該議員參與表決 | **不受限制**——更新未完成前他仍是議員 |
| 首長被其選區更換 | 喪失議員身分；**首長職務不受影響** |
| 憲法法官被要求罷免 | **無此程序** |
