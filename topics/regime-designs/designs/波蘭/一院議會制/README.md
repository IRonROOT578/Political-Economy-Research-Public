# 波蘭：一院議會制

本憲政設計最新更新：2026-11-11

## 一句話

**取消參議院**；眾議院 **340＝單一 204（top-3 孔多賽）＋複數 136（彈性名單、無法定門檻、12 國內區＋海外）**；總理由**全院記名排名投票**選出（≥171），**總統不提名**；總統仍直選（top-3 孔多賽），但只有**擱置否決**（全院過半推翻）；建設性更新、無解散、固定選舉日、供給自動生效；組織法要**兩種多數**；**憲法法院 12 人三組、判決自動生效**；司法委員會法官互選；**檢察總長與司法部長分離**；公投用支持票地板；公共媒體理事會 STV、財源列組織法。

## 三個最容易讀錯的地方

**一、2023 年放大的是第三條路，不是 PiS 或 KO。** 決選三人多半是 PiS、KO、TD；兩大陣營的選民都把 TD 排在對方前面。TD 以 14.4% 第一偏好拿到全院 138，當選者第一偏好中位數只有 17.5%（[`12`](12-預期政治生態.md) §6.1）。

**二、2019 年 PiS 仍單獨過半（171，剛好），但改不了法院。** 組織法要全院 3/5 且複數 3/5，PiS 只有複數 56（[`05`](05-法規位階與修憲.md)）。

**三、總統還是直選，但不能卡政府。** 2025 年在本夾當選的是中間的 TD（2023 名單票；現實第一輪對照下是 PiS），但否決全院過半就推翻、不提名總理、不任命法官（[`04`](04-總統.md)）。

## 本夾承認做不到的事

- **居中黨被放大**：一個 14–21% 第一偏好的黨可以單獨或主導執政；防線放在組織法。
- **小黨當總理人選**：議員排序的算術。
- **2018 年以後任命的法官**：不處理。
- **完全不論轉型可行性**。
