## 1 本檔繼承

## 2 規則（主路徑）

### 2.1 三層

1. **憲法**
2. **基本法**（中位法那條硬性要的那一層；本夾稱基本法）
3. **法律**

**位階由內容決定，不由名稱決定。** 一部法案若涉及下列列舉事項，即須以基本法程序通過；以普通法律程序通過者，該部分無效。

### 2.2 基本法事項（封閉列舉）

1. 選舉與公民投票程序。
2. **選區劃分規則**與人口偏差上限（含國民院與參議院大區劃分與 M 的配置）。
3. 政黨與公民連署名單的登記。
4. 中央與地方之財政劃分、移轉公式。
5. 文官制度、考選與銓敘基準。
6. 審計制度。
7. 法院組織與法官任用、身分保障。
8. 監察院、考試院之組織。
9. 緊急狀態的法律效果。
10. 國籍。
11. 貨幣。
12. 國防義務。

清單是封閉的。要增加事項，只能修憲。

### 2.2.1 躍升門檻不在基本法

**躍升門檻（該區 Droop 額數的 25%）寫在憲法，不是基本法。** 理由同 [`01a`](01a-國民院組成與選制.md) §2.3：把旋鈕交給名單受益者，等於把黑金硬性交給利害關係人自行處分。選區劃分與 M 的配置留在基本法（第 2 項）。

### 2.3 普通法律（兩院路徑）

| 步驟 | 規則 |
|---|---|
| 1. 國民院通過 | 同意 **> 總額半數（≥76／150）**；缺席與棄權計入分母 |
| 2. 參議院表決 | **60 日內**須表決；屆期由議長逕付表決。同意 **> 總額半數（≥38／75）** 即成立 |
| 3. 參議院不同意或修正 | 進**協調委員會**：兩院各派 10 人（依各院政黨比例），30 日內提出協調案 |
| 4. 協調案 | 兩院各自整案表決，門檻同第 1、2 步；任一院不通過，**法律不成立** |
| 5. 公布 | 行政首長須公布；**無法律覆議權** |

**雙重同意沒有覆寫。** 國民院不能以超多數推翻參議院——那正是 `配置/個人偏好/行政立法/兩院議會制.md` 硬性排除的。**供給與信任不在此路徑**：只看國民院（[`02`](02-行政首長.md)、[`03`](03-行政權預算與供給.md)）。

法律採「同意 > 總額半數」是可選條件的**第二支（行動通過門檻）**。**突襲立法不成立。**

**不採第一支（受影響方否決）**：界定「誰是受影響方」本身會變成新的爭議場域——Herding cats。

本夾是議會制：行政首長由國民院全院 150 產生。再給首長法律覆議權，等於同一多數既提案又有第二次否決——Herding cats。參議院的同意權是**立法內部**的第二把鑰匙，不是行政否決。

### 2.4 基本法

| | 通過 |
|---|---|
| 國民院 | **≥90（3/5）** |
| 參議院 | **≥45（3/5）** |
| 行政覆議 | **無** |

兩院皆須通過；無跨屆要求（與修憲的差別）。任一院未達則不成立。

### 2.5 穩定性與彈性

| | 穩定性 | 彈性 |
|---|---|---|
| 基本法 | 兩院各 3/5；無行政覆議；事項封閉列舉 | **不需跨屆、不需人民複決** |
| 普通法律 | 兩院各自過半；協調委員會有期限 | 一屆內可完成 |

**人民可投票修改基本法**是獨立硬性，見 [`06`](06-修憲與人民修改法規範.md) §3。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 法案內容跨基本法與普通法律 | 全案走基本法程序；或拆案分別通過。以普通法律通過的基本法事項部分無效 |
| 位階有爭議 | 司法院認定（[`09`](09-司法院.md)） |
| 基本法牴觸憲法 | 該條文無效 |
| 行政命令牴觸法律 | 無效 |
| 行政首長對已通過之法律拒不公布 | 逾 15 日未公布者由國民院議長公布；國民院議員 ≥38 得聲請司法院確認公布義務 |
| 參議院 60 日內未排入議程 | 議長逕付表決 |
| 協調案任一院未通過 | 法律不成立；得於同會期內容實質變更後再提 |
| 同一會期同一法案被否決後再提 | 須有新的提案人組成或內容實質變更，否則不予受理 |
