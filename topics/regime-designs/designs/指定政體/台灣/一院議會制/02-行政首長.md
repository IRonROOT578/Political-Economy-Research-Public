# 行政首長

## 1 本檔繼承

## 2 規則（主路徑）

### 2.1 某些議員 ＝ 全院 180

理由見 [`00`](00-讀法與推導.md) §3.1：信任與供給都由全院給，提供者相同；政府多數就是立法多數。

過半 **91**。

### 2.2 選出（新屆）

新屆集會後 **7 個開會日**內：

1. 全院 180 人以**記名排名投票**選出行政首長。排名可截斷、可並排。
2. 以孔多賽完成法決出勝者（循環時 Ranked Pairs）。**一次計票**，不拆多輪刷尾。
3. 勝者即為行政首長，**無須另行同意投票**。

無現任時不適用對決門檻——第一次產生不需要贏過任何人。

**7 個開會日是硬期限。** 逾期：改為每個開會日一輪、篩掉排名最後一名，直到只剩一人（自由發揮，回答荷蘭組閣過長）。

**沒有「談不攏就繼續談」這個選項。** 這是對荷蘭 299 日組閣的直接回答（[`13`](13-反例診斷.md) §6.1）。

**對決強度用勝方得票，不用勝差。** 議員的排名可以截斷、可以並排，所以某一場對決裡可能有人不表態；每場的參與票數不同，兩種量法會分岔。

★ 分岔的地方正是可操弄的地方。100 名議員，三位人選甲、乙、丙：

| 人數 | 真實排序 |
|:--:|---|
| 49 | 甲 > 丙 > 乙 |
| 40 | 乙 > 丙 > 甲 |
| 11 | 丙 > 甲 > 乙 |

真實排序下丙對甲 51:49、丙對乙 60:40，**丙是兩兩對決贏家**。現在甲派 49 人只排甲、其餘留白：

| 對決 | 票數 | 勝差 | 勝方得票 |
|---|:--:|:--:|:--:|
| 甲對乙 | 60:40 | 20 | 60 |
| 丙對甲 | 51:49 | **2** | 51 |
| 乙對丙 | 40:11 | 29 | **40** |

循環出現。**勝差**下最弱的是「丙勝甲」（差 2），丟掉它 → **甲當選，留白成功**。**勝方得票**下最弱的是「乙勝丙」（40），丟掉它 → **丙仍當選**。那 49 人留白讓「乙對丙」只剩 51 人表態，勝差把這場算成乙大勝；勝方得票只看乙那邊有幾個人明白表態，40 人不因別人留白而變多。

★ 記名讓留白看得見，但看得見不等於擋得住；擋得住的是量法本身。

行政首長**不必是議員**。

### 2.3 職權

- 負責行政；任免政務人員；指揮行政部門。
- **兼國家元首**：對外代表國家、公布法律、主持國家儀典（[`00`](00-讀法與推導.md) §3.2）。
- 提出法律案與行政權供給案。
- 依 [`07`](07-緊急狀態.md) 宣告緊急狀態。
- 統帥武裝力量。**宣戰須全院 ≥120（2/3）同意。**

**無法律覆議權**——他由議員選出，再給他一個擋議會的工具沒有道理（[`05`](05-法律與法規位階.md) §2.3）。

### 2.4 更新（建設性）

| 項目 | 規則 |
|---|---|
| 提案與提名 | 議員 **1/4（≥45）** 連署發動，且**須於提案書中載明挑戰人選姓名**；成案後 48 小時內，其他 ≥45 名議員亦得連署提名挑戰人選 |
| 未載明 | **不予受理**，不列入議程 |
| 決定或選出準人選 | 僅 1 名挑戰人選時，逕行**決定出**為**最高行政首長準人選**；有 2 名以上挑戰人選時，先由全院 180 人以**記名排名投票**（孔多賽完成法，循環時 Ranked Pairs）**選出**一位**最高行政首長準人選**（`1-優化/行政立法/議會制.md` 可選） |
| 對決表決 | **最高行政首長準人選**與現任的**兩兩對決**，記名 |
| 通過 | 最高行政首長準人選得 **≥91／180** |
| 效果 | 最高行政首長準人選就任，現任同時解職 |
| 未達 | **現任留任** |
| 冷卻 | 失敗後 **3 個月**內同一提案人不得再提 |
| 每會期上限 | **2 次** |
| 屆期 | **不重啟。** 議會做滿 4 年 |

**「不載明繼任者即不予受理」是本夾對威瑪消極多數的直接回答；多名挑戰人選先由全院排名投票選出一名的機制，則避免在野各黨搶遞案順序或彼此分散票源。**

### 2.5 不得只撤供給、不提繼任者

- 拒絕行政權供給的**唯一途徑**，是在期限內通過建設性更新信任案（[`03`](03-行政權預算與供給.md)）。
- 不存在「否決供給但保留現任」的表決選項；議事規則不得設置這種動議。

### 2.6 無解散權

行政首長不能解散議會。理由見 [`00`](00-讀法與推導.md) §3.3。

代價：僵局沒有「訴諸選民」這條路。本夾接受——**一個能在內部換掉首長的議會，其僵局本來就可以在內部解決**。

### 2.7 政府成員

首長任免政務人員，不需議會同意。議會得質詢、調查，得對個別政務人員提出**譴責案**（全院 ≥91），但**譴責不生解職效力**——解職只有一條路，就是換掉首長本人。

理由：若個別部長可被議會逐一拔除，行政的組成就變成逐案談判，那是 Herding cats。

### 2.8 副首長

由首長於就任時提名，經全院 ≥91 同意。首長出缺時代理，並於 7 個開會日內依 §2.2 重選。

副首長代理期間**不得**宣告緊急狀態、不得任免政務人員。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆逾 7 個開會日未選出 | 改為每開會日一輪刷尾，直到剩一人 |
| 首長死亡、辭職、永久不能視事 | 副首長代理，**7 個開會日**內重選。**不重啟屆期，議會不被解散** |
| 更新案挑戰人選於表決前退出 | 若僅此 1 人則該案失效；若尚有其他已提名挑戰人選則照常進行 |
| 兩名以上挑戰人選同時成案 | 先由全院 180 以記名排名投票（孔多賽完成法）選出一位最高行政首長準人選，再與現任兩兩對決 |
| 兩兩對決同票 | 現任留任 |
| 準人選當選後拒絕就任 | 該案視為未通過，適用 3 個月冷卻 |
| 首長長期不能視事 | 全院 ≥91 得認定，副首長代理並於 7 個開會日內重選 |
| 出缺致實際人數不足 180 | **分母仍 180**，門檻仍 91 |
| 緊急狀態期間 | 更新程序**不中止**（[`07`](07-緊急狀態.md)）。宣告狀態的人不因此獲得保護 |
| 會期外 | 1/4 連署得要求召開臨時會，議長應於 7 日內召集 |
