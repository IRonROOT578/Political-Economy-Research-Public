## 一句話

180＝單一 100（top-3 孔多賽）＋複數 80（彈性名單、聖拉古、無門檻）。正副總統由人民 top-3 孔多賽選出，並得綁定四年**任期供給案**：選前 21 日公告，人民選出即同時給信任與供給；任內調整須總統與全院 ≥91 同時同意；**被人民更新就終止，改用勝出挑戰者的案**。挑戰者（非在位者）的案與更新第一輪登記一併公告。**不設金額上限。** 人民端的修憲複決、公投、總統更新、議員更新共用一套替代現狀方式。

## 生態的一句話

生態模型下，總統那一場三屆都是全國循環：第 3 屆國民黨候選人當選，但一對一輸給民進黨候選人 48.7 : 51.3。總統與單一席次多數同黨，雙鑰匙兩把在同一手上；預提只在分裂政府時吃重——例如民進黨選民有 60% 把民眾黨排在國民黨前面時，民眾黨贏得總統，而國民黨仍握單一 61 席（[`15`](15-預期政治生態.md)）。
