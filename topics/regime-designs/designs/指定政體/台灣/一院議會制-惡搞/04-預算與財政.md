# 預算與財政

## 1 本檔繼承

`0-基本/總體.md` 把「預算處理」列為必須交代的憲政選擇。`0-基本/財政.md` 無任何條件。

**不繼承**：`1-優化/財政.md` 的**信任供給合一**、規劃保障的供給、**議會制的建設性不信任＋供給自動生效**；`配置/雜項/財政.md` 的防餓死機制與沿用條款。

★ 第二項的缺席特別關鍵：**`1-優化/財政.md` 明白給了議會制一條解法——「建設性不信任＋行政權供給自動通過」。本夾兩半都不繼承。**

## 2 規則（主路徑）

### 2.1 誰決定，能做什麼

全院 225 人，**出席過半**。得**增列**科目，得刪減至**零**，**法定義務支出亦得刪**。

### 2.2 沒有信任供給合一

`1-優化/財政.md` 不繼承。所以本夾出現議會制底下最荒謬的一種組合：

> **議會可以既不倒閣、又不給錢。**

★ 想拆政府的人**不必倒閣，餓死它更省事**——倒閣還要面對「拆掉之後誰上」的難題（雖然本夾連繼任者都不必提，但選不出來的話還是那個人在看守），**餓死不用**。

### 2.3 半條沿用條款，故意留錯

| 情形 | 規則 |
|---|---|
| **看守期間**（無正式政府） | 預算**沿用上一年度**——**但仍得增列新科目** |
| **有正式政府時** | 無沿用條款。新政府送的預算若被刪至零，就停擺 |

★ 這是本夾唯一一條看似仁慈的規定，而它的效果是：**看守政府＋沿用預算＋可增列 ＝ 一個沒有多數支持的人可以無限期地花去年的錢，還能加新的。**

### 2.4 於是理性的議員偏好維持空窗

★ **本夾對「沒有政府」的容忍度高於對「有政府」的容忍度。**

| | 有正式政府 | 看守期間 |
|---|---|---|
| 預算 | 可被刪至零 → 停擺 | 沿用上年度，**不會停擺** |
| 增列 | 要跟政府談 | **看守首長自己就能加** |
| 議員的籌碼 | 與一個有正當性的政府談判 | 與一個**沒有多數、急需不被倒閣**的人談判 |

★ 最後一列是關鍵：**看守首長比正式首長更好談**——他沒有多數，任何一票都值錢。

**於是「不組閣」成為地方派系與小黨的最優策略。這不是失序，是均衡。**

### 2.5 三院預算沒有保護

看守首長得先刪司法院、監察院、考試院的預算再送議會；議會得再刪至零。與總統制惡搞夾相同（[`../一院總統制-惡搞/04-預算與財政.md`](../一院總統制-惡搞/04-預算與財政.md) §2.5）。

### 2.6 決算

監察院有審計權但湊不齊人（[`06`](06-三院.md)）。決算實務上由議會自己看自己——而議會的組成兩年翻一次。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 有正式政府、年度開始未通過預算 | 裁量支出**歸零**，機關停工 |
| 看守期間、年度開始未通過預算 | **沿用上年度**，並得增列 |
| 看守期間增列科目 | **合法**，無限制 |
| 法定義務支出被刪 | 合法，該給付停發 |
| 剛選出正式首長就遇到年度開始 | **失去沿用保護**——這是選出政府的一項代價 |
| 三院預算被刪至零 | 停止運作；無救濟 |
| 未執行餘額 | 無繳庫規定，得留用 |

★ 倒數第三列值得單獨看：**選出一個正式政府，反而讓國家失去停擺保護。** 這是本夾把誘因設反的最清楚的一處。
