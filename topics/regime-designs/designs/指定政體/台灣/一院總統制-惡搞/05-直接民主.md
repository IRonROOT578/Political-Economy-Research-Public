# 直接民主

## 1 本檔繼承

`0-基本/總體.md` 把「人民修改法規範條件（如：對象範圍、效力範圍）」列為必須交代的憲政選擇。

**不繼承** `1-優化/投票.md` 的三版本公投（領銜人版本／政府版本／維持現狀＋6 格排序＋兩要件）。

## 2 規則（主路徑）

### 2.1 諮詢性公投

| 項 | 規則 |
|---|---|
| 連署 | 選舉人 **1%** |
| 次數 | 一年最多四次 |
| 票面 | **單題、同意／不同意** |
| 效力 | **無拘束力** |

憲法明文：

> 公民投票之結果為**人民意向之表達**，政府與議會**應予尊重**，**不得據以直接變更法律**。

### 2.2 對象範圍與效力範圍

`0-基本/總體.md` 要求交代這兩件事，本夾的答案很短：

| 標的 | 可否 | 效力 |
|---|---|---|
| 法律 | 可提案 | **無拘束力** |
| 憲法 | 可提案 | **無拘束力** |
| 預算、稅制 | 可提案 | **無拘束力** |
| 個案 | 可提案 | **無拘束力** |

**什麼都能問，什麼都不算數。**

★ 這是本夾對那條要求的字面滿足：對象範圍是「全部」，效力範圍是「零」。

### 2.3 為什麼保留它

**因為它是本夾最重要的正當性零件。**

★ 人民一年投四次票，投票率高，國際媒體寫「台灣人熱衷公民參與」。**沒有人追問結果有沒有被執行**——因為憲法白紙黑字寫著它不必被執行。

★ 而且它有一個副作用：**理念型的政治人物會被吸引到公投路線**——一年四次、門檻低、聲量大、責任零。於是他們不去爭取那 38 票，議會裡少了他們，兩大黨的對決更純粹。

### 2.4 自由民主投票日

憲法定每年 **12 月第三個星期六**為「自由民主投票日」：

- 全國放假。
- 各級機關舉辦慶典。
- **選務機關公告我國在各國際民主指數的排名，並與威權國家對照。**

這一條不影響任何權力分配，純粹是把「我們有他們沒有的自由、民主、投票」寫進憲法本文。

★ 而排名的兩個項目長期分裂：「選舉自由」名列前段，「政府效能」墊底。**慶典只念前半段。**

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 公投通過但政府不執行 | 合法。無任何後果 |
| 同一議題重複提案 | 無限制 |
| 一年逾四次成案 | 依連署完成先後，逾額者順延至次年 |
| 公投與選舉同日 | 得合併辦理 |
| 政府提出對案 | 無此制度；只有領銜人版本 |
