# 完善與自洽

## 1 條件的落點

| 條件 | 位階 | 落點 |
|---|---|---|
| 不用電子計票 | **硬性** | 人工公開唱票（維持） |
| 兩院直選、至少一院有地方代表性 | 在 `2-配置/台灣/基本/` 與 `2-配置/雜項/`；本夾自願採用 | 眾議院 110 個單一選區、參議院 81 個單一選區 |
| 首長由某些議員選出與更新 | **硬性** | 眾議院全院 200 |
| 法官不當記名投票的投票權人 | **硬性** | 名冊投票與法官互選皆祕密（名冊含最高法院法官） |
| 開放名單黑金 | **硬性** | 彈性名單 |
| 人選不能被杯葛 | **硬性** | [`07`](07-司法權與檢察.md) §5 |
| 不得把提示詞當預期生態 | **硬性** | [`12`](12-預期政治生態.md) §5：三處不合，四項設計因此改過或確認 |
| 信任供給合一 | 非硬性 | 選首長、更新、供給都是眾議院全院 |
| 建設性更新、供給自動生效 | 非硬性 | [`02`](02-政府組成與建設性更新.md)、[`03`](03-預算與供給.md) |
| 決選與單輪同日 | 非硬性 | B 日：所有第二輪＋所有單輪投票 |
| 高政治性裁決從中間向兩側、不審思想 | 非硬性 | 憲法法院並行多數；部長任命不審言論 |
| 適合該國 | 非硬性 | 保留運作良好的部分，只改出過事的零件 |

## 2 張力

| # | 張力 | 處置 |
|:--:|---|---|
| 1 | **向心選制 vs 少數得票的多數政府**：ANO 以約 33% 單獨過半 | 政府歸孔多賽贏家；規則歸比例層與參議院 |
| 2 | **決選投票率 vs 參議院的制衡**：提高投票率讓參議院跟著眾議院走 | 參議院仍分期改選；乙組法官改由比例層選 |
| 3 | **不審言論 vs 不適任的部長**：總統不能再擋 Turek 這類人選 | 責任回到總理和眾議院 |
| 4 | **一般公投 vs 歐盟、北約成員資格** | 地板 25%（約 206 萬支持票）；這是設計上接受的風險 |
| 5 | **檢察自治 vs 政治問責** | 檢察委員會含比例層和名冊成員；抽籤調查庭 |

## 3 自洽檢查

| 檢查 | 結果 |
|---|---|
| 是否存在「沒有信任的政府」 | 否 |
| 是否存在「沒有預算」 | 否：供給自動生效、非供給沿用 |
| 總統能否卡組閣、卡部長 | 否 |
| 一個政黨能否單獨改規則 | 否：所有情境中單一政黨的複數席次最高是 ANO 30／90（門檻 54） |
| 是否有機關能決定選舉日 | 否 |

## 4 本夾不宣稱能做到的事

- **不宣稱捷克的制度原本很糟。** 它是四夾外國設計裡最健康的一個。
- **不宣稱能防止一個居中政黨長期執政。** 防的是同一政黨改寫規則。
- **不宣稱 2021 年新制的結果比現實「更對」。** 那取決於是否接受孔多賽（[`12`](12-預期政治生態.md) §5.2）。
- **不宣稱參議院會維持現在的性格。**
- **不宣稱模型的偏好位置是對的。**
- **完全不論轉型可行性。**
