# 預算與供給

`1-優化/財政.md`（信任供給合一；供給自動生效）；`1-優化/行政立法/共用.md`（避免預算不決）。

| 項目 | 規則 |
|---|---|
| 規劃保障的供給 | 政策裁量性資本門、預備金、行政機關經常門、列名政策計畫（封閉列舉）；不含法定義務支出、歲入、稅制、大區公式化移轉 |
| 自動生效 | 送達後 **20 個開會日**內未通過建設性更新（≥201），供給生效 |
| 國會修正 | **得刪不得增**；現行財政法案的「微型撥款修正案」（議員的地方加碼）不再可能 |
| 非供給歲出 | ≥201，得刪不得增；60 日未決沿用上年度（取代「臨時預算執行」esercizio provvisorio） |
| 歲入、稅制 | ≥201 |
| 財政規則 | 憲法第 81 條的平衡預算原則保留；細則屬組織法；議會預算辦公室（UPB）每年公告是否遵守 |
| 審計法院 | 保留；院長由三組選出 |

★ 義大利的預算每年 12 月底以信任案綁著過關，國會沒有逐項審議的機會。本夾讓預算**不必綁信任案也一定過**（自動生效），國會反而能逐項刪減。
