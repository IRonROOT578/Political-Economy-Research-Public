# 芬蘭：一院議會制

本憲政設計最新更新：2026-11-11

## 一句話

國會 **200＝單一 120（本土 119＋奧蘭 1，top-3 孔多賽）＋複數 80（八區彈性名單、聖拉古、無法定門檻）**；廢強制開放名單與 d'Hondt；首長全院排名投票選出（棄權不計）、30 日預設值；建設性更新、禁技術性總辭轉看守、**無解散**；總統直選改 top-3、削第 93 條第 1 項；憲法法院 12 人三組；**保留限度例外法（雙重 2/3＋≤1 年日落）**；福利區須有自有稅源。

## 三個最容易讀錯的地方

**一、芬蘭已是一院——本夾不是廢上院。** 病在開放名單、組閣程序、雙首長殘留與缺憲法法院。

**二、2023／2019 套新制首長都是中間黨，2026 民調社民黨大幅領先時也還是中間黨。** 孔多賽單一放大城市中右（聯合黨）與農村中位（中間黨），芬人黨幾乎只靠名單；中左＋RKP＋奧蘭要跨過 101 席首長才會轉為社民黨；參選方層下 Yle／Taloustutkimus 2026-11 民調是 96 席，還差 5 席。

**三、不是「保證中間黨或聯合黨能單獨改規則」。** 見 [`12`](12-預期政治生態.md)。組織法要全院 ≥120 且複數 ≥48，單一黨或雙黨執政都改不了規則。

## 本夾承認做不到的事

- 市鎮連續切成 119 本土單一區（大市鎮依目標人口預拆），不是官劃；新地西／東依市鎮清單（見 `14`）。
- 奧蘭源檔政黨列在「其他」→ 單一席記「奧蘭」。
- 總統 2024 重算目前用全國第一偏好＋距離模型，不是逐市鎮。
- 不論轉型可行性。
