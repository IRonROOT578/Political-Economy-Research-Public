# 邦與地方

## 1 本檔繼承

`0-基本/總體.md`（緊急狀態、水平分權）；`1-優化/總體.md`（適合該國的治理——**聯邦國**）。

## 2 緊急狀態

| 期間 | 條件 |
|---|---|
| 宣告 | 首長宣告，7 日內全院 ≥211 追認 |
| 每次最長 | 3 個月；延長要全院 ≥252 且複數 ≥101 |
| 不得 | 延選舉、延任期、修憲、停止建設性更新與憲法法院、廢邦 |

## 3 聯邦第二院

| 現行 | 本夾 |
|---|---|
| Bundesrat：邦政府派遣；Zustimmung 絕對否決＋Einspruch | **廢除 Bundesrat 的聯邦立法角色**（機關得廢或改為諮詢檔案館） |

★ 不符 `0-基本`「兩院皆直選」；改直選又民選加固 Zustimmung。邦聲音改走 §4–§5。

## 4 十六邦保留

| 層級 | 本夾 |
|---|---|
| Landtage | **保留**；選制建議彈性名單、每區 ≤16 |
| 邦政府首長 | 邦議會記名排名選出；建設性更新；30 日預設值；**無解散** |
| 市長 | 市議會記名排名選出；建設性更新（大城市得由組織法另定） |
| 邦權清單 | 維持現行基本法對邦權的大體劃分；改劃分屬組織法／修憲 |

## 5 邦在聯邦的聲音（替代 Bundesrat）

| 機制 | 規則 |
|---|---|
| 複數席次 | 十六邦名單區（[`01`](01-國會與選制.md)） |
| 影響邦權的組織法 | 全院 ≥252 **且**複數 ≥101；另得規定相關邦複決（支持票 ≥ 該邦選舉人 25%） |
| 邦首長會議 | 入憲、**諮詢性**；可承接部長會議實務；討論聯邦影響邦的法案；**無否決權** |

## 6 中央內水平分權

| 權 | 機關 |
|---|---|
| 立法 | 國會 420 |
| 行政 | 首長與內閣 |
| 元首 | 總統（間接形式化，[`04`](04-總統.md)） |
| 司法 | 憲法法院、普通／行政法院系統 |
| 審計 | 聯邦審計院 |
| 選舉 | 獨立選舉委員會（三組選出） |
| 邦協調 | 邦首長會議 |
