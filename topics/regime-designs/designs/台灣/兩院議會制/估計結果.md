# 估計結果

> 近期大選與民調的民意套進本夾後的席次、組閣與朝野互動：§1 近期大選、§2 民調、§3 長期推估、§4 朝野互動。席次圖見 [`席次圖.md`](席次圖.md)；算法見 [`17-近期大選重算.md`](17-近期大選重算.md)（[`近期大選推估.py`](近期大選推估.py)），計算方式總說明見 。第一偏好一律用不分區政黨票，不用區域立委或總統的實際得票（受棄保、禮讓影響）。

選制：**國民院 150＝單一 120（top-3 孔多賽）＋複數 30（全國聖拉古、無門檻）**；**參議院 75＝6 區比例**。首長、供給、普通法律 ≥76（國民院）；參議院擱置否決；基本法國民院 ≥90 且參議院 ≥50。

## 計算方式

| 層 | 本夾的做法 |
|---|---|
| 民意層（第一偏好） | 同一院議會制（逐村里不分區政黨票） |
| 參選方層 | 每個政黨都可推人；場外小黨互併（低票讓低票）、場內黨為相鄰場外黨退讓或共推（高票讓低票；受讓方至少有讓方一半的票）、場內黨單純退選（避免當攪局者）——都要雙方偏好整合後的勝者；正式結盟照現實 |
| 制度層：單一席次 | 國民院單一 120 依人口切區，top-3 孔多賽：第一輪取前 k 名，第二輪全體選民照完整排序兩兩對決，循環用 Ranked Pairs；選民的排序由各黨的政策位置推得 |
| 制度層：複數席次 | 國民院複數 30（全國）、參議院 75（6 區），聖拉古、無門檻 |
| 首長、組閣 | 國民院全院 150 記名排名 |
| 民調 | 以最近一次大選的地理分布，依民調的全國比例縮放各黨得票，再跑同一套計算 |

細節與敏感度：[`17-近期大選重算.md`](17-近期大選重算.md)；程式：[`近期大選推估.py`](近期大選推估.py)；共同算法：[`選舉結果計算方式`](../../../notes/算法/選舉結果計算方式.md)。
