# 行政權預算與供給

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `1-優化/財政.md` | 非硬性 | **信任供給合一**：禁止只撤供給、不撤信任；提供者須相同 |
| `1-優化/財政.md` | 非硬性 | **議會制：建設性不信任＋供給在議會不作為下自動通過**（參考法國第 49.3 條） |
| `1-優化/財政.md` | 可選 | 立法權管好自己的立法，行政權管好自己的行政（含：部分行政權預算） |
| `配置/個人偏好/行政立法/兩院議會制.md` | **硬性** | 雙重同意**不含供給** |

預提是總統制的解法，本夾不適用。

## 2 規則（主路徑）

### 2.1 誰給供給：兩院聯席 180

信任與供給由同一批人給（`1-優化/財政.md` 非硬性）：都是兩院聯席，一次表決（[`00`](00-讀法與推導.md) §3.1）。

**本夾把整份行政權預算當「供給」讀**——包括 §2.2 的規劃保障部分與 §2.5 的其餘行政歲出。理由：其餘行政歲出若要兩院各自同意，任一院就能用一般支出逼政府讓步，那是美國「不撤信任卻撤錢」的形狀，也就是 `1-優化/財政.md` 要禁止的事。

### 2.2 規劃保障的供給（封閉列舉）

1. 政策裁量性資本門支出。
2. 預備金與政務應變預算。
3. 行政機關經常門運作費用。
4. 列名政策計畫的經常門支出。

**不含**：法定義務支出（始終撥付）、歲入與稅制（法律，[`04`](04-其餘預算.md)）、非行政部門預算（[`04`](04-其餘預算.md)）、中央對地方的財政移轉公式（基本法）。

### 2.3 自動生效

政府將供給案送達兩院聯席會議後，**15 個開會日**內未通過建設性更新，供給案**自動生效**。期限依曆日併計，不因不開議而中止。

聯席會議仍得在生效前以 **≥91** 通過建設性更新：現任去職，改用準人選政府及其供給。**拒絕這筆錢與換掉這個人是同一個動作。**

### 2.4 與第 49.3 條不同之處

| | 第 49.3 條 | 本夾 |
|---|---|---|
| 提案的政府從哪來 | 總統指定的總理 | 兩院聯席 180 人自己選出的首長 |
| 議會的回應 | 不信任案，不必提繼任者 | 建設性更新，不提繼任者不受理 |
| 性質 | 政府按下的挑釁按鈕 | 預設值：不做事就生效 |

### 2.5 規劃保障以外的行政歲出

由聯席會議 **≥91** 議決：

- **得刪不得增**；不得把整案凍結為零；附條件通過視為未通過。
- 會計年度開始後 **60 日**未議決者，**沿用上一年度已議決額度**。

沿用條款是自由發揮：`1-優化/行政立法/共用.md` 非硬性把美國的預算停擺列為要避免的事。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 供給案送達後政府更迭 | 新首長得撤回重送，15 個開會日重新起算 |
| 期限內提出建設性更新但未通過 | 供給案於表決日次日生效 |
| 供給案逾越 §2.2 封閉列舉 | 逾越部分無效，其餘仍自動生效 |
| 範圍有爭議 | 權限爭議，司法院裁判；未決期間該項依上年度額度撥付 |
| 任一院單獨就行政權預算作成決議 | 無效力；行政權預算只在聯席會議表決 |
| 歲入不足 | 法定義務優先；裁量支出依政府提出、聯席會議 ≥91 同意的減列順序削減；未及議決者按比例削減 |
| 緊急狀態期間 | 預備金與政務應變得先行動支，30 日內補送聯席會議備查 |
