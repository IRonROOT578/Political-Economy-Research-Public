## 2 規則（主路徑）

### 2.1 三層

1. **憲法**
2. **基本法**（`配置/台灣/優化` 硬性要的那一層）
3. **法律**

**位階由內容決定，不由名稱決定。** 一部法案若涉及下列列舉事項，即須以基本法程序通過；以普通法律程序通過者，該部分無效。

### 2.2 基本法事項（封閉列舉）

1. 選舉與公民投票程序。
2. **選區劃分規則**與人口偏差上限（含國民院與參議院大區劃分與 M 的配置）。
3. 政黨與公民連署名單的登記。
4. 中央與地方之財政劃分、移轉公式。
5. 文官制度、考選與銓敘基準。
6. 審計制度。
7. 法院組織與法官任用、身分保障。
8. 監察院、考試院之組織。
9. 緊急狀態的法律效果。
10. 國籍。
11. 貨幣。
12. 國防義務。

清單是封閉的。要增加事項，只能修憲。

### 2.2.1 躍升門檻不在基本法

**躍升門檻（該區 Droop 額數的 25%）寫在憲法，不是基本法。** 理由同 [`01a`](01a-國民院組成與選制.md) §2.3：把旋鈕交給名單受益者，等於把黑金硬性交給利害關係人自行處分。選區劃分與 M 的配置留在基本法（第 2 項）。

### 2.3 普通法律（兩院路徑）

| 步驟 | 規則 |
|---|---|
| 1. 國民院通過 | 同意 **> 總額半數（≥76／150）**；缺席與棄權計入分母 |
| 2. 送參議院 | 參議院得於 **60 日**內以 ≥38 通過**延宕決議**；未延宕則法律成立 |
| 3. 延宕期間 | 法律不生效；參議院得提出修正建議（無強制力） |
| 4. 覆寫 | 延宕期滿或參議院否決後，國民院得以 **≥90（3/5）** 覆寫，法律成立 |
| 5. 公布 | 行政首長須公布；**無法律覆議權** |

法律採「同意 > 總額半數」是可選條件的**第二支（行動通過門檻）**。**突襲立法不成立。**

**不採第一支（受影響方否決）**：界定「誰是受影響方」本身會變成新的爭議場域——Herding cats。

本夾是議會制：行政首長由國民院單一 90 產生。再給首長法律覆議權，等於同一多數既提案又有第二次否決——Herding cats。參議院延宕是**立法內部**的第二讀時間，不是行政否決。

### 2.4 基本法

| | 通過 |
|---|---|
| 國民院 | **≥90（3/5）** |
| 參議院 | **≥45（3/5）** |
| 行政覆議 | **無** |

兩院皆須通過；無跨屆要求（與修憲的差別）。任一院未達則不成立。

### 2.5 穩定性與彈性

| | 穩定性 | 彈性 |
|---|---|---|
| 基本法 | 兩院各 3/5；無行政覆議；事項封閉列舉 | **不需跨屆、不需人民複決** |
| 普通法律 | 國民院過半＋參議院延宕／覆寫 | 一屆內可完成 |

**人民可投票修改基本法**是獨立硬性，見 [`06`](06-修憲與人民修改法規範.md) §3。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 法案內容跨基本法與普通法律 | 全案走基本法程序；或拆案分別通過。以普通法律通過的基本法事項部分無效 |
| 位階有爭議 | 司法院認定（[`09`](09-司法院.md)） |
| 基本法牴觸憲法 | 該條文無效 |
| 行政命令牴觸法律 | 無效 |
| 行政首長對已通過之法律拒不公布 | 逾 15 日未公布者由國民院議長公布；國民院議員 ≥38 得聲請司法院確認公布義務 |
| 參議院 60 日內未作成延宕決議 | 法律成立，送公布 |
| 國民院覆寫未達 90 | 法律不成立；得於同會期內容實質變更後再提 |
| 同一會期同一法案被否決後再提 | 須有新的提案人組成或內容實質變更，否則不予受理 |
