## 2 規則（主路徑）

### 2.1 三層

1. **憲法**
2. **基本法**（中位法那條硬性要的那一層；本夾稱基本法）
3. **法律**

**位階由內容決定，不由名稱決定。** 一部法案若涉及下列列舉事項，即須以基本法程序通過；以普通法律程序通過者，該部分無效。

### 2.2 基本法事項（封閉列舉）

1. 選舉與公民投票程序。
2. **選區劃分規則**與人口偏差上限（含國民院單一／複數比例在 [24,36] 區間內的配置與參議院 6 區 M 的分配）。
3. 政黨與公民連署名單的登記。
4. 中央與地方之財政劃分、移轉公式。
5. 文官制度、考選與銓敘基準。
6. 審計制度。
7. 法院組織與法官任用、身分保障。
8. 監察院、考試院之組織。
9. 緊急狀態的法律效果。
10. 國籍。
11. 貨幣。
12. 國防義務。

清單是封閉的。要增加事項，只能修憲。

### 2.2.1 躍升門檻不在基本法

**躍升門檻（該區 Droop 額數的 25%）寫在憲法，不是基本法。** 理由同 [`01a`](01a-國民院組成與選制.md) §2.3：把旋鈕交給名單受益者，等於把黑金硬性交給利害關係人自行處分。選區劃分與 M 的配置留在基本法（第 2 項）。

### 2.2.2 只放一半的第二項：孔多賽的 k 與更新的 n

**憲法規定 k ≥ 3（國民院單一席次第一輪取前幾名）、n ≥ 2（國民院單一席次議員更新的挑戰者數）；實際採用的 k 與 n 屬第 1 項「選舉與公民投票程序」，在基本法。**

★ **理由**：把 k 從 3 降到 2，單一選區第二輪變回兩強對決，第三名支持者的第二偏好不再決定勝負，向心機制被拆；n 降到 1，更新退回「換這一個人、還是不換」，對現任有利。自肥的方向只有往下降，故下限鎖進憲法，實際值留基本法（國民院 ≥90 且參議院 ≥50）。

### 2.3 普通法律（擱置否決）

| 步驟 | 規則 |
|---|---|
| 1. 國民院通過 | 同意 **> 總額半數（≥76／150）**；缺席與棄權計入分母 |
| 2. 參議院表決 | **60 日內**表決；同意 **≥38／75** 即成立；得附修正案送回國民院 |
| 3. 參議院否決或逾期 | 國民院於 **60 日後**得就原案或採納參議院修正之案，以**全院 ≥76** 重新表決；通過即成立 |
| 4. 公布 | 行政首長須公布；**無法律覆議權** |

**供給與信任不在此路徑**：只看國民院（[`02`](02-行政首長.md)、[`03`](03-行政權預算與供給.md)）。

**為什麼不是絕對否決**：比例參議院沒有單一政黨過半（重算 2012–2024 最大黨 28–36／75）。絕對否決會讓政府逐案在參議院另組多數——`2-配置/台灣/優化/行政立法/共用.md` 硬性要避免的 Herding cats、為反而反。

**為什麼重新表決門檻是 ≥76 而不是更高**：76 已是「同意 > 總額半數」（`1-優化/行政立法/共用.md` 可選的第二支），缺席棄權都算反對；再加 60 日冷卻與參議院的公開辯論，突襲立法不成立。門檻若提高到組閣多數以上，等於回到絕對否決。

**為什麼重新表決要等 60 日**：讓參議院的反對意見有時間進入公共討論；`1-優化/行政立法/共用.md` 可選的「受影響方否決」在這裡的版本是**延後**，不是否決。

本夾是議會制：行政首長由國民院全院 150 產生。再給首長法律覆議權，等於同一多數既提案又有第二次否決。

### 2.4 基本法（國民院 3/5 ＋ 參議院 2/3）

| | 通過 |
|---|---|
| 國民院 | **全院 ≥90／150（3/5）** |
| 參議院 | **≥50／75（2/3）** |
| 行政覆議 | **無** |

兩院皆須通過；無跨屆要求（與修憲的差別）。人民另有獨立渠道（[`06`](06-修憲與人民修改法規範.md) §3）。

★ **為什麼參議院要 2/3 而不是 3/5**：以 3/5（45）重算，2024 國民黨＋民眾黨在參議院 46、國民院 94，可以不經民進黨單獨改選舉法、選區與法院組織——那是「中＋右」的單側聯盟（`0-基本/其他權/司法權.md` 非硬性點名的極端型態）。2/3（50）下，2012–2024 四屆與兩家民調都需要藍綠兩大黨同時同意（或在民眾黨很大時，民眾黨加其中一大黨）。

| 屆 | 國民黨＋民眾黨（院／參） | 民進黨＋民眾黨 | 民進黨＋國民黨 |
|---|---|---|---|
| 2024 政黨票 | 94／46 → 不可 | 72／47 → 不可 | 132／57 → **可** |
| 2020 | 39／36 → 不可 | 110／39 → 不可 | 141／55 → **可** |
| 2016（親民黨） | — | 120／42 → 不可 | 142／58 → **可** |
| 2012（親民黨） | 89／40 → 不可 | — | 144／63 → **可** |
| 推估第 3 屆 | 127／51 → **可** | 108／50 → **可** | 65／49 → 不可 |

第 3 屆推估（民眾黨約 30%）下，民眾黨加任一大黨就跨過門檻：居中黨夠大時，基本法仍要兩個主要政黨同意。

### 2.5 穩定性與彈性

| | 穩定性 | 彈性 |
|---|---|---|
| 基本法 | 國民院 3/5 且參議院 2/3；無行政覆議；事項封閉列舉 | **不需跨屆、不需人民複決** |
| 普通法律 | 參議院擱置 60 日；國民院重新表決要 ≥76 | 一屆內可完成，不會被比例院卡死 |

**人民可投票修改基本法**（`中位法.md` 可選採用），見 [`06`](06-修憲與人民修改法規範.md) §3。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 法案內容跨基本法與普通法律 | 全案走基本法程序；或拆案分別通過。以普通法律通過的基本法事項部分無效 |
| 國民院達 90，參議院未達 50 | 基本法不成立 |
| 位階有爭議 | 司法院認定（[`09`](09-司法院.md)） |
| 基本法牴觸憲法 | 該條文無效 |
| 行政命令牴觸法律 | 無效 |
| 行政首長對已通過之法律拒不公布 | 逾 15 日未公布者由國民院議長公布；國民院議員 ≥38 得聲請司法院確認公布義務 |
| 參議院 60 日內未表決 | 視為否決；國民院得於期滿後 60 日重新表決 |
| 國民院重新表決未達 76 | 法律不成立；得於同會期內容實質變更後再提 |
| 同一會期同一法案被否決後再提 | 須有新的提案人組成或內容實質變更，否則不予受理 |
