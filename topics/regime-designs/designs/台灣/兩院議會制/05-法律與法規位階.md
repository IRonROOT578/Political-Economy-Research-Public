## 2 規則（主路徑）

### 2.1 三層

1. **憲法**
2. **基本法**（中位法）
3. **普通法律**

**位階由內容決定，不由名稱決定。** 涉及 §2.2 列舉事項的條文，須以基本法程序通過；以普通法律程序通過者，該部分無效。

稱「基本法」而不稱「中位法」：與台灣其他三個正經夾同名，讀者跨夾比較時不必換字典。

### 2.2 基本法事項（封閉列舉）

1. 選舉與公民投票程序（含**實際的 k 與 n**；下限 k ≥ 3、n ≥ 2 在憲法）。
2. 選區劃分規則、人口偏差上限、參議院大區劃分與 M 的配置。
3. 政黨與公民連署名單的登記。
4. 中央與地方之財政劃分、移轉公式。
5. 文官制度、考選與銓敘基準。
6. 審計制度。
7. 法院組織與法官任用、身分保障。
8. 監察院、考試院之組織。
9. 緊急狀態的法律效果。
10. 國籍。
11. 貨幣。
12. 國防義務。

清單封閉；要增加事項只能修憲。**躍升門檻（該區 Droop 額數 25%）在憲法，不在清單內**——它的受益者正是能湊出 3/5 的名單政黨（[`01b`](01b-參議院組成與選制.md) §2.3）。

**k、n 的下限為什麼在憲法。** 降 k、降 n 只對大黨有利：k＝2 時第二輪是兩強對決；n＝1 時更新退回「換不換這一個人」。生態模型下兩大黨合計在國民院約 100、參議院約 52，**夠過基本法**（[`15`](15-預期政治生態.md) §5），而他們正是唯一的得利者。3 與 2 本身是偏好，往上調不該要修憲。**降不下去，調得上來。**

### 2.3 普通法案：兩院路徑

| 步 | 規則 |
|---|---|
| 1. 提出 | 任一院議員、行政首長得向任一院提出 |
| 2. 先審院通過 | 同意 **> 該院總額半數**（國民院 ≥51；參議院 ≥41）；缺席與棄權計入分母 |
| 3. 另一院表決 | 收到後 **60 日內必須表決**：通過、修正或否決。**逾期未表決視為否決**，進第 5 步 |
| 4. 修正的處理 | 另一院修正時，先審院 **30 日內**表決是否接受；接受即成立 |
| 5. 協商委員會 | 兩院各 **10 人**，依各院政黨席次以聖拉古分配；**30 日內**產出一份統一文本，須兩院代表團**各自過半**（各 ≥6）。文本不得加入兩院版本都沒有的事項 |
| 6. 統一文本表決 | 兩院**各 15 日內只表決一次、不得修正**；兩院都 > 總額半數才成立 |
| 7. 未成立 | 法案不成立，現行法繼續有效；同一會期內同內容不得再提 |
| 8. 公布 | 行政首長須公布；**無法律覆議權** |

**優先法案。** 行政首長每會期得指定 **5 件**，第 3–6 步各期限減半。

**這條路沒有的東西**：延宕期滿視為通過、一院覆寫另一院、不表決視為同意。任何一條都會讓某一院單獨讓法律成立。

**為什麼收斂到「一份文本、各表決一次」。** 荷蘭的法案協商時間長，是因為談判沒有終點、而且政府存續押在談判上。本夾兩件都拿掉：(1) 協商委員會有期限、產出只有一份、表決不得修正，第 6 步之後沒有下一輪；(2) 信任與供給不在這條路上（[`03`](03-行政權預算與供給.md)），法律卡住的代價是現狀，不是政府。最長約 4.5 個月走完；優先法案約 2.3 個月。

**為什麼「同意 > 總額半數」。** `1-優化/行政立法/共用.md` 可選的第二支（行動通過門檻）：缺席與棄權計入分母，突襲立法不成立。不採第一支（受影響方否決）：界定誰是受影響方本身就是新的爭議場域。

### 2.4 基本法

| | 通過 |
|---|---|
| 國民院 | **≥60（3/5）** |
| 參議院 | **≥48（3/5）** |
| 不一致時 | 同 §2.3 第 3–7 步，統一文本仍須兩院各 3/5 |
| 行政覆議 | 無 |

**改規則要兩種多數。** 國民院是單一選區院，會把大黨放大：生態模型下單一大黨在國民院有 55–62 席，可以單獨過 60。參議院是比例院，同一個黨只有 24–27 席。基本法要兩院各 3/5，就是**選制放大出來的多數改不動規則，只有真實的得票多數改得動**（[`15`](15-預期政治生態.md) §5.3）。

### 2.5 穩定性與彈性

| | 穩定性 | 彈性 |
|---|---|---|
| 基本法 | 兩院各 3/5；事項封閉列舉；人民公投改它的地板 25% | **不需跨屆、不需人民複決**——與修憲的差別 |
| 普通法律 | 兩院各過半 | 一屆內可完成 |

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 法案跨基本法與普通法律 | 全案走基本法程序，或拆案；以普通法律通過的基本法事項部分無效 |
| 位階有爭議 | 司法院認定 |
| 另一院 60 日未表決 | 視為否決，進協商委員會 |
| 協商委員會 30 日未產出文本 | 法案不成立 |
| 統一文本一院通過、一院未過 | 法案不成立，現行法有效 |
| 行政首長逾 15 日未公布 | 由國民院議長公布；國民院 ≥25 或參議院 ≥20 得聲請司法院確認公布義務 |
| 基本法牴觸憲法 | 該條文無效 |
