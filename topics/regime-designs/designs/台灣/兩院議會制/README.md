# 台灣：兩院議會制

本憲政設計最新更新：2026-11-10

## 一句話

**國民院 150＝單一 120（純依人口跨縣市 top-3 孔多賽）＋複數 30（全國彈性名單、聖拉古、無門檻）**是政府院：選出、建設性更新行政首長（≥76）、給供給；**參議院 75＝6 區比例代表**（彈性名單、聖拉古、無門檻）是規則院：對普通法律只有**擱置否決**（國民院 60 日後全院 ≥76 重新表決即成立），對**基本法要 2/3（≥50）**、修憲提案 2/3，並選出三院人事的乙組。兩院 4 年、同日改選。無解散、無行政否決、無全國直選總統。

## 五個本夾特有的決定

**一、政府院與規則院分工。** 國民院以單一 120 為主幹，向心多數決定政府與錢；參議院全部比例，反映政黨民意，管規則與人事。

**二、參議院比例代表、只有擱置否決。** 比例院從未有單一政黨過半（重算最大黨 28–36／75），絕對否決會讓政府逐案另組多數，變成拖延不決的多黨協商；擱置否決讓它延後、辯論、修正，但不卡死。

**三、基本法：國民院 3/5 且參議院 2/3。** 參議院若只要 3/5（45），2024 國民黨＋民眾黨 46 就能單獨改選舉與法院規則；2/3（50）下四屆重算都要藍綠兩大黨同時同意。

**四、國民院複數只有 30。** 比例民意的主要落點在參議院；國民院複數只為壓低單一選區的席次獎勵、讓小黨有發聲處。

**五、三院人事三組：甲＝國民院單一 120、乙＝參議院 75、丙＝首長對決各方。** 平行選出，沒有雙重同意。

## 三個最容易讀錯的地方

**一、國民院的多數很集中，但 2024 三黨接近時仍由居中者出任首長。** 2020 民進黨 34.0% 政黨票 → 國民院 109 單獨過半；2024 國民黨 34.6% → 國民院 74（差 2 席過半），兩大黨皆把民眾黨排第二，首長出自民眾黨、民眾黨＋國民黨 94 組閣；推估第 3 屆民眾黨約 30% → 85（[`估計結果.md`](估計結果.md)）。

**二、但規則改不動。** 同一年參議院國民黨 28、民眾黨 18，加起來 46 < 50；基本法要民進黨同意（[`05`](05-法律與法規位階.md) §2.4）。

**三、參議院不是第二個國民院。** 它不能倒閣、不能卡死普通法律，只能延後 60 日；它的權力在規則與人事。

## 本夾承認做不到的事

- **國民院一黨單獨過半常見**，普通法律可以單黨推動（參議院只能延後）。
- **居中第三黨夠大時會被大幅放大**（第 3 屆推估民眾黨 85／150）。
- **不論轉型可行性**。
