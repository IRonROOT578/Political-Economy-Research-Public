## 2 修憲

### 2.1 硬性條件是功能標準，不是程序標準

「不能如台灣現行一樣**實質改不了**」——判準是**功能的**。

#### 主論證：門檻高過這個國家動員能力的上限

★ **硬性條件自己給了數字**：「特別是 **歷史最高得票 817 萬 <** 台灣現行人民複決：『須有效同意票過選舉人總額之半數』」。

| | 票數 |
|---|---|
| 現行複決所需（選舉人約 1,924 萬之半） | 約 **962 萬** |
| **台灣史上任何一場全國投票的最高得票** | **約 817 萬** |
| 差距 | **約 145 萬** |

> **不是「某一次沒過」，是「沒有任何一次過得了」。**

#### 佐證：一次真實的失敗

2022 年 11 月 26 日十八歲公民權修憲複決，同意 **5,647,102** 票、不同意 **5,016,427** 票——**同意方多出約 63 萬票**，仍因未達約 962 萬而未通過。

#### 驗證本夾

修憲複決是替代現狀：修憲案 vs 維持現狀。一定票數＝選舉人 **25%**。2022 那案同意 564.7 萬對維持現狀的兩兩 ≈ **29.3%**，過淘汰線且決選勝出 → **通過**。史上最高 817 萬 ≈ **42.5%** → **通過**（現行制度下仍**不通過**）。

### 2.2 一般軌（兩院＋跨屆＋人民）

1. **本屆**：國民院 **≥90（3/5）** 且參議院 **≥45（3/5）** 提出。
2. **下一屆**：國民院 **≥76** 且參議院 **≥38** 確認（跨屆——至少經過一次國民院改選；參議院若恰逢半數改選，由新組成的參議院確認）。
3. 人民複決通過（§2.4）。

跨屆確認讓修憲**至少經過一次全國大選**。

### 2.3 急迫軌

同屆國民院 **≥100（2/3）** 且參議院 **≥50（2/3）** 提出，90 日內複決。

急迫軌**不得**修改：政體類型（兩院議會制；哪一院掌行政）、行政首長與兩院任期、本條、§2.5、人權清單、基本法事項清單。

### 2.4 人民複決（替代現狀）

替代方案＝該條修憲案；維持現狀＝現行條文。票面 2 格。

1. **先淘汰**：修憲案在與維持現狀的兩兩對決中支持票 **< 選舉人總額 25%** 者出局 → 維持現狀。
2. **再決選**：通過淘汰則以孔多賽完成法（兩案即該對決）決採用方案。

第 1 款的 25% 取代現行的「過選舉人總額之半數」。**25% 是防投票率過低的地板，不是障礙。**

### 2.5 逐條分別複決

> 修憲案有二以上獨立條項者，**應逐項分別付諸複決、分別計票、分別生效**。不得以單一贊否選項就整包表決。

## 3 人民修改法規範

### 3.1 對象範圍

這條獨立硬性：**人民可投票來修改憲法與法案之間那一層（基本法）。**

| 標的 | 可否以公投直接變更 | 為什麼 |
|---|---|---|
| 法律 | **可** | — |
| 基本法 | **可**，一定票數提高至 25% | 位階高，門檻跟著高 |
| 憲法 | **否** | 修憲走 §2；公投是那裡的複決階段，不是獨立入口 |
| 預算、稅制 | **否** | 防止「多數投票決定少數繳稅」 |
| 個案處分、特定人之權利義務 | **否** | 司法或行政的事 |
| 剝奪或限制人權清單所列權利 | **否** | 多數不得投票取消少數的基本權 |

### 3.2 提案與方案

- 選舉人 **1.5%** 連署成案，連署期間 6 個月。
- 成案後 30 日內，**行政首長得提出政府方案**。領銜人即為政府時只有領銜人方案＋維持現狀。
- 票面：領銜人方案、政府方案（若有）、維持現狀；3 個方案 → 6 格完整排序單選；兩方案時改 2 格。
- 計票地點規則同 [`01a`](01a-國民院組成與選制.md) §2.8。

### 3.3 成立條件（替代現狀方式）

一定票數：法律 **選舉人總額 20%**；涉及基本法事項 **25%**。

1. **先淘汰**：領銜人方案、政府方案各自與「維持現狀」兩兩對決；未達一定票數者出局。
2. **再決選**：對通過淘汰的替代方案與維持現狀，用孔多賽完成法決一採用方案。
3. 採用維持現狀 → 當然維持現狀。全部替代方案被淘汰 → 維持現狀。

### 3.4 效力範圍

- 自公告日起 **30 日**生效；**位階依其內容決定**。
- 牴觸憲法者無效，由司法院認定。
- **鎖定期 3 年**：期間內兩院不得以同位階規範變更其實質內容；期滿回復一般程序。
- 同一議題失敗後 **2 年**內不得再次提案。

### 3.5 公投不是信任投票

公投結果與行政首長的去留、與 [`03`](03-行政權預算與供給.md) 的年度議決**沒有任何制度性連結**：

- 政府方案敗給領銜人方案，行政首長不必辭職。
- 公投不觸發 [`12`](12-人選更新.md) 的更新程序。
- 行政首長不得宣布「本案通過即視為對本人之信任」而使其產生法律效果。

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 修憲案提出後國民院屆期改選 | 跨屆確認由新屆國民院為之；參議院依當時組成確認 |
| 新屆未於首會期確認 | 該案失效 |
| 逐條複決中部分通過、部分未過 | 通過者生效，未過者不生效 |
| 急迫軌含禁止修改事項 | 該部分不予付諸複決，其餘部分程序不受影響 |
| 連署期滿未達 1.5% | 不成案，已繳連署作廢 |
| 政府未於 30 日內提方案 | 視為不提，票面改 2 格；仍先淘汰再決選 |
| 兩方案實質相同 | 選務機關通知後合併；領銜人不同意者維持兩案 |
| 出現孔多賽循環 | 依完成法（Ranked Pairs）決出；淘汰已做完 |
| 替代方案未過一定票數 vs 維持現狀 | 該方案出局，不順延給次高第一偏好 |
| 鎖定期內兩院通過牴觸之法律 | 該法律於鎖定期內不生效力，期滿後始生效 |
| 緊急狀態期間 | 已定投票日的公投與複決**不延期**（[`07`](07-緊急狀態.md)） |
