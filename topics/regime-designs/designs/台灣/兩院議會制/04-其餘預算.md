# 其餘預算

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `1-優化/財政.md` | 可選 | 立法權管好自己的立法，行政權管好自己的行政（含部分行政權預算）——本檔寫那個「部分」以外的東西 |
| `0-基本/其他權/總體.md` | 硬性 | 給各權的權力與組織（本檔負責其財政獨立性那一面） |
| `1-優化/行政立法/共用.md` | 非硬性 | 避免美國因兩大黨對立而預算停擺 |

沿用與「行政首長不得刪三院」是自由發揮。**不採**考試權先經行政刪減。對應表不點雜項。

## 2 規則（主路徑）

### 2.1 非行政部門的預算

國民院、參議院、司法院、監察院、考試院、選務機關、獨立劃分委員會的歲出：

1. 各該機關**自行編列**歲出上限。
2. **行政首長不得刪減**這些科目，只能轉送。
3. **國民院 ≥76 且參議院 ≥38** 議決，**得刪不得增**。參議院未於 30 日內議決者，視為同意國民院版本。
4. 會計年度開始前未議決者，**沿用上一年度已議決額度**。

第 2 點：一個能刪司法院預算的行政首長，不需要違憲就能讓憲法法庭停轉。

第 3 點用**兩院**而非僅單一席次：這些不是行政的錢，「僅單一席次表決預算」那條可選條件針對的是行政權預算。

兩院各自預算由兩院共同批准——形式上互審，但讓行政或司法批准立法權的預算，等於給它們一根對立法權的常設槓桿。**冗餘比癱瘓好。**

### 2.2 稅制與歲入

稅目與稅率以**法律**定之（走 [`05`](05-法律與法規位階.md) 普通法律路徑：國民院 ≥76，參議院得延宕，國民院得覆寫）。

`1-優化/財政.md` 的規劃保障供給明文不含歲入與稅制。

### 2.3 為什麼不採「考試權先經行政權刪減，再送議會」

對應表不點雜項。即使當自由發揮，本夾**仍不採用**：考試院掌文官的「進得來」與「趕不走」（[`11`](11-考試院.md)），若其預算須先經行政刪減，行政就取得一根對文官體系的間接槓桿。

### 2.4 中央與地方的財政劃分

屬**基本法**事項（[`05`](05-法律與法規位階.md)）。

移轉公式須**普遍適用**：憲法明文禁止中央與個別地方自治團體締結變更其財政地位之個別協定。

年度移轉總額由國民院 ≥76 且參議院 ≥38 議決，不由 [`03`](03-行政權預算與供給.md) 的單一席次議決。

### 2.5 決算與餘額

- 未執行的預算餘額應**繳庫**，不得留用、不得移作他項。
- 決算由監察院審計查核（[`10`](10-監察院.md)）。
- 監察院每年公布行政權預算的 **議決額／實際支出／差異理由** 對照表，直接送兩院與公眾，不經行政首長核閱。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 某機關編列的上限被兩院刪至無法運作 | 該機關得聲請司法院認定；認定成立者恢復至上一年度額度 |
| 行政首長刪減非行政部門科目後轉送 | 刪減無效，以原編列數送兩院 |
| 會計年度開始前未議決 | 全部沿用上年度已議決額度，不歸零 |
| 參議院 30 日內未議決非行政預算 | 視為同意國民院版本 |
| 移轉公式修正案未跨屆確認 | 不生效，續用原公式（若屬基本法程序） |
| 個別地方自治團體主張其財政地位應調整 | 只能主張公式適用錯誤，由司法院裁判；不得請求個別協定 |
| 餘額未繳庫 | 監察院逕行認定該支出無法證明合法性並公告 |
| 三院之間就同一經費爭執 | 各自編列，由兩院議決；不由行政協調 |
