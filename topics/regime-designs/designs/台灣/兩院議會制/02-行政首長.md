## 2 規則（主路徑）

### 2.1 某些議員 ＝ 兩院聯席 180

理由與模型比較見 [`00`](00-讀法與推導.md) §3.1。國民院 100 人與參議院 80 人在聯席會議**一起投一次**，不是兩院各自同意。過半 **91**。

### 2.2 選出（新屆）

兩院新屆集會後 **7 個開會日**內，召開聯席會議：

1. 聯席 180 人以**記名排名投票**產生首長。排名可截斷、可並排。
2. 孔多賽完成法決出勝者（循環時 Ranked Pairs）。一次計票。
3. 勝者即為行政首長，無須另行同意投票。

**7 個開會日是硬期限。** 逾期改為每個開會日一輪、篩掉排名最後一名，直到剩一人。**沒有「談不攏就繼續談」。**

**對決強度用勝方得票，不用勝差。** 議員可以截斷、並排，某場對決可能有人不表態，兩種量法就會分岔；分岔處正是可操弄處：一派只排自己的人、其餘留白，在勝差量法下能讓對手的某場勝利「變弱」而在循環裡被丟掉。手算例見 [`../一院議會制/02-行政首長.md`](../一院議會制/02-行政首長.md) §2.2。勝方得票只看那一場明白表態站在勝方的人數，不因別人留白而變化。

行政首長**不必是議員**。

### 2.3 職權

- 負責行政；任免政務人員；指揮行政部門。
- **兼國家元首**：對外代表、公布法律、主持國家儀典。理由：另設元首就是另一個宣稱代表全國的職位，危機時會被要求介入。
- 提出法律案（得向任一院提出）、行政權預算案。
- 依 [`07`](07-緊急狀態.md) 宣告緊急狀態。
- 統帥武裝力量。**宣戰須國民院 ≥67 且參議院 ≥54（各 2/3）。**
- 每會期得指定 **5 件優先法案**，其兩院程序期限減半（[`05`](05-法律與法規位階.md) §2.3）。

**無法律覆議權。** 首長由兩院聯席選出，法律已要兩院各自同意；再給首長一道否決，就是第三道關卡。

### 2.4 更新（建設性）

| 項目 | 規則 |
|---|---|
| 提案 | 兩院議員合計 **1/4（≥45）** 連署，**須載明準人選姓名** |
| 未載明 | 不予受理 |
| 表決 | 準人選與現任的**兩兩對決**，記名；聯席會議一次投票 |
| 通過 | 準人選得 **≥91／180** |
| 效果 | 準人選就任，現任同時解職 |
| 未達 | 現任留任 |
| 冷卻 | 失敗後 **3 個月**內同一提案人不得再提 |
| 每會期上限 | **2 次** |
| 屆期 | **不重啟**，兩院做滿 4 年 |

**「先決定出準人選」**（`1-優化/行政立法/議會制.md`）落在提案要件：沒有準人選，案子排不上議程。

### 2.5 不得只撤供給、不提繼任者

拒絕行政權供給的唯一途徑，是期限內在聯席會議通過建設性更新（[`03`](03-行政權預算與供給.md)）。不存在「否決供給但保留現任」的表決選項。

### 2.6 無解散權

行政首長不能解散任何一院。聯席會議能換掉首長，僵局本來就有內部出口；解散只會讓首長取得一個「選到法律過為止」的工具。

### 2.7 政府成員

首長任免政務人員，不需任一院同意。兩院得質詢、調查；聯席會議得以 ≥91 譴責個別政務人員，**不生解職效力**——解職只有換掉首長本人這一條路。

### 2.8 副首長

首長就任時提名，經聯席會議 ≥91 同意。首長出缺時代理，並於 7 個開會日內依 §2.2 重選。代理期間不得宣告緊急狀態、不得任免政務人員。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆逾 7 個開會日未選出 | 每開會日一輪刷尾，直到剩一人 |
| 首長出缺 | 副首長代理，7 個開會日內重選；不重啟屆期 |
| 準人選於表決前退出 | 該案失效；冷卻期不重新起算 |
| 兩案同時成案 | 依連署完成先後表決；前案通過則後案失效 |
| 兩兩對決同票 | 現任留任 |
| 議員出缺致實際人數不足 180 | 分母仍 180，門檻仍 91 |
| 首長的優先法案在參議院被否決 | 照 [`05`](05-法律與法規位階.md) §2.3 走協商委員會；**與首長去留無關** |
| 緊急狀態期間 | 更新程序不中止（[`07`](07-緊急狀態.md)） |
| 會期外 | 兩院議員合計 1/4 連署得要求召開聯席臨時會，國民院議長 7 日內召集 |
