## 2 規則（主路徑）

### 2.1 某些議員 ＝ 國民院單一席次 90

理由見 [`00`](00-讀法與推導.md) §3.1：信任供給合一要求提供者相同；供給表決者是單一席次。參議院不在「某些議員」內。

過半 **46**。

### 2.2 選出（新屆）

國民院新屆集會後 **7 個開會日**內：

1. 單一席次議員 90 人以**記名排名投票**產生準人選。排名可截斷、可並排。
2. 以孔多賽完成法決出勝者。**一次計票**，不拆多輪刷尾。
3. 勝者即為行政首長，**無須另行同意投票**。

無現任時不適用對決門檻。

**7 個開會日是硬期限。** 逾期：改為每個開會日一輪、篩掉排名最後一名，直到只剩一人（自由發揮，回答荷蘭組閣過長）。

**沒有「談不攏就繼續談」這個選項。**

行政首長**不必是議員**。

### 2.3 職權

- 負責行政；任免政務人員；指揮行政部門。
- **兼國家元首**：對外代表國家、公布法律、主持國家儀典（[`00`](00-讀法與推導.md) §3.3）。
- 提出法律案與行政權供給案。
- 依 [`07`](07-緊急狀態.md) 宣告緊急狀態。
- 統帥武裝力量。**宣戰須國民院 ≥100（2/3）且參議院 ≥50（2/3）同意。**

**無法律覆議權**——他由議員選出，再給他一個擋議會的工具沒有道理（[`05`](05-法律與法規位階.md)）。參議院的延宕不是行政否決。

### 2.4 更新（建設性）

| 項目 | 規則 |
|---|---|
| 提案 | 單一席次議員 **1/4（≥23）** 連署，且**須於提案書中載明準人選姓名** |
| 未載明 | **不予受理**，不列入議程 |
| 表決 | 準人選與現任的**兩兩對決**，記名；僅單一 90 投票 |
| 通過 | 準人選得 **≥46／90** |
| 效果 | 準人選就任，現任同時解職 |
| 未達 | 現任留任 |
| 冷卻 | 失敗後 **3 個月**內同一提案人不得再提 |
| 每會期上限 | **2 次** |
| 屆期 | **不重啟。** 國民院做滿 4 年 |

參議院**不得**提出或表決建設性更新。

**「不載明繼任者即不予受理」是本夾對威瑪消極多數的直接回答。**

### 2.5 不得只撤供給、不提繼任者

- 拒絕行政權供給的**唯一途徑**，是在期限內通過建設性更新信任案（[`03`](03-行政權預算與供給.md)）。
- 不存在「否決供給但保留現任」的表決選項。
- 國民院複數席次與參議院完全不參與行政權供給的表決。

### 2.6 無解散權

行政首長不能解散國民院或參議院。理由見 [`00`](00-讀法與推導.md) §3.1：一個能在內部換掉首長的國民院，其僵局本來就可以在內部解決。

### 2.7 政府成員

首長任免政務人員，不需兩院同意。國民院得質詢、調查，得對個別政務人員提出**譴責案**（國民院 ≥76），但**譴責不生解職效力**——解職只有一條路，就是換掉首長本人。

### 2.8 副首長

由首長於就任時提名，經單一席次 ≥46 同意。首長出缺時代理，並於 7 個開會日內依 §2.2 重選。

副首長代理期間**不得**宣告緊急狀態、不得任免政務人員。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆逾 7 個開會日未選出 | 改為每開會日一輪刷尾，直到剩一人 |
| 首長死亡、辭職、永久不能視事 | 副首長代理，**7 個開會日**內重選。**不重啟屆期，兩院不被解散** |
| 更新案準人選於表決前退出 | 該案失效；提案人得另提，冷卻期不重新起算 |
| 兩案同時成案 | 依連署完成先後表決；前案通過則後案失效 |
| 兩兩對決同票 | 現任留任 |
| 準人選當選後拒絕就任 | 該案視為未通過，適用 3 個月冷卻 |
| 首長長期不能視事 | 單一席次 ≥46 得認定，副首長代理並於 7 個開會日內重選 |
| 單一席次出缺致實際人數不足 90 | **分母仍 90**，門檻仍 46 |
| 緊急狀態期間 | 更新程序**不中止**（[`07`](07-緊急狀態.md)） |
| 會期外 | 1/4 連署得要求召開國民院臨時會，議長應於 7 日內召集 |
