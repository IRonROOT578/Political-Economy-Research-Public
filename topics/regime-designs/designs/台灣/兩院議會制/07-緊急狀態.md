## 2 規則（主路徑）

### 2.1 兩種狀態（封閉列舉）

憲法未列名的狀態不存在。

| | 戰爭／武力攻擊 | 重大災害、疫病 |
|---|---|---|
| 宣告 | 行政首長宣告 | 行政首長宣告 |
| 追認 | **72 小時內**國民院 ≥76 **且**參議院 ≥38，否則失效 | 同左 |
| 一次期限 | 30 日 | 15 日 |
| 延長 | 國民院 **≥90** 且參議院 ≥45，每次 ≤30 日 | 國民院 ≥76 且參議院 ≥38，每次 ≤15 日 |
| 累計上限 | **180 日** | **90 日** |
| 逾期未表決 | **狀態終止** | **狀態終止** |
| 適用範圍 | 得限於特定地區 | 得限於特定地區 |

累計上限屆滿後仍需延長者，須以**基本法程序**（兩院各 ≥3/5）逐次為之，每次不得逾 30 日。

「逾期未表決即**終止**」而非「視為同意」：**讓沉默的結果是狀態結束。**

### 2.2 離島與集會（自由發揮）

- 狀態得**限於特定地區**宣告。
- **兩院**因故不能在其所在地集會時，得於任一地點集會，其決議有效——包含以經認證的遠距方式為之，但表決仍須記名並公開紀錄。
- 離島選區之投票所不能開設時，得設本島替代投票所；**投票日不得變更**。

### 2.3 緊急命令

- 行政首長於狀態期間得發布緊急命令，具法律效力。
- 命令須於發布後 **7 日內**送兩院。
- 國民院得以 **≥76** 廢止任一命令；**廢止不受行政覆議**（本夾無法律覆議權）。參議院得以 ≥38 建議廢止；國民院應於 7 日內表決。
- 未於 30 日內送達，或經國民院否決者，即失效。
- **狀態終止時，所有緊急命令同時失效。**
- 緊急命令不得變更憲法、基本法、選舉法規、法院組織。

因為行政首長**沒有解散權**（[`02`](02-行政首長.md)），議會的廢止權是真的。威瑪的失敗機制：議會廢止緊急命令，總統就解散議會——本夾兩個槓桿都不給。對照句裡的「總統」是威瑪史例，不是本夾機關。

### 2.4 期間不得停止的事（紅線）

- **任何選舉。** 兩院的定期選舉、補選一律照常。**任期不因緊急狀態延長。**
- **建設性更新與議員更新**不因緊急狀態停止（[`02`](02-行政首長.md)、[`12`](12-人選更新.md)）。
- 已定投票日的公民投票與修憲複決（[`06`](06-修憲與人民修改法規範.md)）。
- 彈劾程序（[`09`](09-司法院.md)、[`10`](10-監察院.md)）。
- 兩院的集會與表決（§2.2）。
- 司法院的審查程序。

**這一節沒有但書。** 本夾不套「總統更新」硬性——沒有直選總統。

### 2.5 不得停止的權利

生命權、不受酷刑、不受奴役、罪刑法定與不溯及既往、法律人格、公正審判的核心、思想與宗教自由，於任何狀態下均不得停止。

得暫時限制者以**列舉**為限：遷徙、集會、營業、財產之徵用（徵用須補償，並於狀態終止後 180 日內完成給付）。

**行政拘束不得逾 48 小時**，逾時須由法官裁定。

### 2.6 防常態化

> 緊急狀態存續期間及其終止後 **24 個月**內，不得以法律或基本法將該狀態下行使之行政權力改為常態權力；**違反者，該條文無效**。

排除方式：國民院得以 **≥90**、參議院得以 **≥45**，逐條記名並敘明理由排除本款之適用。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 宣告後 72 小時內兩院未追認 | 狀態失效。行政首長得於兩院集會後重新宣告 |
| 兩院不能在所在地集會 | 於任一地點或經認證的遠距方式集會，決議有效 |
| 追認一院通過、一院未過 | 未通過，狀態失效 |
| 累計上限屆滿仍有戰事 | 改走基本法程序兩院各 ≥3/5 逐次延長 |
| 緊急命令與現行法律牴觸 | 狀態期間命令優先；狀態終止時命令失效，法律回復適用 |
| 狀態期間屆期改選 | 照常改選。新屆須於首次集會 72 小時內重新追認，否則狀態終止 |
| 狀態期間行政首長被建設性更新 | 新首長承接該狀態，期限與累計上限不重新起算 |
| 離島投票所不能開設 | 設本島替代投票所；投票日不變 |
| 防常態化爭議 | 任何人於具體案件中得主張，由司法院認定 |
