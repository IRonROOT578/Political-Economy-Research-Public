# 緊急狀態

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/總體.md` | 要求 | 緊急狀態是重大憲政選擇的舉例之一 |
| `1-優化/總體.md` | 非硬性 | 適合該國的治理 |
| `1-優化/行政立法/議會制.md` | 非硬性 | 避免非建設性的更新——建設性更新不因緊急狀態停止 |

內容自由發揮：狀態種類、期限、追認門檻、緊急命令的廢止、防常態化、不得停止事項。

## 2 規則（主路徑）

### 2.1 兩種狀態（封閉列舉）

| | 戰爭／武力攻擊 | 重大災害、疫病 |
|---|---|---|
| 宣告 | 行政首長 | 行政首長 |
| 追認 | **72 小時內**國民院 ≥51 **且**參議院 ≥41，否則失效 | 同左 |
| 一次期限 | 30 日 | 15 日 |
| 延長 | 國民院 **≥60** 且參議院 **≥48**，每次 ≤30 日 | 兩院各過半，每次 ≤15 日 |
| 累計上限 | **180 日** | **90 日** |
| 逾期未表決 | **狀態終止** | **狀態終止** |

累計上限屆滿仍需延長者，須以**基本法程序**（兩院各 3/5）逐次為之，每次 ≤30 日。

**追認與延長要兩院。** 緊急狀態讓行政權暫時取得立法的效力；立法要兩院同意，讓它取得立法效力的決定也要兩院同意。**沉默的結果是狀態結束**，不是「視為同意」。

### 2.2 緊急命令

- 狀態期間得發布緊急命令，具法律效力；發布後 **7 日內**送兩院。
- **任一院以過半（國民院 ≥51 或參議院 ≥41）即得廢止**任一命令；廢止不受覆議。
- 未於 7 日內送達者失效。狀態終止時，所有緊急命令同時失效。
- 不得變更憲法、基本法、選舉法規、法院組織。

**為什麼任一院就能廢止。** 法律要兩院都同意才成立；緊急命令跳過了兩院。任一院撤回同意，命令就失去它代替法律的依據。行政首長沒有解散權，所以這個廢止權是真的——威瑪的失敗機制是議會廢止緊急命令、總統就解散議會，本夾兩個槓桿都不給。

### 2.3 集會與離島

- 狀態得限於特定地區宣告。
- 兩院因故不能在所在地集會時，得於任一地點或以經認證的遠距方式集會，表決仍記名並公開。
- 離島投票所不能開設時，設本島替代投票所；**投票日不得變更**。

### 2.4 期間不得停止的事（紅線）

- **任何選舉**：兩院定期選舉、補選照常；**任期不因緊急狀態延長**。
- **建設性更新與議員更新**（[`02`](02-行政首長.md)、[`12`](12-人選更新.md)）。
- 已定投票日的公投與修憲複決。
- 彈劾程序、司法院審查、兩院集會與表決。

這一節沒有但書。本夾沒有總統，「總統更新（若有）」無適用對象；這裡不停更新，理由是不讓現任多數用緊急狀態保護自己。

### 2.5 不得停止的權利

生命權、不受酷刑、不受奴役、罪刑法定、法律人格、公正審判核心、思想與宗教自由，不得停止。得暫時限制者以列舉為限：遷徙、集會、營業、財產徵用（須補償，狀態終止後 180 日內給付）。行政拘束不得逾 48 小時，逾時須法官裁定。

### 2.6 防常態化

> 緊急狀態存續期間及終止後 **24 個月**內，不得以法律或基本法將該狀態下行使之行政權力改為常態權力；**違反者該條文無效**。

排除方式：兩院各 3/5，逐條記名並敘明理由。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 72 小時內一院追認、一院未追認 | 未通過，狀態失效 |
| 兩院不能在所在地集會 | 任一地點或遠距集會，決議有效 |
| 累計上限屆滿仍有戰事 | 基本法程序逐次延長 |
| 狀態期間屆期改選 | 照常改選；新屆兩院須於首次集會 72 小時內重新追認 |
| 狀態期間首長被建設性更新 | 新首長承接，期限與累計上限不重新起算 |
| 一院廢止某命令、另一院反對 | 命令失效 |
| 防常態化爭議 | 具體案件中得主張，由司法院認定 |
