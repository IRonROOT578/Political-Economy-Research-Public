
繼承層與 [`../一院總統制/`](../一院總統制/) **完全相同**——差別只有 `0-基本/行政立法/` 取的是**一院議會制**那一份，以及**沒有「不用／用 預提」那一句**（預提是總統制的解法）。

## 一句話

國民議會一院 **180＝單一 100＋複數 80**（席次與選制與總統制夾相同）。行政首長由 **100 名單一席次議員**以記名排名投票選出、**建設性更新**（準人選須贏過現任 ≥51）、**兼國家元首**——全國層級只有這一個行政職位。行政權供給**期限內未通過建設性更新即自動生效**。**無解散權、無覆議權。** 五權：行政、立法、司法、監察、考試。

## 四個本夾特有的決定

**一、某些議員＝單一席次 100。** `1-優化/財政.md` 的信任供給合一要求提供者相同，而同檔可選條件把供給的表決者指定為單一席次議員——兩條的交會把「某些議員」釘在單一席次。**錢與政府是同一批人的事，規則是全院的事。** 見 [`00`](00-讀法與推導.md) §3.1。

**二、行政首長兼國家元首。** 另設的元首即使「沒有實權」，仍是第二個宣稱代表全國的職位，**每次政府危機都會有人要求它介入**——那正是 `1-優化` 把台美韓列為內耗例子的那種形態。本夾把那個位子拿掉。見 [`00`](00-讀法與推導.md) §3.2。

**三、制衡不在行政與立法之間，在立法內部。** 議會制的政府就是多數，行政與立法之間的制衡天然薄弱。本夾把它移到兩處：**執政多數 51 遠不足以立法（91）或修憲提案（108）**；以及行政不得刪三院預算、不提名任何法官、檢察人事不歸行政。見 [`08`](08-中央內水平分權.md) §2.2。

**四、三院丙組改用專業名冊。** 「正副總統候選人加權」那條可選條件**明文限於總統制**。若三組全由議員產生，三院會變成當屆議會多數的延伸——**而在議會制裡議會多數就是政府**，等於行政間接掌握司法人事與查核自己的機關。名冊由**另一院**公布，避免任一院自行決定自己的選舉權人。見 [`09`](09-司法院.md) §2.2。

## 「總統更新」那條硬性怎麼算

`配置/台灣` 硬性：總統更新不應讓立法權凌駕人民罷免權。

**本夾沒有總統。** 首長由議員選出，也由議員更新——**這不是凌駕，因為被凌駕的前提是先有那個權**，而人民從來沒有對他的授權；`0-基本/行政立法/一院議會制.md` 硬性本身就寫「更新方式：某些議員投票」。

但那條硬性的**精神原封不動套在議員身上**：議員的人民更新**不受任何議會關卡拘束**，穩定性機制全在人民端，並新增禁止——**議會不得以任何決議停止、延後或附條件於議員的人民更新程序**（否則現任多數可以保護自己的成員）。見 [`12`](12-人選更新.md) §2。
