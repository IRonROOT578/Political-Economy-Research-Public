# 台灣：一院議會制

本憲政設計最新更新：2026-11-10

## 一句話

國民議會一院 **180 席＝單一選區 100（top-3 孔多賽）＋複數選區 80（7 區、彈性名單、聖拉古、無法定門檻）**。行政首長由全院 180 記名排名選出，只能被「建設性更新」換掉（準人選須在與現任的對決中拿到 ≥91）；首長兼國家元首；議會不能被解散。行政權供給在期限內沒有被更新就自動生效。人民端的修憲複決、公投、單一選區議員更新共用同一套「替代現狀」投票。

## 四個結構決定

1. **信任與供給都由全院 180 給。** 政府多數就是立法多數；單一選區勝者全拿的放大，被照比例分配的 80 席稀釋，不會直接變成換政府（[`00`](00-讀法與推導.md) §2.1）。
2. **首長兼元首，無解散。** 組閣有硬期限、更新是建設性的，不需要規則外的仲裁者；解散權在這套規則下只剩「首長威脅議會」一種用途（[`00`](00-讀法與推導.md) §2.2–§2.3）。
3. **替代現狀投票先淘汰、再決選。** 地板量的是「該方案與維持現狀一對一時的支持票」，排在投票系統之前，避免一個民意不足的方案順帶擋掉另一個足夠的方案（[`06`](06-修憲與人民修改法規範.md) §2）。
4. **三院丙組由最近一次首長對決的各方選出。** 每一票背後都有議員的記名授權，不用專業名冊上的個人（[`00`](00-讀法與推導.md) §2.4）。

**2024 年的意思**：國民黨在單一選區拿最多，但全院 85 不過半；兩大黨的議員都把民眾黨排第二，所以首長出自民眾黨，與國民黨組成 114 席的政府。民進黨要回到執政，必須讓民眾黨選民不再把它排最後——動員自己的基本盤沒有用，基本盤早就把它排第一。

## 預期政治生態

- **批鬥對手陣營有了價格。** 每一場區域對決都由不在場上那一方的選民決定：民眾黨選民把國民黨排在民進黨前面的比例每移 5 個百分點，民進黨約少 3 席（[`15`](15-預期政治生態.md) §2.4、§9）。
- **政府通常是兩黨。** 第三黨是兩大黨議員共同的第二偏好，組閣一次投票結束；基本法層級只有兩大黨一起才改得動。
- **代價**：單一選區對第二偏好極敏感，約三分之一的選區出現循環（Ranked Pairs 處理，選務機關公告三場對決的票數）；一次夠大的浪潮仍可能讓一大黨加盟友跨過基本法門檻，所以基本法要全院與複數 80 各自達 3/5（[`15`](15-預期政治生態.md) §11）。
