## 一句話

國民議會一院 **180＝單一 100（top-3 孔多賽）＋複數 80（彈性名單、聖拉古、無門檻）**。行政首長由**全院 180** 記名排名選出、建設性更新（準人選須贏現任 ≥91）、兼元首。供給期限內未更新即自動生效。無解散。人民端的修憲複決、公投、議員更新共用一套替代現狀方式。

## 四個本夾特有的決定

**一、某些議員＝全院 180。** 信任與供給同由全院給；政府多數就是立法多數，建設性更新是真的出口。模型把「全院」與「只由單一 100」各跑一次的比較在 [`00`](00-讀法與推導.md) §3.1。代價是兩黨聯合政府、民眾黨兩邊都組得成（[`15`](15-預期政治生態.md) §11.5）。

**二、首長兼元首，無解散。** 組閣有硬期限、更新是建設性的，不需要規則外的仲裁者，也不給首長拿解散威脅議會（[`00`](00-讀法與推導.md) §3.2–§3.3）。

**三、替代現狀方式先淘汰、再決選。** 地板量的是與「維持現狀」兩兩對決的票數，排在投票系統之前（[`06`](06-修憲與人民修改法規範.md) §2）。

**四、丙組＝最近一次首長對決的各方。** 不用名冊（[`00`](00-讀法與推導.md) §3.4）。

「總統更新」那條台灣優化硬性在本夾沒有適用對象：本夾沒有直選總統（[`12`](12-人選更新.md) §2）。

## 生態的一句話

生態模型下，第 3 屆國民黨以 34% 的第一偏好拿到單一席次 61 席、單獨組閣：民眾黨選民在兩大黨之間略偏國民黨，而民進黨選民沒有把民眾黨排在國民黨前面。每一場區域對決都由不在場上那一方的選民決定，所以批鬥對手陣營有了價格；代價是單一席次對這些第二偏好極敏感，約三分之一選區出現循環（[`15`](15-預期政治生態.md)）。
