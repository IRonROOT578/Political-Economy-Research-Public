## 2 規則（主路徑）

### 2.1 兩種狀態（封閉列舉）

憲法未列名的狀態不存在。不得以命令創設憲法與基本法皆未規定的回應等級。

| | 戰爭／武力攻擊 | 重大災害、疫病 |
|---|---|---|
| 宣告 | 行政首長宣告 | 行政首長宣告 |
| 追認 | **72 小時內**全院 ≥91，否則失效 | 同左 |
| 一次期限 | 30 日 | 15 日 |
| 延長 | 全院 **≥108**，每次 ≤30 日 | 全院 ≥91，每次 ≤15 日 |
| 累計上限 | **180 日** | **90 日** |
| 逾期未表決 | **狀態終止** | **狀態終止** |
| 適用範圍 | 得限於特定地區 | 得限於特定地區 |

累計上限屆滿後仍需延長者，須以**基本法程序（≥108）**逐次為之，每次不得逾 30 日。

「逾期未表決即**終止**」而非「視為同意」，是刻意的預設值選擇：**讓沉默的結果是狀態結束。**

### 2.2 離島與集會（自由發揮）

已刪的「地理情形」硬性不再是出處。本夾仍作這些安排，理由自負：離島與海空聯繫可被切斷。

- 狀態得**限於特定地區**宣告（例如僅及於某離島）。
- 議會**因故不能在其所在地集會時，得於任一地點集會，其決議有效**——包含以經認證的遠距方式為之，但表決仍須記名並公開紀錄。
- 離島選區（[`01`](01-議會組成與選制.md) §2.6）之投票所不能開設時，得設本島替代投票所；**投票日不得變更**。

### 2.3 緊急命令

- 行政首長於狀態期間得發布緊急命令，具法律效力。
- 命令須於發布後 **7 日內**送議會。
- 議會得隨時以 **≥91 廢止**任一命令；**廢止不受覆議**（本夾無法律覆議權）。
- 未於 30 日內送達，或經議會否決者，即失效。
- **狀態終止時，所有緊急命令同時失效。**
- 緊急命令不得變更憲法、基本法、選舉法規、法院組織。

因為行政首長**沒有解散權**（[`02`](02-行政首長.md)），議會的廢止權是真的。威瑪的失敗機制正在這裡：議會廢止緊急命令，總統就解散議會，重選期間再發同一道命令。本夾兩個槓桿都不給。

### 2.4 期間不得停止的事（紅線）

- **任何選舉。** 議員的定期選舉、補選一律照常。**任期不因緊急狀態延長。**
- **建設性更新與議員更新**不因緊急狀態停止（[`02`](02-行政首長.md)、[`12`](12-人選更新.md)）。宣告狀態的人不因此獲得保護。
- 已定投票日的公民投票與修憲複決（[`06`](06-修憲與人民修改法規範.md)）。
- 彈劾程序（[`09`](09-司法院.md)、[`10`](10-監察院.md)）。
- 議會的集會與表決（§2.2）。
- 司法院的審查程序。

**這一節沒有但書。** 一個「經議會同意得延期」的但書一旦存在，它就是整部憲法裡最先被用掉的東西。

而且它與 `1-優化/行政立法/一院議會制.md` 非硬性直接相關：**建設性更新不因緊急狀態停止**。若緊急狀態能停止更新，現任就取得自我保護。本夾不套「總統更新」硬性——沒有直選總統。

### 2.5 不得停止的權利

生命權、不受酷刑、不受奴役、罪刑法定與不溯及既往、法律人格、公正審判的核心（獨立法院、辯護權）、思想與宗教自由，於任何狀態下均不得停止。

得暫時限制者以**列舉**為限：遷徙、集會、營業、財產之徵用（徵用須補償，並於狀態終止後 180 日內完成給付）。

**行政拘束（不經法院裁定的人身自由限制）不得逾 48 小時**，逾時須由法官裁定。

### 2.6 防常態化

> 緊急狀態存續期間及其終止後 **24 個月**內，不得以法律或基本法將該狀態下行使之行政權力改為常態權力；**違反者，該條文無效**。

排除方式：全院得以 **≥108 逐條記名並敘明理由**排除本款之適用。

本夾不禁止這種轉換，只要求它必須在 24 個月的冷卻之後、以基本法門檻、**逐條記名地**做——必須有人具名承擔。

「**違反者該條文無效**」這六個字是這一條的全部力量。沒有它，這就只是一句還得靠別人去查有沒有人遵守的勸誡——而查的人通常就是通過那條法律的人。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 宣告後 72 小時內議會未集會 | 狀態失效。總統得於議會集會後重新宣告 |
| 議會不能在所在地集會 | 於任一地點或經認證的遠距方式集會，決議有效（§2.2） |
| 追認票 90（差一票） | 未通過，狀態失效 |
| 累計上限屆滿仍有戰事 | 改走基本法程序 ≥108 逐次延長 |
| 緊急命令與現行法律牴觸 | 狀態期間命令優先；狀態終止時命令失效，法律回復適用 |
| 命令失效後已完成之處分 | 不因命令失效而當然無效，但相對人得請求救濟與補償 |
| 狀態期間屆期改選 | 照常改選。新屆須於首次集會 72 小時內重新追認，否則狀態終止 |
| 狀態期間總統被更新或彈劾 | 新總統承接該狀態，期限與累計上限不重新起算 |
| 離島投票所不能開設 | 設本島替代投票所；投票日不變 |
| 防常態化爭議 | 任何人於具體案件中得主張，由司法院認定 |
| 24 個月內以「非該狀態下之權力」為名立法 | 是否為同一權力由司法院認定，不由立法者自我認定 |
