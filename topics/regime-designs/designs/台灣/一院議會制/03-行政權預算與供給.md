# 行政權預算與供給

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `1-優化/財政.md` | 非硬性 | **信任供給合一**：禁止只撤供給、不撤信任；提供者須相同。**規劃保障的供給**對應於部分行政權預算（如政策裁量性資本門、預備金與政務應變；不含法定義務、歲入、稅制） |
| `1-優化/財政.md` | 非硬性 | **議會制：建設性不信任＋行政權供給自動通過**（參考自法國第 49.3 條）。若某些議員期限內不通過更新信任案，政府提出的供給自動生效 |
| `1-優化/財政.md` | 非硬性 | 法國的問題是**政體錯配**：建設性不信任不適用於「總統決定總理」，故只有供給保障沒有信任保障 |
| `1-優化/財政.md` | 可選 | 立法權管好自己的立法，行政權管好自己的行政（含：**部分行政權預算**） |
| `1-優化/財政.md` | 可選 | 僅單一席次議員表決預算 |

對應表不點雜項。供給自動生效是本檔主路徑。預提是總統制的解法，本夾不適用。

## 2 規則（主路徑）

### 2.1 框架

> 立法權就管好自己的立法，行政權就管好自己的行政（含：**部分**行政權預算）。

在議會制裡，供給的授權者仍是議員——但**授權的預設值是給，不是不給**。「部分」的限制由 §2.2 的封閉列舉落實。

### 2.2 規劃保障的供給（範圍，封閉列舉）

1. 政策裁量性資本門支出。
2. 預備金與政務應變預算。
3. 行政機關經常門運作費用。
4. **列名**政策計畫的經常門支出。

**不含**：法定義務支出、歲入、稅制、非行政部門預算、中央對地方之財政移轉公式。

法定義務支出（已立法之給付、債務還本付息、確定判決）**始終撥付**，不需年度議決。

### 2.3 自動生效

政府將供給案送達單一席次議員後：

- 若 **15 個開會日**內未通過建設性更新信任案，該供給案**生效**。
- 100 人仍得在生效前以 **≥51** 通過建設性更新，順便換掉政府。

**拒絕這筆錢與換掉這個人是同一個動作。** 想拒絕供給的人必須拿出繼任者。

### 2.4 這與第 49.3 條哪裡不同

形狀來自 49.3。差別四處，每一處都對應提示詞自己指出的問題：

| | 第 49.3 條 | **本夾** |
|---|---|---|
| 提案的政府從哪來 | **總統指定的總理** | **100 名單一席次議員自己選出的首長** |
| 議會的回應 | 不信任案，**不必提繼任者** | 建設性更新，**不提繼任者不予受理** |
| 倒閣之後 | 下一任總理仍由總統指定 | 通過的那一刻準人選就任 |
| 性質 | 政府主動按下的挑釁按鈕 | **預設值**：不做事情就生效 |

第一行正是 `1-優化/財政.md` 點名的**政體錯配**——本夾沒有總統可以指定首長，錯配不成立；建設性不信任因此真的用得上。

第四行是溫度差：49.3 每次使用都被解讀為藐視議會；本夾的自動生效是**不作為的後果**。

### 2.5 非供給的行政歲出

規劃保障的供給以外的行政歲出，由單一席次議員 **≥51** 議決：

- **得刪不得增**。
- 不得把整案凍結為零。
- 附條件通過視為未通過。
- 會計年度開始後 **60 日**未作成議決者，**沿用上一年度已議決額度**。

### 2.6 複數席次不參與

80 名複數席次議員不表決任何行政權預算。他們的場域是法律、基本法、修憲與非行政部門預算（[`04`](04-其餘預算.md)）。

**結構性後果**：執政多數（51／100）與立法多數（91／180）可以是不同的人。**政府能活，大法案仍可能卡住。** 寫進 [`16`](16-完善與自洽.md)。

### 2.7 沿用條款是自由發揮

`配置/雜項/財政.md` 未繼承，仍採用，理由自負：停擺是 `1-優化/行政立法/共用.md` 非硬性點名的美國病灶之一；一個把台灣列為二極化反例的提示詞，不會希望本設計自己留一個停擺開關。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 供給案送達後政府更迭 | 新首長得撤回並重送，15 個開會日重新起算 |
| 15 個開會日內提出建設性更新但未通過 | 供給案於表決日**次日**生效 |
| 建設性更新通過 | 供給案失效。新首長重送，期限重新起算 |
| 供給案逾越 §2.2 的封閉列舉 | 逾越部分無效，其餘部分仍適用自動生效 |
| 範圍有爭議 | 屬權限爭議，由司法院裁判；未決期間該項目暫依上年度額度撥付 |
| 歲入不足 | 法定義務優先撥付；供給案內裁量支出依政府提出並經單一席次 ≥51 同意的減列順序削減；未及議決者按比例齊頭削減 |
| 非供給歲出逾 60 日未決 | 沿用上年度已議決額度，不歸零 |
| 議會拒絕開議以規避期限 | 期限依**曆日**併計，不因不開議而中止 |
| 單一席次出缺 | 分母仍 100，門檻仍 51 |
| 緊急狀態期間 | 預備金與政務應變得先行動支，30 日內補送單一席次備查 |
