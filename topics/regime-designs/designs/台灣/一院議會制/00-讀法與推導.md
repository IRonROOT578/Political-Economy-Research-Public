# 讀法與推導

本檔是概要層。本夾是**一院議會制**：行政首長由某些議員選出並更新；供給走議會制路徑。提示詞以 `origin/user/work` **`e0fdb55`** 為準。

議會組成數字（180＝100＋80）與總統制正式夾相同，是同一套台灣配置下的治理論據收斂，不是「完工定義＝同總統制夾」。規則敘事以本夾機關稱謂（行政首長）為準。

## 1 對應表

```
都用 0-基本
都用 民選制
# 台灣
都用 配置\台灣\基本
1. 一院議會制: 1-優化 配置\台灣\優化 配置\個人偏好
```

監察／考試出處在 `配置/台灣/基本/其他權` **硬性**，不在對應表映射句。投票：唱票式 **且** 不用電子計票。議會組成**給**含總席次數、每個成分的選制與席次數。

台灣優化硬性（Herding cats、兩個程度比較）落點見本夾 [`13`](13-反例診斷.md)。本夾有組閣（7 個開會日＋刷尾）、有建設性更新、無全國直選總統。不要把總統制夾的「無組閣」複製過來。

## 2 塊怎麼接

```
人民 ── 單一 100 + 複數 80 ──► 議會
單一 100 ── 選出／更新行政首長（某些議員）
         ── 表決供給
         ── 甲組專選三院
複數 80 ── 乙組專選三院
最近一次首長對決各方 ── 丙組
首長 ── 建設性更新；供給逾期自動生效；無法律覆議；無解散
```

## 3 三個結構決定

**某些議員＝單一 100。** `0-基本` 硬性：選出與更新皆某些議員投票。信任供給合一：提供者須相同。供給表決者是單一席次。交會把「某些議員」釘在 100 人、過半 51。

**首長兼元首。** 虛位元首在危機時會被要求介入。本夾全國層級只有這一個行政職位。

**丙組不用名冊。** 現役丙組＝法律專業名冊，正中台灣基本反例。改用對決各方（民意代理）。乙組留下。

## 4 與總統制夾（對照，不是完工定義）

| | 總統制夾 | 本夾 |
|---|---|---|
| 行政 | 人民選總統 | 單一 100 選首長 |
| 更新 | 人民更新，無議會關卡 | 建設性；準人選贏現任 ≥51 |
| 彈劾 | 首長可被彈劾 | 首長不彈劾 |
| 供給 | 拿掉撤供給工具，不用預提 | 期限內不更新則自動生效 |
| 法律覆議 | 總統得退回一次 | **無** |
| 丙 | 正副總統決選各組 | 首長對決各方 |
| 總統更新硬性 | 適用 | **無適用對象** |
