| 來源 | 條件 | 位階 |
|---|---|---|
| `0-基本/行政立法/一院議會制.md` | **最高行政首長**，功能含負責行政；**選出方式：某些議員投票；更新方式：某些議員投票** | 硬性 |
| `1-優化/行政立法/一院議會制.md` | **建設性更新信任案**：準人選須在與現任的兩兩對決中獲得超過一定量的某些議員支持 | 非硬性 |
| `1-優化/行政立法/一院議會制.md` | 準人選由某些議員採排名投票選出 | 可選 |
| `1-優化/財政.md` | 議會制的供給解法：**建設性不信任＋行政權供給自動通過**（參考自法國第 49.3 條） | 非硬性 |
| `配置/台灣` 四條硬性＋架構一條 | 亞洲效率／反 Herding cats／反為反而反；黑金（如：台灣立委曾經的 sntv）；修憲難度不能實質改不了（**歷史最高得票 817 萬 < 選舉人總額之半數**）；**總統更新不應讓立法權凌駕人民罷免權**；**架構：憲法與法案之間設一法規位階** | 硬性 |
| `配置/雜項/行政立法/共用.md` | **少身分政治**（映射只取這一條） | 硬性 |
| 對應表 | **有監察權、考試權** | 映射 |

**沒有「不用／用 預提行政權預算」那一句**——預提是總統制的解法（`1-優化/財政.md`），議會制走另一條。

## 2 席次與選制：與總統制夾相同

**180＝單一 100＋複數 80**，7 大區、彈性名單、聖拉古、無門檻、M∈[8,14]，離島合 1 席，無民族席、無性別配額。

推導完全相同（同一份台灣配置、同一組硬性），**不重寫**：見 [`../一院總統制/00-讀法與推導.md`](../一院總統制/00-讀法與推導.md) §2–§5。

門檻：

| 場域 | 過半 | 3/5 | 2/3 |
|---|---|---|---|
| 全院 180 | 91 | 108 | 120 |
| 單一 100 | **51** | 60 | 67 |
| 複數 80 | 41 | 48 | 54 |

**單一 100 的過半 51，在本夾同時是「選出並更新行政首長」與「行政權供給」的門檻**——比總統制夾多一項。

## 3 政體的三個結構決定

### 3.1 某些議員 ＝ 單一席次 100

`0-基本` 只寫「某些議員」，沒有指定是誰。本夾定為**單一席次 100**。

理由是兩條條件的交會：

- `1-優化/財政.md` **信任供給合一**：信任與供給的提供者須**相同**。
- 同檔可選條件：**僅單一席次而非複數席次議員表決預算，避免預算案上 Herding cats**。

第二條指定了供給的提供者，第一條把信任的提供者綁成同一批。**於是「某些議員」＝單一席次 100，建設性更新的門檻 ≥51。**

分工因此是制度性的：

| | 單一席次 100 | 複數席次 80 |
|---|---|---|
| 選出行政首長 | **是** | 否 |
| 建設性更新 | **是** | 否 |
| 表決行政權供給 | **是** | 否 |
| 法律、基本法、修憲 | 是 | 是 |
| 非行政部門預算 | 是 | 是 |
| 三院人選 | 甲組 | 乙組 |

**錢與政府是同一批人的事，規則是全院的事。**

### 3.2 行政首長兼國家元首，不另設元首

本夾**不設**一個與行政首長分離的國家元首。

理由與 `1-優化/行政立法/共用.md` 的非硬性條件直接相關：它把**台美韓**列為社會二極化與內耗的例子。一個另外產生的元首，即使「沒有實權」，仍是第二個宣稱代表全國的職位——**每次政府危機都會有人要求它介入**，而那正是內耗的形態。

本夾把那個位子拿掉：**全國層級只有一個行政職位，而它由 100 名單一席次議員產生。**

代價：交接期間沒有超然的象徵性延續者，由副首長代理（[`02`](02-行政首長.md) §3）。

### 3.3 無解散權

行政首長不能解散議會。

- 換人走建設性更新，**不重啟屆期**——議會做滿 4 年。
- 僵局有內部出口（換首長），不需要外部出口（提前大選）。
- 解散權會把僵局升級成全國性動員，而那是 §3.2 同一條非硬性要避免的。

## 4 與總統制夾的差異一覽

| 面向 | 一院總統制 | **本夾** |
|---|---|---|
| 行政首長怎麼產生 | 人民 top-3 孔多賽直選 | **單一席次 100 記名排名投票** |
| 怎麼換 | 人民更新（連署 10%、地板 40%） | **建設性更新（≥51／100，須具名準人選）** |
| 國家元首 | 總統本人 | **行政首長兼任** |
| 行政權供給 | 年度議決＋四條防餓死規則 | **期限內未通過建設性更新即自動生效** |
| 預提 | 不用（對應表指定） | 不適用（總統制的解法） |
| 三院丙組 | 正副總統候選人加權 | **專業名冊**（本夾無直選正副總統） |
| 人民更新的對象 | 總統、單一席次、複數席次 | **只有議員**（[`12`](12-人選更新.md) §2） |
| 屆期 | 總統與議會同 4 年 | 議會 4 年；換首長不重啟 |

## 5 「總統更新」那條硬性在本夾怎麼處理

`配置/台灣` 硬性：**總統更新：不應讓立法權凌駕人民罷免權**（如：現行經全體立法委員 2/3 以上同意），但仍有穩定性。

**本夾沒有總統。** 行政首長由 100 名議員選出，也由他們更新。

這**不是**「立法權凌駕人民罷免權」——被凌駕的前提是**先有那個權**。行政首長不由人民直接選出，人民從來沒有對他的授權；`0-基本/行政立法/一院議會制.md` 硬性本身就寫明「更新方式：某些議員投票」。

人民更新的對象是**議員**，而議員換了，首長的多數就換了（[`12`](12-人選更新.md) §2.1）。**議員的人民更新不受任何議會關卡拘束**——那一條在本夾照樣成立。
