# 讀法與推導

本檔是概要層。議會組成與總統制夾相同，見 [`../一院總統制/00-讀法與推導.md`](../一院總統制/00-讀法與推導.md)——同一份台灣配置、同一組硬性。本檔只寫差異。

## 1 對應表

```
1. 一院議會制: 1-優化 配置\台灣\優化 配置\個人偏好
```

另加 `0-基本`、`配置/台灣/基本`、民選制、監察、考試。不點雜項。不套「總統更新」硬性（無直選總統）。

## 2 塊怎麼接

```
人民 ── 單一 100 + 複數 80 ──► 議會
單一 100 ── 選出／更新行政首長（某些議員）
         ── 表決供給
         ── 甲組專選三院
複數 80 ── 乙組專選三院
最近一次首長對決各方 ── 丙組
首長 ── 建設性更新；供給逾期自動生效
```

## 3 三個結構決定

**某些議員＝單一 100。** `0-基本` 硬性：選出與更新皆某些議員投票。信任供給合一：提供者須相同。供給表決者是單一席次。交會把「某些議員」釘在 100 人、過半 51。

**首長兼元首。** 虛位元首在危機時會被要求介入。本夾全國層級只有這一個行政職位。

**丙組不用名冊。** 現役丙組＝法律專業名冊，正中台灣基本反例。改用對決各方（民意代理）。乙組留下。

## 4 與總統制夾

| | 總統制夾 | 本夾 |
|---|---|---|
| 行政 | 人民選總統 | 單一 100 選首長 |
| 更新 | 人民更新，無議會關卡 | 建設性；準人選贏現任 ≥51 |
| 彈劾 | 首長可被彈劾 | 首長不彈劾 |
| 供給 | 拿掉撤供給工具，不用預提 | 期限內不更新則自動生效 |
| 丙 | 正副總統決選各組 | 首長對決各方 |
| 總統更新硬性 | 適用 | **無適用對象** |
