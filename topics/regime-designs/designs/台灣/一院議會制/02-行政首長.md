## 2 規則（主路徑）

### 2.1 某些議員 ＝ 單一席次 100

理由見 [`00`](00-讀法與推導.md) §3.1：信任供給合一要求提供者相同，而可選條件把供給的提供者指定為單一席次議員。

過半 **51**。

### 2.2 選出（新屆）

新屆集會後 **7 個開會日**內：

1. 單一席次議員 100 人以**記名排名投票**產生準人選。排名可截斷、可並排。
2. 以孔多賽完成法決出勝者。**一次計票**，不拆多輪刷尾。
3. 勝者即為行政首長，**無須另行同意投票**。

無現任時不適用對決門檻——第一次產生不需要贏過任何人。

**7 個開會日是硬期限。** 逾期：改為每個開會日一輪、篩掉排名最後一名，直到只剩一人（自由發揮，回答荷蘭組閣過長）。

**沒有「談不攏就繼續談」這個選項。** 這是對荷蘭 299 日組閣的直接回答（[`13`](13-反例診斷.md) §5.1）。

行政首長**不必是議員**。

### 2.3 職權

- 負責行政；任免政務人員；指揮行政部門。
- **兼國家元首**：對外代表國家、公布法律、主持國家儀典（[`00`](00-讀法與推導.md) §3.2）。
- 提出法律案與行政權供給案。
- 依 [`07`](07-緊急狀態.md) 宣告緊急狀態。
- 統帥武裝力量。**宣戰須全院 ≥120（2/3）同意。**

**無法律覆議權**——他由議員選出，再給他一個擋議會的工具沒有道理（[`05`](05-法律與法規位階.md) §2.3）。

### 2.4 更新（建設性）

| 項目 | 規則 |
|---|---|
| 提案 | 單一席次議員 **1/4（≥25）** 連署，且**須於提案書中載明準人選姓名** |
| 未載明 | **不予受理**，不列入議程 |
| 表決 | 準人選與現任的**兩兩對決**，記名 |
| 通過 | 準人選得 **≥51／100** |
| 效果 | 準人選就任，現任同時解職 |
| 未達 | 現任留任 |
| 冷卻 | 失敗後 **3 個月**內同一提案人不得再提 |
| 每會期上限 | **2 次** |
| 屆期 | **不重啟。** 議會做滿 4 年 |

**「不載明繼任者即不予受理」是本夾對威瑪消極多數的直接回答。** 反對現任的多數必須先在自己內部產生一個共同的人，否則連把案子排上議程都做不到。

### 2.5 不得只撤供給、不提繼任者

- 拒絕行政權供給的**唯一途徑**，是在期限內通過建設性更新信任案（[`03`](03-行政權預算與供給.md)）。
- 不存在「否決供給但保留現任」的表決選項；議事規則不得設置這種動議。
- 複數席次議員完全不參與行政權供給的表決，因此也不可能只撤供給。

### 2.6 無解散權

行政首長不能解散議會。理由見 [`00`](00-讀法與推導.md) §3.3。

代價：僵局沒有「訴諸選民」這條路。本夾接受——**一個能在內部換掉首長的議會，其僵局本來就可以在內部解決**。

### 2.7 政府成員

首長任免政務人員，不需議會同意。議會得質詢、調查，得對個別政務人員提出**譴責案**（全院 ≥91），但**譴責不生解職效力**——解職只有一條路，就是換掉首長本人。

理由：若個別部長可被議會逐一拔除，行政的組成就變成逐案談判，那是 Herding cats。

### 2.8 副首長

由首長於就任時提名，經單一席次 ≥51 同意。首長出缺時代理，並於 7 個開會日內依 §2.2 重選。

副首長代理期間**不得**宣告緊急狀態、不得任免政務人員。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆逾 7 個開會日未選出 | 改為每開會日一輪刷尾，直到剩一人 |
| 首長死亡、辭職、永久不能視事 | 副首長代理，**7 個開會日**內重選。**不重啟屆期，議會不被解散** |
| 更新案準人選於表決前退出 | 該案失效；提案人得另提，冷卻期不重新起算 |
| 兩案同時成案 | 依連署完成先後表決；前案通過則後案失效 |
| 兩兩對決同票 | 現任留任 |
| 準人選當選後拒絕就任 | 該案視為未通過，適用 3 個月冷卻 |
| 首長長期不能視事 | 單一席次 ≥51 得認定，副首長代理並於 7 個開會日內重選 |
| 單一席次出缺致實際人數不足 100 | **分母仍 100**，門檻仍 51 |
| 緊急狀態期間 | 更新程序**不中止**（[`07`](07-緊急狀態.md)）。宣告狀態的人不因此獲得保護 |
| 會期外 | 1/4 連署得要求召開臨時會，議長應於 7 日內召集 |
