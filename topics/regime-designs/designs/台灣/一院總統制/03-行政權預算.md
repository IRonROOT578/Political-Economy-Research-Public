# 行政權預算

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| 對應表 | 映射 | **不用 預提行政權預算** |
| `1-優化/財政.md` | 非硬性 | 信任供給合一：禁止只撤供給不撤信任；提供者須相同。**總統制：可用其他設計降低供給問題** |
| `1-優化/財政.md` | 可選 | **僅單一席次而非複數席次議員表決預算** |
| `1-優化/行政立法/共用.md` | 非硬性 | 避免美國因兩大黨對立而預算停擺 |

**對應表指定不用預提**，所以本夾走「總統制：可用**其他設計**降低供給問題」。沿用條款是自由發揮（對應表不點雜項），理由是停擺被同檔非硬性點名。

## 2 規則（主路徑）

### 2.1 誰表決

行政權預算**只由單一席次議員 100 人表決**。通過門檻 **≥51**。複數席次不參與。

理由是 `1-優化/財政.md` 的可選條件：避免預算案上 Herding cats。100 人比 180 人容易達成共識，而單一席次議員有明確的領土問責對象，比名單議員更適合對錢負責。

**代價**：51／180 ＝ **28.3%**。這是那條可選條件的必然結果。**但在總統制夾它只影響錢**——總統由人民直選，不靠這 51 人存在；凡是留得下來的東西一律要全院（[`00`](00-讀法與推導.md) §4.5）。

### 2.2 不用預提，那供給問題怎麼解

預提的作用是讓行政不被議會餓死。本夾不用它，改用**四條把「餓死」這個動作拿掉的規則**：

| # | 規則 | 拿掉了什麼 |
|---|---|---|
| 1 | **法定義務支出自動撥付** | 已立法之給付、債務還本付息、確定判決不需年度議決 |
| 2 | **裁量支出得刪不得增，且不得整案凍結為零** | 拿掉「歸零」這個選項 |
| 3 | **逾期沿用**：會計年度開始後 60 日仍未議決者，裁量支出沿用上一年度已議決額度 | 拿掉「不表決就停擺」這個選項 |
| 4 | **附條件通過視為未通過**，走第 3 條 | 拿掉「用條件綁架」這個選項 |

**「只撤供給、不撤信任」在本夾無從發生**——不是因為禁止，是因為**議會沒有那個工具**：它撤不了總統（無倒閣），也把政府停不到餓死（第 1、3 條）。它能做的是逐年砍新計畫。

這就是「信任供給合一」在總統制的另一種達成方式：**不是把兩者綁在一起，是把撤供給的工具拿掉。**

### 2.3 「部分行政權預算」

`1-優化/財政.md`：「立法權就管好自己的立法，行政權就管好自己的行政（含：**部分**行政權預算）。」

在本夾，「部分」的落實是**第 1 條的法定義務支出**——那一份不經年度議決，是行政那一份裡議會碰不到的核心。其餘裁量支出仍每年由單一席次議決，議會保有實質的年度決定權。

**與測試夾的差別就在這裡**：測試夾用預提，把「部分」擴大成一份選前公告、任期有效的清單；本夾不用，「部分」只有法定義務那一塊。

### 2.4 逐年砍新計畫是議會真正的工具

議會不能餓死政府，但**能不批准新的**。裁量支出得刪不得增，意味著：

- 總統想開新計畫，必須說服單一席次的 51 人。
- 議會想停掉某個計畫，把它刪到不能運作即可（但不能刪到零）。
- 兩邊的實際戰場是**增量**，不是存量。

**這是刻意的**：存量的爭議會變成停擺，增量的爭議只會變成政策辯論。

### 2.5 沿用條款是自由發揮

對應表不點雜項。本夾仍採用逾期沿用，理由自負：

**停擺是 `1-優化/行政立法/共用.md` 非硬性點名的美國病灶之一。** 一個把台灣列為二極化反例的設計，不該自己留一個停擺開關。

### 2.6 三院與議會的預算不在本檔

司法院、監察院、考試院、議會、選務機關的歲出走 [`04`](04-其餘預算.md)，由**全院**議決，且**總統不得刪減**。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 逾 60 日未議決 | 裁量支出沿用上年度已議決額度。**不是歸零，也不是總統原案自動通過** |
| 議會刪減某科目至無法運作 | 該科目仍得撥付至「不能運作」的界線；界線爭議由司法院裁 |
| 議會將某科目刪至零 | 該刪減無效，回復至上年度額度 |
| 附條件通過 | 視為未通過，走沿用 |
| 總統拒絕執行已議決之科目 | 為彈劾事由；監察院得逕行調查 |
| 法定義務支出被列入年度議決 | 該部分議決無效，仍自動撥付 |
| 某支出是否屬法定義務有爭議 | 由司法院裁判；未決期間依上年度處理方式撥付 |
| 未執行之餘額 | 應繳庫，不得留用（[`10`](10-監察院.md) 查核） |
| 緊急狀態期間 | 預備金與政務應變得先行動支，30 日內補送單一席次備查 |
