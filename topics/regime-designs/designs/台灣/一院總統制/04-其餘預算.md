# 其餘預算

## 2 規則（主路徑）

### 2.1 非行政部門的預算

國民議會、司法院、監察院、考試院、選務機關、獨立劃分委員會的歲出：

1. 各該機關**自行編列**歲出上限。
2. **總統不得刪減**這些科目，只能轉送。
3. **全院 ≥91** 議決，**得刪不得增**。
4. 會計年度開始前未議決者，**沿用上一年度已議決額度**。

第 2 點是本夾對權限爭議最實際的防線：一個能刪司法院預算的總統，不需要違憲就能讓憲法法庭停轉。

第 3 點用**全院**而非單一席次：這些不是行政的錢，「僅單一席次表決預算」那條可選條件的理由（避免預算案上 Herding cats）針對的是行政權預算的協商，不適用於此。

議會的預算由議會自己批准。形式上是自己審自己，但讓行政或司法批准立法權的預算，等於給它們一根對立法權的常設槓桿。**冗餘比癱瘓好。**

### 2.2 稅制與歲入

稅目與稅率以**法律**定之（全院 ≥91）。

`1-優化/財政.md` 的規劃保障供給明文不含歲入與稅制。界線：**行政可以在議決範圍內花已議決的錢，不能在同一個機制下決定人民繳多少稅。**

### 2.3 為什麼不採「考試權先經行政權刪減，再送議會」

`配置/雜項/總體.md` 有這條可選條件，但**本夾的映射只取該目錄下 `行政立法/共用.md` 的「少身分政治」**，未繼承此條。

即使把它當自由發揮的選項，本夾**仍不採用**：考試院掌文官的「進得來」與「趕不走」（[`11`](11-考試院.md)），若其預算須先經行政刪減，行政就取得一根對文官體系的間接槓桿——那與 §2.1 第 2 點的整個用意相反。

### 2.4 中央與地方的財政劃分

屬**基本法**事項（[`05`](05-法律與法規位階.md)）。

移轉公式須**普遍適用**：憲法明文禁止中央與個別地方自治團體締結變更其財政地位之個別協定。

年度移轉總額由全院 ≥91 議決，不由 [`03`](03-行政權預算.md) 的單一席次議決。

### 2.5 決算與餘額

- 未執行的預算餘額應**繳庫**，不得留用、不得移作他項。
- 決算由監察院審計查核（[`10`](10-監察院.md)）。
- 監察院每年公布行政權預算的 **議決額／實際支出／差異理由** 對照表，直接送議會與公眾，不經總統核閱。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 某機關編列的上限被議會刪至無法運作 | 該機關得聲請司法院認定；認定成立者恢復至上一年度額度 |
| 總統刪減非行政部門科目後轉送 | 刪減無效，以原編列數送議會 |
| 會計年度開始前未議決 | 全部沿用上年度已議決額度，不歸零 |
| 移轉公式修正案未跨屆確認 | 不生效，續用原公式 |
| 個別地方自治團體主張其財政地位應調整 | 只能主張公式適用錯誤，由司法院裁判；不得請求個別協定 |
| 餘額未繳庫 | 監察院逕行認定該支出無法證明合法性並公告 |
| 三院之間就同一經費爭執 | 各自編列，由議會議決；不由行政協調 |
