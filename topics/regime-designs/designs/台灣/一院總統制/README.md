# 台灣：一院總統制

```
# 台灣
有監察權、考試權
2. 一院總統制: 0-基本 1-優化 配置\台灣
配置\雜項\行政立法\共用.md : 「少身分政治」
不用 預提行政權預算。
```

繼承 `0-基本`＋`1-優化`＋`配置/台灣`，以及 `配置/雜項/行政立法/共用.md` 的**「少身分政治」一條**。**不**繼承 `配置/俄羅斯`、`配置/中國`、`配置/惡搞`，也不繼承雜項的其餘各條。

## 一句話

國民議會一院 **180＝單一 100＋複數 80**。總統正副同組、人民 **top-3 孔多賽**選出、負責行政；**無倒閣、無解散、不設行政院長**。行政權預算**不用預提**，只由單一席次 100 人表決，並用四條規則把「餓死政府」這個動作拿掉。五權：行政、立法、司法、監察、考試。

## 四個本夾特有的決定

**一、席次從 113 增到 180。** 舊依據「避免冗員太多（如 200 多席），參考 225→113」隨映射移出本夾的繼承範圍——那條現在在 `配置/雜項`，而本夾只取該檔的「少身分政治」。新依據是**方便治理＋國際對照**：180 的每席人口 13.0 萬、立方根比值 0.63，落在人口 1,500–3,000 萬民主國家的區間（130–250 席）；**現行 113 的比值只有 0.40**。見 [`00`](00-讀法與推導.md) §4。

**二、複數席次改用彈性名單、無門檻、7 大區。** 提示詞對複數席次**只規定聖拉古、無門檻、允許聯盟，沒有規定名單型式**；而硬性條件反過來點名開放名單 PR 是黑金風險。台灣立委 SNTV 時期的黑金經濟學建立在「拿 10–15% 就當選」，**彈性名單把個人票的邊際報酬壓在躍升門檻之下，那塊小票源不再夠用**。M 因此鬆綁到 [8,14]。見 [`01`](01-議會組成與選制.md) §2.3。

**三、台灣自己是被點名的反例。** `1-優化` 把台美韓列為社會二極化與內耗的例子，理由是**「提高敵國在國內拉一打一、滲透的難度」**。所以 [`13`](13-反例診斷.md) §2 不是外國經驗的借鏡，是自我診斷：總統相對多數一輪、區域立委相對多數、不分區 5% 門檻、曾經的 SNTV，逐條對應本夾的處理。

**四、總統更新完全沒有議會關卡。** `配置/台灣` 硬性點名現行的「立法委員 2/3 以上同意才交付人民投票」是立法權凌駕人民罷免權。本夾：議會**沒有**提議權、同意權、審查權；穩定性由**人民端的三個門檻**提供（連署 10%、票數地板 40%、冷卻 12／24 個月）。見 [`12`](12-人選更新.md) §2。
