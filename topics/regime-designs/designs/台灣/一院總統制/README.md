# 台灣：一院總統制

本憲政設計最新更新：2026-11-10

## 一句話

國民議會一院 **180＝單一 100＋複數 80**。總統正副同組、人民 top-3 孔多賽選出、負責行政；無倒閣、無解散、不設行政院長。行政權預算**不用預提**，由全院 180 表決（≥91），法定義務照撥、逾期沿用，把「餓死政府」這個動作拿掉。五權：行政、立法、司法、監察、考試。其他權高層由甲／乙／丙三組代理人專選；高政治性裁決從甲向兩側同時擴展。

## 四個本夾特有的決定

**一、180＝12 個常設委員會 × 約 15 人。** 判準是議會要能開會、能審查行政、能形成可鞭策的多數。113 的委員會偏薄；立方根 286 對這一院過大。見 [`00`](00-讀法與推導.md)。

**二、複數 80：聖拉古、無法定門檻、允許聯盟、彈性名單。** 不用開放名單：8–14 席的開放名單讓同黨候選人互搶個人票，和過去的 SNTV 一樣養出樁腳與黑金。

**三、身分保障只用在地方。** 澎金馬合 1 區；不設特殊民族保障席與性別配額。

**四、三院人選由甲（單一 100）、乙（複數 80）、丙（正副總統決選各組，權重依第二輪首選票）三組平行選出**，沒有雙重同意可以杯葛。高政治性裁決從甲（居中）向兩側同時擴展；只靠單側湊滿門檻不能通過。

| 2020-01 大選 | 民進黨 | 民進黨 108、國民黨 51、民眾黨 10 … | 一致 |

| 2012-01 大選 | 國民黨 | 國民黨 99、民進黨 68 … | 一致 |
| 美麗島 2026-09 民調 | 民進黨 | 民進黨 107、國民黨 41、民眾黨 32 | 一致 |

總統與議會的第一偏好都用不分區政黨票，不用總統第一輪或區域立委的實際得票（受棄保、禮讓影響），也不用個別候選人。2024 年三黨彼此循環：民進黨一對一勝國民黨、民眾黨勝民進黨、國民黨勝民眾黨；Ranked Pairs 不採認最弱的一環，國民黨當選。改變第二偏好的假設，三黨都可能當選（[`估計結果.md`](估計結果.md) §0）。民調是政黨喜好度換算的占比，只當方向參考。
