## 2 硬性條件怎麼落實

那條硬性有**兩半**，缺一不可。主詞是**總統更新**。被禁止凌駕的是**人民的意志**，不只罷免權。現行「需經全體立委 2/3 以上同意才交付人民」是**含**，必須具體處理。

### 2.1 前半：不應讓立法權凌駕人民的意志（含現行 2/3）

**現行制度的形態**：總統罷免須經全體立法委員 1/4 提議、**2/3 以上同意**，才能交付人民投票。人民要不要更新總統，**先由立法院決定人民有沒有資格投這一票**。

**本夾的作法：完全沒有議會關卡。**

- 更新的發動與成案**只需人民連署**。
- 議會**沒有**提議權、沒有同意權、沒有審查權。
- 議會唯一與總統去職有關的角色是**彈劾**（法律責任），由監察院提案、司法院審判（[`09`](09-司法院.md)、[`10`](10-監察院.md)），與本檔的政治責任是兩條路。
- 沒有別的立法權程序卡住人民對總統的更新（覆議、緊急狀態停止投票都不構成關卡，見 [`07`](07-緊急狀態.md)）。

### 2.2 後半：但仍有穩定性（如：冷卻期）

硬性條件明文要穩定性，並以冷卻期為例。本夾用三樣，**全部在人民端，沒有一樣經過議會**：

| 機制 | 內容 | 為何不算「立法權凌駕」 |
|---|---|---|
| **連署門檻** | 選舉人 10%，180 日內完成 | 人民端的動員成本 |
| **一定票數** | 替代方案對現任的兩兩對決支持票數須 ≥ 選舉人 **25%**，否則先淘汰 | 防投票率過低。30% 投票率兩兩過半 ≈ 選舉人 15%；25% 擋這條 |
| **冷卻期** | 失敗後 12 個月；對現任兩兩支持票最高者仍 < 選舉人 25% 則 24 個月 | 時間，不是誰的同意 |

**這三樣都不是「誰的許可」，是人民自己要跨過的門檻。** 硬性條件反對的是把資格的判斷交給另一個機關，不是反對門檻本身。

## 3 規則（主路徑）

### 3.1 更新 ≠ 出缺 ≠ 彈劾

| | 性質 | 誰決定 | 落點 |
|---|---|---|---|
| **更新** | 政治責任 | **人民** | 本檔 |
| 彈劾 | 法律責任 | 監察院提案、司法院審判 | [`09`](09-司法院.md)、[`10`](10-監察院.md) |
| 出缺 | 事實 | — | §3.6 |

### 3.2 為什麼用替代現狀，不用「同意／不同意」

同意／不同意只問「要不要拿掉這個人」，不問「換成誰」。反對現任的人可以是一群彼此毫無共識的人，他們能拆掉現任，卻產生不出替代者。

替代現狀把兩個問題合成一個：**在具體的替代方案和現任之間選一個採用方案。** 未達一定票數 vs 現任的替代方案先出局，再決選——不是先決出孔多賽贏家再另加地板。

### 3.3 總統（替代現狀方式）

本夾採用 `1-優化/投票` 可選。n＝2（自由發揮；3 個方案 → 6 個完整排序選項單選，落在如）。一定票數＝選舉人 **25%**（自由發揮）。

| 階段 | 規則 |
|---|---|
| 連署 | 選舉人總額 **10%**，180 日內完成。**無任何議會關卡** |
| 第一輪 | **只負責選出 n＝2 名備胎**。全國單記，取得票前 2 名挑戰者。現任不參加第一輪 |
| 第二輪票面 | 2 個備胎為替代方案，現任為「維持現狀」，共 3 個方案；6 格完整排序單選 |
| **先淘汰** | 任一備胎在與現任的兩兩對決中支持票 **< 選舉人總額 25%** 者出局，不進入決選 |
| **再決選** | 對通過淘汰的備胎與現任，用**孔多賽完成法**（如，本夾採用）決出一採用方案 |
| 採用維持現狀 | 現任留任 |
| 採用某備胎 | 該人接任 |
| 冷卻 | 失敗後 **12 個月**內不得再對同一職位發動。看的是備胎對現任的**兩兩支持票**（不是第一輪單記、也不是第二輪首選）。兩名備胎裡這筆票較高的那一名若仍 < 選舉人 25%，改為 **24 個月**。從第二輪投票日起算。失敗幾次都一樣，沒有次數上限 |
| 任期 | 替換成功者接續**原任期之剩餘期間**，不重新起算 |
| 副總統 | 與新任總統同組登記，同時就任 |

兩名備胎都未過 25% 淘汰線時，決選只剩現任 → 當然維持現狀。

「接續原任期」是防止把更新程序當成延長任期的工具。

### 3.4 單一席次議員

該選區選舉人 **10%** 連署。程序同總統（n＝2；先淘汰再決選）。一定票數為**該區選舉人 25%**。冷卻同總統。替換者任期至本屆屆滿。

### 3.5 複數席次議員

該選區選舉人 **10%** 連署後，該區**全部席次**依定期選舉規則重選，**不得針對名單上的個別議員**。

理由：單獨罷免一人只會讓同一份名單的下一位遞補，什麼也沒改變，卻給了對手一個便宜的騷擾工具。整區重選則是真的把選擇交還選民。

重選產生的議員任期至本屆屆滿。該區冷卻 12 個月。

### 3.6 出缺（不是更新）

- 總統：副總統繼任至原任期屆滿，**不補選**（[`02`](02-總統與行政.md) §3）。
- 單一席次：90 日內補選；剩餘任期不足 1 年不補。空席期間分母仍 100。
- 複數席次：同區同名單未當選者依名單順位遞補；名單用盡則空席，分母仍 80。
- 三院：見各該檔，**不走人民更新**。

### 3.7 緊急狀態不停止更新

見 [`07`](07-緊急狀態.md) §2.4。已成案的更新投票不因緊急狀態延期；投票地點得變更，投票日不得變更。

**若緊急狀態能停止更新，總統就取得一個比議會 2/3 更強的自我保護工具**——那是 §2.1 那條硬性要防的東西的變形。

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 連署期間現任辭職 | 改走出缺。已繳連署作廢，不轉成更新 |
| 第一輪後現任死亡 | 改走出缺。第二輪不辦 |
| 挑戰者僅 1 人 | n＝1；第二輪 1 備胎＋現任，票面改 2 格；仍先淘汰再決選 |
| 挑戰者 0 人 | 不辦第二輪，現任留任，冷卻 12 個月 |
| 第一輪第 2 名同票 | 併列進第二輪，票面改 4!＝24 格；淘汰線仍逐一對現任 |
| 兩備胎都過淘汰線，孔多賽贏家不是對現任兩兩最高者 | 決選看完成法；淘汰已做完，不再另加地板 |
| 出現孔多賽循環 | 依完成法（Ranked Pairs）決出 |
| 冷卻末日恰逢定期改選 | 更新不辦，走定期改選 |
| 距定期改選投票日不足 12 個月 | 不辦更新 |
| 更新與彈劾同時進行 | 兩者並行，互不停止；任一成立即生效，另一程序終止 |
| 緊急狀態中 | 更新照辦。得變更投票地點，不得變更投票日 |
