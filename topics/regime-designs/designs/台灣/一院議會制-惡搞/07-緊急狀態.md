# 緊急狀態

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/總體.md` | 硬性 | 緊急狀態是必須交代的憲政選擇之一 |
| `配置/惡搞/總體.md` | **硬性** | **仍為民主和民選國家，不能被認為是獨裁** |
| `配置/惡搞/總體.md` | 非硬性 | 混亂 |

## 2 兩條寫死的紅線

1. **緊急狀態不得延後任何選舉、複決或人選更新投票。** 無例外、無但書。
2. **緊急狀態不停止倒閣程序。**

★ 第二條在本夾特別重要：宣告狀態的可能是一個**看守首長**——一個議會多數已經否定的人。**若緊急狀態能停止倒閣，他就取得了一個自己宣告、自己受益的免疫期。**

★ 草擬階段曾考慮「無期限、選舉得延期」，那越過本夾唯一的硬性條件，已刪除（[`00`](00-為何這仍然不是獨裁.md) §6）。

## 3 規則（主路徑）

### 3.1 宣告與失效

| 項目 | 規則 |
|---|---|
| 宣告 | 行政首長逕行宣告，**含看守首長** |
| 自動失效 | 宣告後 **14 日** |
| 延長 | 議會**出席過半**追認，每次 14 日 |
| 追認失敗 | 立即終止，緊急命令同時失效 |
| 重新宣告 | 無次數限制、無冷卻期 |
| 種類 | 無列舉 |
| 累計上限 | 無 |

### 3.2 混亂在哪裡：與總統制惡搞夾**刻意相反**

| | 總統制惡搞夾 | **本夾** |
|---|---|---|
| 延長門檻 | **2/3（≥150）**，湊不到 | **出席過半**，延得下去 |
| 結果 | 救災每兩週歸零 | **狀態可以無限延長** |
| 混亂的來源 | 應變措施反覆失效 | **看守首長也能宣告；緊急不停倒閣、倒閣不停緊急** |

★ **同一條硬性，兩種壞法。** 總統制惡搞夾壞在「延不下去」，本夾壞在「延得下去，但指揮官一直在換」。

### 3.3 本夾特有的荒謬：同一場災害換三次指揮官名義

★ 示意時序：

| 日 | 事件 |
|---|---|
| 第 1 日 | 災害發生。行政首長宣告緊急狀態，發布徵用與管制命令 |
| 第 5 日 | 議會倒閣通過（出席過半）。**首長解職，但繼續看守**——緊急狀態不因此終止 |
| 第 12 日 | 議會追認延長（出席過半）。**追認的對象是一個他們五天前才否定的人所宣告的狀態** |
| 第 20 日 | 議會選出新首長。**新首長承接該狀態**，期限不重新起算 |
| 第 26 日 | 新首長又被倒閣，繼續看守 |
| 第 34 日 | 再次追認延長 |

**應變指揮官在同一場災害裡換了三次名義，實際上前後只有兩個人，其中一個還是被倒閣過的。**

★ 而每一次交接，緊急命令的署名機關都要重新確認，受徵用的相對人要重新收到通知。

### 3.4 看守首長也能宣告

**明文允許。**

★ 理由（惡搞的理由）：本夾沒有「看守政府權力打折」的概念（[`02`](02-行政首長與看守.md) §2.5）。一個剛被議會多數否定的人，可以宣告緊急狀態、發布緊急命令、並在緊急狀態中**增列預算**（[`04`](04-預算與財政.md) §2.3）。

★ 而這**仍然不是獨裁**：他的權力隨時可被 113 票拿走，他不能延後選舉、不能停止倒閣、不能解散議會（本夾根本沒有解散制度）。

### 3.5 沒有防常態化條款

正式各夾都有「狀態終止後 24 個月內不得把該狀態的行政權力改為常態權力，違反者該條文無效」——那是它們的自由發揮，**本夾不寫**。

★ 但本夾**也沒有一個穩定多數**能把緊急權力寫進常態法律（[`03`](03-立法與修憲.md) §2.2：法律活不過一次倒閣）。**爛規則互相抵銷。**

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 第 14 天議會未表決 | 狀態失效 |
| 追認通過但當日倒閣 | 狀態存續；被倒閣者繼續看守並繼續行使緊急權力 |
| 狀態期間選出新首長 | 新首長承接，期限不重新起算 |
| 狀態期間屆期改選 | **照常改選，不得延期** |
| 狀態期間罷免案成案 | **照常投票，不得延期** |
| 狀態期間倒閣案提出 | **照常表決** |
| 抽籤議長看守期間 | 得宣告狀態（他是代理首長） |
| 緊急命令與看守期增列的預算並存 | 兩者互不影響，皆有效 |
