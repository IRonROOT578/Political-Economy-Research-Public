## 一句話

議會 **225 席全 FPTP**。某些議員＝**全院 225**。首長秘密投票、一輪相對多數（62 票可當）；倒閣出席過半且不必提繼任者；被倒者繼續看守且權力不打折。三院議會記名同意、全體一致。拆得掉，組不出。

## 病理

兩個民選機關對撞是總統制惡搞夾的事。本夾只有一個民選機關，僵局來自：議會有能力拆掉行政權，卻沒有能力產生行政權。不繼承建設性更新、不繼承信任供給合一。
