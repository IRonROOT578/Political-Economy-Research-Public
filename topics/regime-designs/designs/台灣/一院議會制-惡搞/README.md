# 台灣：一院議會制－惡搞

```
# 台灣
有監察權、考試權
2. 一院議會制 惡搞: 0-基本 配置\惡搞
```

只繼承 `0-基本` 與 `配置/惡搞`。**不**繼承 `1-優化`、`配置/台灣`、`配置/雜項`。**有監察權、考試權**（寫在 `# 台灣` 標題下、五夾之上）。

## 手法

> **凡是硬性條件，一字不差地遵守；壞事全發生在硬性條件沒有規定的地方。**

`0-基本/行政立法/一院議會制.md` 的硬性只寫「最高行政首長，選出方式：**某些議員投票**；更新方式：**某些議員投票**」。**它沒有說幾票、沒有說記名、沒有說要不要提繼任者、沒有說多久要選出來。** 本夾把這四個空白填滿。

## 一句話

議會 **225 席全 FPTP**、任期 2 年、**無解散制度**；行政首長由全院 **秘密投票、一輪相對多數**產生（**62 票可當**）；倒閣只要**出席過半且不必提出繼任者**，組閣**無時限**，**被倒閣者繼續看守且權力不打折、還能增列預算**；預算與信任分離，於是**議會可以既不倒閣、又不給錢**；沿用條款只給看守期，**選出正式政府反而失去停擺保護**；三院全體一致決；修憲連提案都到不了；罷免 1% 連署、無地板、無冷卻。

**每一條都合法、民選、可問責，加起來讓國家長期沒有一個有正當性的政府。**

## 病理：拆得掉，組不出

★ 這是本夾與 [`../一院總統制-惡搞/`](../一院總統制-惡搞/) 的根本差別。那夾是**兩個民選機關對撞**；本夾**只有一個民選機關**，行政權從它產生——照理說不該有僵局。

**僵局來自：議會有能力拆掉行政權，卻沒有能力產生行政權。**

三個反例同時存在：

| 來源 | 本夾怎麼裝進去 |
|---|---|
| **威瑪的消極多數** | 倒閣**不必提出繼任者**（不繼承 `1-優化` 的建設性更新） |
| **荷蘭的組閣長跑** | 組閣**無時限** |
| **拿掉解散這個出口** | 無解散制度，僵局只能耗到屆期 |

**於是拆政府的成本極低、組政府的成本極高，而兩者之間的空檔沒有人負責。**

## 提示詞已經寫好解藥，本夾兩帖都不吃

`1-優化` 對議會制給了兩項明確的處方：

1. **建設性更新信任案**——準人選須在與現任的兩兩對決中贏過門檻。
2. **信任供給合一＋行政權供給自動生效**（`1-優化/財政.md`）。

**本夾兩項都不繼承。** 第一項的缺席造成空窗；第二項的缺席造成「既不倒閣、又不給錢」。

★ **本夾因此是那兩條處方的反證**——它示範拿掉它們會發生什麼（[`11`](11-對照.md) §2）。

## 唯一的硬性是上限，不是籌碼

`配置/惡搞` 只有一條硬性：**仍為民主和民選國家，不能被認為是獨裁。**

本夾最需要正面回答的一題是：**一個被議會多數否定的人握著完整行政權長達一年半，這算不算獨裁？**

不算，理由有五個（[`00`](00-為何這仍然不是獨裁.md) §5）。最短的版本是：

> **一個隨時可以被投票拿掉、卻始終沒人來拿的權力，仍然是民主的權力。**

★ 相應地，緊急狀態**不得延後任何選舉**，且**不停止倒閣**——後半在本夾特別重要，因為宣告者可能就是那個看守首長。

## 秘密選首長，記名選大法官

`0-基本/其他三權/總體.md` 那條記名硬性，**該檔開頭寫明「關於除了立法權、行政權以外的權」**。行政首長屬行政權，不在範圍內。

**所以本夾把最需要問責的那場投票做成黑箱，而且沒有違反任何條件。**

★ 這產生一個具體後果：**秘密投票讓「答應了不投」零成本**，於是首長選舉前的談判普遍失效——沒有人相信任何承諾（[`12`](12-預期政治生態.md) §4.2）。
