# 憲政架構圖

`0-基本/總體.md`：給多張憲政設計架構圖，方便讀者理解。

## 1 外形：一個標準的議會制民選國家

```mermaid
flowchart LR
  People[人民] -->|225 區 FPTP，一輪，2 年| Parl[議會 225]
  Parl -->|秘密投票，一輪相對多數| PM[行政首長]
  PM --> Exec[行政部門]
  Parl --> Law[法律與預算]
  Parl -->|記名同意| Three[司法院 15／監察院 19／考試院 19]
  Parl -->|全體議員抽籤，1 年| Speaker[議長兼禮儀元首]
  People -->|1% 連署| Recall[議員罷免]
  People -->|1% 連署，一年四次| Ref[諮詢性公投]
```

★ 這張圖上沒有任何異常。**異常全在下一張。**

## 2 拆得掉，組不出

```mermaid
flowchart TD
  Parl[議會 225] -->|10 人連署，出席過半，**不必提繼任者**| Down[倒閣通過]
  Down --> Care[**被倒閣者繼續看守**]
  Care -->|權力不打折：任免、命令、**增列預算**、宣告緊急狀態| Full[完整行政權]
  Parl -->|另選新首長，**無時限**| Try{湊得到相對多數嗎}
  Try -->|湊不到| Care
  Try -->|湊到了| New[正式首長]
  New -->|**失去沿用預算保護**| Risk[預算可被刪至零 → 停擺]
  Risk -.->|所以議員寧可不投| Try
  NoDiss[**無解散制度**] --> Care
  Care -->|耗到屆期| Term[2 年後改選]
```

★ 兩條回饋線是全圖的重點：**「湊不到 → 看守」與「湊到了 → 失去保護 → 所以不投」。** 第二條讓第一條變成理性選擇。

## 3 預算：半條沿用條款把誘因設反

```mermaid
flowchart TD
  Q{現在有正式政府嗎}
  Q -->|**有**| A[**無沿用條款**]
  A --> A1[預算被刪至零 → 機關停工]
  Q -->|**沒有，看守中**| B[**沿用上年度**]
  B --> B1[不會停擺]
  B --> B2[**看守首長仍得增列新科目**]
  B2 --> B3[議員向看守首長要建設經費，比向正式政府要容易]
  B3 --> C[**不組閣是地方派系的最優策略**]
  A1 --> C
```

## 4 三院：安全溫室，高政治性歸零

```mermaid
flowchart TD
  Req[惡搞硬性：對立內鬥／咎責盲區／安全溫室] --> Rule[全體一致，缺額計入分母]
  NoMaj[本夾根本沒有穩定多數] --> Rule
  Rule --> High[高政治性過不了]
  Rule --> Safe[考試仍辦、民刑事仍判]
  High --> C1[看守政府得否增列預算：無人可答]
```

★ 中間多出來的 `NoMaj` 是本夾與總統制惡搞夾的差別：**那邊是兩大黨互否，這邊是連湊出一個多數來同意都做不到。**

## 5 兩種公開性

```mermaid
flowchart LR
  Hard[0-基本／其他權：高層間接選舉採**記名**] -->|該檔開頭寫明「除了立法權、行政權以外的權」| Scope{適用範圍}
  Scope -->|三院人選：**在**範圍內| Named[記名投票]
  Scope -->|行政首長：**行政權，不在**範圍內| Secret[**秘密投票**]
  Named --> N1[議員須具名否決對方人選 → 沒有人敢先鬆手 → 加深癱瘓]
  Secret --> S1[62 票可當首長，且沒有人知道是誰投的]
  S1 --> S2[**承諾無法履約 → 選前談判普遍失效**]
```

## 6 緊急狀態：同一場災害，三次指揮官名義

```mermaid
flowchart LR
  D1[第 1 日：首長宣告緊急狀態] --> D5[第 5 日：倒閣通過]
  D5 --> D5b[**首長解職但繼續看守，狀態不終止**]
  D5b --> D12[第 12 日：議會出席過半追認延長]
  D12 --> D12b[**追認的是他們 7 日前否定的人所宣告的狀態**]
  D12b --> D20[第 20 日：選出新首長，**承接該狀態，期限不重算**]
  D20 --> D26[第 26 日：新首長被倒閣，繼續看守]
  D26 --> D34[第 34 日：再次追認延長]
```

★ 紅線：**不得延後任何選舉、不停止倒閣。** 沒有但書（[`07`](07-緊急狀態.md) §2）。

## 7 唯一的硬性：一條沒有越過的線

```mermaid
flowchart TD
  H[配置／惡搞 唯一硬性：仍為民主民選，不能被認為是獨裁] --> Y[**可以要的**]
  H --> N[**不能要的**]
  Y --> Y1[腐敗、對立內鬥、混亂]
  Y --> Y2[看守者長期掌權]
  Y --> Y3[三院癱瘓、法律活不久、預算停擺]
  N --> N1[延後選舉]
  N --> N2[凍結倒閣或罷免]
  N --> N3[取締反對黨、言論入罪]
  Y2 --> Why[**為何仍不是獨裁**]
  Why --> W1[113 票選出任何人即可拿走他的權力]
  Why --> W2[他不能解散議會、不能延選、不能停止倒閣]
  Why --> W3[他自己也可被選區以 1% 連署罷免]
```

> **一個隨時可以被投票拿掉、卻始終沒人來拿的權力，仍然是民主的權力。**
