# 直接民主

## 1 本檔繼承

`0-基本/總體.md` 把「人民修改法規範條件（如：對象範圍、效力範圍）」列為必須交代的憲政選擇。**不繼承** `1-優化/投票.md` 的三版本公投與兩要件。

## 2 規則（主路徑）

### 2.1 諮詢性公投

| 項 | 規則 |
|---|---|
| 連署 | 選舉人 **1%** |
| 次數 | 一年最多四次 |
| 票面 | 單題、同意／不同意 |
| **對象範圍** | **全部**（法律、憲法、預算、稅制、個案皆可提案） |
| **效力範圍** | **零** |

憲法明文：公投結果為「人民意向之表達」，政府與議會「應予尊重」，**不得據以直接變更法律**。

★ 這是對 `0-基本` 那條要求的字面滿足：**什麼都能問，什麼都不算數。**

### 2.2 在議會制惡搞裡它多一個功能

總統制惡搞夾的公投是純裝飾。**本夾的公投多一項：它是空窗期唯一還在運轉的政治程序。**

★ 政府倒了、新政府選不出來、法案通過了也活不久——**而公投照辦**。媒體有題目，人民有票投，看守首長宣布「將尊重民意」然後什麼也不做，因為它無拘束力。

★ 而且**看守首長特別喜歡公投**：它讓他看起來在做事，而且不需要議會同意。

### 2.3 自由民主投票日

憲法定每年 12 月第三個星期六為「自由民主投票日」：全國放假、各級機關舉辦慶典、選務機關公告我國在各國際民主指數的排名並與威權國家對照。

★ 過去八年，我國在「選舉自由」項目連續名列前段，在「政府效能」項目連續墊底。**慶典只念前半段。**

★ 本夾多一個細節：**慶典遇政府空窗仍照常舉辦**——由看守首長主持，或由抽籤議長主持。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 公投通過但無政府可執行 | 無所謂——它本來就無拘束力 |
| 看守首長宣布尊重公投結果 | 無法律效果 |
| 同一議題重複提案 | 無限制 |
| 一年逾四次成案 | 依連署完成先後，逾額順延至次年 |
| 慶典遇空窗 | 照常舉辦 |
