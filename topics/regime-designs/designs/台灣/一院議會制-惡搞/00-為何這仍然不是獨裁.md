# 為何這仍然不是獨裁

本檔是概要層。繼承與 [`../一院總統制-惡搞/00-為何這仍然不是獨裁.md`](../一院總統制-惡搞/00-為何這仍然不是獨裁.md) 相同，只換 `0-基本/行政立法/一院議會制.md`。

```
都用 0-基本
都用 民選制
# 台灣
有監察權、考試權
都用 配置\台灣\基本
2. 一院議會制 惡搞: 配置\惡搞
```

| 來源 | 條件 | 位階 |
|---|---|---|
| `配置/惡搞/總體.md` | 仍為民主；對立內鬥或混亂；咎責盲區／安全溫室 | **硬性** |
| `配置/台灣/基本` | 人工計票；專門選舉權人須代理；記名 | **硬性** |
| `0-基本/行政立法/一院議會制.md` | 首長負責行政；選出與更新皆某些議員投票 | **硬性** |
| `0-基本/其他權/司法權.md` | 普通法官不當記名選舉權人 | **硬性** |

**不繼承**：`1-優化`、`配置/台灣/優化`、`配置/個人偏好`、`配置/雜項`。現役「不繼承配置／台灣全部」刪掉。

## 手法相同，病理不同

| | 總統制惡搞 | **本夾** |
|---|---|---|
| 病理 | 兩個民選機關對撞 | **拆得掉，組不出** |
| 某些議員 | — | **全院 225** |
| 誰握行政權 | 35% 選出的總統 | **一個議會多數已經否定的看守者** |

一個隨時可以被投票拿掉、卻始終沒人來拿的權力，仍然是民主的權力。緊急狀態**不得延後任何選舉**，且**不停止倒閣**。不取消投票、不改任命制。
