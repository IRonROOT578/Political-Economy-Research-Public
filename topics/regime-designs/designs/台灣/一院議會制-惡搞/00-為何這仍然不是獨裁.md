# 為何這仍然不是獨裁

## 1 本檔繼承

```
# 台灣
有監察權、考試權
2. 一院議會制 惡搞: 0-基本 配置\惡搞
```

繼承與 [`../一院總統制-惡搞/`](../一院總統制-惡搞/) **完全相同**——只有 `0-基本/行政立法/` 取的是**一院議會制**那一份。

| 來源 | 條件 | 位階 |
|---|---|---|
| `配置/惡搞/總體.md` | **仍為民主和民選國家，不能被認為是獨裁** | **硬性（唯一）** |
| `配置/惡搞/總體.md` | 惡搞型；腐敗、對立內鬥、混亂；選制簡單；治理不如獨裁；人民驕傲吹捧自由民主投票 | 非硬性 |
| `0-基本/行政立法/一院議會制.md` | 最高行政首長負責行政；**選出方式：某些議員投票；更新方式：某些議員投票** | 硬性 |
| `0-基本` 其餘 | 全套 | 各異 |
| 對應表 | **有監察權、考試權** | 映射 |

**不繼承**：`1-優化` 全部、`配置/台灣` 全部、`配置/雜項` 全部。

## 2 手法相同，病理不同

手法與總統制惡搞夾一樣：**凡是硬性條件，一字不差地遵守；壞事全發生在硬性條件沒有規定的地方。**

**但病理完全不同：**

| | 總統制惡搞 | **本夾** |
|---|---|---|
| 病理 | 兩個民選機關對撞，憲法沒有出口 | **拆得掉，組不出** |
| 誰握有行政權 | 一個 35% 選出的總統 | **一個議會多數已經否定的看守者** |
| 誰能被問責 | 兩邊互指 | **沒有人** |

## 3 五個檢查點

| 檢查點 | 本夾 |
|---|---|
| 選舉是否照常 | 議會 2 年一次，**任何情況下都不得延期**，含緊急狀態（[`07`](07-緊急狀態.md)） |
| 敗選者是否下台 | 是。屆期屆滿全體解職，新屆就任 |
| 反對黨是否合法 | 是。政黨採報備登記，不得以違憲為由解散 |
| 言論與集會 | 不入刑 |
| 有無不受更新的職位 | 無。議員可被選區罷免（門檻 1%）；**行政首長可被議會隨時倒閣** |

## 4 那壞在哪

壞在**權力隨時可以被拆掉，但很難被組起來**。

- 倒閣**不必提出繼任者**（`1-優化` 的建設性更新在本夾不繼承）。
- 組閣**沒有時限**。
- **無解散權**——僵局沒有提前大選這個出口。
- 被倒閣者**繼續看守，權力不打折，還能增列預算**。

**於是拆政府的成本極低、組政府的成本極高，而兩者之間的空檔沒有人負責。**

★ 這是威瑪的「消極多數」在憲法層次被制度化：反對現任的人加起來永遠過半，支持任何一個繼任者的人永遠不過半。加上荷蘭式的無限期組閣，再拿掉解散這個出口——**三者同時存在。**

★ **荷蘭那一項要寫全**：提示詞點名的是「荷蘭（**含**：**法案協商時間長**）」，組閣長跑只是其中最顯眼的一種。本夾把兩半都放大——組閣無時限（[`02`](02-行政首長與看守.md) §3），而法律**過得了卻活不過一次倒閣**、中位數 11 個月（[`03`](03-立法與修憲.md) §2.2）：**同一件事反覆重談，只是這裡連談出來的東西都留不住。**

★ 附帶說明：**本夾不繼承任何含荷蘭的硬性條件**（那些在 `1-優化` 與各國配置）。這裡引用荷蘭是**自願的反面對照**，用來說明本夾刻意做出了什麼。

沒有人違憲，沒有人政變。**只是沒有人在治理。**

## 5 為什麼「看守者長期掌權」仍然不是獨裁

這是本夾最需要正面回答的一題。

一個被議會多數否定的人，握著完整行政權、還能增列預算，可能長達一年半——**這聽起來像獨裁。它不是，理由有五個：**

1. **他的權力隨時可以被拿走**——只要 113 個議員選出**任何一個人**。他的權力來自議會的無能，**不是來自對議會的壓制**。
2. **他不能解散議會**，也沒有任何手段影響議會的組成。
3. **他不能延後選舉**（[`07`](07-緊急狀態.md)）。屆期一到照樣改選，而改選會產生一個新的議會。
4. **他不能取締反對黨、不能以言論入罪。**
5. **他自己也是民選議員**，同樣可被其選區以 1% 連署罷免（[`09`](09-人選更新.md)）。

> **一個隨時可以被投票拿掉、卻始終沒人來拿的權力，仍然是民主的權力。**

★ 這也是本夾最刺人的地方：**它的失敗不是因為有人奪權，是因為沒有人能達成共識把權力交給下一個人。**

## 6 一條刻意沒有越過的線

與總統制惡搞夾相同：緊急狀態**不得延後任何選舉**，且**不停止倒閣程序**（[`07`](07-緊急狀態.md) §3.1）。

★ 後半在本夾特別重要：宣告緊急狀態的可能是一個**看守首長**——一個議會多數已經否定的人。若緊急狀態能停止倒閣，他就取得了一個**自己宣告、自己受益的免疫期**。

**混亂與腐敗可以要，取消選舉或凍結換人不行。**
