# 行政首長與看守政府

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/行政立法/一院議會制.md` | **硬性** | 最高行政首長，功能含負責行政；**選出方式：某些議員投票；更新方式：某些議員投票** |
| `0-基本/其他權/總體.md` | 硬性 | 每權高層人選若為間接選舉，採記名——**該檔開頭寫明「關於除了立法權、行政權以外的權」** |
| `配置/惡搞/總體.md` | 硬性 | 仍為民主民選 |
| `配置/惡搞/總體.md` | 非硬性 | 對立內鬥、混亂 |

**不繼承** `1-優化/行政立法/一院議會制.md` 的**建設性更新信任案**與**排名投票選準人選**；也不繼承 `1-優化/財政.md` 的信任供給合一與供給自動生效。

★ **這兩項的缺席就是本夾的全部病理。**

## 2 規則（主路徑）

### 2.1 某些議員 ＝ 全體 225

`0-基本` 只寫「某些議員」，沒有指定是誰。本夾定為**全院 225**。

理由：人愈多愈難形成多數（對立內鬥），不必再切出一個子集合。

### 2.2 選出：秘密投票、一輪相對多數

**秘密投票**，一輪相對多數。得票最高者即為行政首長，**不需過半**。

★ 示意：225 人的議會，**得 62 票就能當行政首長**；而且**沒有人知道那 62 票是誰投的**，所以沒有人需要對他負責。

#### 為什麼可以不記名

`0-基本/其他權/總體.md` 那條「高層人選若為間接選舉採記名」的硬性，**該檔開頭寫明「關於除了立法權、行政權以外的權（如：司法權）」**。行政首長屬**行政權**，不在該檔範圍。

而 `1-優化/投票.md` 的「間接投票採記名排名」在 `1-優化`，本夾不繼承。

**所以本夾把它做成黑箱，而且沒有違反任何條件。** 三院的同意投票則照樣記名（[`06`](06-三院.md)）。

### 2.3 首長的職權

負責行政，任免政務人員，指揮部會，公布法律。

**無法律否決權**——他由議會產生。

### 2.4 更新：非建設性倒閣

| 項目 | 規則 |
|---|---|
| 提案 | 議員 **10 人**連署 |
| 表決 | **出席過半**即通過 |
| 是否須提出繼任者 | **否** |
| 冷卻期 | **無** |
| 每會期次數上限 | **無** |
| 通過後 | 首長解職，議會另行選出新首長，**無時限** |

★ `1-優化/行政立法/一院議會制.md` 的建設性更新（準人選須在與現任的兩兩對決中贏過門檻）在 `1-優化`，本夾不繼承。**所以拆掉現任不需要拿出替代者。**

### 2.5 看守政府：本夾的招牌

首長解職後至新首長選出前，由**被倒閣的那個人**繼續看守。

**看守政府的權力不打折：**

- 得任免政務人員。
- 得發布命令。
- **得增列預算科目**（[`04`](04-預算與財政.md) §2.3）。
- 得締結行政協定。
- **得宣告緊急狀態**（[`07`](07-緊急狀態.md) §3.2）。

★ 於是出現本夾的招牌景象：**一個剛被議會多數否定的人，握著完整行政權，一邊看守一邊發預算，時間可能長達一年。**

★ 而且**倒閣他的那個多數不會再倒他一次**——因為倒閣的效果就是讓他繼續看守。

### 2.6 無解散權

首長不能解散議會，議會也不能自行解散。僵局沒有提前大選這個出口，只能耗到屆期（[`01`](01-議會組成.md) §2.2）。

### 2.7 國家元首：抽籤

**不設獨立元首。** 議長兼任禮儀性元首，由全體議員**抽籤**產生，任期一年。

**無行政權、無仲裁權、無指定首長的權力。**

★ 抽籤是為了讓這個位子**不值得爭**，也讓它**無法扮演僵局的仲裁者**——本夾不要仲裁者。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆集會後選不出首長 | **無時限**。前屆首長繼續看守 |
| 倒閣通過但選不出繼任者 | 被倒閣者繼續看守，**無時限** |
| 看守期間再次倒閣 | **標的不存在**——他已被倒閣過；程序不受理 |
| 看守首長辭職 | 由副首長看守；副首長亦辭職者，由抽籤議長看守 |
| 同一人被選出後又被倒閣 | 合法，可無限重複 |
| 秘密投票有爭議 | 無驗票程序；以計票結果為準 |
| 得票同高 | 抽籤 |
| 首長被其選區罷免 | 喪失議員身分，但**首長職務不受影響**（首長不必是議員） |
