# 人選更新

## 1 本檔繼承

`0-基本/總體.md` 把「更新人選條件」列為必須交代的憲政選擇。  
`0-基本/行政立法/一院議會制.md` 硬性：最高行政首長的**更新方式：某些議員投票**。

**不繼承** `1-優化/投票.md` 的備胎＋現任孔多賽與票數地板；也不繼承 `配置/台灣` 那條「總統更新不應讓立法權凌駕人民罷免權，**但仍有穩定性（如：冷卻期）**」——★ **後半若繼承，會擋掉本夾的「無地板無冷卻」。**

## 2 兩種更新

| 對象 | 誰更新 | 落點 |
|---|---|---|
| **行政首長** | 議會全院（出席過半倒閣，**不必提繼任者**） | [`02`](02-行政首長與看守.md) §2.4 |
| **議員** | 該選區選民 | 本檔 §3 |

## 3 議員罷免

| 項目 | 規則 |
|---|---|
| 提議 | 該區選舉人 **0.5%** |
| 連署 | 該區選舉人 **1%** |
| 成立 | 同意票多於不同意票 |
| 最低投票率／同意票地板 | **無** |
| 冷卻期 | **無** |
| 次數上限 | **無** |
| 就任後多久可提 | **就職次日起** |
| 補選 | 90 日內，任期至本屆屆滿 |

**投票率愈低愈容易罷免。** 罷免失敗的隔天可以再提。

## 4 本夾特有：罷免直接改變議會算術

★ 這是本夾與總統制惡搞夾最重要的差別。

在總統制惡搞夾，罷免一名議員只改變 225 分之一的立法票數。**在本夾，議會同時是產生行政權的機關**——所以：

| 一次成功的罷免 | 後果 |
|---|---|
| 該席出缺 90 日 | 選首長與倒閣的**出席人數改變** |
| 補選改變黨派歸屬 | **可能直接翻轉倒閣案的成敗** |
| 而倒閣只要**出席過半** | 空席期間更容易通過 |

★ **理性策略因此浮現**：與其在議會裡談判，不如去對方的邊際選區發動罷免。

> **跑三個選區的連署，比說服三個議員便宜——而且不需要對方同意。**

### 4.1 罷免與倒閣的循環

★ 可預期的形態：

1. 議員被罷免 → 議會算術改變。
2. 有人提倒閣（10 人連署、出席過半）→ 通過。
3. 選不出新首長 → 被倒閣者繼續看守。
4. 看守期間又有議員被罷免 → 算術再變。
5. 回到第 2 步。

**這個循環沒有終點，也沒有任何一步違憲。**

## 5 首長的更新

見 [`02`](02-行政首長與看守.md) §2.4：10 人連署、出席過半、**不必提繼任者**、無冷卻、無上限、無時限組閣、**被倒的人繼續看守**。

★ 值得注意：**首長若同時是議員，他可能被自己的選區罷免而喪失議員身分——但首長職務不受影響**（首長不必是議員，[`02`](02-行政首長與看守.md) §3）。

## 6 狀態

| 狀態 | 怎麼走 |
|---|---|
| 罷免投票率 8% | 有效，同意多於不同意即成立 |
| 同一人被連續罷免三次 | 合法，無次數上限 |
| 補選當選人再被罷免 | 合法，程序重跑 |
| 空席期間的倒閣表決 | 出席過半即可，不看法定總額 |
| 罷免與定期改選同期 | 無「距改選幾個月不辦」的規定，照辦 |
| 首長被其選區罷免 | 喪失議員身分，**首長職務不受影響** |
| 緊急狀態期間 | **罷免照常辦理，不得延期**（[`07`](07-緊急狀態.md) §2） |
