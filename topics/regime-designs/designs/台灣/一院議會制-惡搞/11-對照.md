### 1.1 記名硬性怎麼過關

`0-基本/其他權/總體.md` 那條「每權高層人選若為間接選舉，採記名」——**該檔開頭寫明「關於除了立法權、行政權以外的權」**。

行政首長屬**行政權**，不在該檔範圍。**所以本夾把首長選舉做成秘密投票，沒有違反任何條件**（[`02`](02-行政首長與看守.md) §2.2）。三院的同意投票照樣記名。

★ 這是本夾最靠近邊界的一次操作，而它停在邊界內側。

## 2 刻意不繼承什麼

`1-優化` 全部、`配置/台灣/優化`、`配置/個人偏好`、`配置/雜項`。**台灣基本有繼承。**

| 放棄的 | 出處 | 若有它會擋掉本夾的什麼 |
|---|---|---|
| **建設性更新信任案** | `1-優化/行政立法/一院議會制` | **倒閣就得拿出繼任者——空窗根本不會發生** |
| **信任供給合一＋供給自動生效** | `1-優化/財政` | **「既不倒閣又不給錢」不成立** |
| **反杯葛（硬性）** | `1-優化/其他權/總體` | 三院就不會癱瘓 |
| **法規位階（硬性）** | **`配置/台灣/優化/行政立法/共用`** | 選舉法與法院組織法就不能 38 票改 |
| 排名投票選準人選 | `1-優化/行政立法/一院議會制` | 首長選舉會被逼出一個共識人選 |
| 間接投票採記名排名 | `1-優化/投票` | 首長選舉就不能是黑箱 |
| 向心型選制優於 FPTP | `1-優化/行政立法/共用` | 二極化的誘因會被降低 |
| 「同意 > 總額半數」 | `1-優化/行政立法/共用` | 38 票立法不成立 |
| 三版本公投與兩要件 | `1-優化/投票` | 公投就會有效力 |
| 防餓死機制、沿用條款 | `配置/雜項/財政` | 停擺不會是均衡 |
| 反冗員（如 225→113） | **`配置/雜項/行政立法/共用`** | 225 會被壓回去 |
| 罷免須有穩定性（如冷卻期） | `配置/台灣/優化` | 本夾無直選總統；議員 1% 是自由發揮 |
| 身分政治 | `配置/個人偏好` | 本夾不把它當硬性義務 |

★ **前兩列是本夾的全部病理。** `1-優化` 已經把議會制的解藥寫好了——建設性更新 ＋ 供給自動生效——**本夾兩帖都不吃。**

## 3 與總統制惡搞夾的分工

同樣繼承 `0-基本`＋`配置/台灣/基本`＋`配置/惡搞`，同樣 225 全 FPTP，同樣三院全體一致。**差別全在行政權怎麼產生。**

| | [`../一院總統制-惡搞/`](../一院總統制-惡搞/) | **本夾** |
|---|---|---|
| 病理 | 兩個民選機關對撞，憲法沒有出口 | **拆得掉，組不出** |
| 反例來源 | 美式預算停擺 | **威瑪消極多數＋荷蘭的法案協商時間長（含組閣長跑）＋無解散** |
| 行政權在誰手上 | 一個 35% 選出的總統 | **一個議會多數已否定的看守者** |
| 誰能被問責 | 兩邊互指 | **沒有人** |
| 法律 | **過不了**（否決＋覆議 150） | **過得了，但活 11 個月** |
| 緊急狀態延長 | **2/3，湊不到** → 延不下去 | **出席過半** → **延得下去** |
| 罷免的效果 | 改變 225 分之一的立法票數 | **直接改變倒閣算術** |
| 預算沿用 | **完全沒有** | **半條**——看守期有、有政府時沒有 |
| 修憲 | 兩大黨相加 199，169 理論上可能 | **兩大黨 163＜169；113 必須買無黨籍** |

★ **同一組條件，兩種壞法。** 這一組對照本身就是兩夾存在的理由。

## 4 與五個正式夾的對照

| 項目 | 五個正式夾 | **本夾** |
|---|---|---|
| 選制 | 向心型／彈性名單 | FPTP |
| 倒閣 | 建設性（須贏過現任） | **非建設性，不必提繼任者** |
| 供給 | 信任供給合一 | **分離** |
| 三院人選 | 反杯葛，杯葛者浪費投票權 | **全體一致，杯葛零成本** |
| 法規位階 | 有 | 無 |
| 公投 | 三版本、兩要件、有拘束力 | 什麼都能問，什麼都不算數 |
| 修憲 | 兩軌 | 照抄現行，改不動 |
| 選區劃分 | 獨立委員會 | 議會 38 票 |
| 防常態化 | 24 個月 | 無（[`10`](10-憲政選擇.md) §22） |

★ 每一列的左欄都是某條 `1-優化` 或 `配置` 的條件；右欄是**拿掉它之後會發生什麼**。

> **本夾的用處在這裡：它是那些條件的反證。**
