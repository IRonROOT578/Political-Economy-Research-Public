# 台灣：一院總統制－測試（用預提）

```
# 台灣
有監察權、考試權
2. 一院總統制-測試: 0-基本 1-優化 配置\台灣
配置\雜項\行政立法\共用.md : 「少身分政治」
用 預提行政權預算。
```

**繼承層與 [`../一院總統制/`](../一院總統制/) 完全相同。對應表的差別只有一句：「不用」變成「用」預提行政權預算。**

## 這一夾在回答什麼

`1-優化/財政.md` 對總統制給了**兩條路**——「可用**其他設計**降低供給問題」（正式夾走這條），以及可選條件的**預提行政權預算**（本夾走這條）。

**兩夾的席次、選制、三院、修憲、緊急狀態逐項相同。本夾存在的意義是把預提那條路走完，讓兩條路可以並排比較**（[`16`](16-完善與自洽.md) §5）。

## 一句話

議會 **180＝單一 100＋複數 80**（同正式夾）。總統正副同組登記時**得一併提出與其綁定的四年行政權預算案**，於**投票日前 21 日公告全文**，人民選出該組即為授權；就任生效、**去職終止**；任內調整須**總統與單一席次 ≥51 雙鑰匙**；預提外仍走年度議決。**不設金額上限**，改用範圍封閉列舉＋三個硬預設。**更新時備胎得提出自己的預算案。**

## 四個本夾特有的決定

**一、信任供給合一用「提供者統一」達成。** 信任來自人民（選舉與更新），供給也來自人民（選舉時的授權）——這是 `1-優化/財政.md` 對總統制的**原意**。正式夾則是「把撤供給的工具拿掉」。

**二、不設金額上限。** 提示詞標為**（有爭議）**，而「行政權管好自己的行政（含**部分**行政權預算）」那句本身就是反對它的論據：**供給既然是行政那一份、授權者是人民，憲法寫一個百分比等於用固定數字取代人民在選舉時的判斷**。限制改由**範圍封閉列舉**＋**三個硬預設**承擔——其中「**未填減列順序表者由憲法逕行按比例齊頭削減**」是「可實踐性」的硬答案：**不寫怎麼砍，憲法替你砍。** 見 [`03`](03-行政權預算.md) §2.7。

**三、形式審查不得排除候選人。** 只審欄位齊全與加總正確，**不審政策內容**，且**形式瑕疵不得作為排除候選人的理由**——一個能因為表格問題把人擋在選舉外的審查，會立刻變成排除對手的工具。

**四、備胎得提出自己的預算案，但預算不列入替換條件。** 這把更新從「要不要換掉這個人」變成「**要不要換成這個人和他的那份預算**」；而門檻只衡量人的對決，否則會出現「提大案比較容易罷免現任」的扭曲。見 [`12`](12-人選更新.md) §2。
