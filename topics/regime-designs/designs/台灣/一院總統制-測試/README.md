# 台灣：一院總統制－測試（用預提）

本憲政設計最新更新：2026-11-10

與 [`../一院總統制/`](../一院總統制/) 同一份議會、三院、選制；差別只有：**用**預提行政權預算。與 [`../一院議會制/`](../一院議會制/) 的差別見 [`00`](00-讀法與推導.md) §7。

## 一句話

180＝單一 100（top-3 孔多賽）＋複數 80（彈性名單、聖拉古、無門檻）。正副總統由人民 top-3 孔多賽選出，並得綁定四年**任期供給案**：選前 21 日公告，人民選出即同時給信任與供給；任內調整須總統與全院 ≥91 同時同意；**被人民更新就終止，改用勝出挑戰者的案**。挑戰者（非在位者）的案與更新第一輪登記一併公告。**不設金額上限。** 人民端的修憲複決、公投、總統更新、議員更新共用一套替代現狀方式。

## 生態的一句話

生態模型下，總統那一場三屆都是全國循環：第 3 屆國民黨候選人當選，但一對一輸給民進黨候選人 48.7 : 51.3。總統與單一席次多數同黨，雙鑰匙兩把在同一手上；預提只在分裂政府時吃重——例如民進黨選民有 60% 把民眾黨排在國民黨前面時，民眾黨贏得總統，而國民黨仍握單一 61 席（[`15`](15-預期政治生態.md)）。

## 估計結果

| 民意 | **總統** | 議會全院 180 | 府會 |
|---|---|---|---|
| 2024-01 大選 | **國民黨**（三方循環） | 國民黨 85、民進黨 60、民眾黨 35 | 總統的黨差 6 席過半，要民眾黨 |
| 2020-01 大選 | 民進黨 | 民進黨 108、國民黨 51、民眾黨 10 … | 一致 |
| 2016-01 大選 | 民進黨 | 民進黨 123、國民黨 40 … | 一致 |
| 2012-01 大選 | 國民黨 | 國民黨 99、民進黨 68 … | 一致 |
| 美麗島 2026-09 民調 | 民進黨 | 民進黨 107、國民黨 41、民眾黨 32 | 一致 |
| 戴立安 2026-10 民調 | 民進黨 | 民進黨 92、民眾黨 56、國民黨 32 | 一致，只多 1 席 |

總統與議會的第一偏好都用不分區政黨票，不用總統第一輪或區域立委的實際得票（受棄保、禮讓影響），也不用個別候選人。2024 年三黨彼此循環：民進黨一對一勝國民黨、民眾黨勝民進黨、國民黨勝民眾黨；Ranked Pairs 不採認最弱的一環，國民黨當選。改變第二偏好的假設，三黨都可能當選（[`估計結果.md`](估計結果.md) §0）。民調是政黨喜好度換算的占比，只當方向參考。
