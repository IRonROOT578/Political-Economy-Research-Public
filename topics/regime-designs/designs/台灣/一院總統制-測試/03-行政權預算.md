# 行政權預算（預提）

## 1 本檔繼承

| **更新投票前：挑戰現任者（非在位者）可提出自己的行政權預算** | §2.6，程序見 [`12`](12-人選更新.md) §3.3a |

## 2 規則（主路徑）

### 2.1 框架

> 立法權就管好自己的立法，行政權就管好自己的行政（含：**部分**行政權預算）。

供給不是議會施捨給行政的東西，它本來就是行政那一份的一部分——**本夾把授權者從議員換成人民**。`1-優化/財政.md`：人民向總統同時提供信任和供給，否則總統就是空殼。被更新後收回該供給，改用替換者提出的供給。

「**部分**」是限制。落實方式是 §2.2 的範圍封閉列舉，不是金額百分比（§2.7.5）。

### 2.2 範圍（封閉列舉）

任期供給案只能包含：

1. 政策裁量性資本門支出。
2. 預備金與政務應變預算。
3. 行政機關經常門運作費用。
4. **列名**政策計畫的經常門支出。

**不含**：法定義務支出、歲入、稅制、非行政部門預算、中央對地方之財政移轉公式。

法定義務支出**始終撥付**，不需年度議決，也不在案內。

移轉公式排除的理由：能用任期供給案綁定對地方的移轉，等於把地方財政變成總統任期內的籌碼。它屬基本法（[`04`](04-其餘預算.md)）。

### 2.3 誰授權、何時授權

**人民。**

- 正副總統候選人**同組**登記時，得一併提出與其綁定的行政權預算案（下稱「**任期供給案**」）。
- 提出為**非強制**。不提也可以登記參選。
- **須於第一輪投票日前 21 日公告全文**——「在投票前公告一段時間」是**要件**，不是時程建議。逾期公告者，該案不生授權效力，視為未提出。
- 人民選出該組，即為對該案的授權。

### 2.4 生效與終止

自就任日生效，至任期屆滿為止。

| 事由 | 任期供給案 | 為什麼 |
|---|---|---|
| **人民更新成功** | **終止**，改用勝出者的案（勝出者未提則走 §2.8） | 提示詞：被人民更新就終止；授權者收回授權 |
| 總統彈劾成立、辭職、死亡，副總統繼任 | **繼續** | 人民授權的是**這一組**；彈劾是法律責任，不是人民收回授權 |
| 正副總統同時缺位，補選 | 終止；補選當選組得依 §2.3 提出自己的案 | 授權的那一組已不在 |

### 2.5 任內調整（雙鑰匙）

生效後的調整，須**總統與全院同時同意**（全院 **≥91／180**）。

**議會不能獨自修改**人民授權給總統的部分；**總統也不能**。兩把鑰匙缺一不可。

為什麼是全院：預算的議會端和法律是同一個多數，總統不必另找第二個多數；只讓單一 100 同意，會讓少數地方議員成為調整的定價者。

### 2.6 更新時挑戰者的預提案

`1-優化/財政.md`：「更新投票前：挑戰現任者（非在位者）可提出自己的行政權預算。」

| 項 | 規則 |
|---|---|
| 誰能提 | 更新第一輪的**每一位挑戰者**；**非強制** |
| 何時公告 | 與第一輪登記一併提出，**第一輪投票日前 21 日**公告；格式同 §2.7 |
| 第二輪 | 晉級的兩名挑戰者**原案帶進第二輪，不得修改** |
| 在位者 | **不得另提新案**。他在第二輪代表「維持現狀」，他的原案就是現狀的一部分 |
| 呈現 | 兩名挑戰者的摘要表與現任原案的摘要表**並列於選舉公報同一頁** |
| 勝出者的案 | 自就任日生效至**原任期屆滿**，不重新起算 |
| 勝出者未提 | 未覆蓋部分走 §2.8，**不繼承**現任的案 |
| 現任留任 | **原案繼續有效**，不因更新被發動而中斷 |
| 是否影響替換條件 | **否。** 預算不列入淘汰線或決選 |

★ **為什麼鎖在第一輪之前。** 第一輪的選民決定哪兩位挑戰者進第二輪；他們若不知道每位挑戰者帶什麼案，那一票就是盲投。第一輪後才能改案，挑戰者會照第一輪的結果改寫預算去換另一群選民的第二偏好——那是用預算在兩輪之間買票。

★ **為什麼在位者不能另提。** 提示詞寫的是「挑戰現任者（非在位者）」。在位者的案是人民上次授權的東西；讓他在更新時換一份新的，就等於讓他用新承諾抵銷舊承諾的失敗。

★ **為什麼預算不影響門檻。** 若預算能影響淘汰線，就會出現「提大案比較容易罷免現任」或反過來的扭曲。門檻只衡量人的對決；預算只影響選民排序時的判斷。

### 2.7 形式（子項 3 的交付）

提示詞說的是「**給**候選人預提行政權預算的形式」——不是討論怎麼控制，是**交出規格**。

#### 2.7.1 硬性要求

| 要求 | 違反的後果（自動發生，不需誰去查） |
|---|---|
| 逐項列明 | **未列即未授權**——未逐項列明者不在授權範圍，回到 §2.8 的年度議決 |
| 歲入假設須明列 | **歲入假設不構成授權**。授權的是支出上限，不是「保證有這麼多錢」 |
| 須附減列順序表 | **未填者，由憲法逕行按比例齊頭削減** |
| 不得以散文說明替代科目表 | 該部分視為未列明，適用第一列 |
| 必填欄不得留白 | 留白視為該欄為零，**不得事後補充** |

第三列是「**可實踐性**」的硬答案：**不寫怎麼砍，憲法替你砍。** 它不是要求候選人寫，是他不寫就吃到一個他不會喜歡的預設。

第一列是「部分」不被吃成「全部」的保險：沒有它，一句概括條款就能把整個裁量支出包進去。

#### 2.7.2 格式

選務機關制訂**空白表**，候選人填入。必含欄位：

- **分年上限**（任期四年各一欄）。
- 科目層級至「政策計畫」。
- 假設之經濟成長率與主要價格參數。
- **減列順序表**（歲入不足時各科目的削減次序與比例）。
- **與上一完整會計年度中央政府總歲出決算實支的倍數對照**。
- 與上一任期實際支出的對照欄。

倍數對照欄取代了金額上限的功能：**讓選民看得到規模，而不是由憲法替他判斷規模。**理由見 §2.7.5。

#### 2.7.3 對選民呈現方式

- 全文公告於選務機關網站、**各投開票所公告欄**、選舉公報。
- **摘要表**（分年上限＋倍數對照）隨選舉公報送達每一戶。
- 更新投票時，各組的摘要表**並列**於同一頁（§2.6）。

#### 2.7.4 形式審查

由選務機關為之，**只審欄位齊全、加總正確、格式合規，不審政策內容**。

> **形式瑕疵不得作為排除候選人或該組登記的理由。**

這一條要明文寫死。**一個能因為表格問題把人擋在選舉外的審查，會立刻變成排除對手的工具。** 算錯了就公告標示、依 §2.7.1 的預設處理，讓選民看見他算錯了。

#### 2.7.5 為什麼不設金額上限

提示詞在形式的舉例裡列了「金額上限（有爭議）」。本夾不設，理由三個：

1. **「部分」已經由範圍守住。** §2.2 封閉列舉四類，法定義務、歲入、稅制、非行政部門、移轉公式都不在內。上限要防的「把整個預算綁進來」在範圍那一層就做不到。
2. **上限會把提示詞點出的取捨從選民手上拿走。** 提示詞說預提越大越利施政、但可能不利選舉——那是一個應該由選民在投票時判斷的取捨。一個憲法上限替選民先決定「多大算太大」，這個取捨就不再發生在選舉裡。
3. **上限會被繞過。** 候選人可以把超過上限的項目留給年度議決，再用雙鑰匙逐年追加；上限只改變錢走哪條路，不改變總量。

替代品是**規模必須被看見**：倍數對照是必填欄（§2.7.2），摘要表送達每一戶（§2.7.3）。

### 2.8 未覆蓋的部分

預提案未涵蓋的行政歲出，仍走年度議決：

- 全院 **≥91**。
- **得刪不得增**，不得把整案凍結為零。
- 附條件通過視為未通過。
- 會計年度開始後 **60 日**未作成議決者，**沿用上一年度已議決額度**。

**這一段與正式夾 [`../一院總統制/03-行政權預算.md`](../一院總統制/03-行政權預算.md) §2.2 的四條規則相同**——本夾只是把其中一大塊移到人民授權，剩下的部分規則沒變。

### 2.9 任期內無法在選舉時得知的部分（子項 1）

提示詞明白指出這個問題：「考量到任期內部分行政權預算無法在選舉時得知」。

本夾的處理不是要求候選人預測，而是**分層**：

| 層 | 內容 | 誰決定 |
|---|---|---|
| 可預見的 | 已存在的機關運作、已列名的政策計畫、資本門的多年期工程 | **預提案**（選舉時授權） |
| 不可預見的 | 新增的政策、突發需求 | **年度議決**（§2.8） |
| 緊急的 | 災害、危機 | **預備金與政務應變**（在預提案內，但動支後須備查） |

**預提不要求候選人算準四年**，只要求他把「已經知道的那些」寫清楚。不寫的部分自動落回年度議決——這正是 §2.7.1 第一列「未列即未授權」的作用。

### 2.10 提大案還是小案（子項 2）

提示詞已指出這個張力：提得越大越利日後施政，但可能不利選舉。

本夾不介入這個取捨，只讓它**發生在選民面前**：倍數對照欄使「這個人打算鎖住多少」是一個選民看得懂的數字。

★ 可預期的攻防：現任者傾向提大案證明執行力，挑戰者傾向提小案攻擊對手「先把四年綁死」。**這個攻防本身就是課責**——它把「政府未來四年打算花多少錢做什麼」搬到選舉的正中央，而不是留在每年一次的技術性表決裡。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 候選人未提任期供給案 | 全部行政歲出走 §2.8 年度議決（等同正式夾） |
| 公告逾期（不足 21 日） | 該案視為未提出，不生授權效力；**不影響候選資格** |
| 加總錯誤或逾格式 | 公告標示，依 §2.7.1 各列的預設處理；**不影響候選資格** |
| 歲入低於案內假設 | 法定義務優先撥付；案內裁量依減列順序表削減；未填順序表者按比例齊頭削減 |
| 歲入高於假設 | **不自動增加授權**。多出部分屬年度議決範圍 |
| 總統與全院對調整案僵持 | **維持原案**。無仲裁、無自動生效——雙鑰匙的預設是不動 |
| 雙鑰匙的範圍爭議（某項是否在預提內） | 屬權限爭議，由司法院裁判（[`09`](09-司法院.md)）；未決期間依上年度處理方式撥付 |
| 總統去職而副總統繼任 | 原案繼續，不重新授權 |
| 更新成功，新任者未提案 | 舊案於交接日終止；未覆蓋部分走 §2.8 |
| 總統彈劾成立 | 副總統繼任，**原案繼續**（§2.4） |
| 案內某科目之法律依據嗣後被宣告違憲 | 該科目授權失效，餘額繳庫，不移用 |
| 緊急狀態期間 | 預備金與政務應變得先行動支，30 日內補送全院備查；不改變授權上限 |
