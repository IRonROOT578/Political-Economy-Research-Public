# 監察院

## 1 規則

**與 [`../一院總統制/10-監察院.md`](../一院總統制/10-監察院.md) 逐字相同。** 9 人三平行組（審計／糾彈／綜合）；三組選舉權人（單一席次／複數席次／**正副總統候選人加權**）；方案須三組同一份；無雙重同意；反杯葛規則相同；預算總統不得刪減。

## 2 預提碰到本面向：**本夾最重要的一檔**

### 2.1 為什麼

正式夾的行政權預算每年由單一席次議決一次——**議會每年有一次當面問責的機會**。

本夾的預提案一次授權四年。**人民授權之後，沒有一個常設機關替他們每年看帳**——議會只在「預提外」與「雙鑰匙調整」時介入。

**所以監察院的年度對照表在本夾不是補充，是主要的事後課責管道。**

### 2.2 任期供給案執行對照表

每年公布，直接送議會與公眾，**不經總統核閱**：

| 欄位 | 內容 |
|---|---|
| 授權額 | 預提案該年度的分年上限，逐科目 |
| 實際支出 | 決算數，逐科目 |
| 差異 | 絕對數與百分比 |
| 差異理由 | 行政機關陳述；監察院得併列自己的認定 |
| 減列情形 | 若歲入不足，實際依減列順序表削減了哪些、削了多少 |
| 累計 | 任期至今的合計與四年上限的對照 |

### 2.3 選前的承諾與事後的對照可以逐欄比對

**這是本夾課責的核心設計**：預提案的格式（[`03`](03-行政權預算.md) §2.7.2）與對照表的欄位**刻意對齊**——選民在選舉公報上看到的那張表，四年後會被逐欄對照。

★ 正式夾的課責是「今年給不給錢」，每年來一次但可以被當成談判籌碼；**本夾的課責是「當初說的和實際做的差多少」，一次涵蓋整個任期，而且無法在事後改寫**——當初的案子印在選舉公報上。

### 2.4 監察院不評價政策當否

對照表只陳述**授權額、實支、差異、理由**。**是不是該花這些錢，是選民與議會的事。**

★ 這條界線在本夾特別重要：監察院若能評價政策，它就成了一個沒有選舉授權、卻能否定人民授權的機關。

### 2.5 未執行餘額

案內未執行的餘額**應繳庫**，不得留用、不得移作他項；不繳庫者，監察院得逕行認定該支出無法證明合法性並公告。

★ 若餘額可留用，四年的上限就會變成四年的實際下限——**總統會有把錢花完的誘因**，而那與「上限」的性質相反。

## 3 狀態

同 [`../一院總統制/10-監察院.md`](../一院總統制/10-監察院.md) §3，並加：

| 狀態 | 怎麼走 |
|---|---|
| 對照表與行政機關數字不符 | 兩份併列公告，差異理由各自陳述；監察院不因此停止公告 |
| 行政機關拒絕提供決算明細 | 逕行認定該項無法證明合法性並公告 |
| 總統去職後該年度對照表 | 照常公布，涵蓋至去職日；新任者的案另起一份 |
| 監察院對政策當否表示意見 | 逾越權限，該部分不生效力 |

## 4 指向

對照表對應的格式：[`03`](03-行政權預算.md) §2.7.2、[`預提範例.md`](預提範例.md)。兩條路的課責比較：[`16`](16-完善與自洽.md) §4。正式夾：[`../一院總統制/10-監察院.md`](../一院總統制/10-監察院.md)。
