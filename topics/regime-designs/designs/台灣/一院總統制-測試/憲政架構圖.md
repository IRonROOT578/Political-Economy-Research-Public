# 憲政架構圖

`0-基本/總體.md`：給多張憲政設計架構圖。

**大部分結構與 [`../一院總統制/憲政架構圖.md`](../一院總統制/憲政架構圖.md) 相同**（五權、無倒閣無解散、三院人事、司法方案門檻、緊急狀態、更新程序）。本檔只畫**預提改變的部分**。

## 1 供給的授權鏈：從議會改成人民

```mermaid
flowchart TD
  Cand[正副候選人同組登記] -->|**投票日前 21 日公告全文**| Bundle[任期行政權預算案]
  Bundle -->|摘要表送達每一戶；全文貼投開票所公告欄| Voter[選民]
  Voter -->|選出該組＝授權該案| Auth[授權]
  Auth -->|就任日生效，四年有效| Exec[行政運作]
  Auth -.->|去職即終止：更新成功／彈劾／辭職／死亡| End[終止]
  Auth -.->|副總統繼任| Keep[承接原案]
```

## 2 「部分」怎麼落實：範圍，不是天花板

```mermaid
flowchart LR
  In[案內可含：裁量資本門／預備金與政務應變／行政經常門／列名政策計畫]
  Out[案外不含：法定義務／歲入／稅制／非行政部門預算／地方移轉公式]
  In --> Bundle[任期供給案]
  Out --> Year[年度議決或其他程序]
  D1[未列即未授權] --> Year
  NoCap[**不設金額百分比上限**] -.->|理由：授權者是人民，憲法不替他判斷規模| Bundle
  Scale[倍數對照欄取代天花板的功能] --> Voter[選民自己判斷規模]
```

## 3 三個硬預設：不需要誰去查

```mermaid
flowchart TD
  R1[逐項列明] -->|未列| C1[未授權，回到年度議決]
  R2[歲入假設須明列] -->|但| C2[歲入假設不構成授權]
  R3[須附減列順序表] -->|未填| C3[**由憲法逕行按比例齊頭削減**]
  Note[全部是自動發生的後果，不是「應公開、應說明」]
```

## 4 雙鑰匙：兩邊都不能單獨動

```mermaid
flowchart LR
  Pres[總統] --> Key1[鑰匙一]
  SMD[單一席次 ≥51] --> Key2[鑰匙二]
  Key1 --> Adjust[調整任期供給案]
  Key2 --> Adjust
  Pres -.->|不能獨自修改| Adjust
  SMD -.->|不能獨自修改| Adjust
  Stuck[僵持] -->|預設| Keep[維持原案，無仲裁、無自動生效]
  Order[緊急命令] -.->|**不得擴張額度或範圍**| Adjust
```

## 5 更新：在「人＋預算」的包裹之間排序

```mermaid
flowchart LR
  Sign[連署 10%，無議會關卡] --> R1[第一輪：選出 2 名挑戰者]
  R1 --> Bud[**各備胎得提出自己的任期供給案，格式與公告同大選**]
  Bud --> Show[三份摘要表並列於選舉公報同一頁]
  Show --> R2[第二輪：2 備胎 + 現任孔多賽，6 格單選]
  R2 -->|贏家 且 兩兩對決過半 且 ≥選舉人 40%| New[替換：新案自就任日生效至原任期屆滿]
  R2 -->|未達| Stay[現任留任，**原案不中斷**]
  NoEffect[**預算不列入替換條件的計算**] -.->|否則「提大案比較容易罷免現任」| R2
```

## 6 課責從「今年給不給錢」換成「說的和做的差多少」

```mermaid
flowchart TD
  Promise[選舉公報上的預提案：分年上限、科目、減列順序、倍數對照] --> Vote[投票]
  Vote --> Auth[授權四年]
  Auth --> Spend[實際支出]
  Spend --> Audit[監察院年度對照表：授權額／實支／差異／理由／減列情形]
  Audit -->|欄位與預提案刻意對齊| Compare[逐欄比對]
  Promise --> Compare
  Compare --> Next[下一次選舉的主要材料]
  Note[當初的案子印在選舉公報上，無法在事後改寫]
```

## 7 形式審查：只擋錯誤，不擋人

```mermaid
flowchart TD
  Case[候選組提出的案] --> Check[選務機關形式審查]
  Check --> C1[欄位齊全？]
  Check --> C2[加總正確？]
  Check --> C3[格式合規？]
  Check -.->|**不審政策內容**| X[不評價金額大小或政策方向]
  C1 -->|否| Mark[公告標示 + 依硬預設處理]
  C2 -->|否| Mark
  C3 -->|否| Mark
  Mark -.->|**形式瑕疵不得作為排除候選人的理由**| Run[照常參選]
  Why[能因表格問題把人擋在選舉外的審查，會立刻變成排除對手的工具]
```
