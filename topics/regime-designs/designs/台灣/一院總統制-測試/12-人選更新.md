# 人選更新

## 2 硬性條件怎麼落實

那條硬性有**兩半**，缺一不可。

### 2.1 前半：不應讓立法權凌駕人民罷免權

**現行制度的形態**：總統罷免須經全體立法委員 1/4 提議、**2/3 以上同意**，才能交付人民投票。也就是說，人民要不要罷免總統，**先由立法院決定人民有沒有資格投這一票**。

**本夾的作法：完全沒有議會關卡。**

- 罷免的發動與成案**只需人民連署**。
- 議會**沒有**提議權、沒有同意權、沒有審查權。
- 議會唯一與總統去職有關的角色是**彈劾**（法律責任），而那由監察院提案、司法院審判（[`09`](09-司法院.md)、[`10`](10-監察院.md)），與本檔的政治責任是兩條路。

### 2.2 後半：但仍有穩定性（如：冷卻期）

硬性條件明文允許穩定性機制，並以冷卻期為例。本夾用三樣，**全部在人民端，沒有一樣經過議會**：

| 機制 | 內容 | 為何不算「立法權凌駕」 |
|---|---|---|
| **連署門檻** | 選舉人 10%，180 日內完成 | 人民端的動員成本 |
| **票數地板** | 挑戰者對現任的兩兩對決支持票數須 ≥ 選舉人 40% | 人民端的門檻，防低投票率動員 |
| **冷卻期** | 失敗後 12 個月；最強挑戰者未達 40% 者 24 個月 | 時間，不是誰的同意 |

**這三樣都不是「誰的許可」，是人民自己要跨過的門檻。** 硬性條件反對的是把資格的判斷交給另一個機關，不是反對門檻本身。

## 3 規則（主路徑）

### 3.1 更新 ≠ 出缺 ≠ 彈劾

| | 性質 | 誰決定 | 落點 |
|---|---|---|---|
| **更新** | 政治責任 | **人民** | 本檔 |
| 彈劾 | 法律責任 | 監察院提案、司法院審判 | [`09`](09-司法院.md)、[`10`](10-監察院.md) |
| 出缺 | 事實 | — | §3.6 |

### 3.2 為什麼不用「同意／不同意」的罷免

同意／不同意只問「要不要拿掉這個人」，不問「換成誰」。反對現任的人可以是一群彼此毫無共識的人，他們能拆掉現任，卻產生不出替代者——結果是空缺、補選、再一次動員。

「備胎＋現任孔多賽」把兩個問題合成一個：**你要不要換成這個具體的人。**

這是 `配置/台灣/優化` 非硬性「**反為反而反**」在人事程序上的落點。

### 3.3 總統

k＝3，故第二輪是 **2 名備胎＋現任**共 3 人，票面仍是 6 個完整排序選項單選。

| 階段 | 規則 |
|---|---|
| 連署 | 選舉人總額 **10%**，180 日內完成。**無任何議會關卡** |
| 第一輪 | 全國單記，選出得票前 **2** 名挑戰者。現任不參加第一輪 |
| 第二輪 | 對「2 名挑戰者＋現任」採孔多賽完成法，6 格單選 |
| 替換條件 | 挑戰者須為孔多賽贏家，**且**在與現任的兩兩對決中得有效票過半，**且**該對決之支持票數 **≥ 選舉人總額 40%** |
| 未達 | 現任留任 |
| 冷卻 | 失敗後 **12 個月**；若最強挑戰者未達選舉人 40%，冷卻 **24 個月**。自投票日起算。無次數上限 |
| 任期 | 替換成功者接續**原任期之剩餘期間**，不重新起算 |
| 副總統 | 與新任總統同組登記，同時就任 |

「接續原任期」是防止把更新程序當成延長任期的工具。

### 3.3a 備胎的預提包

更新第二輪的每名備胎**得**提出自己的行政權預算，公告規則同定期選舉（[`03`](03-行政權預算.md)）。現任沿用其原包。替換成功則備胎的包生效於剩餘任期。未提自己的包者，就任後該部分走年度議決，不繼承現任的包。

### 3.4 單一席次議員

該選區選舉人 **10%** 連署。程序同總統（2 名備胎＋現任孔多賽）。地板為**該區選舉人 40%**。冷卻同總統。替換者任期至本屆屆滿。

### 3.5 複數席次議員

該選區選舉人 **10%** 連署後，該區**全部席次**依定期選舉規則重選，**不得針對名單上的個別議員**。

理由：單獨罷免一人只會讓同一份名單的下一位遞補，什麼也沒改變，卻給了對手一個便宜的騷擾工具。整區重選則是真的把選擇交還選民。

重選產生的議員任期至本屆屆滿。該區冷卻 12 個月。

### 3.6 出缺（不是更新）

- 總統：副總統繼任至原任期屆滿，**不補選**（[`02`](02-總統與行政.md) §3）。
- 單一席次：90 日內補選；剩餘任期不足 1 年不補。空席期間分母仍 100。
- 複數席次：同區同名單未當選者依名單順位遞補；名單用盡則空席，分母仍 80。
- 三院：見各該檔，**不走人民更新**。

### 3.7 緊急狀態不停止更新

見 [`07`](07-緊急狀態.md) §2.4。已成案的更新投票不因緊急狀態延期；投票地點得變更，投票日不得變更。

**若緊急狀態能停止更新，總統就取得一個比議會 2/3 更強的自我保護工具**——那是 §2.1 那條硬性要防的東西的變形。

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 連署期間現任辭職 | 改走出缺。已繳連署作廢，不轉成更新 |
| 第一輪後現任死亡 | 改走出缺。第二輪不辦 |
| 挑戰者僅 1 人 | 第二輪為 1 備胎＋現任，票面改 2!＝2 格 |
| 挑戰者 0 人 | 不辦第二輪，現任留任，冷卻 12 個月 |
| 第一輪第 2 名同票 | 併列進第二輪，票面改 4!＝24 格 |
| 孔多賽贏家非最強挑戰者 | 以贏家與現任的兩兩對決判斷替換條件 |
| 出現孔多賽循環 | 依完成法（Ranked Pairs）決出；替換條件仍須逐項滿足 |
| 冷卻末日恰逢定期改選 | 更新不辦，走定期改選 |
| 距定期改選投票日不足 12 個月 | 不辦更新 |
| 更新與彈劾同時進行 | 兩者並行，互不停止；任一成立即生效，另一程序終止 |
| 緊急狀態中 | 更新照辦。得變更投票地點，不得變更投票日 |
