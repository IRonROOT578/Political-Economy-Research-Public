## 1 本檔繼承

## 2 備胎的行政權預算

`1-優化/財政.md`：「總統更新時：**備胎可提出自己的行政權預算。**」

**這一條把更新從「要不要換掉這個人」變成「要不要換成這個人和他的那份預算」。** 第二輪的孔多賽因此是在數個完整的「人＋預算」包裹之間排序。

### 2.1 規則

| 項 | 規則 |
|---|---|
| 提出 | 備胎（含其副手，同組）得於更新投票前提出自己的任期供給案；**非強制** |
| 公告 | **與大選完全相同**：第一輪投票日前 **21 日**公告全文（[`03`](03-行政權預算.md) §2.3） |
| 格式 | **與大選完全相同**：空白表、必填欄、減列順序表、倍數對照欄（[`03`](03-行政權預算.md) §2.7） |
| 形式審查 | 與大選相同；**形式瑕疵不得作為排除備胎資格的理由** |
| 呈現 | 各組的**摘要表並列於選舉公報同一頁**，與現任的現行案並列 |
| 勝出者的案 | 自就任日生效至**原任期屆滿**，不重新起算 |
| 勝出者未提 | 未覆蓋部分走 [`03`](03-行政權預算.md) §2.8 的年度議決 |
| 現任留任 | **原案繼續有效**，不因更新程序被發動而中斷 |

### 2.2 為什麼格式必須與大選相同

若備胎的案子可以不照格式，就會出現一條漏洞：**大選時要填減列順序表、要寫倍數對照，補位時不用**——那會讓「更新」成為規避格式規格的入口，而格式正是本夾對「透明度與可實踐性」的交付（[`03`](03-行政權預算.md) §2.7）。

### 2.3 **預算不列入替換條件**

> 替換條件只衡量**人的對決**：孔多賽贏家、兩兩對決有效票過半、該對決支持票數 ≥選舉人 40%。**備胎或現任的預提案，不影響上述任一項的計算。**

**為什麼要明文寫死**：若預算能影響門檻，就會出現扭曲——例如「提一份很大的案子來拉高自己的支持度以跨過 40%」，或反過來「現任提高原案以綁住支持者」。

**門檻衡量的是人民要不要換這個人；預算只影響選民排序時的判斷。** 兩者分開。

### 2.4 現任者的案在更新期間不中斷

從連署成案到投票日之間，現任的預提案**照常執行**。

理由：更新是一個可能失敗的程序，若一提出就凍結預算，發動連署本身就成了一種癱瘓工具——那與「只撤供給不撤信任」是同一個病。

## 3 與正式夾的差異一覽

| | 正式夾 | **本夾** |
|---|---|---|
| 更新的門檻與程序 | 相同 | 相同 |
| 更新投票時選民看到什麼 | 三個人 | **三個「人＋預算」的包裹** |
| 更新成功的財政後果 | 無（預算本來就年年議決） | **舊案終止，新案自就任日生效** |
| 更新失敗的財政後果 | 無 | **原案繼續，不中斷** |
| 備胎的額外負擔 | 無 | 須在 21 日前完成一份合格式的預算表 |

★ 最後一列是一個真實的門檻：**它使更新的發動成本上升**。本夾接受——一個連四年預算都提不出來的挑戰者，本來就不該只靠「反對現任」上台。這與「反為反而反」的方向一致。

## 4 狀態

同 [`../一院總統制/12-人選更新.md`](../一院總統制/12-人選更新.md) §4，並加：

| 狀態 | 怎麼走 |
|---|---|
| 備胎公告逾期（不足 21 日） | 該案視為未提出，不生授權效力；**不影響其備胎資格** |
| 備胎的案加總錯誤 | 公告標示，依 [`03`](03-行政權預算.md) §2.7.1 的預設處理；不影響資格 |
| 兩名備胎皆未提案 | 更新照常進行；勝出者的未覆蓋部分走年度議決 |
| 第一輪後備胎退出 | 其案隨之失效；第二輪票面依剩餘人數調整 |
| 更新成功但新任者的案牴觸憲法 | 牴觸部分無效，該部分回到年度議決（[`05`](05-法律與法規位階.md)） |
| 緊急狀態期間 | 更新照辦；**備胎的公告期不因狀態延長或縮短** |
