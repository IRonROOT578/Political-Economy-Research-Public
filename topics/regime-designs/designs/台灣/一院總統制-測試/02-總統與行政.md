## 2 規則（主路徑）

### 2.1 選出

正副總統**同組**登記。人民 **top-3 孔多賽**：第一輪全國單記，取得票前 3 組；第二輪對這 3 組採孔多賽完成法，票面為 6 個完整排序選項單選。

與議會第二輪、複數席次同日（[`01`](01-議會組成與選制.md) §2.9）。

**不用相對多數一輪。** 台灣現行的總統選舉即為相對多數一輪，而 `1-優化/行政立法/共用.md` 把台灣列為二極化的反例之一——**單一勝者的全國競爭是二極化誘因最強的場域**，選制若再是相對多數，激怒對方陣營就成為最划算的動員手段。

孔多賽的第二輪要求爭取第三名支持者的第二偏好，把那個誘因倒轉。

### 2.2 任期

**4 年，連任一次**，與議會同屆。

### 2.3 職權

- 為行政首長，任免政務人員，指揮行政部門。
- 決定並執行外交、國防、安全政策。
- 公布法律；對法律有一次退回覆議權。
- 依 [`07`](07-緊急狀態.md) 宣告緊急狀態。
- 統帥武裝力量。**宣戰須議會 ≥120（2/3）同意**，總統不得單獨為之。
- 為國家對外代表。

### 2.4 與議會的關係

| 項 | 規則 |
|---|---|
| 議會能否因政策撤換總統 | **否** |
| 總統能否解散議會 | **否** |
| 法律覆議 | 總統得退回一次，議會以 **≥91** 維持則原案成立 |
| 基本法 | 總統**不得**覆議 |
| 彈劾 | 監察院提案，司法院審理，見 [`09`](09-司法院.md)、[`10`](10-監察院.md) |
| 政治責任 | 走 [`12`](12-人選更新.md) 的**人民更新**，不走議會 |
| 行政權預算 | 僅單一席次議員表決，見 [`03`](03-行政權預算.md) |

### 2.5 為什麼沒有解散權

威瑪的失敗機制不在於總統直選，而在於**第 25 條的解散權與第 48 條的緊急命令權互相解鎖**：議會要廢止緊急命令，總統就解散議會；重選期間再發同一道命令。

拿掉解散權，議會對緊急命令的廢止權（[`07`](07-緊急狀態.md)）才是真的。這一條同時服務執政效率——沒有解散就沒有隨時可能被重設的政治局面。

### 2.6 不設行政院長

行政首長就是總統本人。**不設一個對議會負責、又由總統指定的中間人**——`1-優化/財政.md` 已寫明那是政體錯配（法國的問題）：建設性不信任案不適用於「總統決定總理」的情況，於是只有供給保障沒有信任保障。

政務人員對總統負責；議會得質詢、調查，得對個別政務人員提出**譴責案**（全院 ≥91），但譴責不生解職效力。

### 2.7 副總統

與總統同組選出。總統缺位由副總統繼任至原任期屆滿，**不補選**。

副總統缺位時，由總統提名、議會 ≥91 同意；議會 **60 日內未表決視為同意**——避免用懸缺癱瘓繼任順序。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 總統缺位 | 副總統繼任至原任期屆滿。繼任者的任期計入其連任次數 |
| 正副同時缺位 | 司法院長代行職權，90 日內辦理補選。代行者不得宣告緊急狀態、不得任免政務人員 |
| 總統永久不能視事 | 由司法院以 ≥12／15 認定（[`09`](09-司法院.md)），副總統繼任。認定程序不得由總統本人啟動或阻止 |
| 覆議期間屆期改選 | 覆議案由新屆議會表決，門檻不變 |
| 當選組於就任前解散 | 另一人單獨就任，缺位者依 §2.7 補 |
| 更新成功 | 見 [`12`](12-人選更新.md)。新總統接續**原任期之剩餘期間**，不重新起算 |
| 彈劾成立 | 解職，副總統繼任 |
| 總統拒不公布已通過之法律 | 逾 15 日由議長公布，效力相同；拒不公布為彈劾事由 |
