# 為何這仍然不是獨裁

本檔是概要層。

## 1 對應表

```
都用 0-基本
都用 民選制
# 台灣
有監察權、考試權
都用 配置\台灣\基本
1. 一院總統制 惡搞: 配置\惡搞
```

| 來源 | 條件 | 位階 |
|---|---|---|
| `配置/惡搞/總體.md` | 仍為民主，符合自由、民主、投票；不能被認為是獨裁 | **硬性** |
| `配置/惡搞/總體.md` | 惡搞型；腐敗、對立內鬥**或**混亂；治理不如獨裁或威權；人民有空間吹捧；咎責盲區／安全溫室 → 假性掌控 | **硬性** |
| `配置/台灣/基本/投票.md` | 人工計票（含單選）；不集中、不長距離運輸 | **硬性** |
| `配置/台灣/基本/其他權/總體.md` | 專門選舉權人若有須代理；高層間接選舉記名 | **硬性** |
| `0-基本/其他權/司法權.md` | 普通法官不當記名選舉權人 | **硬性** |
| `0-基本/其他權/司法權.md` | 高政治性不應極端、狹隘派系化 | **非硬性，本夾不採** |
| 對應表 | 有監察權、考試權 | 映射 |

**不繼承**：`1-優化` 全部、`配置/台灣/優化`、`配置/個人偏好`、`配置/雜項`。現役那句「不繼承配置／台灣全部」刪掉——本夾吃台灣**基本**。

## 2 手法

> **凡是硬性條件，一字不差地遵守；壞事全發生在硬性條件沒有規定的地方。**

全體一致不是「遵守舊司法硬性的字面」。那條已降非硬性。門檻掛在惡搞硬性：對立內鬥或混亂、咎責盲區。安全溫室：日常民刑事與考試仍轉；失靈被隱形。假性掌控：人民罵兩黨，不罵規則。

## 3 五個檢查點

| 檢查點 | 本夾 |
|---|---|
| 選舉是否照常 | 總統 4 年、議會 2 年，**任何情況下都不得延期**，含緊急狀態（[`07`](07-緊急狀態.md)） |
| 敗選者是否下台 | 是。任期屆滿當日解職 |
| 反對黨是否合法 | 是。政黨登記採報備，不得以違憲政黨為由解散 |
| 言論與集會 | 不入刑 |
| 有無不受更新的職位 | 無。總統與議員皆可被人民更新；總統那條先經議會 2/3（[`09`](09-人選更新.md)） |

## 4 那壞在哪

壞在每一項都合法、民選、可問責，加起來讓國家做不了事。沒有人違憲，沒有人政變：

- 預算年年停擺，是議會依法否決。
- 憲法法庭常年缺額，是因為同意門檻依法是全體一致。
- 總統罷免卡在議會 2/3，人民罵兩黨杯葛。
- 選區每兩年重畫一次，是因為劃分依法由普通法律為之。
- 救災措施每兩週歸零一次，是因為緊急狀態依法 14 日自動失效。

**治理成績會比一個有效率的威權國家難看。但威權國家沒有這些程序，本夾有——人民也就是拿這一點驕傲。**

## 5 一條刻意沒有越過的線

草擬階段曾考慮「緊急狀態無期限、得延後選舉至多 1 年」。**那條越線了**：延後選舉是最典型的獨裁標記。

改成 [`07`](07-緊急狀態.md)：**14 日自動失效、延長須 2/3（湊不到）、重新宣告無次數限制**。效果一樣混亂，但**沒有任何一次選舉被延後**。不取消投票、不改任命制。
