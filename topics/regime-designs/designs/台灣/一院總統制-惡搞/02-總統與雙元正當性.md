# 總統與雙元正當性

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/行政立法/一院總統制.md` | **硬性** | 總統負責行政；選出方式為人民投票 |
| `配置/惡搞/總體.md` | 硬性 | 仍為民主民選 |
| `配置/惡搞/總體.md` | 非硬性 | 對立內鬥；混亂 |

**不繼承** `1-優化` 的 top-k 孔多賽、決選同日、信任供給合一。

## 2 規則（主路徑）

### 2.1 選出

人民**一輪相對多數**。無第二輪、無孔多賽、無最低得票門檻。

★ 三腳督時 **35% 就能上**，而且他知道自己是 35%。

任期 4 年，**連選連任無次數限制**——這不是威權延任，是每次都要真的贏一次選舉（§4 的界線）。

副總統與總統同組。總統缺位由副總統繼任；副總統缺位時**懸缺至下次大選**。

### 2.2 職權

負責行政，任免政務人員，指揮部會，公布法律，對外代表。

### 2.3 與議會

| 項 | 規則 |
|---|---|
| 議會能否因政策撤換總統 | **否** |
| 總統能否解散議會 | **否** |
| 法律否決 | 總統對法律有**整案否決權**（不得逐條否決） |
| 覆議 | 全院 **2/3（≥150）** 維持，原案才成立 |
| 彈劾 | 議會 2/3（≥150）提案，憲法法庭 **全體一致** 成立 |

彈劾那一列實質是裝飾：法庭長年湊不到全員（[`06`](06-三院.md)）。

### 2.4 雙元正當性，沒有出口

總統說「兩千萬人選我」，議會說「225 個選區選我們」。**兩邊都對，而憲法沒有給出口**：

- 沒有解散。
- 沒有倒閣。
- 沒有提前大選。
- **沒有可運作的仲裁者**——憲法法庭裁不了任何事（[`08`](08-中央內水平分權.md)）。

**剩下的唯一出口是耗到下一次期中選舉。** 而任期錯開保證那一次一定會來，也保證它會把局面再翻一次。

這正是 `配置/惡搞` 要的「對立內鬥」。**它不是獨裁——它是兩個民選機關合法地互相癱瘓。**

### 2.5 為何連任無次數限制不算越線

**因為每一次都要真的贏一次選舉。**

獨裁的標記是「不必再贏就能留任」（延任、取消選舉、修憲歸零）。本夾沒有這些：選舉照常、對手合法、計票乾淨（[`01`](01-議會組成.md) §2.5）、罷免門檻極低（[`09`](09-人選更新.md)）。

★ 一個連任五次的總統，若每次都是在真實選舉中以 35% 相對多數勝出、期間被罷免案追著跑，那是**難看的民主**，不是獨裁。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 總統缺位 | 副總統繼任至原任期屆滿 |
| 副總統缺位 | **懸缺至下次大選**——沒有補位機制 |
| 正副同時缺位 | 議長代行至補選；補選於 90 日內辦理 |
| 總統拒不公布法律 | 逾 15 日由議長公布；拒不公布為彈劾事由（而彈劾過不了） |
| 總統整案否決預算 | 走 [`04`](04-預算與財政.md) 的停擺 |
| 覆議票 149（差一票） | 否決維持，原案不成立 |
