# 憲政架構圖

`0-基本/總體.md`：給多張憲政設計架構圖，方便讀者理解。

## 1 外形：一個標準的總統制民選國家

```mermaid
flowchart LR
  People[人民] -->|一輪相對多數，4 年，連任無限制| Pres[總統]
  People -->|225 區 FPTP，一輪，2 年| Parl[議會 225]
  Pres --> Exec[行政部門]
  Parl --> Law[法律與預算]
  Parl -->|記名同意| Three[司法院 15／監察院 19／考試院 19]
  People -->|1% 連署| Recall[罷免]
  People -->|1% 連署，一年四次| Ref[諮詢性公投]
```

## 2 沒有出口的雙元正當性

```mermaid
flowchart TD
  Pres[總統：兩千萬人選我] -.->|不能解散| Parl[議會：225 個選區選我們]
  Parl -.->|不能倒閣| Pres
  Pres -->|整案否決| Bill[法律／預算]
  Parl -->|覆議須 150，湊不到| Bill
  Court[憲法法庭] -.->|15／15，裁不了| Deadlock[僵局持續到期中改選]
  Term[任期錯開：總統 4 年、議會 2 年] --> Deadlock
```

## 3 三院：字面達成，功能歸零

```mermaid
flowchart TD
  Req[0-基本 硬性：避免方案的通過，極端、派系化] --> Rule[同意與方案門檻皆為全體一致]
  Rule --> Nothing[任何方案都過不了，極端的當然也過不了]
  Vacancy[缺額計入分母] --> Nothing
  NoAnti[**不繼承 1-優化 的反杯葛硬性**] --> Vacancy
  Nothing --> C1[違憲的法律照樣有效]
  Nothing --> C2[選區重劃無人審查]
  Nothing --> C3[權限爭議無裁判者]
  Nothing --> C4[彈劾實質不可能成立]
```

## 4 預算：沒有防餓死機制

```mermaid
flowchart TD
  Budget[總預算] --> Add[議會**得增列**地方建設]
  Budget --> Zero[議會**得刪至零**，法定義務亦可刪]
  Budget --> Three[總統**得先刪三院預算**再送]
  Add --> Veto[總統整案否決]
  Zero --> Veto
  Veto -->|覆議 150 湊不到| Shutdown[年度開始即停擺]
  Shutdown -.->|**無沿用條款**，先讓步者失去籌碼| Shutdown
```

## 5 緊急狀態：每 14 天歸零，但選舉照常

```mermaid
flowchart LR
  Dec[總統逕行宣告] --> D14[**14 日自動失效**]
  D14 -->|延長須 2/3＝150| Fail[追認失敗]
  Fail --> Void[緊急命令同時失效：徵用、管制、預算依據全部消滅]
  Void --> Redec[**隔日重新宣告，無次數限制**]
  Redec --> Dec
  Dec -.->|**不得延後任何選舉、複決、罷免**| Elec[民主程序照常]
  Dec -.->|不創設解散權、不停止彈劾與更新| Elec
```

## 6 罷免常態化

```mermaid
flowchart TD
  Sign[選舉人 1% 連署] --> Vote[同意多於不同意即成立]
  Vote -.->|**無投票率地板、無冷卻期、無次數上限**| Recall[任期實質縮短]
  Recall --> Defend[當選人**就職次日起**防守連署]
  Cheap[罷免比談判便宜：跑三個邊際選區的連署，比說服三個議員容易]
  Cheap --> Replace[議會內部協商被外部動員取代]
  Pres[總統被罷免] -->|**不補選**| VP[副總統繼任——沒有人單獨投過票給他]
```

## 7 五權：多兩個院等於多兩個湊不齊的機關

```mermaid
flowchart TD
  Exec[行政：總統] -->|得先刪三院預算| Three
  Leg[立法：議會 225] -->|**普通法律 38 票**可改法院組織、三院組織、文官任用、選區劃分| Three
  Three[司法 15／監察 19／考試 19]
  Three -.->|全部全體一致，全部湊不齊| Nil[實質不行使]
  Nil -.->|沒有可運作的裁判者| Overlap[三處權限重疊：法律解釋、機關組織、預算指定]
  Overlap --> How[實際解決方式：誰能拖、誰敢不執行]
```

## 8 為什麼這仍然不是獨裁

```mermaid
flowchart TD
  Sym[三權互相都有武器，沒有一權能單方面消滅另外兩權]
  Sym --> P1[總統不能解散議會]
  Sym --> P2[議會不能撤換總統]
  Sym --> P3[法庭誰也動不了]
  Sym --> Concl[**對稱的僵局，不是一個中心**]
  Line[五條檢查點：選舉不得延期／屆滿解職／反對黨合法／言論不入刑／無不受更新的職位]
  Line --> Concl
  Concl --> Final[獨裁需要一個中心。本夾沒有]
```

## 9 正當性零件

```mermaid
flowchart LR
  Ref[一年四次諮詢公投：對象範圍全部、效力範圍零] --> Pride[高投票率與參與感]
  Recall[隨時在跑的罷免] --> Pride
  Day[自由民主投票日：放假、慶典、公告國際民主排名] --> Pride
  Ref -.->|憲法明文：不得據以直接變更法律| Nil[不變更任何法律]
  Day -.->|排名分裂：選舉自由前段、政府效能墊底| Half[慶典只念前半段]
```
