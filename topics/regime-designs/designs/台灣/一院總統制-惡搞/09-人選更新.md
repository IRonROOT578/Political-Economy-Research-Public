# 人選更新

## 1 本檔繼承

`0-基本/總體.md` 把「**更新人選條件**」列為必須交代的憲政選擇。

**不繼承** `1-優化/投票.md` 的更新設計（第一輪選前 k−1 名、第二輪對「備胎＋現任」孔多賽、備胎須在兩兩對決贏過現任、票數地板）。**本夾用最簡單的版本。**

`配置/台灣/優化` 那條「總統更新不應讓立法權凌駕人民罷免權，但仍有穩定性（如：冷卻期）」在台灣**優化**，**本夾不繼承**——所以本夾用正式夾禁止的形狀：議會 **2/3** 同意後才交付人民。議員罷免維持 1% 連署、無地板無冷卻（那條硬性只談總統）。

## 2 規則（主路徑）

### 2.1 罷免

| 項目 | 總統 | 議員 |
|---|---|---|
| 提議 | 選舉人 **0.5%** | 該區選舉人 0.5% |
| 連署 | 選舉人 **1%** | 該區選舉人 1% |
| 議會關卡 | **全體立法委員 2/3 同意後才交付人民投票** | 無 |
| 成立 | 同意票多於不同意票 | 同左 |
| 最低投票率 | **無** | **無** |
| 同意票地板 | **無** | **無** |
| 冷卻期 | **無** | **無** |
| 次數上限 | **無** | **無** |
| 就任後多久可提 | **就職次日起** | 就職次日起 |

### 2.1a 總統罷免的議會 2/3

正式夾禁止的形狀，本夾採用：人民連署只是啟動，**全體立法委員 2/3 同意後才交付人民投票**。

這是咎責盲區：人民看見「兩黨又擋罷免」，看不見規則本身。連署門檻極低，所以連署常年在跑、投票日慶典常有——但總統那一票幾乎交不出去。議員罷免沒有這道關卡。

### 2.2 議員：沒有地板的後果

**投票率愈低愈容易罷免。**

★ 示意：一個當初以 40% 得票、投票率 70% 當選的議員（約 28% 選舉人支持），在一場投票率 16% 的罷免投票中，只要動員 8.5% 的選民投同意就會被罷掉。

### 2.3 沒有冷卻期的後果

**罷免失敗的隔天可以再提。**

★ 於是罷免不是例外程序，是**常態政治工具**。當選人**就職第一週就開始防守連署**，任期實質縮短為「到下一個罷免案為止」。

### 2.4 補選

| 對象 | 規則 |
|---|---|
| 議員 | 罷免成立後 90 日內補選，補選者任期至本屆屆滿（可能只剩幾個月），然後又要再選一次 |
| 總統 | 罷免成立由**副總統繼任至任期屆滿**——**不補選** |

★ 總統那一列很關鍵：**罷免總統的實際效果，是把行政權交給一個沒有人單獨投過票的副手**（他是同組當選的，選民投的是這一組）。而副總統缺位時懸缺至下次大選（[`02`](02-總統與雙元正當性.md) §2.1），所以罷免總統之後，**繼任者沒有副手，正副同時缺位的風險提高**。

### 2.5 225 個區，一年到頭都在投票

★ 議員 2 年一任、225 個選區、罷免無冷卻無地板、補選任期至本屆屆滿。

**可預期的形態**：一年通常有三到四波罷免投票，加上補選、公投（一年四次）、以及兩年一次的定期改選。

★ **投票率高、選舉多、參與熱烈——這些數字都會很好看，而且是真的。**

### 2.6 罷免比談判便宜

★ 一個理性的政治行動者，與其在議會裡說服三個議員，不如去他們的邊際選區跑三場連署——**後者只要該區 1% 的簽名，而且不需要對方同意。**

**於是議會內部的協商被外部的罷免動員取代。** 這正好加深 `配置/惡搞` 要的「對立內鬥」。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 罷免與定期改選同期 | 無「距改選幾個月不辦」的規定；照辦 |
| 同一人被連續罷免三次 | 合法。無次數上限 |
| 罷免投票率 8% | 有效。同意多於不同意即成立 |
| 補選當選人再被罷免 | 合法，程序重跑 |
| 總統連署完成、議會未達 2/3 | 不交付人民投票。連署可再提 |
| 總統罷免成立 | 副總統繼任至任期屆滿；不補選 |
| 副總統已懸缺時總統被罷免 | 議長代行，90 日內補選（[`02`](02-總統與雙元正當性.md) §3） |
| 緊急狀態期間 | **罷免照常辦理，不得延期**（[`07`](07-緊急狀態.md) §3.1） |
