## 2 刻意不繼承什麼

`1-優化` 全部、`配置/台灣/優化`、`配置/個人偏好`、`配置/雜項`。**台灣基本有繼承。**

具體被放棄的東西：

| 放棄的 | 出處 | 若有它會擋掉本夾的什麼 |
|---|---|---|
| **法規位階（硬性）** | **`配置/台灣/優化/行政立法/共用`** | 選舉法與法院組織法就不能 38 票改 |
| **反杯葛（硬性）** | `1-優化/其他權/總體` | **三院就不會癱瘓** |
| **向心型選制優於 FPTP** | `1-優化/行政立法/共用` | 二極化的誘因會被降低 |
| 「同意 > 總額半數」 | `1-優化/行政立法/共用` | 突襲立法不成立 |
| 修憲兩軌 | `1-優化/行政立法/共用` | 憲法就改得動 |
| 信任供給合一、預提 | `1-優化/財政` | 「只撤供給不撤信任」就不成立 |
| 三版本公投 | `1-優化/投票` | 公投就有實效 |
| 聖拉古三件 | `配置/個人偏好/投票` | 本夾無複數席次，N/A |
| 身分政治 | `配置/個人偏好/行政立法/共用` | 本夾不把它當硬性義務 |
| 反冗員（200 多席） | **`配置/雜項`** | 225 就站不住 |
| 修憲難度不能實質改不了 | `配置/台灣/優化` | 就不能照抄現行門檻 |
| 總統更新不得立法凌駕人民罷免 | `配置/台灣/優化` | 就不能用議會 2/3 關卡 |
| 防餓死、沿用 | `配置/雜項/財政` | 停擺就不會發生 |

**沒有一項是違反提示詞的**——它們全部標在非硬性或可選，而本夾的映射沒有引入它們。

## 3 三個看似矛盾之處

**1.「不是獨裁」×「緊急狀態」。** 緊急狀態不得延後任何選舉、不創設解散權、不停止彈劾與更新、14 日自動失效。**上限鎖住。** 草擬階段的「得延期至多 1 年」已刪除（[`00`](00-為何這仍然不是獨裁.md) §5）。

**2.「不是獨裁」×「總統罷免卡在 2/3」。** 連署常年在跑，人民投票幾乎交不出去。人民罵兩黨，不罵門檻。議員罷免仍對稱、無議會關卡。

**3.「安全溫室」×「法庭癱瘓」。** 考試仍辦、民刑事仍判；失靈在補人與高政治性。全體一致掛惡搞硬性，**不是**舊司法硬性的字面。
