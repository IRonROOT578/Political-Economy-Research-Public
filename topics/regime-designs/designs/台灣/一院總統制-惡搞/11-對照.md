## 2 刻意不繼承什麼

`1-優化` 全部、`配置/台灣` 全部、`配置/雜項` 全部。

具體被放棄的東西：

| 放棄的 | 出處 | 若有它會擋掉本夾的什麼 |
|---|---|---|
| **法規位階（硬性）** | **`配置/台灣/行政立法/共用` ＞ 架構** | 選舉法與法院組織法就不能 38 票改 |
| **反杯葛（硬性）** | `1-優化/其他權/總體` | **三院就不會癱瘓**——這是本夾最關鍵的一項 |
| **向心型選制優於 FPTP** | `1-優化/行政立法/共用` | 二極化的誘因會被降低 |
| 黑金與 SNTV／開放名單的考量 | `1-優化/行政立法/共用` | 選制會被迫變複雜 |
| 「同意 > 總額半數」 | `1-優化/行政立法/共用` | 突襲立法不成立 |
| 修憲兩軌（跨屆＋急迫） | `1-優化/行政立法/共用` | 憲法就改得動 |
| 信任供給合一、規劃保障的供給、預提 | `1-優化/財政` | 「只撤供給不撤信任」就不成立 |
| 三版本公投＋兩要件 | `1-優化/投票` | 公投就有實效 |
| top-k 孔多賽、聖拉古、無門檻、席次區間 | `1-優化/投票` | 選制會複雜且較不失真 |
| 備胎＋現任孔多賽、票數地板 | `1-優化/投票` | 罷免就不會常態化 |
| 反冗員（200 多席）、廢 SNTV、地方代表性 | **`配置/雜項/行政立法/共用`** | 225 就站不住 |
| 修憲難度不能實質改不了 | `配置/台灣` | 就不能照抄現行門檻 |
| 總統更新不應讓立法權凌駕人民罷免權，但仍有穩定性 | `配置/台灣` | **後半**會擋掉「無地板無冷卻」 |
| 少身分政治 | `配置/雜項` | — |
| 防餓死機制、沿用條款 | `配置/雜項/財政` | 停擺就不會發生 |
| 席次圖的仿維基要求 | `配置/雜項/行政立法/共用` | **不影響**——`0-基本/總體` 自己就有這條 |

**沒有一項是違反提示詞的**——它們全部標在非硬性或可選，而本夾的映射沒有引入它們。

## 3 三個看似矛盾之處

**1.「不是獨裁」×「緊急狀態」。** 緊急狀態不得延後任何選舉、不創設解散權、不停止彈劾與更新、14 日自動失效。**上限鎖住。** 草擬階段的「得延期至多 1 年」已刪除（[`00`](00-為何這仍然不是獨裁.md) §5）。

**2.「不是獨裁」×「罷免太容易」。** 罷免對所有職位一視同仁，包括執政方自己的議員。**它是對稱的騷擾工具，不是清洗工具。**

**3.「司法避免極端方案」×「法庭癱瘓」。** 字面達成，功能歸零。**這是刻意的字面主義，不是漏洞**——寫在 [`10`](10-憲政選擇.md) 第 15 項。
