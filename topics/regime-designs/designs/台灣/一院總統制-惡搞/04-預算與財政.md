# 預算與財政

## 1 本檔繼承

`0-基本/總體.md` 把「預算處理」列為必須交代的憲政選擇。`0-基本/財政.md` **沒有任何條件**。

**不繼承**：`1-優化/財政.md` 的信任供給合一、規劃保障的供給、預提、僅單一席次表決預算；`配置/雜項/財政.md` 的**防餓死機制與沿用條款**。

## 2 規則（主路徑）

### 2.1 誰決定，能做什麼

全院 225 人表決，**出席過半**。

| 議員得為之 | 說明 |
|---|---|
| **增列**科目 | 無「得刪不得增」的限制 |
| 刪減至**零** | 任一科目皆可 |
| 刪減**法定義務支出** | 憲法沒有把它們排除在議決之外 |

### 2.2 沒有任何防餓死機制

`配置/雜項/財政.md` 有「各權有防餓死機制（如：沿用條款）」，**本夾不繼承那個檔案**，所以不寫。結果：

- 會計年度開始仍未通過總預算 → **裁量支出歸零**，機關停止運作。
- **法定義務支出也可以被刪**——社會給付、債務還本付息都在議決範圍內。
- 三院（司法、監察、考試）的預算與行政同一程序，**總統得先刪再送**。

### 2.3 沒有信任供給合一

`1-優化/財政.md` 不繼承。所以「**只撤供給、不撤信任**」是本夾的常態動作：

- 議會撤不掉總統（無倒閣），就每年拿預算當人質。
- 總統撤不掉議會（無解散），就整案否決預算報復。

**兩邊都合法。**

### 2.4 停擺是均衡，不是意外

★ 沒有沿用條款，也就**沒有人有動機先讓步**——讓步的一方失去下一輪的籌碼。

可預期的循環：

1. 議會在期中改選前把預算拖過年度開始，讓總統扛停擺責任。
2. 總統在選前否決預算，讓議會扛。
3. 停擺第三週，雙方各自召開記者會。
4. 妥協版通過，地方建設科目全數保留，國防與外交的裁量科目被砍。

**誰也沒違憲。**

★ 這正是 `1-優化/行政立法/共用.md` 點名的美國病灶（「美國政府曾因兩大黨對立而預算停擺」）——**而本夾不繼承 `1-優化`，所以沒有義務避免它。本夾把它當成目標。**

### 2.5 三院的預算沒有保護

總統得先刪司法院、監察院、考試院的預算再送議會；議會得再刪至零。

★ 五個正式夾都有「行政首長不得刪減非行政部門預算」這一條——**本夾沒有**。後果：一個能刪憲法法庭預算的總統，不需要違憲就能讓法庭停轉，而法庭本來就已經因為缺額而不運作（[`06`](06-三院.md)）。

### 2.6 決算：沒有獨立審計的實效

監察院有審計權（[`06`](06-三院.md)），但它自己也湊不齊人。決算實務上由議會自己看自己。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 年度開始未通過總預算 | 裁量支出**歸零**，機關停工 |
| 法定義務支出被刪 | **合法**，該給付停發 |
| 總統整案否決 | 覆議須 2/3（≥150） |
| 覆議失敗 | 回到「未通過」，繼續停擺 |
| 停擺期間的必要支出 | 無任何緊急撥付條款 |
| 三院預算被刪至零 | 該機關停止運作；無救濟 |
| 未執行餘額 | 無繳庫規定，得留用 |
