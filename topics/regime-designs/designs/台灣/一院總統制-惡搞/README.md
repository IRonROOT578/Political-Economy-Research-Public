# 台灣：一院總統制－惡搞

```
# 台灣
有監察權、考試權
1. 一院總統制 惡搞: 0-基本 配置\惡搞
```

只繼承 `0-基本` 與 `配置/惡搞`。**不**繼承 `1-優化`、`配置/台灣`、`配置/雜項`。**有監察權、考試權**（寫在 `# 台灣` 標題下、五夾之上）。

## 手法

> **凡是硬性條件，一字不差地遵守；壞事全發生在硬性條件沒有規定的地方。**

`0-基本` 的硬性照做：人工計票、不集中運票、高層間接選舉記名、司法避免極端方案通過。**而「避免極端方案通過」是用全體一致決達成的——任何方案都過不了，極端的當然也過不了。**

## 一句話

議會 **225 席全 FPTP**、任期 2 年與總統 4 年錯開；總統**一輪相對多數**（35% 可當選）、連任無限制、對法律有整案否決權而覆議要 2/3；**無倒閣、無解散、無可運作的仲裁者**；預算**可增列、可歸零、法定義務亦可刪、無沿用條款**；三院同意與方案門檻皆為**全體一致**且缺額計入分母；修憲照抄現行門檻因而**改不動**；罷免 **1% 連署、無地板、無冷卻**。

**每一條都合法、民選、可問責，加起來讓國家做不了事。**

## 唯一的硬性是上限，不是籌碼

`配置/惡搞` 只有一條硬性：**仍為民主和民選國家，不能被認為是獨裁。**

★ 草擬階段曾寫「緊急狀態無期限、選舉得延期至多 1 年」，自辯是「仍不是取消選舉」。**那越線了**——延後選舉是最典型的獨裁標記。

**改成：14 日自動失效、延長須 2/3（湊不到）、重新宣告無次數限制。** 效果一樣混亂（救災每兩週歸零、同一場災害重跑數次程序），但**沒有任何一次選舉被延後**。見 [`00`](00-為何這仍然不是獨裁.md) §5、[`07`](07-緊急狀態.md)。

## 為什麼三院會癱瘓：一個繼承上的關鍵

`1-優化/其他三權/總體.md` 有一條**硬性**：「人選不能被杯葛（如：雙重同意），要讓杯葛者付出代價（含：浪費投票權）。」

**那條正是為了防止本夾發生的事——而本夾不繼承 `1-優化`。**

於是憲法法庭 15 席只補到 6 人、已連續多年零判決；監察院提不出彈劾；考試院訂不出錄取方針。**違憲的法律有效、選區重劃無人審查、權限爭議永遠沒有裁判者。**
