# 緊急狀態

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/總體.md` | 硬性 | 緊急狀態是「重大影響政體運作」的憲政選擇舉例之一 |
| `配置/惡搞/總體.md` | **硬性** | **仍為民主和民選國家，不能被認為是獨裁** |
| `配置/惡搞/總體.md` | 非硬性 | 混亂 |

**不繼承** `1-優化` 的防常態化概念（那不在提示詞裡，是正式各夾的自由發揮）。

## 2 這一檔是本夾的界線所在

**緊急狀態是最容易越過「不能被認為是獨裁」那條線的地方。**

草擬階段曾寫「無列舉、無期限、選舉得延期至多 1 年」，自辯是「仍不是取消選舉」。**那是錯的**：延後選舉是最典型的獨裁標記，而它是本夾唯一的硬性條件。

**改掉了。混亂改由別的機制製造。**

## 3 規則（主路徑）

### 3.1 兩條寫死的紅線

1. **緊急狀態不得延後任何選舉、複決或人選更新投票。** 沒有例外，沒有「經議會同意得延期」的但書。
2. **緊急狀態不創設解散權，也不停止彈劾與更新程序。**

### 3.2 宣告與失效

| 項目 | 規則 |
|---|---|
| 宣告 | 總統得**逕行宣告**，無須事前同意 |
| 自動失效 | 宣告後 **14 日**屆滿即失效 |
| 延長 | 須議會 **2/3（≥150）** 追認，每次 14 日 |
| 追認失敗 | 立即終止，已發布之緊急命令同時失效 |
| 重新宣告 | **無次數限制、無冷卻期** |
| 種類 | **無列舉**——總統認定即可宣告 |
| 期限上限 | **無累計上限**（因為每次都會死在第 14 天） |

### 3.3 混亂在哪裡

在「**2/3 追認**」與「**重新宣告無限制**」的組合。

★ 兩黨對立下 150 票湊不到（[`12`](12-預期政治生態.md) §3：兩大黨 105 與 96，從不合作）。所以**每一次緊急狀態都在第 14 天死掉**。

真的有颱風或地震時：

1. 總統宣告，機關依緊急命令徵用、管制、動支。
2. 第 14 天，狀態失效，**所有緊急命令同時失效**——徵用命令沒了、管制解除、預算依據消滅。
3. 總統隔天重新宣告，機關**重跑一次全部程序**。
4. 循環。

**救災變成每兩週一次的憲法儀式。** 沒有人濫權，效率極差。

### 3.4 沒有防常態化條款

正式各夾都有「狀態結束後 24 個月內不得把該狀態的行政權力改為常態權力，違反者該條文無效」——那是它們的自由發揮，**本夾不寫**。

★ 但因為緊急狀態每 14 天就斷一次，**也沒人有機會把它常態化**。本夾的一條爛規則保護了另一條。

### 3.5 停擺期間宣告緊急狀態也沒用

★ 若預算停擺（[`04`](04-預算與財政.md)）期間宣告緊急狀態，緊急命令**不能創設預算依據**——沒有任何條文授權緊急命令動支未經議決的經費，而本夾也沒有預備金的憲法保障。

**停擺與緊急狀態可以同時存在，而且互相加重。**

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 第 14 天議會未表決 | 狀態失效 |
| 追認票 149（差一票） | 失效 |
| 隔日重新宣告 | **合法**，程序全部重跑 |
| 緊急命令已執行之處分 | 命令失效後，該處分之效力由普通法院個案認定（無統一規定） |
| 狀態期間屆期改選 | **照常改選**，不得延期 |
| 狀態期間罷免案成案 | **照常投票**，不得延期 |
| 狀態與預算停擺並存 | 兩者互不影響，緊急命令不得創設預算依據 |
| 總統連續宣告一年 | 合法。共約 26 次 |
