# 秘魯：一院議會制

本憲政設計最新更新：2026-11-10

```
秘魯：0-基本 ＋ 1-優化（秘魯不在 各設計對應.md；依使用者指示，比照「其他」組）
至少做 1 個版本：本夾一院議會制；同國另有 一院總統制。
```

提示詞見本庫政體設計提示詞。**不繼承任何 `2-配置/`**。計劃： §4a。

## 一句話

首長由**全院 160 記名排名投票**選出（≥81，30 日預設）、**建設性更新**（就任 1 年內不得發動）、無解散；**信任供給合一**；直選總統 top-3、削權；國會、政黨、法規、司法、人選更新與總統制夾**共用**（[`../共用/`](../共用/README.md)）。

## 三個最容易讀錯的地方

**一、首長不是最大黨。** 2026 年首長 OBRAS（31 席），最大黨 AN 34；2021 年首長 SP（28），最大黨 AP 32。議員孔多賽選的是居中的黨。

**二、首長比總統制夾的總統穩定。** 2021 年四種選民假設都是 SP、2026 年都是 OBRAS；總統制夾的總統在四人之間換。

**三、撤換權在國會。** 門檻 81，但要同時選出繼任者、就任 1 年後才能發動；仍防不了整個多數換邊（[`12`](12-預期政治生態.md) §4.1）。

## 本夾承認做不到的事

- 防不了國會多數真的換邊。
- 首長的第一偏好小。
- 2026 年省內分布是推估；選後沒有民調。
- **完全不論轉型可行性**。
