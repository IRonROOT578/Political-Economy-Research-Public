# 人選更新

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `配置/南韓/行政立法/共用.md` | **硬性** | **若為總統制**：總統更新應可由人民發動（現行只有彈劾），但仍需有穩定性（如：冷卻期） |
| `1-優化/投票.md` | 可選 | 人民直接投票出的單一席次職位，對現任的更新：發動後採**替代現狀方式**，第一輪只選出 n 名作為備胎（本夾稱**挑戰者**），第二輪的替代方案即這 n 名挑戰者、「維持現狀」即現任 |
| `1-優化/投票.md` | 可選 | 複數席次：發動後選區內全部席次重選，無單獨對任一人罷免 |

未提及而自由發揮：連署門檻、一定票數的百分比、冷卻期長度、n＝2。

本夾**選了總統制**（[`00`](00-讀法與政體選擇.md) §2），該條硬性開火。本夾用預提：更新成功，現任的任期供給案終止，改用勝出挑戰者的案（[`03`](03-行政權預算.md) §3.3、§3.5）。

## 2 硬性怎麼落

### 2.1 人民可發動（相對現行只有彈劾）

南韓現行：總統去職的途徑實質上只有彈劾（國會提出、憲法裁判所審判）——那是法律責任，政治上的「不再支持」沒有出口，只能擠進彈劾程序。本夾：更新的發動與成案**只需人民連署**。議會沒有提議權、同意權、審查權。

彈劾仍在，是另一條路：審計院提案、憲法裁判所審判（[`09`](09-憲法裁判所.md)、[`10`](10-審計院.md)）。

### 2.2 仍有穩定性（如：冷卻期）

| 機制 | 內容 |
|---|---|
| 連署門檻 | 選舉人 10%，180 日內完成 |
| 一定票數 | 挑戰者與現任兩兩對決的支持票須 ≥ 選舉人總額 **25%**，否則先淘汰 |
| 冷卻期 | 失敗後 12 個月；兩名挑戰者對現任的支持票都 < 25% 則 24 個月 |
| 距改選不足 12 個月 | 不辦更新 |

四樣都在人民端，不是誰的許可。

## 3 總統（替代現狀方式）

走 [`06`](06-人民修改法規範.md) §2。n＝2、一定票數＝選舉人總額 25%，理由見該節 §2.3–§2.4。

| 階段 | 規則 |
|---|---|
| 連署 | 選舉人 **10%**。無議會關卡 |
| 第一輪 | **只負責選出 n＝2 名挑戰者**（正副同組）。現任不參加。同票抽籤。挑戰者可與登記一併公告自己的任期供給案（[`03`](03-行政權預算.md) §3.5） |
| 第二輪票面 | 2 名挑戰者為替代方案，現任為維持現狀；6 格完整排序單選 |
| **先淘汰** | 與現任兩兩對決支持票 **< 選舉人 25%** 者出局 |
| **再決選** | 對存活者與現任用孔多賽完成法；循環時 Ranked Pairs，勝方得票 |
| 結果 | 採用某挑戰者：接續原任期剩餘期間。採用維持現狀：現任留任 |

### 3.2 單一席次議員

該區選舉人 10% 連署。程序同總統。一定票數為該區選舉人 25%。替換者任期至本屆屆滿。

### 3.3 複數席次議員

該區選舉人 10% 連署後，該區**全部席次**重選，不得針對個別議員：單獨罷免一人只會讓同名單下一位遞補，什麼也沒改變。

### 3.4 緊急狀態不停止更新

見 [`07`](07-緊急狀態.md)。若緊急狀態能停止更新，總統就取得一個比彈劾更強的自我保護工具——2024 年 12 月的戒嚴布告第 1 條，就是禁止國會與政黨的一切政治活動。

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 連署期間現任辭職 | 改走出缺；副總統繼任。已繳連署作廢 |
| 挑戰者僅 1 組 | n＝1，票面 2 格；仍先淘汰再決選 |
| 挑戰者 0 組 | 不辦第二輪，現任留任，冷卻 12 個月 |
| 第一輪第 2 名同票 | 同票者抽籤，票面恆 6 格 |
| 第二輪循環 | Ranked Pairs，勝方得票（[`06`](06-人民修改法規範.md) §2.5）；公告三場票數與不採認的那一場 |
| 更新與彈劾同時進行 | 並行，任一成立即生效，另一程序終止 |
| 緊急狀態中 | 更新照辦；投票日不得變更 |
