## 六個正式夾的共通決定

| 項目 | 決定 |
|---|---|
| 單一席次選制 | **top-3 孔多賽**（票面 6 個完整排序選項供單選） |
| 複數席次名單型式 | **彈性名單**（Droop 額數 25% 躍升） |
| 每區席次 | **M∈[8,14]**（南韓複數 **[10,14]**），憲法寫區間 |
| 分配法 | 台灣正式三夾：聖拉古、無法定得票門檻、允許聯盟；南韓用黑爾＋最大餘數；中法俄見各夾 |
| 誰表決行政權預算 | **僅單一席次** |
| 信任與供給的提供者 | **相同** |
| 三個議會制夾的供給 | 期限內不通過建設性更新即**自動生效** |
| 總統制夾的供給 | 台灣正式夾**不用預提**；台灣測試夾與俄羅斯**用預提**；南韓**可選不採用** |
| 反杯葛 | 三組選舉權人、**票作廢且不重分配**、缺額不降門檻、逾期由現任續任 |
| 防常態化 | 緊急狀態終止後 **24 個月**，違反者該條文無效 |

## 四條共用結論

正式夾一體適用：

1. **複數席次一律改彈性名單**——開放名單 PR 被硬性點名，不能只是「把 M 壓小」來緩解。
2. **「反 Herding cats」管協調成本，不管席次總額**——它自己點名的荷蘭只有 150 席。
3. **席次總額的判準是「方便治理」，再對外部檢查**（每席人口、立方根比值）。
4. **分清楚哪些條件是提示詞的、哪些是定稿加的**——後者一律標明是自由發揮並自負理由。
