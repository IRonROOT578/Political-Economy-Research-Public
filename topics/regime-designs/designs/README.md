## 中國

[`中國/一院議會制/`](中國/一院議會制/)：450＝單一 260＋複數 190。行政首長兼國家元首；省長亦由建設性更新產生；席次圖以**意識形態光譜**而非黨籍分組。

## 俄羅斯

[`俄羅斯/一院總統制/`](俄羅斯/一院總統制/)：杜馬 **350＝單一 200＋複數 150**；**用預提行政權預算**；無聯邦院；不設次國家政治層級。

## 法國

[`法國/一院議會制/`](法國/一院議會制/)：**400＝單一 230＋複數 170**；建設性更新＋供給自動生效；**無參議院、不設與行政首長分離的國家元首**；其他權為司法權與**審計權**。
