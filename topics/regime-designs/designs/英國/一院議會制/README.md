# 英國：一院議會制

本憲政設計最新更新：2026-11-10

```
英國：0-基本 ＋ 1-優化
至少做 1 個版本。
```

提示詞見本庫政體設計提示詞。**不繼承任何 `2-配置/`**。只用當時民意（2024、2019 大選）。

## 一句話

**廢上議院、寫一部成文憲法的一院議會制**：國會 **400＝單一 240（top-3 孔多賽，取代 FPTP）＋複數 160（彈性名單、15 區、M∈[8,16]）**；首長由全院記名排名投票選出（≥201），國王只公布、換黨魁不換首長；建設性更新、**無解散、固定 5 年**；供給自動生效；組織法與修憲要全院與複數各自 3/5、修憲一律複決；憲法法院 9 人三組；**權力下放入憲**、自決公投有程序；北愛首席部長改排名投票，結束強制共治的停擺。

## 三個最容易讀錯的地方

**一、新制沒有讓工黨變小多少。** 2024 得票下工黨 243／400（61%）：它是大部分選區的孔多賽贏家。新制擋的不是它執政，是它**改規則**（複數 52，要 96）（[`12`](12-預期政治生態.md) §5.1）。

**二、Reform 與 SNP 的單一席次都是 0，自民黨只剩 3。** Reform 不是任何人的第二偏好；SNP 在蘇格蘭被聯合派選民一致排後；自民黨 2024 的選區勝利大量靠工黨選民的戰略投票，校正後多半回到工黨。三黨的代表主要在名單層。

**三、2019 年的保守黨首長很脆弱。** 保守黨 197，差 4 席過半，首長投票對 UUP 200:200 靠平手規則；陣營內校正拉高到 0.75 時首長翻成 UUP（[`14`](14-近期大選重算.md) §5）。
