# 人民修改法規範

有拘束力的公投，採替代現狀方式。

| 項目 | 規則 |
|---|---|
| 方式 | 替代現狀方式：領銜人方案、政府方案、維持現狀，3 方案 6 格單選；先淘汰與「維持現狀」一對一支持票未達地板者，再孔多賽（循環 Ranked Pairs） |
| 地板 | 法律 20%；組織法、修憲 25%（支持票／選舉人總額）；無投票率門檻 |
| 發動 | 選舉人 2%（約 95 萬）；或政府；或全院 ≥201 |
| 排除 | 年度供給、個案人事、赦免 |
| 效力 | 有拘束力；勝出之法律 2 年內國會以 ≥240 才能修改 |

★ 英國的公投（2011 選制、2014 蘇格蘭、2016 脫歐）都是政府決定辦不辦、題目怎麼問、結果算不算。2016 年脫歐公投是二選一、無地板、法律上只是諮詢——**「哪一種脫歐」從未交付投票**。本夾的公投有政府對案、有地板、有拘束力。
