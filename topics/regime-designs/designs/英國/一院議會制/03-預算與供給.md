# 預算與供給

`1-優化/財政.md`（信任供給合一；供給自動生效）。

| 項目 | 規則 |
|---|---|
| 規劃保障的供給 | 政策裁量性資本門、預備金、行政機關經常門、列名政策計畫（封閉列舉） |
| 自動生效 | 送達後 20 個開會日內未通過建設性更新（≥201），供給生效 |
| 國會修正 | **得刪不得增**（延續下議院只能刪不能增的財政慣例，改為憲法規則） |
| 非供給歲出 | ≥201；60 日未決沿用上年度 |
| 歲入、稅制 | ≥201 |
| 財政規則 | 組織法；預算責任辦公室（OBR）入憲，每年公告是否遵守 |
| 審計 | 國家審計署（NAO）的審計長由三組選出 |

★ 英國的預算很少卡住（政府在下議院有多數）；本夾的自動生效是為了**少數政府**——新選制下多黨國會的機率比 FPTP 高。
