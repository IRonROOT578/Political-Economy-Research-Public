# 人民修改法規範

有拘束力的公投，採**替代現狀方式**：先淘汰與「維持現狀」一對一時支持票未達地板的方案，剩下的方案與「維持現狀」再用孔多賽完成法（循環時 Ranked Pairs）決定。地板放在投票系統之前，一個民意不足的方案只淘汰自己。

| 項目 | 規則 |
|---|---|
| 方式 | 替代現狀方式：領銜人方案、政府方案、維持現狀，3 方案 6 格單選 |
| 地板 | 法律、乙類組織法 20%；甲類組織法、修憲 25%（支持票／選舉人總額） |
| 發動 | 選舉人 2%（約 75 萬）；或政府；或全院 ≥176 |
| 排除 | 年度供給、個案人事、赦免 |
| 效力 | **有拘束力**；勝出之法律 2 年內議會以 ≥210 且複數 ≥84 才能修改 |

★ 現行第 92 條的公投只有諮詢性，人民創制（50 萬連署）只能把法案送進議會，且不得涉及組織法、稅與赦免。本夾讓人民可以直接通過法規範。
