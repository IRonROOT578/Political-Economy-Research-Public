# 完善與自洽

## 1 條件的落點

| 條件 | 位階 | 落點 |
|---|---|---|
| 不用電子計票 | **硬性** | 紙本、投開票所內人工計票 |
| 首長由某些議員選出與更新 | **硬性** | 全院 450（[`02`](02-政府組成與建設性更新.md)） |
| SNTV、開放名單黑金 | **硬性** | 彈性名單；市議會同改（[`01`](01-國會與選制.md)、[`08`](08-緊急狀態、地方與民選官員.md)） |
| 法官不當記名投票的投票權人 | **硬性** | 丙組名冊與法官委員會丙組為祕密投票（[`07`](07-司法權與選舉機關.md)） |
| 人選不能被杯葛 | **硬性** | 定日選舉、缺席票作廢、無出席門檻、30 日預設值 |
| 不得把提示詞當預期生態 | **硬性** | [`12`](12-預期政治生態.md) §5 |
| 不考慮政治推行可行性 | 要求 | 2017 年公投結果不計入政體選擇（[`00`](00-讀法與政體選擇.md) §3） |
| 建設性更新、供給自動生效 | 非硬性 | [`02`](02-政府組成與建設性更新.md)、[`03`](03-預算與供給.md) |
| 修憲兩軌 | 可選 | [`05`](05-憲法與修憲.md) |
| 替代現狀方式 | 可選 | [`06`](06-人民修改法規範.md)、[`09`](09-人選更新.md) |

## 2 張力

| # | 張力 | 處置 |
|:--:|---|---|
| 1 | 中位黨被放大（İYİ、MHP） | 改規則要兩種多數；名單層接近得票 |
| 2 | 選舉人平等 vs 每省一席 | 平等優先，可跨省界（[`01`](01-國會與選制.md) §2） |
| 3 | 誰當總理對「陣營軸」假設敏感 | 敏感度列出；2023 年**組閣陣營在各偏好假設下不變**（AKP 得票 −3 點時首長變 İYİ）（[`12`](12-預期政治生態.md) §6） |
| 4 | 民選官員保護 vs 涉案官員繼續任職 | 法院可停職，但不得官派 |
| 5 | 解散只限武裝暴力 vs 第 68 條的國家完整條款 | 綱領與言論交給選舉；第 1–3 條本身不動 |

## 3 本夾不宣稱能做到的事

- 不宣稱兩大陣營會消失：組閣陣營在每個假設下都是人民聯盟兩黨。
- 不宣稱 İYİ 或 MHP 的放大會長期存在：它取決於它們能否進入前三名。
- 2025 年以後的政局（伊斯坦堡市長案、修憲與提前改選的討論、PKK 解除武裝）不在重算內。
- 完全不論轉型可行性。
