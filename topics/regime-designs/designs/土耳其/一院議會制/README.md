# 土耳其：一院議會制

本憲政設計最新更新：2026-11-10

```
土耳其：0-基本 ＋ 1-優化
至少做 1 個版本。
```

提示詞見本庫政體設計提示詞。**不繼承任何 `2-配置/`**。只用當時民意（2023、2018 大選；2024 地方選舉代理）。

## 一句話

**從總統制換成一院議會制**：大國民議會 **450＝單一 270（top-3 孔多賽、±10%、可跨省界）＋複數 180（彈性名單、16 區、無法定門檻）**；總理由全院記名排名投票選出（≥226）、30 日預設值；建設性更新、**無解散、固定 5 年**；**廢總統令**；供給自動生效；象徵性總統由議會選出、無出席門檻；組織法與修憲要全院與複數各自 3/5、選制骨架延後一屆生效；憲法法院、法官委員會、選舉委員會都改三組、各組至少一人同意；**選舉機關的決定可上訴、只能局部重辦**；政黨解散只限武裝暴力；民選首長只能由法院、定罪才解職、不得官派。

## 三個最容易讀錯的地方

**一、2023 年的總理是 MHP，但政府還是人民聯盟。** MHP 9.9%，全院 58 席；CHP 與 İYİ 的議員把它排在 AKP 前（[`12`](12-預期政治生態.md) §3）。組閣陣營 MHP＋AKP 230 在每個假設下都不變，變的只是總理是哪一黨（§6）。

**二、İYİ 9.8% 拿到 58 個單一席次。** 它是 AKP 與 CHP 選民共同的第二偏好；和日本國民民主、荷蘭 CDA 同型（§5.1）。

**三、2017 年公投選了總統制，本夾不計入。** 依「不考慮政治推行可行性」（[`00`](00-讀法與政體選擇.md) §3）。本夾也不是回到 2017 年以前：10% 門檻、367 出席門檻、倒閣不必有繼任者都拿掉了。
