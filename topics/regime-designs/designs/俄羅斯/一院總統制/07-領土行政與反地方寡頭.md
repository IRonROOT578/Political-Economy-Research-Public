## 2 規則（主路徑）

### 2.1 要反的是什麼

「地方寡頭」在本夾指一個具體結構：**政治機器、資源租金、執法力量集中在同一人（或同一家族）手上，並且他能把這個地方權力轉換成全國層次的否決權。**

歷史上的轉換通道有四條：地方首長依職權進入全國立法機關；地方與中央個別議定財政待遇；資源租金留在地方；地方自有的武裝或執法力量。

前一種設計思路是逐條封鎖這四條通道。那是**先承認有一個值得奪取的位子，再繞著它設防**。

本夾改為**拿掉那個位子**。

### 2.2 沒有次國家政治層級

**不設區域議會、不設區域首長、不設區域自有財源。**

沒有區域選舉，就沒有值得買的區域選舉；沒有區域財源，就沒有可攫取的區域租金；沒有區域執法力量，就沒有可私有化的強制力。三者皆無，區域寡頭在結構上無從生成。

### 2.3 行政區：派出，不是自治

國土劃為約 **20 個行政區**，人口約 300 萬至 1000 萬，界線依人口與交通軸線劃定，設置與界線屬基本法事項（見 [`05`](05-法律基本法與修憲.md)）。

| 項 | 規則 |
|---|---|
| 性質 | **中央部會系統的派出機關**，執行國家法律 |
| 首長 | **文官**，非政治職位。由總統依文官法任免，任期不與選舉週期綁定 |
| 立法權 | **無** |
| 自有稅收 | **無**。人事與運作費列在中央行政經常門（見 [`04`](04-其餘預算與國家財政.md)） |
| 警察 | **無**。警政為全國性，直屬中央，不受行政區首長指揮 |
| 議會 | **無** |

行政區首長不得兼任杜馬議員；欲參選者須先辭職（見 [`01`](01-國家杜馬與選制.md)）。

### 2.4 市鎮：唯一的民選自治層級

市鎮（城市、鎮、鄉）設**民選議會與民選首長**。

**權限（基本法封閉列舉）**：地方公共服務、公用事業、地方道路、國家框架內的土地使用許可、學校與診所的營運（不含課綱與醫療給付標準）、地方文化設施。

**明文不得為之**：設置任何武裝或執法單位；課徵列舉以外的稅；舉借外幣債務；以未來資源收入為擔保發債；與中央締結變更其財政地位之個別協定。

**財源**：地方財產稅與規費（稅率上限由基本法定）＋依基本法公式的移轉（見 [`04`](04-其餘預算與國家財政.md)）。

**更新**：市鎮首長與議員適用 [`12`](12-人選更新.md) 的人民更新規則。**中央不得解職市鎮民選職務**——只能由該市鎮的選民更新，或由法院判決解職。

#### 為什麼留這一層

市鎮不是寡頭的棲地：它太小，成不了全國性的否決者；租金與執法都不在這一層；而它管的事（垃圾、道路、供水、許可、學校營運）是人民真的會碰到的。

「中央不得解職」這一條看起來與集權矛盾，其實不然：一個可以被中央撤換的地方首長不會變成獨立寡頭，但會變成**中央的地方代辦**——那沒有解決問題，只是換了主人。本夾要的是市鎮首長對他的選民負責。

### 2.5 地方代表性在哪裡

在 **200 個全國單一選區**裡（見 [`01`](01-國家杜馬與選制.md)）。

單一席次議員有明確的領土問責對象，而且他們是本夾裡權力很集中的一群人——行政權預算的雙鑰匙之一（[`03`](03-行政權預算.md)）、憲法法庭甲組的選舉權人（[`10`](10-憲法法庭與司法.md)）。

差別在於：**地方在國家議會裡面有聲音，但沒有一個獨立於國家議會的層級可以否決國家政策。**

### 2.6 民族權利：非領土的文化自治

不設民族共和國、不設民族自治區、不設民族保障席。

改設**文化自治團體**：

| 項 | 規則 |
|---|---|
| 成立 | 任何民族或語言群體得依基本法登記設立全國性文化自治團體 |
| 成員 | **個人自願登記**，不依居住地，不依血統推定 |
| 權限 | 母語教育之課程與師資、文化機構、傳統習俗事務、該語言之公共標示申請 |
| 財源 | 依登記人數的公式撥款，公式屬基本法 |
| 不得為之 | 行使任何領土管轄權、設置執法單位、限制非成員之權利 |

語言權利：俄語為國家官方語言；**個人有權以其登記之文化自治團體語言與行政機關往來**，行政機關應提供翻譯——這是個人權利，不是某塊土地的地位。

#### 這是一個有代價的選擇

民族聯邦制與領土制的取捨是聯邦主義文獻的老題目。本夾選領土制，理由是治理面的：**把身分與土地統治權綁在一起，會讓身分動員與地方機器互相供養**——機器用身分動員鞏固地盤，身分訴求用機器換取資源，兩者都因此更難挑戰。

代價是真的：少數民族的權利從「一塊地的統治權」降成「個人與團體的權利」。這一項寫進 [`17`](17-完善與自洽.md) 的張力清單，不迴避。

### 2.7 邊界與爭議

- 行政區界線之變更以基本法為之，無須任何地方同意（它是派出單位，不是主體）。
- **市鎮之設立、合併、廢止或界線變更，須經該市鎮選民複決同意。**
- 市鎮與中央之權限爭議由憲法法庭裁判；市鎮有獨立聲請權（見 [`09`](09-中央內水平分權.md)）。

市鎮有聲請權而行政區沒有，是因為前者是自治體、後者是中央自己的手腳。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 行政區首長違法 | 依文官法懲處、免職；不經任何地方程序 |
| 市鎮首長違法 | 只能由該市鎮選民更新（[`12`](12-人選更新.md)）或法院判決解職。中央不得停職 |
| 市鎮拒絕執行國家法律 | 中央得由行政區代行並向該市鎮求償；不得因此解散市鎮議會 |
| 市鎮財政失衡 | 依基本法公式的補助程序處理；不得以個別協定解決 |
| 某市鎮人口銳減至無法維持自治 | 得由中央提案合併，仍須該市鎮選民複決 |
| 文化自治團體登記人數不足門檻 | 依基本法所定最低人數處理；未達者得與他團體聯合登記 |
| 文化自治團體主張某地區之管轄權 | 該主張無效；團體不具領土權能 |
| 二以上文化自治團體就同一語言競爭 | 由登記人數較多者行使公款支持之權限，另一團體仍得自費運作 |
| 行政區首長參選杜馬未辭職 | 登記無效（[`01`](01-國家杜馬與選制.md)） |
