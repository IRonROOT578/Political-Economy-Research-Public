## 2 規則（主路徑）

### 選出

正副總統**同組**登記。人民 **top-3 孔多賽**：第一輪全國單記，取得票前 3 組；第二輪對這 3 組採孔多賽完成法，票面為 6 個完整排序選項單選一個。

**沒有選舉人團、沒有地區加權、沒有各地區門檻。全國一票一值。**

與杜馬第二輪、複數席次同日（見 [`01`](01-國家杜馬與選制.md)）。

### 任期

**6 年，連任一次，合計上限兩任。**

附一條反自我交易規則：

> 修改總統任期長度或連任次數上限之憲法修正，**不適用於提出時之現任總統及副總統**；最早自下一任起適用。

目的很直接：**讓延任永遠不可能是現任者自己的收益。** 想改任期規則可以，改完的人享受不到。沒有這條，任期限制就只是一次修憲的距離；有這條，修憲的動機必須是制度性的，不能是個人性的。

這是配置要的「自身底氣」裡最實在的一塊——尤其在一個明說不在意偏向一黨制的設計裡，它是「一黨獨大可以，一黨不受規則拘束不行」的第一條（見 [`14`](14-正當化.md)）。

### 職權

- 行政首長，任免政府成員，指揮全國行政機關與派出的行政區（見 [`07`](07-領土行政與反地方寡頭.md)）。
- 決定並執行外交、國防、安全政策。
- 公布法律；對法律有一次退回覆議權。
- 依 [`08`](08-緊急狀態.md) 宣告緊急狀態。
- 統帥武裝力量。**宣戰須杜馬 ≥200（2/3）同意**，總統不得單獨為之。

### 不設總理

政府首長就是總統本人。**不設一個對議會負責、又由總統指定的中間人。**

`1-優化/財政.md` 已寫明那是政體錯配：建設性不信任案不適用於「總統決定總理」的情況，於是只有供給保障沒有信任保障。政府成員對總統負責；杜馬得質詢、調查、彈劾，但不得以不信任案撤換部長。

### 與杜馬的關係

| 項 | 規則 |
|---|---|
| 杜馬能否因政策撤換總統 | 否 |
| 總統能否解散杜馬 | **否** |
| 法律覆議 | 總統得退回一次，杜馬以 ≥151 維持則原案成立 |
| 基本法 | 總統**不得**覆議 |
| 彈劾 | 杜馬 ≥180 提案，憲法法庭審理，見 [`10`](10-憲法法庭與司法.md) |
| 政治責任 | 走 [`12`](12-人選更新.md) 的人民更新，不走議會 |
| 行政權預算 | 由人民在選舉時授權，見 [`03`](03-行政權預算.md) |

### 為什麼沒有解散權

威瑪的失敗機制不在於總統直選，而在於**第 25 條的解散權與第 48 條的緊急命令權互相解鎖**：議會要廢止緊急命令，總統就解散議會；重選期間再發同一道命令。

拿掉解散權，杜馬對緊急命令的廢止權（[`08`](08-緊急狀態.md)）才是真的。這一條同時服務 Herding cats——沒有解散就沒有隨時可能被重設的政治局面，任期是確定的。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 總統缺位 | 副總統繼任至原任期屆滿，**不補選**。繼任者的任期計入其連任次數 |
| 副總統缺位 | 總統提名、杜馬 ≥151 同意。杜馬 **60 日內未表決視為同意**——避免用懸缺癱瘓繼任順序 |
| 正副同時缺位 | 憲法法庭庭長代行職權，90 日內辦理補選。代行者不得宣告緊急狀態、不得任免政府成員 |
| 總統永久不能視事 | 由憲法法庭以 ≥9／12 認定，副總統繼任。認定程序不得由總統本人啟動或阻止 |
| 覆議期間屆期改選 | 覆議案由新屆杜馬表決，門檻不變 |
| 當選組於就任前解散（一人死亡或喪失資格） | 另一人單獨就任，缺位者依上列規則補 |
| 更新成功 | 見 [`12`](12-人選更新.md)。新總統接續**原任期之剩餘期間**，不重新起算 |
