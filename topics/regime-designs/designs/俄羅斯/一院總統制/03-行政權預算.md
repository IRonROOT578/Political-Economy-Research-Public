# 行政權預算（預提）

## 1 本檔繼承

`1-優化/財政.md` 可選條件「信任供給合一－總統制」的全部，位階為**可選（不採用不扣分）**，本夾**採用**。

| 提示詞 | 本檔落點 |
|---|---|
| **立法權就管好自己的立法，行政權就管好自己的行政（含：部分行政權預算）** | §2 開頭的框架；並為「議會不能獨自修改」提供理由 |
| 總統需要信任（人民的選舉罷免）和供給（人民授權部分行政權預算），否則總統就是空殼 | §2.1 |
| 候選人得提出與其綁定的行政權預算，**並要在投票前**向人民公告一段時間 | §2.3 |

| **總統更新時：備胎可提出自己的行政權預算** | §2.7 |

| 正副候選人組一起選者，人民投票即授權他們任期的該預算 | §2.3 |
| 子項 1：能否支撐任期內一定的保障（有無能提的項目） | §2.2 |

| 子項 3：給形式——硬性要求、**金額上限（有爭議）**、格式、對選民呈現方式；增加透明度**和可實踐性** | §2.6；金額上限的處理見 §2.6.0 |
| 子項 4：給範例 | 本夾不另出範例檔；範例在測試夾 `預提範例.md` |

## 2 規則（主路徑）

### 2.1 框架

> 立法權就管好自己的立法，行政權就管好自己的行政（含：**部分**供給）。

供給不是議會施捨給行政的東西。它本來就是行政那一份的一部分，只是**授權者從議員換成人民**。

由此推出三件事，本檔其餘各節都是它們的展開：

1. 授權在選舉時發生，不是每年重新發生（§2.3）。
2. 議會不能獨自修改人民授給行政的那一份（§2.5）——那不是保護總統，是分權。
3. 「**部分**」是限制。預提只能覆蓋供給的一部分，不能全部（§2.2）。

### 2.2 範圍（封閉列舉）

任期供給案只能包含：

1. 政策裁量性資本門支出。
2. 預備金與政務應變預算。
3. 行政機關經常門運作費用。
4. **列名**政策計畫的經常門支出。

**不含**：法定義務支出、歲入、稅制、非行政部門預算、對市鎮之財政移轉公式。

法定義務支出（已立法之給付、債務還本付息、確定判決）**始終撥付**，不需年度議決，也不在預提案內。

移轉公式排除的理由要單獨說：能用任期供給案綁定對地方的移轉，等於以中央寡頭取代地方寡頭。它屬基本法（見 [`04`](04-其餘預算與國家財政.md)）。

**範圍就是「部分」的落實方式。** 每一項的納入或排除都說得出理由，這比一個憑空的百分比可靠。

### 2.3 誰授權、何時授權

**人民。**

- 正副總統候選人同組登記時，得一併提出與其綁定的行政權預算案（下稱「任期供給案」）。
- 提出為**非強制**。不提也可以登記參選。
- **須於第一輪投票日前 21 日公告全文**——「在投票前公告一段時間」是要件，不是時程建議。逾期公告者，該案不生授權效力，視為未提出。
- 人民選出該組，即為對該案的授權。

### 2.4 生效與終止

自就任日生效，至任期屆滿為止。

終止事由：該組去職（更新成功、彈劾成立、辭職、死亡）。副總統繼任者**承接原案**——繼任不是換人授權，人民當初授權的是這一組。

### 2.5 任內調整（雙鑰匙）

生效後的調整，須**總統與單一席次議員同時同意**（單一席次 **≥91／180**）。

杜馬**不能**獨自修改人民授權的部分；總統也不能。兩把鑰匙缺一不可。

為什麼是單一席次而非全院：`1-優化/財政.md` 可選「僅單一席次而非複數席次議員表決預算」。180 人比 300 人容易達成共識，而單一席次議員有明確的領土問責對象，比名單議員更適合對錢負責。

### 2.6 形式

#### 2.6.0 先講金額上限：**不設**

提示詞把金額上限標為**（有爭議）**。本夾不設百分比天花板，理由三項：

1. §2.1 那句話本身就是反對它的論據——供給既然是行政那一份、授權者是人民，憲法寫一個百分比等於**用固定數字取代人民在選舉時的判斷**。
2. 提示詞自己給了自我節制機制：「預提越大對候選人日後施政有利，**但可能不利選舉**」。天花板是在替選民做他們本來就會做的取捨。
3. 百分比訂多少**沒有非任意的答案**，而它會被寫進憲法。

限制改由 §2.2 的範圍封閉列舉與下面三個硬預設承擔。

#### 2.6.1 硬性要求

| 要求 | 違反的後果（自動發生，不需誰去查） |
|---|---|
| 逐項列明 | **未列即未授權**——未逐項列明者不在授權範圍，回到年度議決 |
| 歲入假設須明列 | **歲入假設不構成授權**。授權的是支出上限，不是「保證有這麼多錢」 |
| 須附減列順序表 | **未填者，由憲法逕行按比例齊頭削減** |
| 不得以散文說明替代科目表 | 該部分視為未列明，適用第一列 |
| 必填欄不得留白 | 留白視為該欄為零，**不得事後補充** |

第三列是「可實踐性」的硬答案：**不寫怎麼砍，憲法替你砍。** 它不是要求候選人寫，是他不寫就吃到一個他不會喜歡的預設。

第一列是「部分」不被吃成「全部」的保險：沒有它，一句概括條款就能把整個裁量支出包進去。

#### 2.6.2 格式

選務機關制訂**空白表**，候選人填入。必含欄位：

- 分年上限（任期六年各一欄）。
- 科目層級至「政策計畫」。
- 假設之匯率與主要價格參數。
- 減列順序表（歲入不足時各科目的削減次序與比例）。
- **與上一完整會計年度中央政府總歲出決算實支的倍數對照**。
- 與上一任期實際支出的對照欄。

倍數對照欄取代了金額上限的功能：它讓**選民看得到規模**，而不是由憲法替他判斷規模。

#### 2.6.3 對選民呈現方式

- 全文公告於選務機關網站、**各投開票所公告欄**、選舉公報。
- 摘要表（分年上限＋倍數對照）隨選舉公報送達每一戶。
- 更新投票時，各組的摘要表**並列**於同一頁（見 §2.7）。

#### 2.6.4 形式審查

由選務機關為之，**只審欄位齊全、加總正確、格式合規，不審政策內容**。

> **形式瑕疵不得作為排除候選人或該組登記的理由。**

這一條要明文寫死。一個能因為表格問題把人擋在選舉外的審查，會立刻變成排除對手的工具，那會直接毀掉 [`14`](14-正當化.md) 底氣那一半。算錯了就公告標示、依 §2.6.1 的預設處理，讓選民看見他算錯了。

### 2.7 更新時的備胎預提案

`1-優化/財政.md`：「總統更新時：備胎可提出自己的行政權預算。」

這一條把人選更新從「要不要換掉這個人」變成「**要不要換成這個人和他的那份預算**」。第二輪的孔多賽因此是在數個完整的「人＋預算」包裹之間排序。

| 項 | 規則 |
|---|---|
| 提出 | 備胎得於更新投票前提出自己的任期供給案；**非強制** |
| 公告與格式 | **與大選完全相同**（§2.3、§2.6）。否則會出現「大選要照格式、補位不用」的漏洞 |
| 勝出者的案 | 自就任日生效，至**原任期屆滿**為止，不重新起算 |
| 勝出者未提 | 未覆蓋部分走年度議決（§2.9） |
| 現任留任 | **原案繼續有效，不因更新程序被發動而中斷** |
| 是否影響替換條件 | **否。** 預算不列入替換門檻的計算，避免出現「提大案就比較容易罷免現任」的扭曲 |

程序細節見 [`12`](12-人選更新.md)。

### 2.8 提大案還是小案

提示詞已指出這個張力：提得越大越利日後施政，但可能不利選舉。

本夾不介入這個取捨，只讓它**發生在選民面前**：倍數對照欄使「這個人打算鎖住多少」是一個選民看得懂的數字。現任者傾向提大案證明執行力，挑戰者傾向提小案攻擊對手「先把六年綁死」——這個攻防本身就是課責。

### 2.9 未覆蓋的部分

預提案未涵蓋的行政歲出，仍走年度議決：

- 單一席次 **≥91**。
- **得刪不得增**，不得把整案凍結為零。
- 附條件通過視為未通過。
- 會計年度開始後 **60 日**未作成議決者，沿用上一年度已議決額度。

沿用條款來自 `配置/雜項/財政.md`（本夾未繼承），採用理由自負：**停擺是本夾要拿來攻擊美國的東西（[`14`](14-正當化.md)），自己不能有。**

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 候選人未提任期供給案 | 全部行政歲出走 §2.9 年度議決 |
| 公告逾期（不足 21 日） | 該案視為未提出，不生授權效力；不影響其候選資格 |
| 加總錯誤或逾格式 | 公告標示，依 §2.6.1 各列的預設處理；**不影響候選資格** |
| 歲入低於案內假設 | 法定義務優先撥付；案內裁量依減列順序表削減；未填順序表者按比例齊頭削減 |
| 歲入高於假設 | 不自動增加授權。多出部分屬年度議決範圍 |
| 總統與單一席次對調整案僵持 | 維持原案。無仲裁、無自動生效——雙鑰匙的預設是不動 |
| 雙鑰匙的範圍爭議（某項是否在預提內） | 屬權限爭議，由憲法法庭裁判，見 [`10`](10-憲法法庭與司法.md) |
| 總統去職而副總統繼任 | 原案繼續，不重新授權 |
| 更新成功，新任者未提案 | 舊案於交接日終止；未覆蓋部分走 §2.9 |
| 緊急狀態期間 | 預備金與政務應變得先行動支，30 日內補送單一席次備查；不改變授權上限 |
| 案內某科目之法律依據嗣後被宣告違憲 | 該科目授權失效，餘額繳庫，不移用 |
