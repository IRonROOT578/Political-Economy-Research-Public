## 2 規則（主路徑）

### 2.1 非行政部門的預算

杜馬、憲法法庭、普通法院系統、審計院、選務機關、獨立劃分委員會的歲出：

1. 各該機關**自行編列**歲出上限。
2. **總統不得刪減**這些科目，只能轉送。
3. 全院 **≥151** 議決，**得刪不得增**。
4. 會計年度開始前未議決者，**沿用上一年度已議決額度**。

第 2 點是本夾對權限爭議最實際的防線：一個能刪憲法法庭預算的行政首長，不需要違憲就能讓法庭停轉。

第 4 點的採用理由：停擺是本夾要拿來攻擊美國的東西（[`14`](14-正當化.md)），自己不能有。這與「行政權管好自己的行政」並不衝突——沿用條款保護的是**其他權**不被行政或立法餓死。

杜馬的預算由杜馬自己批准。形式上是自己審自己，但讓行政或司法批准立法權的預算，等於給它們一根對立法權的常設槓桿。**冗餘比癱瘓好。**

### 2.2 稅制與歲入

稅目與稅率以**法律**定之（全院 ≥151），不適用 [`03`](03-行政權預算.md) 的任期供給授權。

`1-優化/財政.md` 的規劃保障供給明文不含歲入與稅制。界線因此很清楚：**行政可以在人民授權的範圍內花已授權的錢，不能在同一個機制下決定人民繳多少稅。**

**主要稅目全部屬國家層級**：所得稅、增值稅、礦產資源開採稅、關稅、企業所得稅。沒有次國家單位得設立競合稅目（見 [`07`](07-領土行政與反地方寡頭.md)）。

礦產租金與關稅直接入國庫，這是反地方寡頭的財政面：租金留在地方，就會養出一台獨立於中央的政治機器。本夾把它寫進憲法而不是留給法律。

### 2.3 對市鎮的財政移轉

市鎮是唯一的民選自治層級（見 [`07`](07-領土行政與反地方寡頭.md)）。其財源為：

1. 地方財產稅與規費（稅率上限由基本法定）。
2. **依基本法所定公式**自國庫移轉。

公式須**普遍適用**。憲法明文：

> 國家與個別市鎮之間，不得締結變更其財政地位之個別協定。

移轉公式屬基本法事項（≥180 且跨屆，見 [`05`](05-法律基本法與修憲.md)），且**明文排除在任期供給案之外**（見 [`03`](03-行政權預算.md) §2.2）。

既然拿掉了地方在中央的否決權，就必須用一條難改的普遍公式取代它，否則地方的財政地位會變成每年談判的對象——而談判桌正是機器生長的地方。

市鎮**不得舉借外幣債務**，不得以未來資源收入為擔保發債。

### 2.4 行政區的經費

行政區是派出機關，無自有財源、無自有預算（見 [`07`](07-領土行政與反地方寡頭.md)）。其人事與運作費用列在中央各部會的行政經常門內，屬 [`03`](03-行政權預算.md) 的範圍。

### 2.5 決算與餘額

- 未執行的預算餘額應**繳庫**，不得留用、不得移作他項。
- 決算由審計院查核，見 [`11`](11-審計院.md)。
- 任期供給案的執行情形，審計院每年公布**授權額／實際支出／差異理由**對照表，直接送杜馬與公眾，不經總統核閱。

最後一項是本夾財政設計的關鍵補償。預提把年度課責的一部分拿走了，換回來的是：課責從「今年給不給錢」變成「當初公告的承諾與實際做的差多少」。後者一次涵蓋整個任期，而且**無法在事後改寫**——當初的案子早就印在選舉公報上。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 某機關編列的歲出上限被杜馬刪至無法運作 | 該機關得聲請憲法法庭認定；認定成立者恢復至上一年度額度 |
| 總統刪減非行政部門科目後轉送 | 刪減無效，以原編列數送杜馬 |
| 會計年度開始前未議決 | 全部沿用上年度已議決額度，不歸零 |
| 移轉公式修正案未跨屆確認 | 不生效，續用原公式 |
| 個別市鎮主張其財政地位應調整 | 只能主張公式適用錯誤，由憲法法庭裁判；不得請求個別協定 |
| 市鎮違法舉借外幣債務 | 該債務對國庫不生效力；市鎮首長之責任依法律 |
| 餘額未繳庫 | 審計院逕行認定該支出無法證明合法性並公告，見 [`11`](11-審計院.md) |
| 稅法與任期供給案的假設不一致 | 以稅法為準；供給案的歲入假設本就不構成授權 |
