## 2 規則（主路徑）

### 2.1 更新 ≠ 出缺

死亡、辭職、屆滿、永久不能視事、彈劾解職，走補選／遞補／繼任（§2.7），**不是本檔的更新**。

更新走「備胎＋現任孔多賽」或「整區重選」。

### 2.2 為什麼不是「同意／不同意」的罷免

同意／不同意只問「要不要拿掉這個人」，不問「換成誰」。它的結構性問題與威瑪的消極多數相同：反對現任的人可以是一群彼此毫無共識的人，他們能拆掉現任，卻產生不出任何替代者，結果是空缺、補選、再一次動員。

「備胎＋現任孔多賽」把兩個問題合成一個：**你要不要換成這個具體的人。** 反對者必須先在自己內部選出一個共同的替代者，才能挑戰成功。

這正是配置硬性「**反為反而反**」在人事程序上的落點。

### 2.3 總統

k＝3，故第二輪是 **2 名備胎＋現任**共 3 人，票面仍是 6 個完整排序選項單選。

| 階段 | 規則 |
|---|---|
| 連署 | 選舉人總額 **10%**，180 日內完成。**無任何議會關卡** |
| 第一輪 | 全國單記，選出得票前 **2** 名挑戰者。現任不參加第一輪 |
| 第二輪 | 對「2 名挑戰者＋現任」採孔多賽完成法，6 格單選 |
| 替換條件 | 挑戰者須為孔多賽贏家，**且**在與現任的兩兩對決中得有效票過半，**且**該對決之支持票數 **≥ 選舉人總額 25%** |
| 未達 | 現任留任 |
| 冷卻 | 失敗後 **12 個月**內不得再對同一職位發動。看的是挑戰者對現任的**兩兩支持票**（不是第一輪單記、也不是第二輪首選）。兩名挑戰者裡這筆票較高的那一名若仍 < 選舉人 25%，改為 **24 個月**。從第二輪投票日起算。失敗幾次都一樣，沒有次數上限 |
| 任期 | 替換成功者接續**原任期之剩餘期間**，不重新起算 |

25% 的地板是防投票率過低：沒有它，一場 30% 投票率的更新投票（兩兩過半 ≈ 選舉人 15%）就能換掉全國選出的總統。否決 40%：那會讓更新實質走不到。

「接續原任期」是防止把更新程序當成延長任期的工具。

### 2.4 備胎的行政權預算

`1-優化/財政.md`：「總統更新時：備胎可提出自己的行政權預算。」

這一條把更新從「要不要換掉這個人」變成「**要不要換成這個人和他的那份預算**」。第二輪的孔多賽因此是在數個完整的「人＋預算」包裹之間排序。

| 項 | 規則 |
|---|---|
| 提出 | 備胎得提出自己的任期供給案；**非強制** |
| 公告與格式 | **與大選完全相同**（[`03`](03-行政權預算.md) §2.3、§2.6）。否則會出現「大選要照格式、補位不用」的漏洞 |
| 呈現 | 各組的摘要表（分年上限＋倍數對照）**並列於選舉公報同一頁**，使排序是對包裹的排序 |
| 勝出者的案 | 自就任日生效至**原任期屆滿**，不重新起算 |
| 勝出者未提 | 未覆蓋部分走年度議決（[`03`](03-行政權預算.md) §2.9） |
| 現任留任 | **原案繼續有效**，不因更新程序被發動而中斷 |
| 是否影響替換條件 | **否。** 預算不列入 §2.3 的替換門檻計算 |

最後一列要單獨講：**如果預算能影響替換門檻，就會出現「提大案比較容易罷免現任」或反過來的扭曲。** 門檻只衡量人的對決，預算只影響選民排序時的判斷。

### 2.5 單一席次議員

該選區選舉人 **10%** 連署。程序同總統（2 名備胎＋現任孔多賽）。地板為**該區選舉人 25%**。冷卻同總統。

替換者任期至本屆屆滿。

### 2.6 複數席次議員

該選區選舉人 **10%** 連署後，該區**全部席次**依定期選舉規則重選，**不得針對名單上的個別議員**。

理由：複數席次議員是名單與選區的產物，單獨罷免一人只會讓同一份名單的下一位遞補，什麼也沒改變，卻給了對手一個便宜的騷擾工具。整區重選則是真的把選擇交還選民。

重選產生的議員任期至本屆屆滿（不重新起算 5 年）。該區冷卻 12 個月。

### 2.7 市鎮民選職務

市鎮首長與議員適用同一套規則：該市鎮選舉人 10% 連署、2 備胎＋現任孔多賽、地板為該市鎮選舉人 25%。

**中央不得以任何其他方式解職市鎮民選職務**（[`07`](07-領土行政與反地方寡頭.md)）。

### 2.8 出缺（不是更新）

- 單一席次：90 日內補選；剩餘任期不足 1 年不補。空席期間分母仍 180。
- 複數席次：同區同聯盟名單未當選者依個人票遞補；名單用盡則空席，分母仍 120。
- 總統：副總統繼任至原任期屆滿，**不補選**（[`02`](02-總統與行政.md)）。
- 憲法法庭、審計院：見各該檔，**不走人民更新**。

### 2.9 緊急狀態不停止更新

見 [`08`](08-緊急狀態.md)。已成案的更新投票不因緊急狀態延期；投票地點得變更，投票日不得變更。

**宣告緊急狀態的人不因此獲得保護**——這是本夾在一個明說不在意集權的配置下，仍能說「隨時可被人民挑戰」的依據（[`14`](14-正當化.md)）。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 連署期間現任辭職 | 改走出缺。已繳連署作廢，不轉成更新 |
| 第一輪後現任死亡 | 改走出缺。第二輪不辦。備胎已提之預提案失效 |
| 挑戰者僅 1 人 | 第二輪為 1 備胎＋現任，票面改 2!＝2 格，仍人工計票 |
| 挑戰者 0 人 | 不辦第二輪，現任留任，冷卻 12 個月 |
| 第一輪第 2 名同票 | 併列進第二輪，票面改 4!＝24 格 |
| 備胎預提案公告逾期 | 該案不生授權效力，視為未提；**不影響其備胎資格** |
| 備胎預提案加總錯誤 | 公告標示，依 [`03`](03-行政權預算.md) §2.6.1 的預設處理；不影響資格 |
| 孔多賽贏家不是對現任兩兩支持票最高者 | 替換條件仍只看贏家對現任的兩兩對決（與 25% 地板同一筆） |
| 出現孔多賽循環 | 依完成法（Ranked Pairs）決出；替換條件仍須逐項滿足 |
| 冷卻末日恰逢定期改選 | 更新不辦，走定期改選 |
| 更新與定期改選同年 | 距定期改選投票日不足 **12 個月**者，不辦更新 |
| 緊急狀態中 | 更新照辦。得變更投票地點，不得變更投票日 |
