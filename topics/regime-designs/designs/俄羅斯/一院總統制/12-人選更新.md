## 2 規則（主路徑）

### 2.1 更新 ≠ 出缺

死亡、辭職、屆滿、永久不能視事、彈劾解職，走補選／遞補／繼任（§2.8），**不是本檔的更新**。

### 2.2 為什麼不是「同意／不同意」的罷免

同意／不同意只問「要不要拿掉這個人」，不問「換成誰」。它的結構性問題與威瑪的消極多數相同：反對現任的人可以是一群彼此毫無共識的人，他們能拆掉現任，卻產生不出任何替代者，結果是空缺、補選、再一次動員。

替代現狀方式把兩個問題合成一個：**你要不要換成這個具體的人。** 反對者必須先在第一輪產生替代者，才能挑戰。這正是配置硬性「反為反而反」在人事程序上的落點。

機制本身、為何先淘汰、地板的口徑與數字：[`06`](06-人民修改法規範.md) §2。

### 2.3 總統

| 階段 | 規則 |
|---|---|
| 連署 | 選舉人總額 **10%**，180 日內完成。**無任何議會關卡** |
| 第一輪 | 全國單記，只負責選出 **n＝2** 名挑戰者（正副同組）。現任不參加。同票抽籤 |
| 第二輪 | 2 名挑戰者＋現任（「維持現狀」），6 格完整排序單選 |
| **先淘汰** | 挑戰者與現任兩兩對決的支持票 **< 選舉人總額 25%** 者出局 |
| **再決選** | 存活的挑戰者與現任跑孔多賽完成法；循環時 Ranked Pairs，勝方得票 |
| 結果 | 採用某挑戰者：接續**原任期之剩餘期間**，改用他的任期供給案。採用維持現狀：現任留任 |
| 冷卻 | 失敗後 **12 個月**內不得再對同一職位發動；兩名挑戰者對現任的支持票都 < 25% 則 **24 個月**。從第二輪投票日起算 |

25% 防低投票率：沒有它，一場 30% 投票率的更新（兩兩過半 ≈ 選舉人 15%）就能換掉全國選出的總統。不取 40%：那會讓更新實質走不到。

「接續原任期」是防止把更新程序當成延長任期的工具。

### 2.4 挑戰者的行政權預算

規則見 [`03`](03-行政權預算.md) §2.7：與第一輪登記一併公告；晉級後不得改；在位者不得另提；兩名挑戰者與現任原案並列公報同一頁；預算不列入淘汰線或決選。

### 2.5 單一席次議員

該選區選舉人 **10%** 連署。程序同總統（n＝2；先淘汰再決選）。地板為**該區選舉人 25%**。冷卻同總統。替換者任期至本屆屆滿。

### 2.6 複數席次議員

該選區選舉人 **10%** 連署後，該區**全部席次**依定期選舉規則重選，**不得針對名單上的個別議員**。

複數席次議員是名單與選區的產物，單獨罷免一人只會讓同名單下一位遞補，什麼也沒改變，卻給了對手一個便宜的騷擾工具。整區重選才是真的把選擇交還選民。重選產生的議員任期至本屆屆滿。該區冷卻 12 個月。

### 2.7 市鎮民選職務

市鎮首長與議員適用同一套規則：該市鎮選舉人 10% 連署、n＝2、先淘汰再決選、地板為該市鎮選舉人 25%。

**中央不得以任何其他方式解職市鎮民選職務**（[`07`](07-領土行政與反地方寡頭.md)）。

### 2.8 出缺（不是更新）

- 單一席次：90 日內補選；剩餘任期不足 1 年不補。空席期間分母仍 180。
- 複數席次：同區同聯盟名單未當選者依個人票遞補；名單用盡則空席，分母仍 120。
- 總統：副總統繼任至原任期屆滿，**不補選**（[`02`](02-總統與行政.md)）。
- 憲法法庭、審計院：見各該檔，**不走人民更新**。

### 2.9 緊急狀態不停止更新

見 [`08`](08-緊急狀態.md)。已成案的更新投票不因緊急狀態延期；投票地點得變更，投票日不得變更。

**宣告緊急狀態的人不因此獲得保護**——這是本夾在一個明說不在意集權的配置下，仍能說「隨時可被人民挑戰」的依據（[`14`](14-正當化.md)）。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 連署期間現任辭職 | 改走出缺。已繳連署作廢 |
| 第一輪後現任死亡 | 改走出缺。第二輪不辦；挑戰者已提之預提案失效 |
| 挑戰者僅 1 人 | n＝1，票面 2 格；仍先淘汰再決選 |
| 挑戰者 0 人 | 不辦第二輪，現任留任，冷卻 12 個月 |
| 第一輪第 2 名同票 | 同票者抽籤；票面恆 6 格 |
| 挑戰者預提案公告逾期或格式瑕疵 | 該案依 [`03`](03-行政權預算.md) §2.6 處理；**不影響其挑戰者資格** |
| 兩名挑戰者都過淘汰線 | 三方跑孔多賽完成法；淘汰已做完，不再另加地板 |
| 第二輪循環 | Ranked Pairs，勝方得票（[`06`](06-人民修改法規範.md) §2.5）；公告三場票數與不採認的那一場 |
| 距定期改選投票日不足 12 個月 | 不辦更新 |
| 緊急狀態中 | 更新照辦。得變更投票地點，不得變更投票日 |
