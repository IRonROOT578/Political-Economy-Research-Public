# 俄羅斯：一院總統制

```
# 俄羅斯
1. 一憲政設計: 0-基本 1-優化 配置\俄羅斯
選一政體。
```

繼承 `0-基本`＋`1-優化`＋`配置/俄羅斯`。**不**繼承 `配置/台灣`（監察權、考試權、反冗員、地方代表性）、`配置/惡搞`、`配置/雜項`。

## 選的政體

**一院總統制。** 對外競爭需要一個可單獨課責、且不欠任何地方勢力的行政中心；一院議會制的組閣談判會變成地方機器的分贓談判，撞「反地方寡頭」與「反人多嘴雜、反為反而反」。半總統制不採——`1-優化/財政.md` 已寫明「總統決定總理」是政體錯配。理由全文見 [`00`](00-讀法與政體選擇.md) §3。

## 一句話

國家杜馬一院 **350＝單一 200＋複數 150**，無第二院。總統全國 top-3 孔多賽選出、6 年連任一次、**無解散權**、不可被倒閣。行政權供給採**預提行政權預算**，由人民在選舉時授權，任內調整須雙鑰匙。**不設任何次國家的政治層級**——約 20 個行政區是派出機關，只留市鎮一層民選自治。四權：行政、立法、司法、審計。

## 三個本夾特有的決定

**一、廢掉次國家政治層級。** 提示詞裡「地方」只出現三處，唯一與本夾相關的那一條是「反**地方**寡頭」——方向是壓制。逐條封鎖轉換通道是先承認有一個值得奪取的位子再設防；本夾直接拿掉那個位子。民族權利改走**非領土的文化自治**。見 [`07`](07-領土行政與反地方寡頭.md)。

**二、預提不設金額上限。** 提示詞把金額上限標為（有爭議），而「行政權就管好自己的行政（含：**部分**供給）」那句本身就是反對它的論據。限制改由**範圍的封閉列舉**（「部分」的落實）加三個硬預設承擔：未列即未授權、歲入假設不構成授權、**未填減列順序表者由憲法逕行按比例齊頭削減**。見 [`03`](03-行政權預算.md) §2.6。

**三、底氣放在規則上，不放在結果上。** 配置明說**不在意是否偏向一黨制、中央集權**，但沒有解除「正當化」這條硬性。本夾的答案是一句話——**一黨獨大可以，一黨不受規則拘束不行**——並列出八條「即使是獨大的那一黨也被綁住」的條文。見 [`14`](14-正當化.md)。
