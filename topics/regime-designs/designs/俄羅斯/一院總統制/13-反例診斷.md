## 2 配置硬性：Herding cats／為反而反

### 2.1 荷蘭：組閣長跑與**法案協商時間長**（含）

硬性用的是「**含**：法案協商時間長」，兩半都要診斷。

#### 組閣長跑

**病例。** 下院碎片化，組閣無憲法期限。2021 年大選後組閣談判 **299 日**（該國史上最長），2023 年大選後 **223 日**。期間看守內閣能維持運作、不能做大改。

**機制。** 兩件事相乘：（一）行政的存續取決於議會多數的持續同意；（二）沒有任何憲法期限強迫多數在期限內形成。

**本夾的功課。** **本夾是總統制，沒有組閣這件事。** 行政首長是人民直選的總統，選舉結果出來的當天就確定。碎裂的議會不會產生「沒有政府」的狀態——它只產生「立法比較難」的狀態。

#### 法案協商時間長

**病例。** 多黨聯合政府的施政協議書必須逐條談定；協議書之外的議題每次都要重新談。單一法案的協商週期被拉長。

**機制。** 碎裂的議會 ＋ 政府存續依賴聯盟內每個夥伴 ＋ 沒有預設值。

**本夾的功課。**

| 荷蘭 | 本夾 |
|---|---|
| 政府存續依賴每個聯盟夥伴 | **總統不靠議會存活**，不需要施政協議書 |
| 預算要談成才有 | 供給由人民授權；逾期沿用；法定義務自動撥付。**不談也有** |
| 法律要湊出聯盟多數 | 法律要 ≥151，仍要跨黨——**這一半沒有免疫** |

**仍會感染的部分（誠實）。** 全院 300、無全國法定門檻、彈性名單，可能出現五到七個有席次的黨。法律的協商成本是真的。本夾對此的處理**不是設全國門檻**（那會毀掉 [`14`](14-正當化.md) 的一項攻擊面），而是：

1. 單一席次 180 佔全院 60%，用 top-3 孔多賽產生，本身傾向較大的區塊。
2. 複數席次用**杭特法**，對大黨略有獎勵，不像聖拉古把席次切得更碎。
3. **彈性名單**——席次主要來自名單順位，議員的個人授權弱，**要談的是黨不是 300 個人**。
4. 行政不需要立法多數就能運作。**立法拖不會變成國家停轉。**

這就是硬性「含」在總統制裡的落點：協商被拉長的是**法律**，不是**有沒有政府**。

### 2.2 巴西

**病例。** 高度碎裂的多黨體系加上總統制，總統必須逐案向數十個政黨買票才能通過法案；預算修正權被用作交易籌碼（議員增列選區項目換取支持）。結果是治理成本高、貪腐誘因大。

**機制。** 總統制的行政穩定 ＋ 立法端的極度碎裂 ＋ **議員可增列預算科目**，三者相乘。

**本夾為何跑不出這個。** 關鍵是第三項：

| 巴西 | 本夾 |
|---|---|
| 議員得增列預算科目 | 年度議決**得刪不得增**（[`03`](03-行政權預算.md) §2.9）；非行政部門預算亦得刪不得增（[`04`](04-其餘預算與國家財政.md)） |
| 預算是逐案買票的貨幣 | 行政的主要供給由人民一次授權，不是每年向議員買 |
| 選區項目可個別加入 | 未列入任期供給案者回到年度議決，且不得增列，**沒有「加項」這個動作** |

**仍會感染的部分。** 法律仍需跨黨。差別在於買票的貨幣被拿掉了——能交換的是條文內容，不是預算科目。

### 2.3 威瑪時期德國

**病例。** 兩個層次。（一）**消極多數**：反對現任內閣的議員總數過半，但他們支持不出任何繼任者，內閣因此頻繁倒台而無人能組閣。（二）**解散權與緊急命令權互相解鎖**：議會要廢止總統依第 48 條發布的緊急命令，總統就依第 25 條解散議會，在重選期間再發同一道命令。

**本夾為何跑不出第一層。** 本夾是總統制，**沒有倒閣**。消極多數在議會裡形成不了任何後果——它至多讓法律通不過，不會讓行政消失。

**本夾為何跑不出第二層。** 這一層比較危險，因為本夾也有一個直選總統與緊急命令權。三道鎖：

1. **總統沒有解散權**（[`02`](02-總統與行政.md)）。循環的第一步就跑不動。
2. 杜馬對緊急命令的廢止權 **不受總統覆議**（[`08`](08-緊急狀態.md)）。
3. 緊急狀態**不得延後任何選舉**，且杜馬因故不能在所在地集會時得於**任一地點**集會、其決議有效。

**仍會感染的部分。** 緊急狀態期間行政權確實膨脹。本夾用期限、累計上限、逾期即終止的預設值，與防常態化的「違反者該條文無效」壓住它，但不宣稱完全免疫——寫在 [`17`](17-完善與自洽.md)。

### 2.4 以色列、德國這類（如）

**如**，不是窮舉，也不必各開與荷蘭對等的長節。問題類型：小黨否決、聯合協議綁死、為反而反、聯合談判拖過執政空窗。

**以色列這類。** 小黨成為聯合政府的否決者，為反而反或單一議題綁架立法。本夾沒有聯合內閣可綁架：總統不靠議會存活；法律「同意>總額半數」讓棄權不能當便宜否決；要談的是黨不是每名議員。小黨仍能在 151 上討條文，討不到預算加項（得刪不得增）。

**德國這類。** 聯合談判長、小黨作為聯合夥伴否決。威瑪已見 §2.3。現代聯合談判是議會制組閣問題——本夾無組閣。少數否決靠「缺席＝否決」的那一半，被同意>總額半數關掉。

## 3 `1-優化` 非硬性：停擺、搖擺、二極化

這一節是加分，不是配置硬性。本夾**沒有**「負面 < 現在／包容理解 > 現在」。

### 3.1 美國：預算停擺

**病例。** 撥款法案未通過時，聯邦機關的裁量性支出無法動支。2018–19 年那次持續 **35 天**，為該國最長。

**機制。** 行政的資金來源完全取決於立法的年度同意，而立法可以拒絕同意卻不必承擔更換行政的責任——**只撤供給、不撤信任**。

**本夾的功課。** 本夾**用預提**，走「信任與供給的提供者都是人民」那條路徑。

| 美國 | 本夾 |
|---|---|
| 裁量支出全部依賴年度撥款 | 主要供給由**人民**在選舉時授權，任期內有效（[`03`](03-行政權預算.md)） |
| 未通過即停止運作 | 預提外的部分逾 60 日未議決者**沿用上年度額度**，不歸零 |
| 法定義務亦受影響 | 法定義務支出**始終撥付**，不需年度議決 |
| 議會撤供給不必換人 | 議會沒有「撤供給」這個工具可用——它只有一把調整的鑰匙，且另一把在總統手上 |

`1-優化/財政.md` 那句「立法權就管好自己的立法，行政權就管好自己的行政（含：部分行政權預算）」，在這一列上是最直接的：**停擺的本質是立法權拿行政權的運作當談判籌碼。**

### 3.2 美國：政策左右搖擺與二極化

**病例。** 提示詞認為源於 FPTP，且它把機制寫得很具體：FPTP 激勵候選人**及其背後媒體**鞏固基本盤、**「發表激進言論而激怒敵對陣營選民」**。政黨因此向兩極移動，政權交替時政策整批翻轉。

★ **提示詞點的是「候選人及其背後媒體」這一組，不只是候選人。**

**對本國的特殊代價（非硬性理由）。** 敵國「拉一打一、滲透」——一個被切成兩半的社會，對外部操作的抵抗力最低。這是本夾在意二極化的加分理由，不是台灣優化那兩條硬性。

**本夾的處理。**

| 機制 | 落點 |
|---|---|
| 單一席次用 **top-3 孔多賽** 而非相對多數：第三名支持者的第二偏好決定勝負，攻擊第三名等於自殺 | [`01`](01-國家杜馬與選制.md) |
| 複數席次**無全國法定門檻**：不把小黨的票整包送給最大黨 | [`01`](01-國家杜馬與選制.md) |
| 總統全國票 **top-3 孔多賽**，無選舉人團 | [`02`](02-總統與行政.md) |
| 落選的總統候選人組仍持有憲法法庭丙組的選舉權重 → **選輸不等於退出制度** | [`10`](10-憲法法庭與司法.md) |
| 公投不是信任投票 → 爭議不升級成政權存續問題 | [`06`](06-人民修改法規範.md) |
| 政策延續性：主要供給的授權跨越至少一次杜馬改選 | [`03`](03-行政權預算.md)、[`01`](01-國家杜馬與選制.md) |

**仍會感染的部分。** ★ **孔多賽改變的是候選人的誘因，不是媒體的。** 總統選舉本身仍是零和的單一職位競爭。本夾能做的是降低報酬，不是消滅它。媒體那一半**沒有工具**（[`17`](17-完善與自洽.md)）。
