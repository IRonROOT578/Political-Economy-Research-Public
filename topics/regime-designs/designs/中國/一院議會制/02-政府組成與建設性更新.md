## 2 規則（主路徑）

### 2.1 某些議員 ＝ 全院 450

理由見 [`00`](00-讀法與政體選擇.md) §3.6：信任與供給都由全院給，提供者相同；政府多數就是立法多數。

過半 **226**。

| | 全院 450 |
|---|---|
| 選出行政首長 | **是** |
| 建設性更新 | **是** |
| 表決行政權供給 | **是** |
| 法律、基本法、修憲 | 是 |
| 非行政部門預算 | 是 |
| 司法權、審計權人選 | 甲組＝單一、乙組＝複數（[`09`](09-司法權.md)、[`10`](10-審計權.md)） |

**錢、政府與規則是同一批人的事。** 甲／乙組只分司法與審計人選的選舉權人，不另開一條掌政府的多數。

### 2.2 選出（新屆）

新屆集會後 **7 個開會日**內：

1. 全院 450 人以**記名排名投票**產生準人選。排名可截斷、可並排。
2. 以孔多賽完成法決出勝者。多輪進行時，每輪篩掉完成法排名的後段，供協商。
3. 勝者即為行政首長，無須另行同意投票。

無現任時不適用對決門檻——第一次產生不需要贏過任何人。

**7 個開會日是硬期限。** 逾期時程序不停止：改為每個開會日一輪，篩掉排名最後一名，直到只剩一人為止。

行政首長**不必是議員**。任免政府成員，指揮行政機關，提出法律案與行政權預算案，為國家對外代表。

### 2.3 更新（建設性）

| 項目 | 規則 |
|---|---|
| 提案與提名 | 全院議員 **1/4（≥113）** 連署發動，且**須於提案書中載明挑戰人選姓名**；提案成案後 48 小時內，其他 ≥45 名議員（1/10）亦得連署提名挑戰人選 |
| 未載明 | **不予受理**，不列入議程 |
| **第 1 步：決定出或選出一位最高行政首長準人選** | 僅 1 名挑戰人選被提名時，直接**決定出**該人為最高行政首長準人選；有 2 名以上挑戰人選時，先由**全院 450 人以記名排名投票**（孔多賽完成法）**選出**一位最高行政首長準人選 |
| **第 2 步：準人選與現任兩兩對決** | 最高行政首長準人選與現任進行記名**兩兩對決** |
| 通過 | 準人選得 **≥226／450** |
| 效果 | 準人選就任，現任同時解職 |
| 未達 | 現任留任 |
| 冷卻 | 失敗後 **3 個月**內同一提案人不得再提 |
| 每會期上限 | **2 次** |

**「不載明繼任者即不予受理」是三個誤解裡 (c) 的直接解藥。** 反對現任的多數必須先在自己內部產生一個共同的人，否則連把案子排上議程都做不到——威瑪式的消極多數在程序上不成立。

### 2.4 換人不必經全國對決

這是本夾選一院議會制的**決定性理由**（[`00`](00-讀法與政體選擇.md) §3.3）。

在總統制裡換掉行政首長，只能靠一次全國性的罷免或改選——那必然是兩陣營動員，也就是第四條硬性最不想要的畫面。**在本夾，換人是 450 名議員在議會內部提出一個具名繼任者並贏過現任。**

| | 總統制 | **本夾** |
|---|---|---|
| 換人的程序 | 全國投票 | 議會內部的兩兩對決 |
| 動員範圍 | 全國 | 450 人 |
| 產生的畫面 | 兩陣營對決 | 一份具名的替代方案 |
| 屆期 | 可能重設 | **不重啟**，議會做滿 5 年 |

### 2.5 沒有解散權

行政首長不能解散議會。

理由有二：(一) 解散是行政對議會的武器，會把僵局升級成全國性動員，撞第四條硬性；(二) 本夾的僵局有內部出口（建設性更新），不需要外部出口。

代價：僵局沒有「訴諸選民」這條路。本夾接受——一個能在內部換掉首長的議會，其僵局本來就可以在內部解決。

### 2.6 不得只撤供給、不提繼任者

- 拒絕行政權供給的**唯一途徑**，是在期限內通過建設性更新信任案（[`03`](03-行政權預算與供給.md)）。
- 不存在「否決供給但保留現任」的表決選項；議事規則不得設置這種動議。

### 2.7 政府成員

行政首長任免政府成員，不需議會同意。議會得質詢、調查，得對個別政府成員提出**譴責案**（全院 ≥226），但譴責不生解職效力——**解職只有一條路，就是換掉首長本人**。

理由：若個別部長可被議會逐一拔除，行政的組成就變成逐案談判，那是 Herding cats。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆逾 7 個開會日未選出 | 改為每開會日一輪刷尾，直到剩一人 |
| 首長死亡、辭職、經判決解職 | 副首長代理，**7 個開會日**內依 §2.2 重選。**不重啟議會屆期，議會不被解散** |
| 更新案準人選於表決前退出 | 該案失效，提案人得另提，冷卻期不重新起算 |
| 兩案以上同時成案（多名挑戰人選） | 併入第 1 步，由全院 450 人以記名排名投票（孔多賽完成法）先選出一位最高行政首長準人選，再與現任進行兩兩對決（避免比誰先送件的議程操弄） |
| 兩兩對決同票 | 現任留任 |
| 準人選當選後拒絕就任 | 該案視為未通過，適用 3 個月冷卻 |
| 首長長期不能視事 | 全院 ≥226 得認定，副首長代理並於 7 個開會日內重選 |
| 緊急狀態期間 | 更新程序**不中止**（[`07`](07-緊急狀態.md)）。宣告狀態的人不因此獲得保護 |
| 會期外 | 1/4 連署得要求召開臨時會，議長應於 7 日內召集 |
