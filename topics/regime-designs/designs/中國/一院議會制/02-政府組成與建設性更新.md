## 2 規則（主路徑）

### 2.1 某些議員 ＝ 全院 450

`0-基本` 只寫「某些議員」。`1-優化/財政.md` 信任供給合一：信任與供給給同一批人。候選有兩個，用生態模型各跑一次（`生態模型.py --某些議員`，以帶計）：

| 屆 | 全院 450（過半 226） | 單一 260（過半 131） |
|---|---|---|
| 3 | 發展優先 269 單獨；其餘五帶合計 181 | 發展優先 211 單獨；其餘合計 49 |
| 5 | 發展優先 228 單獨；其餘五帶合計 222 | 發展優先 172 單獨；其餘合計 88 |

兩種規則組出的政府一樣——都是發展優先一帶，都不必聯合。差別在**換得掉換不掉**：單一 260 下其餘各帶離 131 很遠，建設性更新對它們是空的；全院 450 下第 5 屆差 4 席。本夾取**全院**：

1. 建設性更新成為真的出口，而政府的穩定不因此打折——兩屆都不需要聯合政府。
2. 信任、供給、法律同一個多數、同一個門檻；政府的基礎是全院過半，不是全院的 29%（131／450）。

過半 **226**。

| | 全院 450 | 另外的要求 |
|---|---|---|
| 選出行政首長、建設性更新、行政權供給、法律、非行政部門預算 | ≥226 | — |
| 基本法、修憲 | ≥270／≥300 | **且**複數 190 ≥114／≥127 |
| 司法權、審計權人選 | 甲組＝單一 260、乙組＝複數 190 | — |

**政府、錢、法律是同一個全院多數；規則另要複數席次那一道。**

### 2.2 選出（新屆）

新屆集會後 **7 個開會日**內：

1. 議員 450 人以**記名排名投票**產生準人選。排名可截斷、可並排。
2. 以孔多賽完成法決出勝者。多輪進行時，每輪篩掉完成法排名的後段，供協商。
3. 勝者即為行政首長，無須另行同意投票。

無現任時不適用對決門檻——第一次產生不需要贏過任何人。

**7 個開會日是硬期限。** 逾期時程序不停止：改為每個開會日一輪，篩掉排名最後一名，直到只剩一人為止。

**對決強度用勝方得票，不用勝差。** 議員可以截斷、並排，某場對決可能有人不表態，兩種量法就會分岔；一派只排自己的人、其餘留白，在勝差量法下能讓對手的某場勝利「變弱」而在循環裡被丟掉。手算例見 [`../../台灣/一院議會制/02-行政首長.md`](../../台灣/一院議會制/02-行政首長.md) §2.2。

行政首長**不必是議員**。任免政府成員，指揮行政機關，提出法律案與行政權預算案，為國家對外代表。

### 2.3 更新（建設性）

| 項目 | 規則 |
|---|---|
| 提案 | 議員 **1/4（≥113）** 連署，且**須於提案書中載明準人選姓名** |
| 未載明 | **不予受理**，不列入議程 |
| 表決 | 準人選與現任的**兩兩對決**，記名 |
| 通過 | 準人選得 **≥226／450** |
| 效果 | 準人選就任，現任同時解職 |
| 未達 | 現任留任 |
| 冷卻 | 失敗後 **3 個月**內同一提案人不得再提 |
| 每會期上限 | **2 次** |

**「不載明繼任者即不予受理」是三個誤解裡 (c) 的直接解藥。** 反對現任的多數必須先在自己內部產生一個共同的人，否則連把案子排上議程都做不到——威瑪式的消極多數在程序上不成立。

### 2.4 換人不必經全國對決

這是本夾選一院議會制的**決定性理由**（[`00`](00-讀法與政體選擇.md) §3.3）。

在總統制裡換掉行政首長，只能靠一次全國性的罷免或改選——那必然是兩陣營動員，也就是「避免以偏概全」那條硬性最不想要的畫面。**在本夾，換人是 450 名議員在議會內部提出一個具名繼任者並贏過現任。**

| | 總統制 | **本夾** |
|---|---|---|
| 換人的程序 | 全國投票 | 議會內部的兩兩對決 |
| 動員範圍 | 全國 | 450 人 |
| 產生的畫面 | 兩陣營對決 | 一份具名的替代方案 |
| 屆期 | 可能重設 | **不重啟**，議會做滿 5 年 |

### 2.5 沒有解散權

行政首長不能解散議會。

理由有二：(一) 解散是行政對議會的武器，會把僵局升級成全國性動員，撞「避免以偏概全」那條硬性；(二) 本夾的僵局有內部出口（建設性更新），不需要外部出口。

代價：僵局沒有「訴諸選民」這條路。本夾接受——一個能在內部換掉首長的議會，其僵局本來就可以在內部解決。

### 2.6 不得只撤供給、不提繼任者

- 拒絕行政權供給的**唯一途徑**，是在期限內通過建設性更新信任案（[`03`](03-行政權預算與供給.md)）。
- 不存在「否決供給但保留現任」的表決選項；議事規則不得設置這種動議。
- 複數席次議員完全不參與行政權供給的表決，因此也不可能只撤供給。

### 2.7 政府成員

行政首長任免政府成員，不需議會同意。議會得質詢、調查，得對個別政府成員提出**譴責案**（全院 ≥226），但譴責不生解職效力——**解職只有一條路，就是換掉首長本人**。

理由：若個別部長可被議會逐一拔除，行政的組成就變成逐案談判，那是 Herding cats。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 新屆逾 7 個開會日未選出 | 改為每開會日一輪刷尾，直到剩一人 |
| 首長死亡、辭職、經判決解職 | 副首長代理，**7 個開會日**內依 §2.2 重選。**不重啟議會屆期，議會不被解散** |
| 更新案準人選於表決前退出 | 該案失效，提案人得另提，冷卻期不重新起算 |
| 兩案同時成案 | 依連署完成先後表決；前案通過則後案失效 |
| 兩兩對決同票 | 現任留任 |
| 準人選當選後拒絕就任 | 該案視為未通過，適用 3 個月冷卻 |
| 首長長期不能視事 | 全院 ≥226 得認定，副首長代理並於 7 個開會日內重選 |
| 緊急狀態期間 | 更新程序**不中止**（[`07`](07-緊急狀態.md)）。宣告狀態的人不因此獲得保護 |
| 會期外 | 1/4 連署得要求召開臨時會，議長應於 7 日內召集 |
