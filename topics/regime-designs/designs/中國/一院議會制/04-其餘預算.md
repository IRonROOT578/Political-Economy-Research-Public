## 2 規則（主路徑）

### 2.1 非行政部門的預算

全國議會、司法權各機關、審計院、選務機關、獨立劃分委員會的歲出：

1. 各該機關**自行編列**歲出上限。
2. **行政首長不得刪減**這些科目，只能轉送。
3. 全院 **≥226** 議決，**得刪不得增**。
4. 會計年度開始前未議決者，**沿用上一年度已議決額度**。

第 2 點是本夾對權限爭議最實際的防線：一個能刪司法預算的行政首長，不需要違憲就能讓法院停轉。

第 4 點的採用理由與 [`03`](03-行政權預算與供給.md) §2.7 相同：停擺是 (b)「民選＝美國式內鬥內戰」最具體的形態，要避免那個印象就不能自己留開關。

議會的預算由議會自己批准。形式上是自己審自己，但讓行政或司法批准立法權的預算，等於給它們一根對立法權的常設槓桿。**冗餘比癱瘓好。**

### 2.2 稅制與歲入

稅目與稅率以**法律**定之（全院 ≥226），不適用 [`03`](03-行政權預算與供給.md) 的自動生效。

`1-優化/財政.md` 的規劃保障供給明文不含歲入與稅制。界線很清楚：**行政可以在授權範圍內花已授權的錢，不能在同一個機制下決定人民繳多少稅。**

### 2.3 對地方層級的財政移轉

移轉**公式**屬基本法事項（[`05`](05-法律與法規位階.md)），且須**普遍適用**：

> 中央與個別地方團體之間，不得締結變更其財政地位之個別協定。

移轉的年度總額由全院 ≥226 議決，不由行政權供給的自動生效機制決定，且明文排除在供給案之外（[`03`](03-行政權預算與供給.md) §2.2）。

理由：地方的財政地位若可年年談判，談判桌本身就會成為地方勢力與中央互相要價的場域——那既傷害治理效率，也讓地方層級的權限形同虛設（[`12`](12-地方層級.md)）。

### 2.4 決算與餘額

- 未執行的預算餘額應**繳庫**，不得留用、不得移作他項。
- 決算由審計院查核（[`10`](10-審計權.md)）。
- 審計院每年就行政權供給的執行公布**議決額／實際支出／差異理由**對照表，直接送議會與公眾，不經行政首長核閱。

供給自動生效降低了事前的財政課責，這張對照表是換回來的事後課責。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 某機關編列的上限被議會刪至無法運作 | 該機關得聲請司法權認定；認定成立者恢復至上一年度額度 |
| 行政首長刪減非行政部門科目後轉送 | 刪減無效，以原編列數送議會 |
| 會計年度開始前未議決 | 全部沿用上年度已議決額度，不歸零 |
| 移轉公式修正案未跨屆確認 | 不生效，續用原公式 |
| 個別地方團體主張其財政地位應調整 | 只能主張公式適用錯誤，由司法權裁判；不得請求個別協定 |
| 餘額未繳庫 | 審計院逕行認定該支出無法證明合法性並公告（[`10`](10-審計權.md)） |
| 稅法與供給案的歲入假設不一致 | 以稅法為準 |
