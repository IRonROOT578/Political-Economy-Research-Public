## 2 規則（主路徑）

### 2.1 三種更新，各走各的路

| 對象 | 誰更新 | 程序 |
|---|---|---|
| **行政首長** | 單一席次議員 260 | 建設性更新，見 [`02`](02-政府組成與建設性更新.md) |
| **議員** | 該選區選民 | 本檔 §2.3–§2.4 |
| **地方民選職務** | 該地方選民 | 本檔 §2.5 |

**行政首長不由人民直接更新**，因為他不由人民直接選出。這不是立法權凌駕人民——**人民從來沒有對他的授權**（[`00`](00-讀法與政體選擇.md) §3.3：首長由 260 名議員選出）。人民更新的對象是議員，而議員換了，首長的多數就換了。

### 2.2 為什麼不用「同意／不同意」的罷免

同意／不同意只問「要不要拿掉這個人」，不問「換成誰」。它的結構性問題與威瑪的消極多數相同：反對現任的人可以是一群彼此毫無共識的人，他們能拆掉現任，卻產生不出任何替代者，結果是空缺、補選、再一次動員。

「備胎＋現任孔多賽」把兩個問題合成一個：**你要不要換成這個具體的人。**

這是配置硬性「**反為反而反**」在人事程序上的落點，與 [`02`](02-政府組成與建設性更新.md) 的建設性更新是同一個原理用在兩個層級。

### 2.3 單一席次議員

k＝3，故第二輪是 **2 名備胎＋現任**共 3 人，票面仍是 6 個完整排序選項單選。

| 階段 | 規則 |
|---|---|
| 連署 | 該選區選舉人 **10%**，180 日內完成。**無任何議會關卡** |
| 第一輪 | 該區單記，選出得票前 **2** 名挑戰者。現任不參加第一輪 |
| 第二輪 | 對「2 名挑戰者＋現任」採孔多賽完成法，6 格單選 |
| 替換條件 | 挑戰者須為孔多賽贏家，**且**在與現任的兩兩對決中得有效票過半，**且**該對決之支持票數 **≥ 該區選舉人 40%** |
| 未達 | 現任留任 |
| 冷卻 | 失敗後 **12 個月**不得再發動；若最強挑戰者未達該區選舉人 40%，冷卻 **24 個月**。自投票日起算 |
| 任期 | 替換成功者接續**本屆剩餘任期**，不重新起算 |

40% 的地板是防低投票率動員：沒有它，一場 30% 投票率的更新投票就能換掉一個以相對多數選出的議員。

### 2.4 複數席次議員

該選區選舉人 **10%** 連署後，該區**全部席次**依定期選舉規則重選，**不得針對名單上的個別議員**。

理由：複數席次議員是名單與選區的產物。單獨罷免一人只會讓同一份名單的下一位遞補，什麼也沒改變，卻給了對手一個便宜的騷擾工具。整區重選則是真的把選擇交還選民。

重選產生的議員任期至本屆屆滿。該區冷卻 12 個月。

### 2.5 地方民選職務

省級與市縣級議會的議員，適用與單一／複數席次議員相同的規則（依其席次型態）。

省級行政首長由省議會以建設性更新替換（[`12`](12-地方層級.md)），與中央同一原理。

**中央不得以任何其他方式解職地方民選職務**——只能由該地方選民更新、由該地方議會建設性更新，或由法院判決解職。

### 2.6 出缺（不是更新）

死亡、辭職、屆滿、永久不能視事、經判決解職，走補選／遞補：

- 單一席次：90 日內補選；剩餘任期不足 1 年不補。空席期間分母仍 260。
- 複數席次：同區同名單未當選者依名單順位遞補（個人票已跨躍升門檻者依躍升後順位）；名單用盡則空席，分母仍 190。
- 行政首長：副首長代理，7 個開會日內依 [`02`](02-政府組成與建設性更新.md) §2.2 重選。
- 憲法法院、審計院：見各該檔，**不走人民更新**。

### 2.7 緊急狀態不停止更新

見 [`07`](07-緊急狀態.md)。已成案的更新投票不因緊急狀態延期；投票地點得變更，投票日不得變更。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 連署期間現任辭職 | 改走出缺。已繳連署作廢，不轉成更新 |
| 第一輪後現任死亡 | 改走出缺。第二輪不辦 |
| 挑戰者僅 1 人 | 第二輪為 1 備胎＋現任，票面改 2!＝2 格 |
| 挑戰者 0 人 | 不辦第二輪，現任留任，冷卻 12 個月 |
| 第一輪第 2 名同票 | 併列進第二輪，票面改 4!＝24 格 |
| 孔多賽贏家非最強挑戰者 | 以贏家與現任的兩兩對決判斷替換條件 |
| 出現孔多賽循環 | 依完成法（Ranked Pairs）決出；替換條件仍須逐項滿足 |
| 冷卻末日恰逢定期改選 | 更新不辦，走定期改選 |
| 距定期改選投票日不足 12 個月 | 不辦更新 |
| 更新成功後行政首長失去多數 | 走 [`02`](02-政府組成與建設性更新.md) 的建設性更新，不因議員更新而自動解職 |
| 緊急狀態中 | 更新照辦。得變更投票地點，不得變更投票日 |
