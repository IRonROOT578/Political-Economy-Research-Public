# 中國：一院議會制

```

1. 一憲政設計: 0-基本 1-優化 配置\中國
選一政體。
預期政治生態、議會席次圖:可用意識形態而非政黨來表示議會分布。
```

繼承 `0-基本`＋`1-優化`＋`配置/中國`。**不**繼承 `配置/台灣`（監察權、考試權、黑金、修憲難度、總統更新）、`配置/俄羅斯`（反地方寡頭、正當化）、`配置/惡搞`、`配置/雜項`（少身分政治、地方代表性、反冗員）。

## 選的政體

**一院議會制。** 決定性的證據來自配置自己：第四條硬性把 (a) 標成「**台美韓式**二極化對立仇恨」，而台灣、美國、南韓的共同結構是**三者都以一次全國性的單一勝者競爭產生行政首長**。被點名的三個地方，共同項不是政黨數，是**那個職位**。

而且在總統制裡換掉行政首長只能靠一次全國性罷免或改選——**本夾最不想要的畫面，在總統制裡是換人的唯一途徑**。理由全文見 [`00`](00-讀法與政體選擇.md) §3。

## 一句話

全國議會一院 **450＝單一 260＋複數 190**。行政首長由 **260 名單一席次議員**以記名排名投票選出，**建設性更新**（準人選須贏過現任 ≥131），**兼國家元首**——全國層級只有這一個經由選舉產生的行政職位。行政權供給**期限內未通過建設性更新即自動生效**。複數席次用**彈性名單**、聖拉古、無得票門檻、M∈[8,14]。四權：行政、立法、司法、審計。

## 三個本夾特有的決定

**一、不另設國家元首。** (b)「民選＝美國式內鬥內戰」的病因是雙元正當性且憲法沒有出口。設一個另外產生的元首，就是在製造第二個宣稱代表全國的職位——**即使它「沒有實權」，每次政府危機都會有人要求它介入**。本夾把那個位子整個拿掉。見 [`08`](08-中央內水平分權.md) §2.1。

**二、省長也不直選。** 若省長由該省人民直選，全國就會出現三十餘場單一勝者的行政首長競爭——**本夾在中央拿掉的東西，會在省級重新長出來三十幾份**。省長由省議會以建設性更新產生。見 [`12`](12-地方層級.md) §2.2。

**三、複數席次用彈性名單。** `1-優化/投票.md` 對複數席次只規定「聖拉古、無門檻、允許聯盟」，**沒有規定名單型式**；而 `1-優化/行政立法/共用.md` 的**硬性**反過來點名開放名單 PR 是黑金風險。改用彈性名單後 M 不必壓在 7，比例性反而變好；而且議員的個人授權弱，**要談的是黨不是 450 個人**——這是本夾對 Herding cats 最直接的一招。見 [`01`](01-全國議會與選制.md) §2.3。

## 第四條硬性怎麼落實

三個誤解是**三個彼此獨立的機制**，三帖藥同時吃（[`00`](00-讀法與政體選擇.md) §2.2）：

| 誤解 | 病因 | 藥 |
|---|---|---|
| (a) 台美韓式二極化對立仇恨、兩黨扯皮 | **非向心型選制** | 單一席次 top-3 孔多賽；不設全國性單一勝者行政職位 |
| (b) 美國式內鬥內戰 | 雙元正當性且憲法無出口 | 只有一個全國性授權機關；無解散；不另設元首 |
| (c) 歐洲式 Herding cats、為反而反 | 信任與組閣的規則 | 建設性更新須具名繼任者；7 個開會日硬期限；供給預設自動生效 |

**本夾不需要限制陣營數量**——(c) 由機制擋掉，不由減少陣營擋掉。所以議會可以誠實地由六個意識形態帶構成，光譜不是風險，**把光譜壓成兩邊才是**。

## 與俄羅斯夾的差異

| | 俄羅斯 | **中國** |
|---|---|---|
| 政體 | 一院總統制 | **一院議會制** |
| 決定性的配置條件 | 反地方寡頭 | **避免以偏概全的三個誤解** |
| 次國家政治層級 | **不設**（依據是反地方寡頭） | **兩級民選自治**（中國無該依據） |
| 正當化專檔 | 有（配置硬性） | **無**（中國無該條） |
| 供給 | 預提行政權預算 | **自動生效** |
| 元首 | 總統即行政首長 | 行政首長兼元首 |
