# 日本：一院議會制

本憲政設計最新更新：2026-11-11

## 一句話

**廢參議院的一院議會制**：國會 **465＝單一 280（top-3 孔多賽、獨立委員會劃界 ±10%）＋複數 185（彈性名單、16 區、廢重複立候補）**；首長由全院記名排名投票選出（≥233）、30 日預設值；**廢第 7 條解散、固定選舉日**、建設性更新；供給自動生效；組織法與修憲要全院與複數各自 3/5、修憲跨屆加地板；新設憲法法院（一票落差越線即無效）；派閥不得收獻金；象徵天皇不動。

## 三個最容易讀錯的地方

**一、2024 年的首長是國民民主黨。** 11.3% 的比例票，全院 146 席：決選「國民／立憲／自民」的 125 區它幾乎全勝。和荷蘭的 CDA、巴西的中間大團同型（[`12`](12-預期政治生態.md) §5.1）。

**二、結果對「公明黨是不是別人的第二偏好」極敏感。** 沒有組織宗教軸時公明黨居中，2024 年單一 101 席；加上後 0 席（[`12`](12-預期政治生態.md) §2）。

**三、2021 年的自民黨單獨過 3/5，仍改不了憲法。** 全院 298，複數 65（要 111）。
