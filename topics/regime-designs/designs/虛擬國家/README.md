# 虛擬國家

虛構國家、虛構數字，三個政體各一版，民意相同（甲居中、乙右、丙左、丁極左、戊極右）。新國家可照這三夾的檔名與表格寫。

| 夾 | 一句話 |
|---|---|
| [`一院議會制/`](一院議會制/) | 國會 100＝單一 60＋複數 40；首長全院排名、建設性更新、供給自動生效 |
| [`兩院議會制/`](兩院議會制/) | 國民院 100（政府院）＋參議院 50（3 區比例，擱置否決、組織法 3/5） |
| [`一院總統制/`](一院總統制/) | 同一國會；總統 top-3 孔多賽、人民更新；不用預提，預算逾期沿用 |

共用模型：[`共用模型.py`](共用模型.py)（參議院、總統、席次圖）。
