# 虛擬國家：兩院議會制

本憲政設計最新更新：2026-11-11

> 虛構國家、虛構數字，可當新國家的格式參考。與 [`../一院議會制/`](../一院議會制/)、[`../一院總統制/`](../一院總統制/) 用同一份民意（[`../共用模型.py`](../共用模型.py)）。

## 一句話

**國民院 100＝單一 60（top-3 孔多賽）＋複數 40（彈性名單、聖拉古、無法定門檻）；參議院 50＝3 區比例代表。** 兩院都直選、4 年、同日改選。首長與供給只在國民院（≥51）；參議院不倒閣、不碰供給，對普通法律只有 30 日擱置否決，對組織法與修憲握第二把鑰匙（3/5）。無解散。
