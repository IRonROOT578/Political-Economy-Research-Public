# 完善與自洽

| 檢查 | 結果 |
|---|---|
| 兩院都由人民直選 | 是 |
| 誰選首長 | 國民院全院；參議院不參與 |
| 倒閣有沒有繼任者 | 有；建設性更新 |
| 供給有沒有預設值 | 有；20 個開會日 |
| 參議院能不能卡死普通法律 | 不能；只能擱置 30 日 |
| 一屆多數能不能單獨改規則 | 不能；參議院 3/5 |
| 法官是不是記名投票權人 | 不是；丙組祕密投票 |
| 人選能不能被杯葛 | 不能；60 日名冊順位 |

席次自洽：國民院 24＋21＋15＝60、複數 40、合計 100；參議院 20＋17＋13＝50。
