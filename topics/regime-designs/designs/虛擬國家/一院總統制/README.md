# 虛擬國家：一院總統制

本憲政設計最新更新：2026-11-11

> 虛構國家、虛構數字，可當新國家的格式參考。議會與 [`../一院議會制/`](../一院議會制/) 相同；民意相同（[`../共用模型.py`](../共用模型.py)）。

## 一句話

國會 **100＝單一 60（top-3 孔多賽）＋複數 40（彈性名單、聖拉古、無法定門檻）**。總統由人民 top-3 孔多賽選出、負責行政；國會不能倒閣，總統不能解散。行政權預算**不用預提**：國會年度議決（≥51），未通過時法定義務照撥、其餘沿用上年度，不會停擺。總統只能由人民更新（替代現狀投票，有冷卻期）；法律責任走彈劾。
