# 完善與自洽

| 檢查 | 結果 |
|---|---|
| 總統由人民選出、負責行政 | 是；top-3 孔多賽 |
| 國會能不能用預算餓死總統 | 不能；法定義務照撥、逾期沿用 |
| 總統更新是不是由人民發動 | 是；國會沒有關卡，有冷卻期 |
| 法官是不是記名投票權人 | 不是；丙組祕密投票 |
| 人選能不能被杯葛 | 不能；60 日名冊順位 |
| 總統估計是否用現實候選人得票 | 否；用政黨得票、每黨一人 |
