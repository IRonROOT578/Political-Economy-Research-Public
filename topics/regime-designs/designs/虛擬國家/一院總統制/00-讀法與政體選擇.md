# 讀法與政體選擇

本檔是概要層。設計條件的落點在 [`07`](07-完善與自洽.md)。

## 1 本夾是什麼

一院總統制：行政由人民選出的總統負責，國會只立法、審預算。國會與一院議會制版本完全相同，差別只在行政怎麼產生、怎麼更新、預算卡住時怎麼辦。

## 2 與議會制版本的差別

| | [`../一院議會制/`](../一院議會制/) | 本夾 |
|---|---|---|
| 行政 | 全院選首長 | 人民選總統（top-3 孔多賽） |
| 更新 | 建設性更新 ≥51 | 人民發動的替代現狀投票 |
| 供給 | 期限內未更新即自動生效 | 國會年度議決；逾期沿用上年度 |
| 法律 | 首長無覆議 | 總統可退回一次 |

## 3 為什麼不用預提行政權預算

候選人在選前提出四年的行政權預算，能把信任與供給都交給人民；但虛擬國家這一版要示範「不用預提」的總統制怎麼避免餓死政府：預算未通過時法定義務照撥、其餘沿用上年度、國會得刪不得增。代價是分立政府時，總統的新政策要靠國會多數。
