## 2 組閣：總統不參與，沒有看守，沒有解散

```mermaid
flowchart LR
  E[新屆集會] --> R1[記名排名投票<br/>每輪篩掉後 1/3<br/>輪間 72 小時]
  R1 -->|勝者 ≥151 排在「維持空缺」之上| OK[就任]
  R1 -->|30 日屆滿| DEF[孔多賽第一名<br/>逕行就任]
  OK --> GOV[首長在任]
  DEF --> GOV

  GOV -.->|辭職或死亡| R1
  OUT[聯合政黨撤出部長] -.->|政府不倒，首長補任| GOV
```

## 3 錢與緊急命令

```mermaid
flowchart LR
  G[政府送供給案] --> W{20 個開會日內<br/>建設性更新 ≥151？}
  W -->|否| ON[供給生效]
  W -->|是| CH[新首長就任<br/>原案失效、重送]
  REV[歲入、稅制] -->|全院 ≥151| TAX[議決]
  OUG[緊急命令<br/>限緊急狀態或歐盟期限] --> A{30 個開會日內<br/>全院 ≥151 追認？}
  A -->|是| KEEP[成為法律]
  A -->|否| LAPSE[自動失效]
  X[刑法、選舉、司法、稅制] -.-x OUG
```

```mermaid
flowchart TB

  C1[一般修憲] -->|全院 ≥180 且 複數 ≥72<br/>跨一次定期改選再過一次| REF[人民複決<br/>支持票 ≥25%]

  INI --> O1
```
