## 2 修憲

### 2.1 一般軌

1. 本屆全院 **≥270（3/5）** 提出。
2. **下一屆**全院 **≥226** 確認（跨屆）。
3. 人民複決通過（§2.3）。

跨屆確認讓修憲**至少經過一次全國大選**——選民有機會用選票對已提出的修憲案表態。

### 2.2 急迫軌

同屆全院 **≥300（2/3）** 提出，90 日內複決。

急迫軌**不得**修改：政體類型（一院議會制）、議會任期、本條、§2.4、人權清單、基本法事項清單。

### 2.3 人民複決的門檻

同意票須**同時**滿足：

1. 為投票方法的贏家。
2. 同意票 > 有效票半數。
3. 同意票 **≥ 選舉人總額 20%**。

第 3 款是防低投票率的地板。用「有效同意票過選舉人總額之半數」那種門檻會使憲法實質改不了（台灣現行即為此類：2022 年那次修憲複決同意 5,647,102 票、不同意 5,016,427 票，同意方多出約 63 萬票，仍因未達約 962 萬而未通過）。

### 2.4 逐條分別複決

> 修憲案有二以上獨立條項者，**應逐項分別付諸複決、分別計票、分別生效**。不得以單一贊否選項就整包表決。

包裹複決把不同性質的條文綁在一起：一個包裹裡放進廣受支持的社會權條款與爭議極大的權力條款，選民只能整包接受或整包拒絕，結果無法區分他們同意的是哪一項。

成本是選票變長；收益是複決結果真的能被讀懂。

## 3 人民修改法規範

### 3.1 對象範圍

| 標的 | 可否以公投直接變更 | 為什麼 |
|---|---|---|
| 法律 | **可** | — |
| 基本法 | **可**，地板提高至 25% | 位階高，門檻跟著高 |
| 憲法 | **否** | 修憲走 §2；公投是那裡的複決階段，不是獨立入口 |
| 預算、稅制 | **否** | 防止「多數投票決定少數繳稅」的直接掠奪 |
| 國際條約之批准 | **否** | 對外承諾的可信度不能每次動員重來 |
| 個案處分、特定人之權利義務 | **否** | 那是司法或行政的事 |
| 剝奪或限制人權清單所列權利 | **否** | 多數不得投票取消少數的基本權 |

### 3.2 提案與三版本

- 選舉人 **2%** 連署成案，連署期間 6 個月。
- 成案後 30 日內，**行政首長得提出政府版本**。領銜人即為政府時只有兩個版本。
- 票面：**6 個完整排序選項單選一個**（3!＝6）；只有兩版本時改 2!＝2 格。
- 計票以孔多賽完成法決出投票方法贏家；計票地點規則同 [`01`](01-全國議會與選制.md)。

### 3.3 成立條件

領銜人版本或政府版本，須**同時**滿足：

(a) 為投票方法的贏家；  
(b) 以該版本為第一偏好者 **≥ 選舉人總額 20%**（涉及基本法事項者 **25%**）。

**二者皆未成立時，維持現狀。**

### 3.4 效力範圍

- 自公告日起 **30 日**生效；**位階依其內容決定**，不因為是公投通過就取得更高位階。
- 牴觸憲法者無效，由司法權認定（[`09`](09-司法權.md)）。
- **鎖定期 3 年**：期間內議會不得以同位階規範變更其實質內容；期滿回復一般程序。
- 同一議題失敗後 **2 年**內不得再次提案。

3 年略長於一屆議會的一半，足以讓公投結果實際運行一次完整的預算與選舉週期；但不是永久拘束——永久拘束會讓公投變成憲法的替身，而那會誘使各方把普通政策爭議都推進公投，因為贏一次就一勞永逸。**那是把 Herding cats 從議會搬到街上。**

### 3.5 公投不是信任投票

公投結果與行政首長的去留**沒有任何制度性連結**：

- 政府版本敗給領銜人版本，首長不必辭職。
- 公投不觸發 [`02`](02-政府組成與建設性更新.md) 的建設性更新程序。
- 首長不得宣布「本案通過即視為對本人之信任」而使其產生法律效果。

理由是把爭議的**出口**與政府危機的**入口**切開。一個可以被當成信任投票的公投，會讓每一次爭議升級成政權存續問題——那正是 [`00`](00-讀法與政體選擇.md) §2.2 的 (a) 與 (b) 要避免的形狀。

## 4 狀態

| 狀態 | 怎麼走 |
|---|---|
| 修憲案提出後屆期改選 | 跨屆確認由新屆為之，這正是設計目的；新屆未於首會期確認者，該案失效 |
| 逐條複決中部分通過、部分未過 | 通過者生效，未過者不生效。提案時應載明條項間有無依存關係；有依存關係而前提未過者，後續不生效 |
| 急迫軌含禁止修改事項 | 該部分不予付諸複決，其餘部分程序不受影響 |
| 連署期滿未達 2% | 不成案，已繳連署作廢 |
| 政府未於 30 日內提版本 | 視為不提，票面改 2 格 |
| 兩版本實質相同 | 選務機關通知後合併；領銜人不同意者維持兩案 |
| 出現孔多賽循環 | 依完成法（Ranked Pairs）決出；仍須各自滿足 (b) |
| 贏家未達 (b) 的地板 | 維持現狀，不順延給次高者 |
| 鎖定期內議會通過牴觸之法律 | 該法律於鎖定期內不生效力，期滿後始生效 |
| 成案後投票前議會自行通過領銜人版本 | 公投停辦；連署人得請求就政府版本另行投票 |
| 緊急狀態期間 | 已定投票日的公投與複決**不延期**（[`07`](07-緊急狀態.md)） |
