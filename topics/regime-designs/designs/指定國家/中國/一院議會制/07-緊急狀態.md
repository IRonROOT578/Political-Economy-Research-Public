## 2 規則（主路徑）

### 2.1 兩種狀態（封閉列舉）

憲法未列名的狀態不存在。不得以命令創設憲法與基本法皆未規定的回應等級。

| | 戰爭／武力攻擊 | 重大災害、疫病 |
|---|---|---|
| 宣告 | 行政首長宣告 | 行政首長宣告 |
| 追認 | **72 小時內**全院 ≥226，否則失效 | 同左 |
| 一次期限 | 30 日 | 15 日 |
| 延長 | 全院 **≥270**，每次 ≤30 日 | 全院 ≥226，每次 ≤15 日 |
| 累計上限 | **180 日** | **90 日** |
| 逾期未表決 | **狀態終止** | **狀態終止** |
| 適用範圍 | 得限於特定地區 | 得限於特定地區 |

累計上限屆滿後仍需延長者，須以**基本法程序（≥270）**逐次為之，每次不得逾 30 日。

「逾期未表決即**終止**」而非「視為同意」，是刻意的預設值選擇：**讓沉默的結果是狀態結束。**

這與 [`03`](03-行政權預算與供給.md) 供給的「逾期即生效」方向相反，差別在誰承擔不作為的成本——供給的不作為成本由議會承擔（它隨時可以提出繼任者），例外狀態的不作為成本由行政承擔（因為它是例外）。

### 2.2 緊急命令

- 行政首長於狀態期間得發布緊急命令，具法律效力。
- 命令須於發布後 **7 日內**送議會。
- 議會得隨時以 **≥226 廢止**任一命令。
- 未於 30 日內送達，或經議會否決者，即失效。
- **狀態終止時，所有緊急命令同時失效。**
- 緊急命令不得變更憲法、基本法、選舉法規、法院組織。

因為本夾**沒有解散權**（[`02`](02-政府組成與建設性更新.md)），議會的廢止權是真的。威瑪的失敗機制正在這裡：議會廢止緊急命令，總統就解散議會，重選期間再發同一道命令。拿掉解散權，這個循環跑不起來。

### 2.3 期間不得停止的事（紅線）

- **任何選舉。** 議會的定期選舉、補選一律照常。**任期不因緊急狀態延長。**
- **[`02`](02-政府組成與建設性更新.md) 的建設性更新程序。** 議會在緊急狀態中照樣可以換掉行政首長——**宣告狀態的人不因此獲得保護。**
- 已定投票日的公民投票與修憲複決（[`06`](06-修憲與人民修改法規範.md)）。
- [`11`](11-人選更新.md) 的人選更新投票。
- 議會的集會與表決。**議會因故不能在其所在地集會時，得於任一地點集會，其決議有效。**
- 司法權的審查程序。

投票所因情勢不能開設者，得變更**投票地點**並設替代投票所，**不得變更投票日**。

**這一節沒有但書。** 一個「經議會同意得延期」的但書一旦存在，它就是整部憲法裡最先被用掉的東西。

### 2.4 不得停止的權利

生命權、不受酷刑、不受奴役、罪刑法定與不溯及既往、法律人格、公正審判的核心（獨立法院、辯護權）、思想與宗教自由，於任何狀態下均不得停止。

得暫時限制者以**列舉**為限：遷徙、集會、營業、財產之徵用（徵用須補償，並於狀態終止後 180 日內完成給付）。

**行政拘束（不經法院裁定的人身自由限制）不得逾 48 小時**，逾時須由法官裁定。

### 2.5 防常態化

> 緊急狀態存續期間及其終止後 **24 個月**內，不得以法律或基本法將該狀態下行使之行政權力改為常態權力；**違反者，該條文無效**。

排除方式：全院得以 **≥270 逐條記名並敘明理由**排除本款之適用。

針對的失敗模式很具體：緊急狀態本身合法地結束，但它創造的權力以其他名義留下來成為常態。本夾不禁止這種轉換，只要求它必須在 24 個月的冷卻之後、以基本法門檻、**逐條記名地**做——也就是必須有人具名承擔。

「**違反者該條文無效**」這六個字是這一條的全部力量。沒有它，這就只是一句還得靠別人去查有沒有人遵守的勸誡——而查的人通常就是通過那條法律的人。

## 3 狀態

| 狀態 | 怎麼走 |
|---|---|
| 宣告後 72 小時內議會未集會 | 狀態失效。首長得於議會集會後重新宣告 |
| 議會不能在所在地集會 | 於任一地點集會，決議有效（§2.3） |
| 追認票 225（差一票） | 未通過，狀態失效 |
| 累計上限屆滿仍有戰事 | 改走基本法程序 ≥270 逐次延長，每次 ≤30 日 |
| 緊急命令與現行法律牴觸 | 狀態期間命令優先；狀態終止時命令失效，法律回復適用 |
| 命令失效後已完成之處分 | 不因命令失效而當然無效，但相對人得請求救濟與補償 |
| 狀態期間屆期改選 | 照常改選。新屆須於首次集會 72 小時內重新追認，否則狀態終止 |
| 狀態期間行政首長被更新 | 新首長承接該狀態，期限與累計上限不重新起算 |
| 防常態化爭議 | 任何人於具體案件中得主張某條文違反本款，由司法權認定 |
| 24 個月內以「非該狀態下之權力」為名立法 | 是否為同一權力由司法權認定，不由立法者自我認定 |
