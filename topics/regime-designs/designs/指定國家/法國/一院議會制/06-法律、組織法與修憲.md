# 法律、組織法與修憲

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `0-基本/要求.md` | **硬性** | 提示詞模糊或未提及處可自由發揮——本檔的**組織法**這一層即依此而設（§2.0） |
| `1-優化/行政立法/共用.md` | 可選 | **議會行動保障受影響方**：(a) 受影響方否決權——議會重新表決「維持」≤總額半數即推翻該行動；或 (b) 行動通過門檻——**同意 > 議會總額半數** |
| `1-優化/行政立法/共用.md` | 可選 | **修憲分一般修憲（跨屆確認）與急迫修憲**；如：先經部分議員同意，再經人民同意 |
| `1-優化/行政立法/共用.md` | 非硬性 | 避免像美國**政策左右搖擺**，降低政策延續性與穩定性 |
| `0-基本/總體.md` | 要求 | 給「重大影響政體運作」的憲政選擇，如：各法規範修改條件 |
| `1-優化/投票.md` | 可選 | 替代現狀方式（本夾延伸到修憲複決），機制見 [`07`](07-人民修改法規範.md) §2 |
| `配置/法國/總體.md` | **硬性** | 避免政府如在第四共和、2025 倒閣潮不穩——**本檔 §2.0 的主要理由** |

### 2.0 為什麼要一個中間層

本夾的提示詞沒有要求憲法與法律之間的一層；設它是自由發揮，理由有兩條：

| 依據 | 若沒有中間位階會怎樣 |
|---|---|
| `配置/法國`：**避免政府如在第四共和、2025 倒閣潮不穩** | 政府的存續規則（建設性更新的門檻、組閣期限、供給的自動生效期間）若寫在普通法律，**同一個全院過半就能改掉建設性更新與供給的規則**——拆政府的路徑會從「找到繼任者」變成「改規則」 |
| `1-優化/行政立法/共用` 非硬性：**避免像美國政策左右搖擺** | 選舉制度與司法組織隨每屆多數翻轉，正是該條要避免的形態 |

★ **第一列是法國夾特有的，而且它是本夾整個病理論證的守門條款。** [`12`](12-反例診斷.md) 說第四共和的病是「門檻不對稱」；**若門檻本身可被普通多數調整，對稱就只是一時的**。

**代價**：多一個位階＝多一道改不動的門；急迫的技術性修正也要跨會期。本夾的處置是 §2.2 的**封閉列舉**與 §2.2.1 的**反向排除**；取捨寫進 [`15`](15-完善與自洽.md)。

## 2 三個位階（主路徑）

| 位階 | 通過條件 | 內容 |
|---|---|---|
| **憲法** | §4 兩軌 | 政體、權力配置、權利清單、修憲程序本身 |
| **組織法** | 全院 **≥240（3/5）且複數 ≥102**，且**跨一次會期** | 見 §2.2 |
| **法律** | 全院 **≥201**（同意 > 總額半數） | 其餘 |

★ 組織法即現行第五共和的 loi organique，本夾把它從「特定事項的特別程序」升為**明確的中間位階**，並提高門檻與加上跨會期要件。**這一步是自由發揮，見 §2.0。**

### 2.1 「同意 > 議會總額半數」

`1-優化/行政立法/共用.md` 可選條件的第 (b) 案。本夾採用：**法律須有 ≥201 名議員投同意票**，不是「出席過半」。

★ 效果：**突襲立法不成立。** 在一個沒有穩定立法多數的議會裡（[`03`](03-行政權預算與供給.md) §2.7），201 這個數字本身就是受影響方的保障。

**同時不採 (a) 案**（受影響方否決權）：兩案是「或」的關係，採其一即可；(a) 案需要先定義「受影響方」是誰，而在一個一院制、無第二院的架構裡沒有現成的機關可以承接。

### 2.2 組織法保留什麼（封閉列舉）

1. 選舉制度、選區劃分委員會的組織與程序。
2. 憲法法院、審計院的組織、員額、任期與選出程序。
3. 法官與檢察官的身分保障、任免與懲戒。
4. 政府與議會的組織與議事基本規則。
5. 地方層級的權限清單與財政移轉公式。
6. 緊急狀態的權力清單（[`09`](09-緊急狀態.md)）。
7. 公民投票的程序與門檻（[`07`](07-人民修改法規範.md)）。
8. 預算的編製、審議與決算程序。
9. 公務員的任用資格與中立義務。

**列舉之外的事項不得以組織法定之**；逾越者該條無效，由憲法法院宣告。

### 2.2.1 一項刻意**不**在列舉內的東西：彈性名單的躍升門檻

**躍升門檻（該區 Droop 額數的 25%）寫在憲法**，第 1 項「選舉制度」**不包含它**。

★ 理由：它是選制的關鍵旋鈕（訂高接近封閉名單、訂低接近開放名單），放進組織法就等於讓 3/5 多數轉動它，**而那批人正是名單的受益者**。**把旋鈕交給受益者，等於把黑金那條硬性交給利害關係人自行處分。**

★ **會腐壞的東西放組織法，會被自肥的東西放憲法**：選區劃分委員會的組織與程序（同第 1 項）必須跟著人口變動走，所以留在組織法。

★ 這條「不得逾越」很重要：中間位階若可以無限擴張，執政多數會把一切都塞進組織法，讓下一個多數改不動。**那正是 §2.4 要避免的另一面。**

### 2.2.2 只放一半的第二項：孔多賽的 k 與更新的 n

**憲法規定 k ≥ 3（單一席次第一輪取前幾名）、n ≥ 2（單一席次議員更新的挑戰者數）；實際的 k、n 屬選舉制度，在組織法。**

★ 降 k、降 n 只對大黨有利：k 降到 2，第二輪變兩強對決，第三名支持者的第二偏好不再決定勝負；n 降到 1，更新退回「換不換這一個人」，對現任有利。自肥只有往下的方向，所以下限放憲法。3 與 2 本身只是偏好（[`07`](07-人民修改法規範.md) §2.4），往上調不該要修憲。**降不下去，調得上來。**

### 2.3 跨會期要件

組織法須經**兩次會期**表決：

1. 第一次會期通過（全院 ≥240，**且**複數席次 ≥102，§2.5）。
2. 至少**間隔一次完整會期**。
3. 第二次會期以**相同文字**再通過（同上）。

**兩次之間該文字全文公告。** 修正即視為新案，程序重跑。

★ 理由：`1-優化/行政立法/共用.md` 非硬性點名「避免像美國政策左右搖擺」。**跨會期把「一次多數的一時衝動」與「一個多數的持續意志」分開。**

### 2.4 為什麼是 3/5 而不是 2/3

| 門檻 | 問題 |
|---|---|
| 過半（201） | 與普通法律相同，**位階不成立** |
| **3/5（240）** | **本夾採用** |
| 2/3（267） | 加上 §2.5 的複數席次要件後實質改不了；而**改不了的中間位階等於把選制與司法組織凍結在制憲當下** |

★ **一個永遠改不動的組織法會把它保護的東西變成不可問責。**

### 2.5 改規則要兩種多數

組織法與修憲的議會門檻，**全院與複數席次 170 各自達標**：

| | 全院 400 | **且**複數 170 |
|---|:--:|:--:|
| 組織法（兩次會期各一次） | ≥240（3/5） | ≥102（3/5） |
| 一般修憲（本屆與次屆各一次） | ≥240（3/5） | ≥102（3/5） |
| 急迫修憲 | ≥267（2/3） | ≥114（2/3） |

**為什麼。** 單一席次的 top-3 孔多賽會把中位陣營放大：生態模型下，中間陣營以約 22% 的區域第一偏好拿到單一 218／230、全院 256——**單獨超過 3/5**（[`14`](14-預期政治生態.md) §9.1）。它是政府穩定的來源，不該拿掉；但選舉制度、司法組織、組閣規則這些**規則**，不該由一個被選制放大的陣營獨自改寫。複數席次用聖拉古、席次跟得票走，中間陣營在那裡是 38／170。

法律不受影響：全院 ≥201，政府的立法照常。

## 3 法律的其他規則

| 項目 | 規則 |
|---|---|
| 提案 | 議員 20 人；或政府 |
| 表決者 | **全院 400**（單一與複數席次一律參與） |
| 首長否決權 | **無**——首長由議會產生 |
| 公布 | 首長於 15 日內公布；逾期由議長公布 |
| 事前違憲審查 | 議員 60 人、或首長，得於公布前聲請憲法法院審查 |
| 事後違憲審查 | 任何法院於審理中得移送；人民得於窮盡救濟後聲請（[`08`](08-司法權與憲法法院.md)） |
| **政府的立法命令** | 政府得依法律授權發布命令，**授權須逐項具體、期限不得逾 2 年**；不得概括授權 |

★ 最後一列是對現行第 38 條（ordonnances）的收緊。現行制度容許政府請求議會概括授權在一段期間內以命令規範某領域；**本夾要求逐項具體且限期兩年**，理由是概括授權在本夾等於把本該由全院立法的事交給行政命令。

★ **本夾也取消現行第 34 條的「法律保留清單」**（loi/règlement 的事項二分）。理由：那條的設計目的是限制議會的立法範圍以扶植行政權，而本夾的行政權來自議會，不需要被扶植。**議會得就任何事項立法。**

## 4 修憲：兩軌（主路徑）

`1-優化/行政立法/共用.md` 可選條件：分**一般修憲（跨屆確認）**與**急迫修憲**。本夾採用。

### 4.1 一般修憲：跨屆確認

| 步驟 | 條件 |
|---|---|
| 1. 提案 | 議員 **80 人**或政府 |
| 2. 本屆通過 | 全院 **≥240（3/5）且複數 ≥102**（§2.5） |
| 3. **跨屆** | 須經一次**定期改選** |
| 4. 次屆確認 | 新屆全院 **≥240 且複數 ≥102**，**文字須完全相同** |
| 5. 人民複決 | 替代現狀方式（[`07`](07-人民修改法規範.md) §2），n＝1：該條項與維持現狀兩兩對決的支持票 **≥ 選舉人總額 25%**，且勝過維持現狀 |

**逐條分別複決。** 一次修憲案含數條者，各條分別計票、分別生效。

### 4.2 急迫修憲

| 步驟 | 條件 |
|---|---|
| 1. 提案 | 議員 **120 人**或政府 |
| 2. 議會通過 | 全院 **≥267（2/3）且複數 ≥114**（§2.5） |
| 3. 人民複決 | 同上，地板 **25%**（與一般軌相同） |
| 4. **不跨屆** | 得於同屆完成 |

★ 兩軌的差別是**時間換門檻**：急迫軌省掉一次改選，代價是議會門檻由 3/5 升到 2/3。複決地板兩軌相同：地板防的是低投票率下的少數，這件事與走哪一軌無關；省掉的那次改選是議會端的檢查，所以代價也放在議會端。

### 4.3 為什麼有 25% 的地板

★ 純多數決的複決在低投票率下可被小幅動員拿下，而修憲是留得下來的東西。地板同時擋住兩件事：**低投票率下的突襲**，以及**杯葛式的低投票率策略**。

**法國自己的例子。** 2000 年的五年任期修憲公投：贊成 73.2%，但投票率只有 30.2%——贊成票約 741 萬，占選舉人約 3,994 萬的 **18.5%**。這正是地板要擋的形狀：一個多數人不在乎、也沒出來投的修憲，不該因為出來投的人一面倒就改掉憲法。

反方向的檢查：2005 年歐洲憲法條約公投，反對票約 1,545 萬、贊成票約 1,280 萬，分別約占選舉人 37% 與 31%，任何一方都過 25%——真的動員起來的議題過得去。

**為什麼比法律公投的 20% 高一級。** 位階照議會端排：議會改法律要 201、改組織法與憲法要 240；人民端也一樣，法律 20%，組織法與憲法 25%（[`07`](07-人民修改法規範.md) §2.3）。否則公投會變成改上位法比議會便宜的繞道。

★ **25% 是落點，不是唯一解**：在「擋得住低投票率的修憲」與「不至於實質凍結」之間。

### 4.4 不得修改的東西

**共和政體、定期改選、普選權、修憲程序本身的門檻**不得以修憲降低。

★ 現行第 89 條末項只保護「共和政體」。本夾加上後三項，理由是：**只保護政體名稱而不保護產生程序，等於允許以修憲取消選舉而保留「共和國」三個字。**

## 5 狀態

| 狀態 | 怎麼走 |
|---|---|
| 法律同意票 200 | **不通過**（須 > 總額半數，即 ≥201） |
| 組織法第二次會期文字有修正 | 視為新案，程序重跑 |
| 組織法逾越 §2.2 列舉 | 逾越之條無效，憲法法院宣告 |
| 修憲案跨屆時該屆提前結束 | 本夾**無解散制度**，屆期固定，不生此問題 |
| 修憲複決同意多於不同意但未達地板 | **不通過**；同一案 2 年內不得再提 |
| 修憲案含多條，部分通過 | **通過之條生效**，其餘不生效 |
| 政府命令逾越授權 | 該命令無效；任何法院得逕行不適用 |
| 授權期限屆滿未完成立法 | 授權失效，已發布之命令須於 6 個月內經法律追認，否則失效 |
| 首長逾期不公布法律 | 議長公布 |
