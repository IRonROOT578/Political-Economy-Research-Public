# 希臘：一院議會制

本憲政設計最新更新：2026-11-11

## 一句話

國會 **220＝單一 132（top-3 孔多賽）＋複數 88（彈性名單、無門檻、**無多數紅利**）**；首長全院排名投票選出（棄權不計）、30 日內選不出由孔多賽第一名逕行就任；**無解散權、沒有探索授權與看守政府**；**選舉法列組織法（兩種多數）、下屆生效**；總統直選、削權、選不出總統不再解散國會；公投只能由人民或國會少數發動、公告 ≥90 日；**部長刑責回到一般司法**；新設**憲法法院** 12 人三組；**情報局改隸國會監督**。

## 三個最容易讀錯的地方

**一、ND 2023-06 不需要紅利也單獨過半。** 148／220：右派小黨的選民把 ND 排在左派前，ND 是孔多賽贏家。本夾的放大比紅利更多，但 ND **改不了選舉法**（[`05`](05-法規位階與修憲.md)）。

**二、2023-05 那次「組不出政府」在本夾不會發生。** ND＋PASOK 158，或 ND 30 日後逕行就任（[`02`](02-政府組成與建設性更新.md)）。

**三、2026 民調下首長是 PASOK。** ND 仍是第一偏好最大黨，但右派分裂、ELAS 與 PASOK 的選民互相支持（[`估計結果.md`](估計結果.md) §2）。這個結論對假設敏感。

- **資料只到 59 選區**：內政部網站擋自動存取（[`14`](14-近期大選重算.md) §1）。
