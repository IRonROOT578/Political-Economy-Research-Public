# 預算與供給

## 1 本檔繼承

| 來源 | 位階 | 本檔吃什麼 |
|---|---|---|
| `1-優化/財政.md` | 非硬性 | **信任供給合一**；議會制：建設性不信任＋**供給自動生效** |
| `1-優化/行政立法/共用.md` | 非硬性 | 避免預算不決、停擺 |

## 2 規則

| 項目 | 規則 |
|---|---|
| 規劃保障的供給 | 政策裁量性資本門、預備金、行政機關經常門、列名政策計畫（封閉列舉）；**不含**法定義務支出、歲入、稅制、地方公式化移轉 |
| 自動生效 | 預算日（9 月第三個星期二，沿用）送達後 **20 個開會日**內未通過建設性更新（≥76），供給生效 |
| 國會的修正 | **得刪不得增**；刪減案要政府同意，不同意以原案生效 |
| 非供給歲出 | 全院 ≥76，得刪不得增；60 日未決沿用上年度 |
| 歲入、稅制 | 全院 ≥76 |
| 財政規則 | 組織法；現行的「預算規則」由獨立的國務委員會（Raad van State）財政監督部門每年公告是否遵守 |
| 審計院 | 保留；院長與委員改由三組選出（全院 STV、複數席次 STV、司法職業名冊祕密 STV） |

★ 現行荷蘭的預算很少卡住，但**參議院可以否決預算章節**，少數政府要在兩院各找多數。本夾廢參議院、供給自動生效，少數政府至少能執行預算。
