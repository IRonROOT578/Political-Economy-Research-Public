# 完善與自洽

## 1 條件的落點

| 條件 | 位階 | 落點 |
|---|---|---|
| 不用電子計票 | **硬性** | 維持紙本、人工計票 |
| 首長由某些議員選出與更新 | **硬性** | [`02`](02-政府組成與建設性更新.md)：全院 150 |
| 兩院議會制兩院都直選 | `f023dc8` 起只約束台灣，不適用本夾 | 不選兩院；廢參議院的理由是它作為否決點（病 1–3） |
| 法官不當記名投票的投票權人 | **硬性** | 法官互選祕密；審判法官不入名冊 |
| 開放名單黑金 | **硬性** | 彈性名單、M≤16（荷蘭現行的 25% 躍升門檻沿用） |
| 人選不能被杯葛 | **硬性** | 定日改選、缺席票作廢、60 日預設值 |
| 不得把提示詞當預期生態 | **硬性** | [`12`](12-預期政治生態.md) §5：兩處不合，兩項設計因此加強 |
| 信任供給合一、建設性更新、供給自動生效 | 非硬性 | [`02`](02-政府組成與建設性更新.md)、[`03`](03-預算與供給.md) |
| 決選與單輪同日 | 非硬性 | 單一第二輪與名單同日 |
| 從中間向兩側 | 非硬性 | [`07`](07-司法權與檢察.md) |
| 修憲兩軌 | 可選 | [`05`](05-憲法與修憲.md) §4 |

## 2 張力

| # | 張力 | 處置 |
|:--:|---|---|
| 1 | **向心 vs 代表**：PVV、GL-PvdA 的代表大幅縮小 | 名單層＋改規則要複數 3/5＋矯正型公投 |
| 2 | **一院 vs 「再想一次」** | 憲法法院；組織法兩種多數 |
| 3 | **君主 vs 民主正當性** | 國王所有權力形式化；法律只要求公布 |

## 3 自洽檢查

| 檢查 | 結果 |
|---|---|
| 是否存在「沒有政府」或「看守政府」 | 否 |
| 一黨退出聯盟會不會倒閣 | 否 |
| 是否存在「沒有預算」 | 否 |
| 一群人能否單獨改規則 | 只有同時過全院 90 與複數 36 |
| 法院能否審法律 | 能（憲法法院） |

## 4 本夾不宣稱能做到的事

- **不宣稱兩端政黨的選民會接受**新制下的代表縮小。
- **不宣稱 CDA 會是首長**；它是模型在大多數假設下的結果。
- **不宣稱 150、[8,16]、30 日是唯一解**。
- **完全不論轉型可行性**。
