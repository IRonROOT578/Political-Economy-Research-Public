讀法：先 `0-基本/`。正式與測試再疊 `1-優化/`、[`配置/台灣/基本/`](配置/台灣/基本/)、[`配置/台灣/優化/`](配置/台灣/優化/)、[`配置/個人偏好/`](配置/個人偏好/)。惡搞不疊 `1-優化/`，改疊台灣基本與 [`配置/惡搞/`](配置/惡搞/)。總統制測試再依對應表「用 預提行政權預算」讀 [`1-優化/財政.md`](1-優化/財政.md) 的總統制可選段。中國／俄羅斯／法國各疊該國配置。子檔覆寫父檔。對應表見 [`各設計對應.md`](各設計對應.md)。

`其他三權/` 在來源裡是分開的 `總體.md`／`司法權.md`，公庫保持同一分檔。

現行提示詞要點：

- 對應表：正式總統制＝`0-基本`＋`1-優化`＋台灣基本／優化＋個人偏好，**不用預提**；測試同層，**用預提**；正式議會制＝同層；惡搞＝`0-基本`＋台灣基本＋`配置/惡搞`。
- 中國／俄羅斯／法國各＝`0-基本`＋`1-優化`＋該國配置，選一政體。中國預期政治生態可用意識形態而非政黨表示議會分布。
- 身分政治在 [`配置/個人偏好/行政立法/共用.md`](配置/個人偏好/行政立法/共用.md)，不是雜項。
- 「信任供給合一」與總統制預提段在 [`1-優化/財政.md`](1-優化/財政.md)。`配置/雜項/` 不在本庫。
