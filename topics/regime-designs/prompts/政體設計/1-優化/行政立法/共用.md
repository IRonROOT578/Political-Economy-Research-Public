# 非硬性條件(達成程度越高越加分) 
1. 避免
    1. 像美國 政策左右搖擺 -> 降低政策延續性與穩定性 -> 不利投資、不利「看不見的手」運作。
    2. 像台美韓 社會二極化、內耗 -> 降低敵國在國內「拉一打一、滲透」的難度。
    3. 像美國 兩大黨對立嚴重、難達成共識 -> 預算案不決 -> 政府停擺。
說明：我認為以上主要由 FPTP 造成，向心型選制(如: 孔多賽完成法)比 FPTP 更好；FPTP 會激勵候選人及其背後媒體鞏固基本盤、「發表激進言論而激怒敵對陣營選民」，加劇社會二極化。

# 可參考、可選、可調整條件(不加扣分)

    1. 受影響方有否決權:議會重新表決「維持」<=議會總額半數，就推翻議會行動；防止突擊立法。
    或
    2. 行動通過門檻:同意>議會總額半數，議會才能通過該行動 。

程序，如:先經 部分議員 同意，再經人民同意。
