# 政體設計

**三十六夾憲政設計**，分三組：指定政體（台灣六夾）、指定國家（中國／俄羅斯／南韓）、其他（含法國與多國一院／兩院設計；秘魯、智利各有總統制與議會制）。提示詞抄本在 [`prompts/政體設計/`](prompts/政體設計/)，資料夾名 `其他權` 改成 `其他三權`。配置層資料夾名是 `2-配置`。

## 活設計

| 分組 | 夾 |
|------|-----|
| [`designs/指定政體/`](designs/指定政體/) | 台灣：一院議會制、兩院議會制、一院總統制、一院總統制-測試、兩個惡搞 |
| [`designs/指定國家/`](designs/指定國家/) | 中國一院議會制；俄羅斯一院總統制；南韓一院總統制 |
| [`designs/其他/`](designs/其他/) | 以色列、保加利亞、匈牙利、土耳其、奧地利、巴西、希臘、德國、愛沙尼亞、拉脫維亞、捷克、斯洛伐克、新加坡、日本、智利、法國、波蘭、秘魯、紐西蘭、丹麥、羅馬尼亞、義大利、英國、荷蘭、西班牙 |

矩陣與一句話見 [`designs/README.md`](designs/README.md)。**沒有議會制測試夾。**

單席孔多塞的計票細節見主題 [two-round-pairwise-runoff](../two-round-pairwise-runoff/)。
