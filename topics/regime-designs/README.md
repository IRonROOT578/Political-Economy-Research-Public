# 政體設計

**二十六套憲政設計**，分三組：指定政體（台灣六夾）、指定國家（南韓／俄羅斯／法國／中國）、其他（十六國）。提示詞抄本在 [`prompts/政體設計/`](prompts/政體設計/)，資料夾名 `其他權` 改成 `其他三權`。配置層資料夾名是 `2-配置`。

## 活設計

| 分組 | 夾 |
|------|-----|
| [`designs/指定政體/`](designs/指定政體/) | 台灣：一院議會制、兩院議會制、一院總統制、一院總統制-測試、兩個惡搞 |
| [`designs/指定國家/`](designs/指定國家/) | 南韓一院總統制；俄羅斯一院總統制；法國一院議會制；中國一院議會制 |
| [`designs/其他/`](designs/其他/) | 以色列、保加利亞、土耳其、巴西、捷克、新加坡、日本、羅馬尼亞、義大利、英國、荷蘭、西班牙、紐西蘭、奧地利、德國、丹麥 |

矩陣與一句話見 [`designs/README.md`](designs/README.md)。**沒有議會制測試夾。**
