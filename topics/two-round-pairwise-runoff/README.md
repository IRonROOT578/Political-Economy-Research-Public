# 兩輪兩兩對決

台灣**單一選區、選出一人**、人工計票的兩輪直接選舉。第一輪取前 **k** 名（人少可跳過）；第二輪對晉級者完整排序，兩兩對決選出一人。

對外用語用「兩兩對決／兩兩對決贏家」，不主打「孔多賽贏家」。

## 先看這裡

主稿是 **第一輪必須 SNTV** 的那一套。k＝3 與 k＝4 **並列**：

- k＝3：[`outputs/第一輪為SNTV的兩輪投票制/k3/選制.md`](outputs/第一輪為SNTV的兩輪投票制/k3/選制.md)
- k＝4：[`outputs/第一輪為SNTV的兩輪投票制/k4/選制.md`](outputs/第一輪為SNTV的兩輪投票制/k4/選制.md)
- 提示詞：[`提示詞/SNTV套.md`](提示詞/SNTV套.md)

人少用組合格、人多選 1 的另一套較低優先，只作對照：[`outputs/第一輪有非SNTV的兩輪投票制-k4/`](outputs/第一輪有非SNTV的兩輪投票制-k4/)。
