# 第二輪計票（k＝3・九選項另版）

**另版。** 預設六欄：[`../第二輪/計票.md`](../第二輪/計票.md)。選制 [`選制.md`](選制.md)。

第一輪規則與預設相同（n>3 取前 3；n≤3 跳過）。本檔只寫**本版第二輪**。

## 1. 票面九種（m＝3）

| 選項 | 意思 |
|:----:|------|
| ① | 完整 `1>2>3` |
| ② | 完整 `1>3>2` |
| ③ | 完整 `2>1>3` |
| ④ | 完整 `2>3>1` |
| ⑤ | 完整 `3>1>2` |
| ⑥ | 完整 `3>2>1` |
| ⑦ | **只選 1** |
| ⑧ | **只選 2** |
| ⑨ | **只選 3** |

m＝2：只印 `1>2`／`2>1`。m＝1：等額。

## 2. 兩兩對決（9 欄）

完整六欄：\(n_{123}, n_{132}, n_{213}, n_{231}, n_{312}, n_{321}\)。  
只選一人三欄：\(b_1, b_2, b_3\)（⑦⑧⑨）。

**只選 \(i\)：** \(i\) 排在另外兩人之前；**另外兩人互相比**那場這張票**不表態**。

| 對決 | 加總 |
|------|------|
| 1 vs 2 | 1 勝：\(n_{123}+n_{132}+n_{312}+b_1\)；2 勝：\(n_{213}+n_{231}+n_{321}+b_2\)（\(b_3\) 不進） |
| 1 vs 3 | 1 勝：\(n_{123}+n_{132}+n_{213}+b_1\)；3 勝：\(n_{231}+n_{312}+n_{321}+b_3\)（\(b_2\) 不進） |
| 2 vs 3 | 2 勝：\(n_{123}+n_{213}+n_{231}+b_2\)；3 勝：\(n_{132}+n_{312}+n_{321}+b_3\)（\(b_1\) 不進） |

某人兩場都勝 → **兩兩對決贏家當選**。否則不採認勝差最小的一場（與預設完成法相同）。

有只選一人票時，三場「參與票數」可以不同。勝差仍＝該場勝方票 − 負方票。

## 4. 對外一句話

> 決選只圈一格：完整順序六種，或「只選這一人」三種，共九格。  
> 有人對其他每位都贏 → **兩兩對決贏家**當選。  
> 圈「只選某人」：這人對另外兩人都算贏；另外兩人互相比的那場，這張票不表態。
