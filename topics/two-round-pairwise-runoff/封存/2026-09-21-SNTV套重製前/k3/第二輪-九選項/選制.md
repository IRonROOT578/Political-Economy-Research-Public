# 第二輪選制（k＝3・九選項另版）

**另版。** 預設六格見 [`../第二輪/選制.md`](../第二輪/選制.md)。目錄 [`README.md`](README.md)。票面 [`選票設計.md`](選票設計.md)。公式 [`計票.md`](計票.md)。例子 [`票型分布例子.md`](票型分布例子.md)。

決選你**只圈一格**：可以圈一種**完整喜歡順序**（三人六種），也可以圈「**只選這一人**」（三人三種）。滿額共 **九格**。若有人對其他每位對手都贏，就是**兩兩對決贏家**，當選。沒有這種人，就**不採認贏最勉強的那一場**，其餘照算。

| 項目 | 規則 |
|------|------|
| 第二輪 | **必定舉行**（n＝1 除外） |
| 選票 | 滿額 **①–⑨**：①–⑥＝完整排序；⑦–⑨＝只選一人。多種排版見 [`選票樣式.md`](選票樣式.md) |
| 計票 | 先兩兩對決；有兩兩對決贏家即當選；否則**不採認最接近的一場** |
| 「只選一人」怎麼算 | 該人在兩場對決都算勝；**另外兩人互相比**的那一場，這張票**不表態**（[`計票.md`](計票.md)） |

n＝2 時改印 2 種（完整 `1>2`／`2>1`；不必另印「只選一人」）。單選 9≤24。

不印「只排兩人、第三人從缺」那六種。見 [`不採用只排兩人.md`](不採用只排兩人.md)。

**有兩兩對決贏家：** 直接當選。  
**三人循環：** 不採認勝差最小的那場（三人下＝Ranked Pairs／minimax 等價）。

不用純 IRV。見 [`../為何優於FPTP與top-2.md`](../為何優於FPTP與top-2.md)。
