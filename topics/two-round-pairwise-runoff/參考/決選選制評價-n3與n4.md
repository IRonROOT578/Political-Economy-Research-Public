# 決選可用選制評價（n＝3 與 n＝4）

> 本檔是**選制評價**，不立法，也不是現行 `outputs/` 定稿。  
> 本文件只評價**第二輪**在決選人數為 3 或 4 時，同一張「單選完整排序」票能怎麼計。  
> k＝3 規則見 [`../outputs/第一輪為SNTV的兩輪投票制/k3/第二輪/選制.md`](../outputs/第一輪為SNTV的兩輪投票制/k3/第二輪/選制.md)、[`../outputs/第一輪為SNTV的兩輪投票制/k3/第二輪/計票.md`](../outputs/第一輪為SNTV的兩輪投票制/k3/第二輪/計票.md)；票型例子 [`../outputs/第一輪為SNTV的兩輪投票制/k3/第二輪/票型分布例子.md`](../outputs/第一輪為SNTV的兩輪投票制/k3/第二輪/票型分布例子.md)。k＝4 見 [`../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/選制.md`](../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/選制.md)、[`../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/計票.md`](../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/計票.md)；票型例子 [`../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/票型分布例子.md`](../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/票型分布例子.md)；組合格套第二輪（較低優先）見 [`../outputs/第一輪有非SNTV的兩輪投票制-k4/第二輪/選制與選票設計.md`](../outputs/第一輪有非SNTV的兩輪投票制-k4/第二輪/選制與選票設計.md)。刷兩位快照已於 2026-08-30 清掉。  
> 此處 **n**＝第二輪實際人數（規則文檔的 **m**）。誰進決選見各套第一輪。  
> 檢索見 [`../sources/第二輪.md`](../sources/第二輪.md)。

票面已是 n! 種嚴格排序擇一，故下列選制都「可用」（不必改票）。核可／計分制（贊成投票、範圍投票）要另印票，**不列入**。

## 0. 評價尺度

| 尺度 | 問什麼 |
|------|--------|
| 兩兩對決 | 有人對每位對手都贏時，會不會當選 |
| 策略 | 是否明顯好過 FPTP、決選內再 top-2（硬性條件） |
| 克隆 | 極相似的人互搶票會不會改誰贏 |
| n＝4 是否繼承 n＝3 | 四人規則限到三人時，是否還是同一套 |
| 面向大眾 | 能否用「兩兩對決贏家」講完，不必先教洋名 |
| 紙筆 | 6 欄／24 欄人工開票是否可行 |

對照文獻：GAT 2016 Table 2（Politbarometer 策略抗性 R；三人場）；Wikipedia／condorcet.vote 準則表；Munger 2022；Brandt et al. 2025；Holliday et al. 2025；Foley & Maskin 2025。

GAT 的 R 愈高愈抗策略。該表：**plurality .7749**、**Borda .6226**、**minimax .8461**、**Hare／Condorcet–Hare .9804**。三人時 minimax＝Ranked Pairs＝Schulze＝Kemeny。GAT **沒有**把兩輪決選單列；top-2 另用 Foley、spoiler 文獻與本庫模擬。

## 1. n＝3：各選制

三人循環時，多數**對決型**完成法選出同一人（去掉勝差最小的一場）。**淘汰型**（IRV、Benham 在循環時）走第一志願，可以選出另一人。

| 選制 | 兩兩對決贏家 | 相對 FPTP、top-2 | 克隆獨立 | 大眾說明 | 紙筆 | 評 |
|------|:------------:|:----------------:|:--------:|----------|:----:|----|
| 決選內 FPTP（只看第一志願） | 否 | **否**（就是 FPTP） | 否 | 最熟 | 易 | 淘汰 |
| 決選內 top-2 | 否（中間人可被擠） | **否**（就是 top-2） | 否 | 熟 | 易 | 淘汰 |
| Borda | 否 | **否**（R=.6226 差於 FPTP） | 否 | 「名次加分」 | 易 | 淘汰 |
| 純排序複選（IRV／Hare） | 否（中間人擠壓） | 是（R=.9804） | 是（禁並列時） | 「第一志願不夠看下一志願」——**不能**主打兩兩對決贏家 | 易 | 策略強，但會淘汰全勝的人 |
| Copeland（贏幾場） | 是 | 優於 FPTP | 否 | 循環時三人皆 1 勝，說不清 | 易 | 僵局無用 |
| **去掉最弱一場**（＝RP／Schulze／Minimax／Kemeny） | 是 | 是（R=.8461） | 三人時與 RP 同結果 | **「兩兩對決贏家；卡住就不採認最接近的一場」** | 易 | **法定** |
| Benham／Condorcet–Hare | 是 | 是（R=.9804；循環時＝IRV） | 是 | 有全勝就停；循環則淘汰第一志願最低 | 易 | 仍是完成法；循環時**不必**與去掉最弱同一人 |

**n＝3 小結：** 非孔多賽裡，只有純 IRV 策略數字高於去掉最弱一場，但會在中間人擠壓時選錯兩兩對決贏家（Foley；規則文檔舉例丙的結構）。Borda、決選內 FPTP／top-2 連硬性條件都過不了。完成法族在三人無平手下**重合**，法定用最好講的那句：不採認最接近的一場。

當選舉例見 [`k3/第二輪/票型分布例子.md`](../outputs/第一輪為SNTV的兩輪投票制/k3/第二輪/票型分布例子.md) 例一（有全勝→候選人 1）、例四（循環→候選人 2）。同票若改用 Benham／IRV 淘汰第一志願最低者，例四會選候選人 3——這是完成法族內分叉，不是「非孔多賽更好」。

## 2. n＝4：各選制

四人起，對決型完成法**不再**保證同一人。Munger 所引 Schulze 2003 三十票：Ranked Pairs 選 D（候選人 4），Beatpath 選 A（候選人 1）。

| 選制 | 兩兩對決贏家 | 相對 FPTP、top-2 | 克隆獨立 | LIIA | n＝3 時是否同一套 | 大眾說明 | 紙筆 | 評 |
|------|:------------:|:----------------:|:--------:|:----:|-------------------|----------|:----:|----|
| 決選內 FPTP | 否 | **否** | 否 | 否 | 仍是 FPTP | 熟 | 易 | 淘汰 |
| 決選內 top-2 | 否 | **否** | 否 | 否 | 三人時＝淘汰第一志願最低再比兩人 | 熟 | 易 | 淘汰 |
| Borda | 否 | **否** | 否 | 否 | 同一套加分 | 加分 | 易 | 淘汰 |
| 純 IRV | 否 | 是 | 是 | 否 | 同一套淘汰 | 排序複選 | 中 | 策略強；Foley：top-four+IRV 仍可能淘汰全勝者 |
| Minimax | 是 | 是 | **否** | 否 | 三人時＝去掉最弱 | 「誰輸得最不慘」 | 易 | 四人準則弱，不作主規則 |
| Kemeny–Young | 是 | 是 | **否** | 是 | 三人時＝去掉最弱 | 「24 種總排序挑最貼對決的」 | n＝4 可窮舉 | 審計備援 |
| Schulze（beatpath） | 是 | 是 | 是 | **否** | 三人時＝去掉最弱 | 「最強路徑」難講、難手驗 | 電腦 | 可複核，不作文宣 |
| Copeland | 是 | 優於 FPTP | 否 | 否 | 循環時多人同勝場 | 贏幾場 | 易 | 僵局說不清 |
| Benham／Smith–IRV | 是 | 是（IRV 族） | 是 | 否 | 三人循環時＝IRV，**≠**去掉最弱 | 全勝就停，否則淘汰第一志願最低 | 中 | 完成法另一支；**不是**去掉最弱的延伸 |
| **Ranked Pairs（由強到弱鎖定）** | 是 | 是；操弄 NP-hard | **是** | **是** | **是**：三人＝去掉最弱 | **「兩兩對決贏家；沒有就先採認贏最多的對決」** | 四人可行 | **法定** |

**n＝4 小結：** 要同時（1）保住兩兩對決贏家、（2）好過 FPTP／top-2、（3）克隆獨立、（4）四人仍接得上三人那句「不採認最弱一場」，只剩 **Ranked Pairs**（與 Schulze 在（4）上：三人同、四人可分叉；Schulze 無 LIIA、路徑難講）。Kemeny 四人算得完但不抗克隆。Benham 策略數字可能更高，但四人規則**不是**三人去掉最弱的延伸。

當選舉例見 [`k4/第二輪/票型分布例子.md`](../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/票型分布例子.md) 例一（全勝→候選人 1）、例四（鎖定→候選人 4；同票 Schulze 選 1）。

## 3. n＝4 是不是 n＝3 的延伸？

分選制看，不要混成一句「四人都繼承三人」。

| 選制 | 四人是否繼承三人 |
|------|------------------|
| FPTP、Borda、IRV、Benham | **同一套規則**加候選人，不是「三人完成法」的延伸 |
| Minimax、Kemeny、Schulze、RP | 三人時**同一人**（去掉最弱一場） |
| **只有 Ranked Pairs** | 四人操作＝把三人「先採認強的對決、不採最弱那場」寫成由強到弱鎖定；限回三人時**逐步等價** |
| Schulze／Minimax | 三人等價於 RP；四人**不必**再等價，故不能說「沿用三人隨便哪種完成法」 |

共同骨架兩邊都有：先問兩兩對決贏家。有人時，3 人與 4 人是同一規則（對決場數 3→6）。

卡住時：三人可以只唸「去掉一場」；四人**不能**只去掉一場（六場去掉一場不一定留下唯一第一名）。法定把四人寫成鎖定法，並規定實際只有 3 人決選時改走三人規則——此時與鎖定法等價。

## 4. 對照總表（給立法者）

| | n＝3 法定 | n＝4 法定 | 不要用 |
|--|-----------|-----------|--------|
| 有兩兩對決贏家 | 當選 | 當選 | — |
| 無人全勝 | 不採認最接近的一場 | 由強到弱鎖定（RP） | 開票後改 Schulze／Kemeny／Benham |
| 對外主詞 | 兩兩對決贏家 | 兩兩對決贏家 | 孔多賽贏家 |
| 為何不改 IRV | 會淘汰全勝者 | 同左 | 策略數字高不能抵銷 |
| 為何不改 Benham | 循環時≠去掉最弱；仍是完成法，不另立法 | 不是 RP 的延伸 | 與定稿分叉時須標明，本設計不採用 |

硬性條件（策略優於 FPTP、top-2）：法定兩種都過。不以「R 必須高過 IRV」為條件。

## 6. 第一輪若是 SNTV 取四人，第二輪還要用 RP 嗎

問的是：[`../outputs/第一輪為SNTV的兩輪投票制/k4/第一輪/`](../outputs/第一輪為SNTV的兩輪投票制/k4/第一輪/) 用每人一票取前四，第二輪還能不能沿用 [`../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/`](../outputs/第一輪為SNTV的兩輪投票制/k4/第二輪/) 的兩兩對決＋由強到弱鎖定。

分兩層，不要混成一句「SNTV＋RP 是不是整套最佳」。

### 6.1 第一輪已經把人擋在門外：RP 救不回來

SNTV 只看第一志願。等距一維模擬（2000 場）：全體兩兩對決贏家進前四的比例，n＝5／6／7 只有 0.72／0.64／0.54；組合格選 4／3／5 則是 1.00。見 [`每人挑幾人-n5至n7.md`](每人挑幾人-n5至n7.md)。

沒進決選的人，第二輪用 RP、Schulze、IRV 都選不到。這是短名單的洞，不是完成法選錯。要補這層只能改第一輪（組合格、核可、刷票），不能靠把 RP 換成別的。

### 6.2 已進門的四人：SNTV 反而更需要 RP，不是更該改 IRV

票仍是 24 種完整排序擇一，§2 的比較表不因「這四人怎麼挑出來」而改：

| 第二輪 | 四人中的兩兩對決贏家 | 相對 FPTP／top-2 | 克隆獨立 | 接得上三人「去掉最弱」 | 大眾說明 |
|--------|:--------------------:|:----------------:|:--------:|:----------------------:|----------|
| **RP（由強到弱鎖定）** | 必當選 | 是 | 是 | **是** | 贏得多的對決先算數 |
| Schulze | 必當選 | 是 | 是 | 三人同、四人可分叉 | 路徑難講 |
| 純 IRV | **否** | 是 | 是 | 同一套淘汰 | 不能主打兩兩對決 |
| Benham | 必當選 | 是（R 可能更高） | 是 | 循環時＝IRV，≠去掉最弱 | 全勝才停 |
| 決選內 FPTP／top-2／Borda | 否 | **否** | 否 | — | 淘汰 |

FairVote 的搭配是 SNTV 初選＋**IRV** 決選。Foley：Alaska 式 top-four＋IRV，第一偏好第三名仍可能是四人裡的兩兩對決贏家，IRV 會先淘汰他。SNTV 短名單本身就偏第一志願高的人；四人裡真正兩兩都能贏的，往往第一志願不是最高。第二輪若再走 IRV，等於把同一偏差用兩次。RP 問的是四人內部誰對每位都贏，剛好補這層。

Benham 有全勝時與 RP 同一人；卡住才改淘汰第一志願最低——那一步踩的就是 SNTV 剛造出來的偏差。GAT 的 R 高，不能抵銷「循環時改選另一人、且不再是去掉最弱的延伸」。

Schulze 四人可與 RP 分叉（Munger：RP 選 D、Beatpath 選 A）。紙筆、LIIA、「由強到弱鎖定」這句，不因第一輪是 SNTV 而變。

孔多賽族弱點是 burying。SNTV 晉級者較像陣營第一志願龍頭，決選裡往下埋對手的誘因可能比組合格短名單高。這是真代價。硬性條件要比過的是 FPTP 與 top-2，不是要比過 IRV；Hare 較不誘發 burying，但會淘汰全勝者。

### 6.3 結論

| 問題 | 答案 |
|------|------|
| 在 SNTV 取出的四人裡，RP 是不是最好的第二輪 | **是**（相對本設計的尺度：保住四人中的兩兩對決贏家、好過 FPTP／top-2、克隆獨立、接三人規則、好講好唱） |
| SNTV＋RP 是不是整套最佳 | **否**。短名單常缺全體兩兩對決贏家；那一層組合格分支較好 |
| 該不該改成 FairVote 的 IRV 決選 | **不該**。SNTV 之後更不該再用第一志願淘汰 |

兩套各有自己的第二輪，完成法相同。差在誰進得了這四人。
