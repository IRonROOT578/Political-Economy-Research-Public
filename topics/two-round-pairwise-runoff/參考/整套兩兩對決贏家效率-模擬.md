# 整套選出兩兩對決贏家的比例（模擬，2026-09-21）

**分析，不是主稿。** 主稿引用處：[`../outputs/第一輪為SNTV的兩輪投票制/共用/為何優於FPTP與top-2.md`](../outputs/第一輪為SNTV的兩輪投票制/共用/為何優於FPTP與top-2.md)。

## 問什麼

硬性條件要「整體表達民意能力比 FPTP、top-2 runoff 好」。本檔量一個可比較的指標：**當全體候選人裡有兩兩對決贏家（對其他每位都贏的人）時，整套選制選到他的比例**。

| 選制 | 怎麼選 |
|------|--------|
| FPTP | 第一志願最多者當選 |
| Top-2 | 第一志願前二再比一場 |
| SNTV 取前 3＋兩兩對決 | 本主題 k＝3 兩套（六選項、九選項，真誠完整排序時相同） |
| SNTV 取前 4＋兩兩對決 | 本主題 k＝4（二十四選項） |

第二輪用兩兩對決，只要全體兩兩對決贏家**進得了決選**就一定選到他（他在決選中仍對每位都贏）。所以後兩列＝「全體兩兩對決贏家進前 k」的比例。

## 模型

- 候選人與選民位置都取自標準常態分布（1 維／2 維），選民依距離排序，**全部真誠投票**。
- 選民 501 人；n＝4–7 各 1500 場、n＝8／10 各 800 場。只統計有兩兩對決贏家的場次。
- n≤k 時跳過第一輪，比例為 100%。

## 讀法與限制

- **每一列都是 FPTP < Top-2 < 前 3 < 前 4。** 這是硬性條件要的方向。
- **洞在第一輪。** 第一輪只看第一志願，n 愈大，全體兩兩對決贏家被擋在門外的機率愈高；第二輪救不回。k＝4 比 k＝3 少漏約 5–11 個百分點。
- 真誠投票、候選人位置隨機——現實裡兩大黨候選人不會隨機散佈，而且 2024 區域立委單一選區最多 10 人（報導者）。數字只拿來比**方向與大小順序**，不當預測值。
- 不含策略投票。策略面見 [`只選一人與對決強度-模擬.md`](只選一人與對決強度-模擬.md) 與主稿。

## 程式

```python
import random, math, itertools
def sim(n, dim, trials=4000, V=1001, seed=0):
    rnd=random.Random(seed*100+n*10+dim)
    res={'FPTP':0,'Top2':0,'SNTV3+對決':0,'SNTV4+對決':0,'CWexists':0,'CWin3':0,'CWin4':0,'CWin2':0}
    for _ in range(trials):
        cands=[[rnd.gauss(0,1) for _ in range(dim)] for _ in range(n)]
        voters=[[rnd.gauss(0,1) for _ in range(dim)] for _ in range(V)]
        prefs=[]
        for v in voters:
            d=[math.dist(v,c) for c in cands]
            prefs.append(sorted(range(n),key=lambda i:d[i]))
        # pairwise
        P=[[0]*n for _ in range(n)]
        for p in prefs:
            pos={c:i for i,c in enumerate(p)}
            for a in range(n):
                for b in range(n):
                    if a!=b and pos[a]<pos[b]: P[a][b]+=1
        cw=[a for a in range(n) if all(P[a][b]>P[b][a] for b in range(n) if b!=a)]
        if not cw: continue
        cw=cw[0]; res['CWexists']+=1
        fp=[0]*n
        for p in prefs: fp[p[0]]+=1
        order=sorted(range(n),key=lambda i:-fp[i])
        if order[0]==cw: res['FPTP']+=1
        t2=order[:2]; w=t2[0] if P[t2[0]][t2[1]]>P[t2[1]][t2[0]] else t2[1]
        if w==cw: res['Top2']+=1
        if cw in order[:2]: res['CWin2']+=1
        if cw in order[:3]: res['CWin3']+=1; res['SNTV3+對決']+=1
        if cw in order[:4]: res['CWin4']+=1; res['SNTV4+對決']+=1
    E=res['CWexists']
    return {k:round(v/E*100,1) for k,v in res.items() if k!='CWexists'}, E
for dim in (1,2):
    for n in (4,5,6,7,8,10):
        r,E=sim(n,dim,trials=1500 if n<8 else 800,V=501)
        print(dim,n,E,r)
```
