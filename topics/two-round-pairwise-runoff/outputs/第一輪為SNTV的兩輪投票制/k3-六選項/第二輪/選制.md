# 第二輪選制（k＝3・六選項）

目錄：[`../README.md`](../README.md)。票面：[`選票設計.md`](選票設計.md)。算法：[`計票.md`](計票.md)。例子：[`票型分布例子.md`](票型分布例子.md)。

## 規則

| 項目 | 規則 |
|------|------|
| 誰參加 | 第一輪前三名；登記 2–3 人則全部（[`../../共用/兩輪怎麼接.md`](../../共用/兩輪怎麼接.md)） |
| 選民動作 | 在 **6 種完整喜歡順序**中**圈一格**（兩人決選時 2 種） |
| 當選 | **兩兩對決贏家**（對另外兩人都贏的人） |
| 卡住時 | 三場中**勝方得票最少**的那一場不採認，其餘兩場排出名次，第一名當選 |
| 同分 | [`../../共用/對決強度.md`](../../共用/對決強度.md) §同分 |

法規附錄的名稱：孔多賽完成法；三人時的完成規則等同 Ranked Pairs、minimax、Schulze（三人、無平手時選出同一人；Brandt, Dong & Peters, *GEB* 2025）。強度採勝方得票（winning votes）；本套只能排完，勝方得票與勝差排出的順序相同。

## 為什麼是兩兩對決，不是 IRV 或第一志願多數

- 第一志願多數（FPTP）在決選裡會重現棄保問題。
- IRV 會淘汰對每位都贏、但第一志願最少的人（[`票型分布例子.md`](票型分布例子.md) 例二、阿拉斯加 2022）。第一輪已經只看第一志願；決選若再用 IRV，同一個偏差用兩次。
- 兩兩對決直接回答「這三人裡誰對每位都贏」。

## 為什麼只印完整順序

這一套的設計選擇是**一定要排完**：

1. 每一張票對三場對決都有意見，每場參與票數相同，計票說明最短（「圈一種排法」）。
2. 卡住時的「最弱一場」用勝差或勝方得票都一樣，不會有 [`../../共用/對決強度.md`](../../共用/對決強度.md) 說的「少表態」操弄空間。
3. 代價：只在乎一人的選民被迫表態另外兩人誰好。這些被迫的表態可能受票面位置影響（[`../../k3-九選項/第二輪/票型分布例子.md`](../../k3-九選項/第二輪/票型分布例子.md) 例三）。允許「只選一人」的版本是九選項那一套。

手寫 1、2、3 名次的票面不採用：《選罷法》第 64 條「加入文字符號」「圈後塗改」無效，而且唱票員要逐格唱出名次，不是唱「所圈的那一格」。
