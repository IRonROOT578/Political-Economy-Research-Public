# 第一輪選票設計（k＝3）

規則見 [`選制.md`](選制.md)。樣張 [`選票樣式.md`](選票樣式.md)（可列印 [`選票樣式.html`](選票樣式.html)）。

每人一欄。圈選、號次、相片、姓名、政黨圖、政黨**各佔一格**，由上往下排；**圈選圓框單獨一格、在最上面**。不要把這些塞進同一格。

《選罷法》第 62 條：區域票刊**號次、姓名、相片**；政黨推薦者刊**推薦政黨名稱**，否則刊「無」。政黨標章法定是不分區政黨票才必刊；本票政黨圖是預留空位，不是圈選區。蓋章打在圈選格，不蓋住下方姓名格。第 64 條：圈兩個以上、空白、塗改無效。

| 列（上→下） | 內容 |
|------|------|
| 圈選 | 圓框一格；全票只圈這一格 |
| 號次 | 抽籤號，獨立一格 |
| 個人照片 | 加分項；獨立一格；不是圈選區 |
| 姓名 | **戶籍全名**，獨立一格，可換行。樣張含複姓（歐陽文心）與較長傳統姓名（瑪拉歐斯·達拉阿道） |
| 政黨圖 | 空位，獨立一格 |
| 政黨 | 推薦政黨名稱／無，獨立一格 |

不要印組合格。不要把六種排序印在第一輪。長名只出現在姓名格。2024 區域立委單一選區人最多約 12 人；9 人以上同一套，只加欄。

選民兩輪都是**全票只圈一格**，投票所肌肉和現行區域票相同。
