# 一院議會制：行政首長怎麼產生

一院議會制國家，行政首長（首相／總理）怎麼選出？常見國怎麼做。

**定稿：** [`outputs/簡答.md`](outputs/簡答.md)

一句話：選民選一院；行政首長由「能取得該院信任」的人出任，幾乎都不是全民直選。國家元首多半只是形式任命。

## 範圍

- 含：一院＋議會制（北歐消極議會主義、威斯敏斯特慣例、就任信任投票）
- 不含：兩院制細節；總統制一院（如韓國）；中國人大；個案組閣史

台灣政體草案（一院總統制／一院議會制怎麼落地）見 [regime-designs](../regime-designs/)。
