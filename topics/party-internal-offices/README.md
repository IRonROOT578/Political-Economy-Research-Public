# 全國性政黨的黨內職位

一個**全國性、非單一議題**政黨：有黨主席、部分職位黨員直選。職位、選舉、權限怎麼排；並與台灣兩大黨對照（不抄他們的組織）。

## 範圍

- 含：職位表與權限；黨員直選的單一／複數選制；內部會議記名投票；**兼容**唱票式人工計票；集體與聯盟的席次分配；與國民黨、民進黨黨章的產生方式對照。
- 不含：國家公職選制（只寫黨內誰有權提名）；把兩黨組織搬過來當本架構。

## 要點

- 黨員直選＝秘密投票；票面**兼容**所內唱票（一圈 → 已公告數字）。STV 若用＝必須記名，因此 **STV 不用於黨員直選**。
- 任何複數席次：**不用** SNTV、**不用**限制連記。
- 不設全代會權力中樞、不設總統當然主席、不設公職當然中常委。
