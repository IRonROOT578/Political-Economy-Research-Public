# 政體與選制（公開展示）

五個主題可分開讀：政體設計（43 夾：依國家分夾）、單一選區兩輪投票、一院議會制如何產生行政首長、全國性政黨的黨內職位。

依展示需要重組過目錄與說明。不是工作庫：沒有私人筆記、規則集或未公開題目。

## 主題

| 主題 | 讀什麼 |
|------|--------|
| [政體設計](topics/regime-designs/) | 43 夾：依國家分夾（含台灣六夾、虛擬國家、阿根廷等） |
| [政體設計提示詞](topics/regime-designs/prompts/政體設計/) | 定稿所依的提示詞（`0-基本`／`1-優化`／`2-配置`／`測試`／`惡搞`） |
| [兩輪兩兩對決](topics/two-round-pairwise-runoff/) | 單一選區、人工計票的兩輪選制與票樣（k3 六選項／k3 九選項／k4 二十四選項） |
| [一院議會制的行政首長](topics/unicameral-parliamentary-executive/) | 常見國怎麼產生首相／總理 |
| [全國性政黨的黨內職位](topics/party-internal-offices/) | 黨主席與委員會怎麼選、權限怎麼切；與兩大黨對照（不抄） |

## 建議讀法

1. 政體設計：先看 [定稿矩陣](topics/regime-designs/designs/README.md)（路徑 [`designs/<國家>/<政體>/`](topics/regime-designs/designs/)）。提示詞在 [政體設計](topics/regime-designs/prompts/政體設計/)。
2. 台灣：路徑 [`designs/台灣/`](topics/regime-designs/designs/台灣/)。
3. 虛擬國家／阿根廷／澳洲等：見 [`designs/`](topics/regime-designs/designs/) 下各國夾（共 43 夾；中國、丹麥、以色列、俄羅斯、保加利亞、匈牙利、南韓、台灣、土耳其、奧地利、巴西、希臘、德國、愛沙尼亞、拉脫維亞、捷克、斯洛伐克、新加坡、日本、智利、法國、波蘭、澳洲、秘魯、紐西蘭、羅馬尼亞、義大利、芬蘭、英國、荷蘭、虛擬國家、西班牙、阿根廷）。
4. 選制：先看 [SNTV 兩輪套](topics/two-round-pairwise-runoff/outputs/第一輪為SNTV的兩輪投票制/)（三種情況並列）。
5. 議會制行政：直接讀 [簡答](topics/unicameral-parliamentary-executive/outputs/簡答.md)。
6. 黨內職位：先看 [架構](topics/party-internal-offices/outputs/架構.md)，再看 [與兩大黨比較](topics/party-internal-offices/outputs/與兩大黨比較.md)。
